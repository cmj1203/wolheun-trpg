## 원인과 수정

정식 결말 진입이 전역 운명 정산을 건너뛰고 있었다. 정식 결말 전에 체력 포획 우선순위를 유지하면서 의심 10의 `spy_cut`을 정산한다. **귀찌 0의 정식 결말 정책은 지시대로 보류**했다. 작은 끝의 기존 귀찌 정산은 그대로다.

소지품 목록은 평면이어서 지도 수납을 표현하지 못했다. `ItemSpec.container`에 가방과 꺼내진 조건을 선언하고, 가방 상실 시 그 안의 지도만 함께 잃게 했다. `지도_꺼냄`은 b05 가방 결과의 효과에 둔다. 따라서 모델이 대사를 재작성해도 소지품 상태는 남는다. 이미 쏟아진 지도는 가방 안으로 취급하지 않는다. 가방이 없거나 끈이 끊겼으면 어깨의 가방을 말하지 않는다.

대가 후보는 발화 전제를 몰랐다. `PriceSpec.spoken`과 현재 해석의 발화 여부를 연결해 말끝 떨림·설명하다 뒷걸음·말 꼬임·집안 이름 대가를 거른다. 버튼은 그 접근법의 기존 예시가 발화인지 읽고, 자유 입력은 해석 결과와 별도로 포함된 실제 발화를 쓴다. 행운 확인 중에도 현재 판정의 전제를 보존한다.

신분 사건과 행동 분류를 분리했다. GM의 소지품 조기 반환에서도 신분 위험을 보존하고, 엔진도 실제 공개 사건을 별도로 확인한다. 모델이 가방 행동만 반환해도 복합 입력의 공개는 남는다. 지명만 적힌 지도를 꺼내는 행동과 공개를 구분한다. 부정·질문·명시적 내적 독백은 공개로 받지 않는다. 내적 독백은 동작 어미가 붙어도 몸의 행동으로 보지 않는다.

`said`는 해석 뒤 실제 긍정 발화만 기록하고, 콜백도 같은 발화 범위를 읽는다. 질문·되돌린 입력은 새 기억을 쓰지 않으므로 예전처럼 마지막 기억을 취소하지 않는다. 의도 카드 취소는 그 카드에 실제로 기록된 발화와 새 플래그만 되돌린다. 이 변경 중 발견한 “새 질문이 이전 발화를 지움”도 회귀 시험으로 막았다.
