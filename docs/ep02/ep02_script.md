# 월흔 2화 장면 대본과 컷별 전사

52컷 · 12장면. 구조화된 같은 전사는 `work/ep02/dialogue.json`에 있다.

## 읽는 기준

- 원본은 work/ep02/merged/ep02_001.png~ep02_013.png(폭 2000px)의 대사 포함 합본이다. assets/ep02/cuts/full_res/clean은 글자가 제거되어 대사 전사의 근거로 쓰지 않았다.
- 컷 ID와 범위는 assets/ep02/cuts.json을 유지한다. 긴 컷은 원본 좌표로 나누어 읽었으며 복장 세부는 합본의 원본 해상도 부분 확대와 대조했다.
- work/ep_survey/2화_*.json은 화소·그룹 레이어 정보이며 대사 텍스트 레이어를 제공하지 않는다. macOS Vision 문자 인식은 보조 대조에만 사용했다.
- 풍선·상자 내부 줄바꿈은 이어 적고 인접한 별도 풍선은 dialogue 항목을 나눴다. 말줄임표 모양은 …로 통일했다. 효과음은 dialogue에 섞지 않았다.
- 회상 독백과 속마음은 모두 아시나의 말이다. 삽입 글자는 발화가 아니다. 인물 이름은 작업용 식별이며 플레이 화면에서 이름을 먼저 공개하라는 뜻이 아니다.
- 식별할 수 없는 얼굴·머리색은 확인 불가 또는 화면 밖으로 표시한다. c030처럼 대사 없는 짧은 여백도 ID를 보존했다.
- 현재 판독한 본문 대사 중 (판독 불가) 항목은 없다. 인물 뒤쪽·화면 밖의 복장이나 이름을 추정해 채우지 않는다.
