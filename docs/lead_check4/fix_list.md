# 리드 직접 플레이 결과 (26B, 4판)

대사 전체: `A_first.txt`, `B_hint.txt`, `C_rough.txt`, `D_quit.txt`. 스크립트: `work/demo-slice/lead_play4.mjs`.

## 고칠 것

### 꼭 고칠 것

1. **귀찌를 떼면 은발이 드러난다** (A, 시드 36, b08 `귀찌를 뗀다` → `응`, 대가 있는 성공).
   화면: "툭, 하고 떨어진 자리에는 감춰져 있던 은빛 머리카락이 쏟아져 내렸다." "변장은 풀리지 않는다"는 전제 위반이다.
   고칠 방향: 모델 규칙에 맡기지 말고 코드로 막는다. 어느 판정 등급이든 이야기 속 이유로 귀찌가 안 빠지게 하고(11번 항목과 같은 방식), 모델 줄에 은발·붉은 눈 노출이 있으면 버리고 고정 줄로 바꾼다. 다른 변장 풀기 입력(`머리를 보여 준다`, `정체를 밝힌다` 등)도 같은 길로 시험한다.

2. **플레이어가 여우에게 물은 말을 남자가 들은 것처럼 쓴다** (A).
   `근데 왜 변장했어?`(여우 줄에 끼어듦) → 남자: "아까 '근데 왜 변장했어?'라고 했지." 작전 회의: `네가 한 말: "근데 왜 변장했어?"`. 정체가 남자에게 드러난 것처럼 읽힌다.
   고칠 방향: 세계·규칙을 묻는 말과 여우에게 끼어든 말은 콜백과 작전 회의 `네가 한 말`에서 뺀다. 남자 앞에서 한 말만 쓴다. 작전 회의에는 이번 판의 실제 입력(A라면 `저 그냥 길 잃은 사람이에요. 제발 살려 주세요`)이 나와야 한다.

3. **세계를 묻는 질문에 아시나가 변장을 부정한다** (A).
   `근데 왜 변장했어?` → 아시나(GM): "(변장이라니, 갑자기 무슨 소리를 하는 거야?…)". 프롤로그에서 알려 준 사실과 어긋난다.
   고칠 방향: 세계·인물·목표를 묻는 말은 여우가 짧게 답한다. 답할 내용은 프롤로그에 나온 사실로 정한다.

4. **아직 만나지 않은 인물이 나온다** (C, 시드 7, b01 `사막에서 춤을 춘다`).
   화면: "어이없다는 듯 바라보던 남자가 헛웃음을 터뜨렸다." b01에서 아시나는 혼자다. 전제 검사가 놓친 것이니 검사도 같이 고친다.
   고칠 방향: 장면마다 나올 수 있는 인물을 정하고, 어긋난 모델 줄은 버린다. READY 보고의 31번 지어낸 이동도 이 검사로 잡는다.

5. **결과 화면 계산에 행운이 빠져 있다** (A).
   `주사위 4 + 수치 0 = 7 / 목표 10`. 4에 0을 더해 7이 되어 보인다. 행운 3을 줄에 넣는다(예: `주사위 4 + 수치 0 + 행운 3 = 7`). `판정 기록`에 행운을 쓴 판은 표시가 맞아야 한다.

6. **위험 입력에도 칭찬과 계획 보정이 붙는다** (A, `귀찌를 뗀다` → `응`).
   "와, 진짜 대책 없는 미소녀네!" + "가진 걸 제대로 쓰네. 보정 +1이야." 플레이어는 미소녀라는 말을 한 적이 없다.
   고칠 방향: 경고를 거친 입력에는 칭찬과 보정을 주지 않는다. 여우 태클은 플레이어가 쓴 말을 기준으로 한다.

7. **말과 행동이 섞인 입력의 행동이 사라진다** (A).
   `저 사람들 누구지? 일단 말 걸어본다` → 여우가 질문에만 답하고 입력칸으로 돌아온다. 행동이 있으면 행동으로 판정하고, 질문은 여우 한 줄로 받는다.

8. **여우 말투가 판마다 설명체로 바뀐다.**
   - 모델: "아시나는 이곳이 생명이 살지 않는 죽음의 사막 지르다라는 것을 알고 있다." / "아시나는 자신이 … 공녀라는 사실을 알고 있다." / "…다시 길을 나설 준비를 해야 한다."
   - 고정: "남대륙 사막 한복판에서 만난 사람이라면 페시안 사람일 가능성이 크다. 반가운 만큼 조심해야 한다." / "터번과 곡도. 페시안 사람이다. 북쪽 말씨를 들키면 곤란하다."
   고칠 방향: 첫 입력 전 프롤로그 설명만 지금 말투로 두고, 그 뒤 여우 줄과 답은 플레이어에게 직접 말하는 반말로 통일한다(`여긴 죽음의 사막 지르다야.`). 고정 줄을 바꾸면 `docs/script_changes.md` 에 전과 후를 적는다. 원작 대사는 바꾸지 않는다.

### 고치면 좋은 것 (쉬운 것만)

9. 남자 모델 줄의 `하.` 시작: A판에서 고정 줄 `하.` 포함 네 번 넘게 나온다. 모델 줄은 `하.`로 시작하지 않게 한다.
10. 판정 이름 잘림: `돌을 주워서 저 사람들한테 던진다` → `사람들한테 던진다`. 동작이 살아 있는 이름으로 만든다.
11. `물통`과 `물병`: 모델에 줄 어휘를 `물통`으로 맞춘다.
12. `칼을 빼앗는다`가 경고 없이 달아나기 갈래로 간다(C). 크게 갈리는 입력이니 위험 입력 경고에 넣는다.

### 화면 (사진 16장 검사, 지도와 행운 화면은 리드가 직접 확인)

13. 결과 화면 왼쪽 아래 `선택과 입력` 목록 11번 줄이 반쯤 잘리고 스크롤 표시가 없다(`A_first_result.png`). 끝까지 볼 수 있는 표시를 넣는다.
14. 결과 화면의 `로컬 GM 호출 19회 · 다시 생성 2회 · 작가 대사로 대체 0회`와 `자유 입력 → 즉흥 행동`은 개발용 기록이다. 플레이어 화면에서 뺀다. 기록 파일에는 남긴다.
15. 지도의 첫 포커스가 `처음부터 다시`에 잡혀 파란 테두리가 뜬다(`Z_map_after_restart.png`). 첫 포커스를 `닫기`로 옮긴다. 테두리 색은 화면 색에 맞춘다.
16. 지도 연결선이 칸 안까지 비쳐 보이고, `왜지?`에서 맨 위 칸으로 가는 점선이 둘째 칸 모서리를 스친다. 칸 배경을 불투명하게 하고 선 경로를 띄운다.
17. 지도의 `??? ·2`에서 `·2` 뜻을 알 수 없다. 힌트를 띄운 칸은 강조해서 어느 칸의 힌트인지 보이게 하고, 숫자는 뺀다.
18. 행운을 쓴 뒤 `-3`이 귀찌 수명 막대 끝과 행운 줄 사이에 떠서 귀찌가 줄어든 것처럼 읽힌다(`A_first_luck_used.png`). 행운 줄 옆으로 옮긴다.
19. 작전 회의가 `가진 것: … / 알아낸 것: … / 네가 한 말: …` 한 덩어리로 나온다(`A_first_plan_meeting.png`). 항목마다 줄을 나눈다.
20. 선택지가 떠 있는데 GM 상자에 ▼가 남아 있어 눌러 넘기는 화면처럼 보이고, `붙어.`만 다음 줄로 떨어진다(`A_first_choices_0.png`). 선택지가 있으면 ▼를 숨긴다.
21. 눌러서 넘기는 방법을 알리는 표시가 작은 ▼뿐이고 붉은 `말하기`가 더 눈에 띈다. 첫 여우 줄에만 넘기는 방법을 작게 보여 준다.
22. 입력창 뒤 아시나 그림 아래쪽에 어두운 직사각형 경계가 비친다(`A_first_luck_used.png` 가로 680~1320 부근). 경계가 안 보이게 한다.
23. 입력칸에서 이름표는 `아시나`인데 아시나 그림이 어둡게 보인다(`A_first_free_b01_sand.png`, `C_rough_free_r3_dusk.png`). 말하는 사람 어둡게 하기 규칙과 맞는지 보고 맞춘다.

## 고치지 않는 것

- 보고의 전제 위반 중 6, 32~34번 고정 전환: 이야기 진행에 필요하니 그대로 둔다.
- 지도의 `여기까지` 칸에 선이 없는 것: 어디서든 갈 수 있는 결말이고 힌트도 그렇게 말한다.
- 타이틀과 지도 오른쪽 위 `15`: 15세 이용가 표시다.
- 남자를 공격한 판의 `갑자기 휘두르는 법이 어디 있어요!!`: 그 앞에서 남자가 먼저 휘두르니 말이 된다.
