## 수정 범위

- `app/src/gm/prompt.ts`: 일반 생성·짧은 반응·교열에서 같은 PROSE_RULE을 쓴다.
  행동자/대상/지각자와 사동·허용 역할, 완료/기회, 시제, 줄 사이 시간 연결,
  관찰 범위와 타인 전체에 대한 단정을 구별한다. 대사 명령·의도·속마음 현재형과
  의도적인 단편은 허용한다. 특정 생성 문구의 금지나 단어 치환은 없다.
- `app/src/gm/gm.ts`: 기존 교열에 task, goal, resolution(action/tier/gist/deed/price/fumble),
  현재 facts, 최근 4줄, 확인된 표시 줄을 전달한다.
  판정 없는 대화의 resolution은 null이다. 질문에서는 기존 inquiry와 공개 questionFacts를 전달해
  공개 근거가 빠져 정상 답이 근거 없는 문장으로 오인되지 않게 한다.
  뒤 고정 대사나 비공개 미래 지식은 새로 주입하지 않는다.
  교정문은 기존 hard grammar 재생성 피드백으로만 쓰며 화면에 직접 치환하지 않는다.
- `app/tests/gm.test.ts`: 기존 테스트 소유 파일에 문맥 전달 2건과
  사동·시간 연결의 전체 재생성 1건을 추가했다. 별도 테스트용 production seam은 없다.
