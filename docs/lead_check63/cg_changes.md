# b04 CG·대사 전후

대사 글자는 유지하고 그림 지정만 바꿨다. `showLine`은 줄마다 CG를 지정하고 글을 출력한다. 따라서 해당 줄의 CG를 대본에 명시했다.

| 장면·줄 | 전 | 후 |
|---|---|---|
| 독백 시작 `꿈에도 몰랐다. 거대한 태양 아래,` | 태양 CG | 목에 닿은 칼날 CG |
| `고국이 아닌 낯선 땅에서` | 땅 CG | 같은 칼날 CG |
| `죽음을 맞이하게 될 줄은―` | 어두운 CG | 같은 칼날 CG |
| 독백 직후 빈 나레이션 | 글 없이 칼날만 뒤늦게 표시 | 빈 줄 제거 |
| `다짜고짜 사람 목에 칼이나…` 속마음 두 분기 | CG 없이 입식 | 같은 칼날 CG |
| `마지막으로 할 말은 있나?` | 남자 CG | 유지 |
| `억울해…` | CG 없이 입식 | 칼날 CG |
| `없다면, 잘 가라.` | CG 없이 입식 | 남자 CG |
| `잠깐만요, 잠깐! 나 아직 아무 말도 안 했어요!` | CG 없이 입식 | 칼날 CG |
| `그것 좀 치워봐요! 난 죽이면 안 돼요.` | CG 없이 입식 | 칼날 CG |
| `……왜지?` | CG 없이 입식 | 남자 CG |

READY 필수 확인:
- 칼끝 경로 죽음 독백 1회, 피함 경로 0회.
- 줄을 넘기기 전후 CG와 대사 조합을 실제 화면으로 확인.
- 독백 시작·목 칼 속마음·남자 대사 1440 캡처.
- 같은 구간 짧은 무음 영상.
- 전 경로 스토리 QA에서 뒤늦은 빈 CG와 관계없는 그림 위 대사를 확인.

실제 화면 확인:
- 분리 서버 18193, 작가 대사 모드, 시드 1, 에고 전용 공간에서 첫 화면부터 접근 단추·주사위·대사를 넘겼다. 실제 26B 생성 검증과는 구분한다.
- `b04/frames.json`: 화면에서 읽은 11줄의 순서·화자·CG URL.
- `b04/frame-01.png`: 첫 독백과 칼끝.
- `b04/frame-04.png`: 목 칼 속마음과 칼끝.
- `b04/frame-05.png`: 남자 첫 대사와 남자 CG.
- `b04/visual_review.md`: Claude가 11장 전부 비교, 항목 11개 PASS. 부모도 목 칼 속마음 화면을 직접 확인했다.
- `b04/replay-silent.mp4`: 실제 연속 캡처를 줄당 1초로 묶은 11초 무음 영상. ffprobe로 video 스트림만 있음·1440×900·11초를 확인했다. 전환 순간의 움직임을 연속 녹화한 영상은 아니므로 그 증거로 쓰지 않는다.

줄 사이 순간 전환과 전 경로의 죽음 독백 횟수는 통합 회귀 및 최종 26B 스토리 QA에서 계속 확인한다. 현재 전체 QA 통과나 READY를 뜻하지 않는다.
