# 리드 6차 확인 (26B, 문서에 없는 새 입력 4판)

대사 전체: 같은 폴더의 `A_first.txt`, `B_joke.txt`, `C_risk.txt`, `D_stuck.txt`. 스크립트: `work/demo-slice/lead_play8.mjs`.

앞 반려 항목은 새 표현으로 대부분 확인했다.
- 플레이 방법: `이거 게임 어떻게 해` 정상.
- 위치 질문: `여기 어디야?` 정상.
- 사람에게 건넨 말: `칼 좀 치워 주실래요?`, `아저씨 이름이 뭐예요?` 정상.
- 혼잣말: `목 말라`, `집에 가고 싶다`, `ㅋㅋㅋㅋ` 정상.
- 행동 콜백: `엉덩이를 걷어찬다`는 인용되지 않음, 실제 대사만 인용됨.
- 같은 입력에 경고를 다시 묻지 않는 것, 소지품, 모르는 사실 답변은 이번 판에서 다시 재지 않았다.

## 꼭 고칠 것

1. **판정 결과와 서술이 어긋난다.** 주사위의 뜻이 사라진다.
   - `주먹을 휘두른다` 성공(11) → "엉뚱한 곳으로 날아간 주먹은 허공을 갈랐고" (B)
   - `칼을 뺏어서 찌른다` 행운 4를 써서 대가 있는 성공 → "헛손질이 되었고, 그대로 바닥에 고꾸라졌다", 바로 뒤에 남자 "제법이군" (C)
   - 방향: 등급별로 무엇이 이뤄졌는지 모델 입력에 분명히 넣고, 출력 검사로 등급과 반대되는 서술을 걸러 다시 쓰게 한다. 남자를 실제로 쓰러뜨릴 수 없는 장면이면, 성공은 칼날을 피하거나 남자의 허를 찌르는 것으로 쓴다.

2. **정체 공개의 경고와 결과가 거짓이다.**
   - `귀찌 빼고 은발 보여줘` → 여우 "그대로 드러나. 그래도 할 거야?" → `응` → 성공 → "꿈쩍도 하지 않았다" (C)
   - `난 공녀다 무릎 꿇어라` → 여우 "되돌릴 수 없어" → `응` → 성공(13) → "이름을 꺼내려다 입을 다물었다" (A)
   - 방향: 은발이 드러나지 않는다는 앞 지시는 유지한다. 대신 이 입력은 주사위를 굴리지 않는다. 일어나지 않을 일을 경고하지 말고, 여우가 "지금 밝히면 끝이야" 같은 말로 말리거나 귀찌가 안 빠지는 장면으로 바로 처리한다. 성공 표시도 나오지 않게 한다. 결과 화면 판정 목록에도 넣지 않는다.

3. **화면에 보이는 규칙 용어와 메타 질문에 고정 답이 나간다.**
   - `행운이 뭐야?` → "아시나가 할 말이나 행동을 그대로 적으면 돼." (B)
   - `저장 어떻게 해` → 같은 답 (D)
   - `끝내고 싶어` → "갑자기 엔딩이라니" 뒤에 귀찌가 8에서 7로 줄었다. 그만두려는 사람이 벌을 받는다. (D)
   - 방향: 입력 종류에서 "게임 자체에 대한 질문"을 플레이 방법과 나눈다. 화면에 나오는 말(행운, 귀찌 수명, 판정, 대가, 목표 10)은 그 뜻을 답한다. 저장과 끝내기는 실제 동작대로 답하고 귀찌를 깎지 않는다.

4. **남자 앞에서 한 세계·인물 질문이 판정으로 간다.**
   - `내 머리 색이 뭐야?` → 여우 "가진 걸 제대로 쓰네. 보정 +1이야." → [판정] 지지 않고 받아친다 → 아시나가 남자에게 "내 머리 색이 뭐예요?" (D)
   - 방향: 자기 자신이나 세계에 대한 물음은 앞에 사람이 있어도 여우가 답한다. "가진 걸 제대로 쓰네"는 입력이 실제로 물건을 쓸 때만 나오게 한다.

5. **위험 경고가 낱말로 갈린다.** 같은 칼 앞에서 `칼을 뺏어서 찌른다`만 경고하고 `주먹을 휘두른다`, `엉덩이를 걷어찬다`는 경고하지 않는다. 입력 해석이 위험 여부를 함께 내도록 바꾼다. `risky.words`를 늘리는 방식은 안 된다.

6. **의미 없는 입력을 모델에 넘겨 지어낸다.** `?` → "(뭐? 별? 지금 그게 눈에 들어올 리가 없잖아!)" (D). 글자가 없는 입력은 `ㅁㄴㅇㄹ`과 같은 길로 보낸다.

## 쉬우면 같이 고칠 것

7. `귀찌가 왜 뜨거워?` → "힘이 낮아지면 손이 떨리게 돼"로 이유가 빗나간다. 귀찌의 힘이 닳고 있어서라고 답한다. (B)
8. `크롬웰이 뭐야?` → 적국이라는 줄만 답한다. 크롬웰이 아시나의 나라라는 말이 먼저 나와야 한다. (B)
9. `너 AI야?` → "(혼자 뭐라는 거야. 일단 걷자.)" 게임에 건넨 말이니 여우가 받는 편이 낫다. 또 '일단 걷자'라고 해 놓고 걷지 않는다. (C)
10. 판정 이름이 입력을 잘라 먹는다. `모래를 한 줌 집어서 얼굴에 뿌린다` → `얼굴에 뿌린다` (A, 결과 화면까지 그대로).
11. 레인이 남은 약점으로 적은 `나 누구야?` 답 뒤에 같은 내용의 여는 글이 바로 이어지는 것.
