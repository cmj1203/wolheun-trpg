## 처음 하는 사람 역할 (판 C)

입력: 이거 맞아? → 가방에 물 있어? → 지도를 펼쳐 방향을 가늠한다 → 오늘 날씨 참 좋네 → 저녁은 뭘 먹지 → 내일 비 올까 → 모래 언덕 뒤에 숨어서 지켜본다 → 설득한다 → 터번의 보석을…

- 첫 3장면에서 막힌 곳은 없었다. 막힌 입력이 세 번 이어지자 힌트와 장면 사건이 나왔고 다음 장면으로 넘어갔다.
- 원작을 몰라도 프롤로그의 GM 줄로 세계, 변장 이유, 목표가 나온다.

## 힌트대로 플레이

`docs/screenshots/map/hint_routes.json`(26B), `docs/screenshots/map/dry/hint_routes.json`(LLM 없음). 표는 `docs/map_hints.md`.

| 결말 | 입력 | 결과 |
|---|---|---|
| 길잡이 계약 | 달려가서 길을 묻는다 → 살려 두면 쓸모가 있을 거예요. 지도도 읽을 줄 알아요 → 지도를 펼쳐 길을 짚어 보인다 | 첫 시도 |
| 값을 매긴 여자 | 달려가서 길을 묻는다 → 저는 대단한 집안 사람이에요. 함부로 하면 후회할걸요 → 궁정식으로 인사한다 | 첫 시도 |
| 크라차로 가는 길 | 몰래 돌아서 달아난다 → 별을 보고 남쪽을 찾는다 | 첫 시도 |
| 살아남은 자 | 달려가서 길을 묻는다 → 억울하다고 호소한다 → 몸을 숙여 피한다 → 고개를 숙이고 조용히 있는다 | 첫 시도 |
| 수상한 이방인 | 달려가서 길을 묻는다 → 핸드폰을 꺼내 수상하게 만지작거린다 → 가방에 손을 넣어 뭔가 꺼내려 한다 → 귀찌를 감추며 수상하게 고개를 돌린다 → 아무도 안 보냈다고 말한다 | 두 번째 시드(첫 시드는 살아남은 자) |
| 흥미로운 여자 | 달려가서 길을 묻는다 → 대륙에서 하나뿐인 미소녀니까요 → 몸을 던져 칼날을 피한다 → 붉은 눈을 끝까지 똑바로 마주 본다 | 두 번째 시드(첫 시드는 살아남은 자) |
