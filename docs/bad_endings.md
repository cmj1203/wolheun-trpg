# 작은 끝(나쁜 끝) — 14차 설계

큰 갈래 5개(e_value·e_deal·e_spy·e_curious·e_survivor·e_road, + e_quit)는 그대로 두고, 상태가 한계에 닿으면 들어가는 작은 끝 4개를 더한다. 사용자 말: "실패해서 죽거나 성공해서 허무하게 끝나는 엔딩은 맘대로 넣어도 돼, 큰 분기만 5개". 리드 결정: 상태 조건으로 들어감, 한 번 실패로 안 끝남, 경고 없이 죽는 길 없음, 나쁜 끝 화면에 '마지막 갈림길에서 다시'/'처음부터', 이야기 지도에 작은 점(도달 뒤만), 15세.

## 작은 끝 4개

| id | 제목 | 들어가는 조건(`when`) | 징조(`warn.lines`, 한 판에 한 번 — 19-C 부터 여우가 아니라 캐릭터에게 일어나는 일) | 왜 한 번 실패로는 안 끝나는가 |
|---|---|---|---|---|
| unmasked | 은발 | `귀찌 <= 0` | `귀찌 <= 2` → 나레이션 "귀찌가 귓불에서 차갑게 식어 갔다." + 속마음 "…오래 못 버티겠어." (전: 여우 "귀찌가 거의 식었어. 다음엔 은발이 나와.") | 귀찌는 8에서 시작해 장면 시간·대가로 1씩 준다. 0 까지는 여러 턴. |
| spy_cut | 첩자 | `의심 >= 10` | `의심 >= 7` → 나레이션 "남자의 손이 칼자루로 내려갔다. 눈은 아시나에게서 떨어지지 않았다." (전: 여우 "저 사람 손이 칼자루에 갔어. 더 수상해 보이면 끝이야.") | 한 판정의 의심 변화는 최대 +3. 7 미만에서 한 번에 10 이 될 수 없다. 정체 발설(의심 +3)도 같은 한도. |
| reckless | 칼 앞에서 | `flag:위험_실패` — 칼 든 남자 앞 맨손 행동은 되묻지 않고 속마음 "맨손이다. 저 칼은 진짜다."(한 판 한 번, `danger.omen`) 뒤 바로 굴린다. 그 판정이 실패(행운으로 메우지 않음)하면 위험_실패 | 징조 자체가 danger.omen (전: 여우 "칼 든 사람한테 맨손이야… 그래도 할 거야?" + 되묻기). | 징조를 거친 행동만(입력은 `state.warned` 에 남아 칭찬·보정 없음). 행운으로 대가 있는 성공으로 바꾸면 안 끝남. |
| collapse | 모래 위에서 | `머뭇 >= 3` — 머뭇 = 재촉 뒤에도 움직이지 않아 인물이 먼저 움직인 횟수 + 말만 거듭해 세계가 먼저 움직인(nudge) 횟수 | `머뭇 >= 2` → 나레이션 "무릎이 한 번 허물어졌다. 모래가 발목을 잡아당겼다." (전: 여우 "다리가 풀리고 있어. 한 번 더 미루면 쓰러져.") | 세 번 미뤄야 한다. 각 단계에 재촉·사건이 먼저 나온다(여우 힌트는 질문 모드에서만). |

조건은 `applyEffects` 뒤와 행동 처리 끝(`act`)에서 본다. 조건이 참이면 다음 비트 대신 작은 끝 비트(`x_unmasked`·`x_spy_cut`·`x_reckless`·`x_collapse`)로 들어간다. 작은 끝 비트는 `bg: blackout`, 나레이션 2~3줄 + 여우 한 줄, `ending.bad: true`.

징조 줄 규칙(리드 19-C, DW "Show signs of an approaching threat" / "Address the characters, not the players"): 여우가 말하지 않고 나레이션·속마음으로 캐릭터에게 일어나는 일만 적는다. 결과 이름·규칙 용어(`끝|은발|쓰러|판정|보정|주사위`)는 로더(`parseOmenLines`)가 막는다. 징조가 처음 나온 턴에는 수치를 문턱 위에 멈추고(holdAboveThreshold) 끝은 다음 턴부터다(DW 소프트 무브 → 하드 무브).

징조 생략 규칙(리드 19-D): 징조는 플레이어가 반응할 자유 입력·선택지 자리가 결말 전에 남아 있을 때만 낸다. 이번 턴 뒤 갈 비트가 결말로만 이어지면 징조를 생략하고 작은 끝 조건은 그대로 적용한다(`reactionAhead`). 자세한 것은 docs/gm_moves.md.

## 화면

- 결말 겹창: 나쁜 끝은 kicker '작은 끝'.
- 결과 화면 단추: 나쁜 끝이면 '마지막 갈림길에서 다시' / '처음부터' / '이야기 지도' / '타이틀로'. 큰 갈래 끝은 지금처럼 '다시 하기'.
- '마지막 갈림길에서 다시' = 자동 저장 칸 `auto_fork` 불러오기. 자동 저장은 갈림길 비트(지도에서 나가는 선이 2개 이상인 칸의 비트: b02_people, b05_why, b06_swing, b09_verdict)에 들어선 직후 서버가 쓴다(화면 저장 칸 1~N 과 별개, 목록에 안 보임).
- 이야기 지도: 작은 끝은 칸이 아니라 지도 아래 작은 점 줄로, 도달한 것만 제목과 함께.
