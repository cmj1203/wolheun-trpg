# 21차 LLM 대조표: 후드 서술과 `…뭐?` 반복

시험 포트 18192(앱)·18190(LLM), 모델 gemma-4-26B-A4B UD-IQ4_XS. 사용자 포트 18080·18081은 건드리지 않았다. 입력은 문서·대본에 없는 표현이다.

## 원인

- `…뭐?`: 대체 문구가 아니라 LLM 답이다(시드 11 재현 GM 기록 `fallback: false`). `lore_wolheun.yaml:151`이 그 말을 예로 시키고, 같은 판의 되풀이를 막는 검사가 없었다.
- 후드: 대가 `hood_slip`("후드가 반쯤 흘러내렸다")이 붙은 판 3개 모두에서 `후드가 어깨 너머로 반쯤 흘러내렸다`류 문장이 나왔다. 대가는 '반드시 장면에 보인다'로 LLM에 전달되는데, 효과에 `후드_벗음`이 없어 입식이 그대로였다. 리드 판의 기록은 찾지 못해서 같은 경로였다는 것은 추정이다.

## 설계

후드 상태는 엔진이 소유한다. 바꿀 수 있는 곳은 대본 효과·결과·대가와 플레이어의 직접 행동뿐이고, LLM 서술은 바꾸지 못한다.

| 경우 | 처리 |
|---|---|
| 대가·결과에 적힌 변화 | 효과가 `후드_벗음`을 켜고 입식이 따라간다(`hood_slip`에 플래그 추가, 이미 벗었으면 후보에서 뺌) |
| 플레이어가 직접 벗음 | 재확인이 입력도 '벗음'으로 읽으면 플래그를 켜고, 줄을 보여 주기 전에 입식을 바꾼다 |
| LLM이 혼자 벗김 | `facts[].state_check` 재확인(낱말 목록이 아니라 뜻으로 묻는 호출)이 막고 다시 쓰게 한다 |
| 같은 인물의 같은 말 | `state.spoken` 장부로 길이와 상관없이 막고 다시 쓰게 한다. 끝내 못 쓰면 대체 문구도 이번 판에 안 쓴 말에서 고른다 |

## `…뭐?` 대조 실험

같은 입력 8개·같은 시드로 첫 답을 비교했다(`work/demo-slice/llm21_probe.ts`). 장부 없음은 이번 판에 그 말을 한 적이 없는 상태, 장부 있음은 이미 `…뭐?`를 한 상태다.

| 입력 | 장부 없음 | 장부 있음 |
|---|---|---|
| 핸드폰을 사용한다 | …뭐? | 묻는 말에나 답해라. |
| 충전기 좀 빌려 줘요 | …뭐? | 충전기? 그게 무슨 소리지. |
| 뿌뿌뿌 뿌뿌 | …뭐? | …미쳤나? |
| 바나나 바나나 | …뭐? | …무슨 헛소리를 하는 거지? |
| 지르다까지 같이 가 줘요 | 지르다까지 같이 가 달라고? 하. | 지르다까지 같이 가 달라고? 하. |
| 삐용삐용 삐용 | …뭐? | 묻는 말에나 답해라. |
| 오늘 저녁은 치킨이다 | …뭐? | 치킨? 대체 무슨 헛소리를 하는 거지? |
| 하늘에 고래가 날아요 | …뭐? | 하늘에 고래라니. 미친 건가, 아니면 죽기 전에 헛것이라도 보이는 건가. |

`…뭐?` 답: 장부 없음 7/8, 장부 있음 0/8. 실제 판에서도 시드 31 b06이 `beat/repeat_play`로 걸려 대체 문구 `……미친 여자군.`이 나왔다.

## 재확인 호출의 정확도와 비용

| 묶음 | 벗음 문장 놓침 | 안 벗음 문장 오탐 |
|---|---|---|
| 질문을 고른 묶음 | 1/13 | 0/15 |
| 따로 둔 묶음 | 1/7 | 0/8 |

놓친 문장은 `쓰고 있던 후드가 툭 떨어져 등 뒤에 걸렸다.`, `쓰개를 움켜쥐어 뒤로 젖혔다. 햇빛이 눈을 찔렀다.`다. 완벽하지 않아서 드물게 서술이 빠져나갈 수 있다. 질문 후보 4개 중 놓침+오탐이 가장 적은 안을 골랐고, 세계 프롬프트를 쓰는 안은 놓침 5·오탐 3으로 더 나빠 짧은 프롬프트를 쓴다.

지연은 호출당 중앙 396ms, 최대 약 0.6s다. 글에 후드·얼굴 같은 낱말이 있을 때만 부른다. 짧은 프롬프트로 재확인한 뒤 다음 호출이 느려지지 않았다(세계 프롬프트 뒤 약 430ms, 짧은 프롬프트 뒤 약 350ms).

## 남은 것

- `…뭐?`는 1화 미인계 대본의 대사이기도 하다. LLM이 먼저 쓰면 대본 쪽에서 한 번 더 나올 수 있다. 이번 수정은 LLM 쪽 되풀이만 막는다.
- `hood_slip` 글은 '반쯤'인데 입식은 후드를 다 벗은 그림이다. 글을 바꾸려면 승인이 필요해 그대로 뒀다.
