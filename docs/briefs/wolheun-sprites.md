# 레인 브리프: wolheun-sprites

목표: 이 맥 안에서만 돌아가는 「월흔」 원작풍 인물 입식 생성 파이프라인을 만든다. 1화 원고로 파일럿 입식을 뽑아 원작과 얼마나 닮았는지 평가하고, 2~10화 원고가 들어오면 같은 명령으로 다시 학습할 수 있게 한다.

배경: /Users/choeminju/월흔_trpg/docs/spec.md 를 먼저 읽는다. 권리사 피칭용 비주얼 노벨형 데모이고, 사용자가 인물 그림을 "AI로 원작풍 입식 생성"으로 정했다. 권리사에게 보여 줄 데모라 원작 화풍(웹툰 그림 하나비)과 맞는 것이 최우선이다.

입력:
- 원고: /Users/choeminju/Downloads/월흔_001/월흔1화_001.psd ~ 019.psd(읽기 전용). 레이어 구조는 /Users/choeminju/월흔_trpg/docs/briefs/wolheun-ep01-assets.md 의 입력 항목에 정리돼 있다.
- 에셋 레인 wolheun-ep01-assets 가 /Users/choeminju/월흔_trpg/assets/ep01/ 에 대사 없는 컷, cuts.json(컷별 등장인물), sprite_feasibility.md 를 만드는 중이다. 학습 데이터는 이 결과를 우선 쓰고, 기다리는 동안 환경 구성, 베이스 모델 선정, 라이선스 확인부터 한다.
- 인물: 아시나는 본모습이 은발 적안이고, 초반에는 마법 귀걸이로 갈색 머리와 갈색 눈으로 변장하며 후드 달린 여행복을 입는다. 베히다트는 어두운 은발에 검붉은 눈이고, 터번과 붉은 천, 금장식 차림의 페시안 왕이다. 더 자세한 설정은 https://namu.wiki/w/월흔 을 본다.
- 장비: MacBook Pro M5 Pro, 통합 메모리 48GB, 디스크 여유 약 230GB. 2~10화 원고 약 120GB가 곧 들어온다.

산출물:
1. /Users/choeminju/월흔_trpg/tools/sprites/ : 데이터 준비(인물 크롭, 캡션), 학습(LoRA 등), 생성, 배경 제거, 규격 맞춤 출력이 단계마다 명령 하나로 돌아가는 파이프라인과 README. README에는 원고가 늘었을 때 재학습하는 방법을 적는다.
2. /Users/choeminju/월흔_trpg/assets/sprites/pilot/ : 아시나(변장 상태)와 베히다트 입식을 표정 4종(기본, 웃음, 놀람, 화남 또는 경계)씩 만든다. 투명 배경 PNG, 같은 캔버스 크기, 같은 구도(허리 위 또는 무릎 위)로 통일한다.
3. /Users/choeminju/월흔_trpg/assets/sprites/pilot/eval.md : 원작 컷과 나란히 놓은 비교 이미지, 닮은 점과 어긋난 점, 2~10화 데이터를 더했을 때 예상되는 개선을 적는다.
4. 사용한 모든 모델과 도구의 이름, 출처, 라이선스, 상업적 이용 가능 여부 표.

멈춤 조건: 파이프라인이 README대로 처음부터 다시 돌아 파일럿 8장을 만드는 것을 직접 확인했고, eval.md와 라이선스 표가 있다. 실행한 명령과 결과, 산출물 경로를 증거로 READY를 보낸다.

제약:
- 모든 학습과 생성은 이 맥에서만 한다. 원고 이미지와 그 파생물을 외부 이미지 생성 서비스, 클라우드 GPU, 공개 저장소에 올리지 않는다.
- 상업적 이용이 허용된 라이선스의 모델만 쓴다. 애매하면 쓰지 말고 리드에게 report로 묻는다.
- 원본 PSD와 ~/Downloads는 읽기만 하고, 그 폴더 안에서 스크립트를 실행하지 않는다. PSD를 읽는 Python은 -I 옵션으로 실행한다.
- 메모리 48GB를 다른 레인과 나눠 쓴다. 10GB 넘게 쓰는 작업은 시작 전에 memory_pressure로 여유를 확인하고, 30분 넘게 돌릴 학습은 시작 전에 예상 시간과 메모리를 report로 알린다.
- 모델과 캐시는 디스크에 합계 25GB 이하로 둔다.
- 15세 이용가에 맞지 않는 이미지는 만들지 않는다.
- git 원격과 PR은 없다. 증거는 파일 경로와 명령 결과로 낸다.
