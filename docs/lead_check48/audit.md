# 48차 CG 원작 대조와 재작업

## 검수 반려와 판단 정정

첫 후보(`work/demo-slice/lane48/new/`)는 전부 사용하지 않는다.

1. 요구는 원작의 인물 배치·자세·표정·옷·머리·소품을 유지한 그림체 변환이다. 원작 픽셀을 가운데 세로 띠로 붙인 첫 후보는 그림체가 바뀌지 않았고 인물이 작아졌다. 원작 픽셀 붙이기와 그 픽셀 일치 검사는 이번 결과의 합격 기준이 아니다.
2. 세로 컷을 가로 화면에 맞춰 크롭하거나 확대해도 인물 배치·자세·옷·소품을 유지하면 구도 오류가 아니다. 기존 CG의 전체 세로 프레임·지도·장식을 복원하려던 판단을 철회한다.
3. c068은 웹툰에서 옆으로 눕혀 그린 장면이므로 `cg_lean`처럼 돌려 쓰는 것이 맞다. 회전 복원 후보는 사용하지 않는다.
4. `cg_hill_silver`·`cg_earring_silver`는 정체 공개를 위해 의도한 은발 파생본이다. 갈색으로 되돌리는 후보는 사용하지 않는다.

다시 그리는 대상은 A `cg_swing`과 B `cg_drink` 둘뿐이다. (11-06 리드 정정: B `cg_drink` 는 원작 c031 도 후드를 써서 원래 그림이 맞다. 원본으로 되돌렸고 새 후보는 쓰지 않는다. 원작 후드 흐름: c031·c034·c041·c047 후드 씀 → c048 벗음 → c056 이후 없음.) 아래 사용처는 첫 조사 때 읽은 YAML 기준이며 이후 담당 레인의 변경과 다를 수 있다. `assets/`·`app/`에는 쓰지 않는다.

## 기반 컷 식별 근거

- `cg_open_blade`: `docs/lead_check42/README.md`의 c004 기록과 실제 후드·눈·목 앞 칼 방향으로 식별했다. 기존 제작 방식은 이 파일의 제작 이력일 뿐 새 후보의 합성 방법으로 쓰지 않는다.
- `cg_hill`과 은발본: c017의 배낭·팔·다리·노을·돌·잎 배치가 대응한다.
- 여행 두 파일: c023 유적·후드 뒷모습, c024 겨울 털옷·마을 사람들, c025 밤 숲·바위 위 인물이 대응한다. `HANDOFF.md` 39차 기록도 세 컷과 크롭 범위를 명시한다.
- `cg_drink`: `art_record.json`의 c031 기록과 물주머니·매달린 뚜껑·옆얼굴·물방울로 식별했다.
- `cg_now`: c006의 남자 전신·칼을 내민 손·전경의 후드 뒷모습이 대응한다.
- `cg_last`: 기록의 c040·c041 중 실제 남자의 등·앞쪽 여자의 두 손·배경은 c041에 대응한다.
- `cg_beauty`: 기록의 c049와 꽃 장식·무지개·머리를 쥔 손·미소가 대응한다.
- `cg_swing`과 후드본: 기록만 보면 c057이지만 현재 그림의 정면 여자·남자의 등은 c055다. c057은 넘어진 여자의 뒷모습·정면 남자·후방 호위 둘·대각 칼 궤적이다.
- `cg_lean`: 실제 턱을 만지는 근접 장면은 c068이다. `HANDOFF.md`의 36차 결정도 c068 시계 방향 90도 회전·크롭을 명시한다. c067은 다른 장면이다.
- 귀찌 두 파일: c056의 한쪽 눈·경악한 얼굴·오른쪽 칼바람·흩날린 머리로 식별했다. 파일 이름을 장면 설명으로 믿지 않았다.
- 풍경 다섯 장은 c001·c002·c003·c010·c012로 식별했다.

## A·B 재제작 방법

- c031 입력 크롭: w1280 clean 원작에서 x251, y328, 폭954, 높이1533. 그림 바깥 여백을 빼고 머리·옆얼굴·손·물주머니를 크게 담는다.
- c057 입력 크롭: w1280 clean 원작에서 x0, y1600, 폭1280, 높이2200. 넘어진 아시나·남자·뒤 호위 둘·대각 칼 궤적을 담는다. 상단 번개는 지시대로 새 화면 위쪽 하늘에 옮길 수 있다.
- 첫 이미지는 위 원작 크롭, 두 번째는 현재 `cg_beauty.png` 또는 `cg_last.png`다.
- 아스트라가 화면 전체를 게임 CG 그림체로 다시 칠하도록 지시한다. 인물은 화면 높이의 70% 이상, 여자는 후드 없이 머리가 보이게 한다. 원작 픽셀 합성·세로 띠·새 인물·새 소품·글자는 금지한다.
- 생성 후 허용하는 처리는 비율을 유지한 1920×1080 크기 맞춤뿐이다. 인물 배치·자세·복장·인원·칼 방향이 다르면 프롬프트를 수정해 컷당 최대 세 번까지 생성한다.
- 프롬프트와 생성 로그는 `/tmp/lane48/gpt2/`에 보관한다. 이전 `new/`의 후보 및 `compare_*.jpg`는 반려된 첫 시도의 기록이다.
