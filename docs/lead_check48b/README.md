2026-11-06. 시드 2, 실제 게임 화면을 Bun.WebView `headless: true`로 진행했다. 데스크톱 뷰포트는 1440×900, 모바일은 390×844다. DPR 2이므로 PNG 크기는 각각 2880×1800, 780×1688이다.

## CSS

레인이 적용한 `app/web/style.css:286`의 `.topbar::before`를 그대로 검증했다. 이 작업에서 CSS·코드·콘텐츠는 추가 수정하지 않았다. 커밋하지 않았다.

| 속성 | 변경 전 | 레인이 적용한 변경 후 |
|---|---|---|
| inset | 메뉴 아래로 2cqw 확장 | `0` |
| gradient | 검정 alpha `0.8` → `0.74` → transparent | `rgba(0, 0, 0, 0.5)` → `rgba(0, 0, 0, 0.32) 60%` → transparent |

변경 전 수치는 작업 지시의 기록이다. 검증 시 현재 파일은 변경 후 값이었다. 장면 제목에는 이미 `app/web/style.css:307`의 `text-shadow: 0 0.1cqw 0.4cqw rgba(0, 0, 0, 0.7)`이 있어 추가 보정하지 않았다.
