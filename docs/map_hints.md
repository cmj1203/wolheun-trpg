# 결말별 힌트

안 가 본 칸을 누르면 여우가 말한다. 누를 때마다 다음 단계가 나온다.

| 칸 | 1단계 | 2단계 |
|---|---|---|
| 값을 매긴 여자 | 칼끝이 목에 닿았을 때 갈라져. | 네가 얼마나 대단한 집안 사람인지 내세워 봐. |
| 길잡이 계약 | 칼끝이 목에 닿았을 때 갈라져. | 살려 두면 뭐가 좋은지 말해 보면 어때? |
| 수상한 이방인 | 끝에 그 사람이 널 어떻게 보느냐로 갈려. | 수상하게 굴수록 이쪽으로 가까워져. |
| 흥미로운 여자 | 칼을 넘기고 눈이 마주친 다음에 갈라져. | 그 사람 눈길을 끝까지 붙잡아 봐. |
| 살아남은 자 | 칼을 넘기고 눈이 마주친 다음에 갈라져. | 너무 튀지 말고 조용히 넘겨 봐. |
| 크라차로 가는 길 | 사람을 본 순간이나 칼끝 앞에서 갈라져. | 맞서지 말고 달아나 봐. 해가 질 때까지. |
| 여기까지 | 어디서든 갈 수 있어. | 그만하고 싶다고 말하면 돼. |
| 사람?! | 사막 한가운데서 누군가를 만나면 갈라져. | 사람을 보면 어떻게 할지 한번 네가 정해 봐. |
| 왜지? | 칼끝이 목에 닿았을 때가 큰 갈림길이야. | 왜 살려 둬야 하는지 네 나름대로 말해 봐. |
| 마지막으로 남길 말인가 | 칼 앞에서 잘 넘기면 그다음이 있어. | 억울하다고 버텨 보는 건 어때? |
| 마음이 바뀌었다 | 칼을 넘기고 눈이 마주친 다음에 정해져. | 그 사람 눈을 피할지 말지 골라 봐. |
| 귀하신 몸 | 칼끝이 목에 닿았을 때 갈라져. | 네가 얼마나 대단한 집안 사람인지 내세워 봐. |
| 그럼 증명해라 | 칼끝이 목에 닿았을 때 갈라져. | 살려 두면 뭐가 좋은지 말해 보면 어때? |
| 묶인 손목 | 끝에 그 사람이 널 어떻게 보느냐로 갈려. | 수상하게 굴수록 이쪽으로 가까워져. |
