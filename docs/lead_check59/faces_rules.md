# 59차 표정 선택 규칙 초안

근거: `docs/lead_check59/faces_survey.md`. 엔진 작업자에게 전달할 초안이며 아직 스키마·프롬프트·게임에 적용하지 않았다. 새 표정 PNG도 아직 없다. 아래 확장 목록을 이미지 설치 전에 활성화하면 안 된다.

## 조사에서 확인한 ID

```yaml
asina: [flustered, scared, indignant, smug, tired]
asina_hood: [flustered, scared, indignant, smug, tired]
behidat: [sneer, cold, dumbfounded, menacing, intrigued]
```

아시나의 `teary`, `pouty`는 조사에서 제외했다. 실제 항의·불만 얼굴을 `indignant`로 구분했다.

`cold`는 베히다트의 기존 `neutral`과 같은 무표정 역할이다. 런타임에서는 기존 `neutral`을 유지하고 별도 `cold`를 중복 추가하지 않는 안을 권한다. 아래 목록은 이 결정을 반영했다. `cold`는 조사·작화 지시 이름이며 모델의 출력 ID가 아니다. 이는 구현 전 명시적으로 정하는 이름 대응이고, 잘못 출력된 ID를 실행 중 조용히 바꾸는 처리가 아니다.

## 이미지 설치 뒤 사용할 화자별 목록 제안

기존 네 표정은 이번 조사에서 새로 제작한 것이 아니라 현재 엔진의 호환 목록이다.

```yaml
아시나:
  faces: [neutral, smile, surprised, wary, flustered, scared, indignant, smug, tired]
속마음:
  faces: [neutral, smile, surprised, wary, flustered, scared, indignant, smug, tired]
남자:
  faces: [neutral, smile, surprised, wary, sneer, dumbfounded, menacing, intrigued]
```

- `아시나`와 `속마음`은 같은 인물의 표정 목록을 공유한다. 후드 유무는 파일 선택에만 영향을 준다.
- 현재 `남자` 화자는 lore `베히다트`, sprite `man`에 연결되어 있다. 표시 이름이 나중에 바뀌어도 같은 인물의 목록을 쓴다. 이 연결 때문에 아직 모르는 이름을 대사에 공개하지 않는다.
- 나레이션에는 `face`를 붙이지 않는다.
- GM 여우는 이야기 진행 중 등장시키지 않는다. 질문 모드·시작 안내에서만 기존 규칙을 따른다.
- 목록의 새 ID를 허용하기 전에 필요한 후드·일반 입식 파일과 실제 sprite 연결을 준비한다. 미설치 파일을 `neutral` 그림으로 덮어 보여 주며 구현 완료로 취급하지 않는다.

## 선택 순서

1. 입력이 플레이 방법 질문인지, 인물에게 건넨 말인지, 혼잣말인지, 행동 시도인지, 아무 시도도 없는 반응인지 먼저 구분한다.
2. 현재 장면에서 실제 일어난 일과 상대의 의도를 판단한다. “이상한 말”이라는 이유로 모두 같은 처리로 묶지 않는다.
3. 각 줄을 말하는 인물의 현재 감정에 맞춰 그 인물 목록에서 표정을 고른다. 플레이어의 감정을 상대 인물에게 그대로 복사하지 않는다.
4. 대사와 표정이 같은 뜻인지 확인한다. 비웃는 대사에 겁먹은 얼굴, 위협하는 대사에 다정한 웃음을 붙이지 않는다.
5. 표정은 그 줄이 끝날 때까지 유지하고, 감정이 바뀌는 다음 줄에서 바꾼다. 한 입력에 여러 감정이 실제로 이어질 수 있다.

## 상황 → 표정

이 표는 단어 매칭 규칙이 아니다. 예시는 의미를 설명하기 위한 것이며 같은 단어라도 의도·사건·대사가 다르면 다른 표정을 고른다.

| 상황 | 아시나 | 베히다트 | 구분할 점 |
|---|---|---|---|
| “핸드폰을 꺼낸다” 등 세계에 없는 물건·개념을 말함 | 자신의 줄이 실제로 생기면 그 줄에 맞는 표정 | 처음에는 `dumbfounded`, 뜻을 모르는 채 빈정거려 넘길 때 `sneer` | 현대 물건을 아는 척 설명하지 않는다. 인물답게 받아넘기며 세계 밖 내용 자체로 판정·수치를 바꾸지 않는다. |
| 갑자기 춤추거나 뜬금없이 저녁 메뉴를 물음 | 능청스럽게 행동한다면 `smug`, 반응에 당황하면 `flustered` | 뜻밖이라 말을 잃으면 `dumbfounded`, 대담함에 관심을 보이면 `intrigued` | 춤·식사는 세계 안에서 가능한 행동이다. 앞 행의 세계 밖 입력과 같다고 취급하지 않는다. |
| 눈앞에서 뽀뽀를 시도하거나 칼날에 혀를 댐 | 시도 전 의도가 자신만만하면 `smug`, 실제 위험을 깨달으면 `scared` | 놀람은 `dumbfounded`, 실제로 저지·압박하면 `menacing` | 큰 행동을 우스운 한마디와 표정 교체만으로 끝내지 않는다. 결과와 인물 반응은 사건 처리에서 먼저 정한다. 무조건 호감 상승이나 무조건 무효로 정하지 않는다. |
| 칭찬·미인계·자기 매력을 내세움 | 의도적인 미인계는 `smug`, 예상 밖의 역공·칭찬에는 `flustered` | 얕은 수를 비웃으면 `sneer`, 예상 밖의 기지를 더 살피면 `intrigued` | 미인계라는 입력만으로 연애 감정·호감 상승을 확정하지 않는다. |
| 실제 위협이 눈앞에 닥침 | 위험을 겪는 순간 `scared`; 단순 경계라면 기존 `wary` | 상대를 위협·제지하는 줄은 `menacing`; 담담한 관찰은 `neutral` | 아직 벌어지지 않은 사건을 예고하려고 겁이나 위협 표정을 미리 띄우지 않는다. |
| 엉성한 협박·허풍 | 자신 있게 주장하면 `smug`, 들켜서 당황하면 `flustered` | 우습게 여기면 `sneer`; 실제 위험으로 판단할 때만 `menacing` | “죽인다” 같은 단어만 보고 자동으로 위협 얼굴을 선택하지 않는다. |
| 억울함을 반박하거나 무례한 취급에 항의함 | `indignant` | 사실만 차갑게 답하면 `neutral`, 조롱한다면 `sneer` | 아시나가 억울하다고 해서 베히다트도 억울한 얼굴을 짓지 않는다. 눈물은 근거 없이 더하지 않는다. |
| 말을 잃거나 실수·발각으로 당황함 | `flustered` | 이해가 안 되어 멈칫하면 `dumbfounded` | 실제 공포라면 아시나는 `scared`로 구별한다. |
| 지쳐서 한숨 쉬거나 고개를 떨굼 | `tired` | 자신의 줄이 있으면 대사에 맞춰 선택 | 기운 없는 반응만으로 행동 판정이나 주사위를 추가하지 않는다. |
| 울기·가만히 있기 등 시도 없는 감정 반응 | 울음 자체는 서술로 표현하고, 실제로 맞는 허용 표정을 다시 선택 | 상대 반응의 감정으로 선택 | 없는 `teary`를 출력하거나, 표정을 보여 주려고 행동 시도로 바꾸지 않는다. |
| 평범한 관찰·대답·질문 | 기존 `neutral` 등 | 기존 `neutral` | 매 줄을 과장된 새 표정으로 채울 필요는 없다. |

## 모델에 전달할 문장 초안

```text
대사·속마음 각 줄에는 그 줄을 말하는 순간의 표정을 화자별 허용 목록에서 고른다.
입력의 단어가 아니라 의도, 실제로 벌어진 일, 인물의 성격과 그 줄의 말투로 판단한다.
아시나: 당황 flustered / 실제 위험에 겁먹음 scared / 불만을 항의함 indignant /
자기 매력이나 수를 믿는 능청 smug / 지침 tired.
남자: 차가운 무표정 neutral / 낮춰 보는 비웃음 sneer / 예상 밖이라 말문 막힘 dumbfounded /
실제로 압박·저지함 menacing / 상대를 더 살펴보고 싶음 intrigued.
상대의 감정과 화자의 감정을 섞지 않는다. 놀림이 곧 위협이나 호감은 아니다.
아시나의 teary·pouty, 남자의 cold는 출력 허용 ID가 아니다.
장면에서 아직 모르는 사실, 미래 사건, 뒤 화의 관계를 표정 선택에 끌어오지 않는다.
나레이션과 GM 줄에는 이야기용 인물 표정을 붙이지 않는다.
```

## 엔진 인계 시 확인할 계약

- 출력 스키마의 `face` enum은 해당 화자의 목록으로 제한한다. 전 인물 합집합 하나로 검증하면 아시나에게 `sneer`가 통과하는 문제가 남는다.
- 허용되지 않은 ID에는 화자와 허용 목록을 포함한 검증 오류를 반환해 다시 고르게 한다. `neutral`로 조용히 바꾸지 않는다.
- 기존 고정 대사의 표정도 원작 컷과 대조한다. 현재 파일 이름이 같다는 이유만으로 원작 감정과 같다고 간주하지 않는다.
- 아시나 후드·일반 양쪽에 같은 새 ID가 있어야 한다. 베히다트 `cold`는 `neutral`을 유지하는 위 이름 계약과 일치시킨다.
- 이 문서는 설계 초안이다. 새 이미지 설치·모델 출력·실제 화면·주사위 동작·테스트 실행은 엔진 작업자의 후속 검증 범위다.
