# 리드 7차 확인 (26B, 어떤 문서에도 없는 새 입력 4판) — 6차 통과

대사 전체: 같은 폴더의 `A_first.txt`, `B_joke.txt`, `C_risk.txt`, `D_stuck.txt`. 스크립트: `work/demo-slice/lead_play10.mjs`(시드 A 61, B 18, C 29, D 93). 멈춤 0, 지도 기록은 서버 재시작 뒤에도 같음.

## 6차 항목이 새 표현에서도 맞는 것

| 항목 | 입력 | 화면 줄 |
|---|---|---|
| 1 판정·서술 일치 | 남자의 가슴을 밀친다 (대가 있는 성공 7) | 밀쳐냈다 → 움찔하며 물러났다 → 중심을 잡고 비웃음 |

| 새 결말 | A: 돈 제안 성공 13 → 길잡이 계약 | 다섯 갈래 중 길잡이 갈래 도달 |

A판은 길잡이 갈래로 빠져 b06·b08에 넣어 둔 `발로 정강이를 찬다`, `내 진짜 이름은 아시나 웰든이야`는 이번에 재지 못했다.

## 쉬우면 같이 고칠 것 (통과를 막지 않음)

1. `주사위는 어떻게 굴려?`(여는 글 중) → 플레이 방법 줄. 판정 설명(주사위 둘+능력치, 10/7~9/6)이 나와야 한다. (A)
2. `성공하면 뭐가 좋아?` → "그건 내가 답할 게 아니야". 게임 규칙 질문이다. 성공·대가·실패가 뭘 바꾸는지 답한다. (D)
3. `메뉴 어디 있어?` → "그건 내가 답할 게 아니야". 저장 질문처럼 화면의 실제 단추를 답한다. (B)
4. `지금 몇 시야?`(남자 앞) → 남자에게 건넨 말로 읽어 "시간을 묻는 건가?". 시한에 '한낮'이 떠 있으니 여우가 답해도 된다. 애매하므로 둘 다 허용. (B)
5. `바닥에 엎드려 운다` → 여우 "와, 진짜 눈물로 모래를 적시려고?!" 놀림이 붙는다. 놀림은 엉뚱한 입력에만. (C)

## 리드 7차 재확인 (26B, 새 표현 9개, `lead_runs.txt`, 스크립트 `work/demo-slice/check10_lead.ts`) — 통과

맞은 것 7개: `주사위 두 개 던지는 거 맞아?`, `점수는 어떻게 매겨?` → 판정 설명. `잘하면 뭐 받아?` → 결과 설명. `불러오기는 어디 눌러?` → 저장 설명. `손으로 얼굴을 가리고 떤다`, `엉엉 울면서 살려 달라고 한다` → 놀림 없음. `내일 비 올까?` → 세계 답(허용).

남은 약점 2개(다음 수정 때 함께):
- `실패하면 죽어?` → 세계 질문으로 읽어 "버티지 못하면 죽을 수도 있어". 규칙상 실패해도 이야기는 이어지므로 틀린 인상을 준다. 판정 결과를 묻는 "죽어?", "끝나?"는 규칙(outcome)으로 가야 한다.
- `수첩은 어디서 봐?` → 세계 질문 none으로 떨어져 플레이 방법 줄. 화면 단추(screen) 항목으로 가야 한다.
