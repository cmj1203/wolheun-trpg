# 54차 B — 아시나 귀찌

원작은 귓불에 바로 붙는 작은 붉은 원형 귀찌다. 정면에서는 원형, 비스듬히 보면 타원으로 보인다. 확대 컷에서는 자주·분홍빛으로 반사되는 보석과 얇은 금빛 테두리를 확인할 수 있다. 귀 아래에 별도의 사슬로 알을 매다는 구조는 아니다. 5화 c003에는 **뒤쪽 집게 부분**이 보이므로 “장신구 전체에 고리가 전혀 없다”는 뜻으로 해석하면 안 된다.

## 조사 범위와 근거

## 후보와 픽셀 검증

원격 `generate_image`를 두 번 호출했으나 모두 `provider_native_bypass`와 네이티브 도구 사용 안내만 반환했다. 이미지 파일은 생성되지 않았다. 허용된 대안으로 기존 붉은 알 픽셀을 **각각 10px 위로 이동**하고, 원래 고리·알 자리는 바로 아래 머리카락 가로띠를 늘려 메웠다. 새 보석·피부를 그리지 않았다. 경계에는 0.35~0.55px 페더를 사용했다.

마스크 PNG의 0인 모든 픽셀에서 RGBA 최대차를 검사했다. 아래 bbox는 양쪽 귀 마스크를 합친 경계이며, 두 귀 사이 얼굴은 마스크 0으로 그대로 유지된다. 원본과 후보는 1024×1536 PNG/RGBA, 알파 최대차는 모두 0이다. 후보 경로 앞에는 `work/demo-slice/lane54/`가 붙는다.

## 직접 판독과 남은 제한

`ears_compare.jpg` 8행과 `item_compare.jpg`를 직접 열어 확인했다. 최초 비교판에서 원작 표시 좌표가 축소 표시 기준으로 잘못 잡힌 것을 발견해 **실제 원본 해상도 기준으로 수정**했다. 처음 메움의 네모 경계도 원인이던 복제 방향을 바꿔 아래 머리카락 결을 쓰도록 고쳤다. 최종판은 늘어진 고리가 없어지고 붉은 알이 귓불에 붙는다.

입식의 금테 세공은 기존 6~8px 크기 알을 보존하므로 새로 그리지 않았다. 아이템은 원작 작은 영역 확대라 선명도에 한계가 있고, 배경 제거 경계는 수동 마스크다. 이를 새 원격 생성 그림으로 보고하지 않는다.

실제 게임 1440 화면은 촬영하지 않았다. 이 갈래는 assets 설치 권한이 없으며 후보 설치와 서버 화면 확인은 레인이 이어서 해야 한다. 18080·18081, app, assets는 수정하지 않았다. 원본 보존 해시·개별 이동 좌표는 `verification.json`에 있다. 검증 스크립트는 `uv run --with pillow --with numpy python work/demo-slice/lane54/make_candidates.py`로 성공했다. 편집기 기본 환경의 PIL/numpy 미설치 진단은 uv 실행 환경과 별개다.
