# 58b 변경

| 어디 | 전 → 후 |
|---|---|
| `app/src/gm/gm.ts` 모델 출력 검증 | 말투 검사의 실패를 상태 사실 `beat/state_check`로 반환 → `lore/reaction_style`로 별도 반환. 상태 검사는 복장 등 실제 상태만 검사 |
| `app/content/lore_wolheun.yaml` 남자 `reaction_check` | 짧고 차갑고 깔보는 말투인지 포괄 판정 → 설명 독백·상황 해설·40자 초과만 거절 |
| `app/src/gm/gm.ts` 감정 반응 | 짧으면 입력과 무관해도 통과 → 현재 감정·몸 반응을 받는지 의미 검사하고 무관하면 `beat/reaction_response`로 다시 쓰기 |
| `app/src/gm/prompt.ts` 감정 반응 | 장면 목표·대사 예시·일반 대화 규칙을 함께 전달 → 감정 반응 전용 문맥과 한 줄 작성 요청. 감탄만 하거나 앞 장면 질문을 반복하지 않음 |
| `app/src/engine/text.ts` 규칙 분류 | 주어에 생긴 피동·상태 변화도 현재형 동작이면 시도로 분류 → 절마다의 주어·목적어·의도 표시를 구분해 저절로 생긴 상태 변화는 무시도로 분류 |
| `app/web/main.ts` 변화 숫자 | 수치 행 바깥에 붙임 → 해당 `.value` 안에 붙임 |
| `app/web/style.css` 변화 숫자 | 기본·CG 축약 판에서 왼쪽 바깥 절대 위치 → 숫자와 같은 flex 행 안에 간격을 두고 배치 |

59차 표정 변경은 이 검증에 포함하지 않았다. `억울해…`의 웃는 얼굴은 그대로 남아 있으며 59차에서 다룬다.

회귀 시험은 실제 `LocalGm.talk` 경계에서 두 계약을 보호한다. 말투 실패가 상태 실패로 돌아가는 회귀와, 짧지만 행동에 무관한 대사가 그대로 통과하는 회귀를 각각 잡는다. 모델 의미 판정의 실제 품질은 별도 26B 입력 10개로 확인한다.
