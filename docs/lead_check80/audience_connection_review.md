## 질문 근거의 현재 경계

`questionFacts`는 공개 수첩·장면 메타데이터·확인된 화면 줄·활성 사실을 사용한다. 현재 `ending.summary`를 질문 근거로 읽지 않는다. 따라서 아래 요약 문장을 청취의 정본 사실로 복사해 넣으면 안 된다.

궁정 네 비트에는 `perspective: audience`가 있지만, 별도 `situation`이나 `conversation` 선언은 없다. 시점은 플레이어의 관전 분류이며 원작 속 인물의 청취자가 아니다. 직접 문답의 수신을 주변 전체의 청취나 앞선 대화 전체의 청취로 확대하지 않는다.
