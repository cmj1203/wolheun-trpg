# 47차 대성공

45b 통과 뒤 적용했다. 6·6이면 능력치·보정·합계와 무관하게 `crit`(대성공)이며, 그 밖에는 기존 합계 등급을 유지한다. 행운은 실패를 `mixed`(합 7)로 메울 뿐 대성공을 만들지 않는다. 난수는 기존대로 두 번만 소비한다.

성공의 서술·분기·플래그를 유지하고 좋은 수치 변화 각각을 한 칸 키운다. 의심·집착 감소와 나머지 수치 증가는 좋은 변화로 판정한다. 집착 증가는 그대로 둔다. 나쁜 비용과 소지품 변화는 증폭하지 않는다. 좋은 변화가 없으면 정신력 +1로 대신한다. 자유 입력의 기존 성공 회복(45차 정신력 +1)은 유지하되, 대체 회복과 중복하지 않는다. 긴장은 일반 성공과 동일하게 -1이다. YAML에 선택형 `crit` 결과가 있으면 그 결과를 그대로 사용하며 해당 경로·효과도 검증한다.

스토리 창은 새 서술 없이 `대성공` 변화 줄과 커진 수치를 표시한다. 기존 수치 공개 조건을 유지한다. 비교 저장에는 이미 공개된 남자 수치(`수첩:man`)와 정신력 2, 의심 3을 사용해 호감 차이가 보이게 했다. 이 설정은 300판 시뮬레이션에 넣지 않았다.

## 고정 시드 비교

| 입력 | 주사위 | 등급 | 수치 변화 |
|---|---|---|---|
| 미소녀니까요(beauty 단추), rng 33 | 6·6 + 매력 2 = 14 | 대성공 | 호감 +2, 집착 +1, 정신력 +1, 긴장 -1 |
| 같은 단추, rng 2 | 6·5 + 매력 2 = 13 | 성공 | 호감 +1, 집착 +1, 정신력 +1, 긴장 -1 |

둘 다 다음 장면은 `b06_swing`이다. 합계 13 일반 성공에는 대성공 연출을 내지 않는다. `rolls.json`에 실제 판정·수치 이벤트가 있다. `compare_rolls.png`와 `compare_story.png`는 각각 왼쪽 대성공, 오른쪽 일반 성공인 원본 캡처 병치다. 개별 화면은 `crit_1440.png`, `hit_1440.png`, `crit_story_1440.png`, `hit_story_1440.png`와 같은 이름의 `_390.png` 파일로 남겼다. 모바일의 기존 가로 무대는 세로 화면 안에서 작게 표시되어 글자 가독성에 한계가 있다. 이번 작업은 이 기존 배치를 바꾸지 않았다.

재현: `bun work/demo-slice/lane47/evidence.ts`로 `/tmp/lane45b/saves/slot1.json`(대성공), `slot2.json`(일반 성공)을 만든다. 환경변수 네 개를 `/tmp/lane45b/` 하위로 지정한 18194 서버에서 불러오기 → 미인계 단추를 누른다. 사용자 서버·LLM·저장·로그·피드백은 사용하지 않았다.

## 검증

- `cd app && bun test tests`: 626 통과, 0 실패, expect 2583회, 종료 코드 0.
- `cd app && bunx tsc --noEmit -p .`: 오류 0, 종료 코드 0.
- 대성공 회귀 6개: 보정과 무관한 6·6 / 난수 소비·재현성, 일반 성공 비교·동일 서술·긴장·무대가, 좋은 증감과 나쁜 비용 구분, 회복 대체·중복 방지, 행운, 선택형 YAML crit·잘못된 경로 거부.
- 기존 세 등급 고정 테스트·도움말 끝문장 고정 테스트와 등급을 다루는 평가·GM 테스트의 타입을 새 계약에 맞췄다. 실패를 삭제하거나 검사를 생략하지 않았다.
- 46 담당자의 시작 전 설명·`game_help.play`는 편집하지 않았다. `main.ts`는 허용받은 주사위 표시 부분만 바꿨다.
- 데스크톱 병치 화면과 390 화면을 직접 확인했다. 첫 스토리 캡처의 전환 중 섬광·잔상은 글과 애니메이션이 끝나는 조건을 기다려 다시 찍었다. 최종 병치 화면은 같은 b06 첫 줄이며 대성공·호감 +2와 일반 성공·호감 +1이 보인다.
- 코드레빗은 `crq add`를 한 번 실행했으나 공유 작업 트리의 변경 파일 220개가 상한 150개를 넘어 등록을 거부했다(`review.log`). 현재 HEAD 기준의 미커밋 변경이므로 더 가까운 기준으로 좁힐 수 없다. 커밋·다른 작업자의 파일 제외·설정 변경은 하지 않았으며 외부 코드 검토는 미실행이다.
