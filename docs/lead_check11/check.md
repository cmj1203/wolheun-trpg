## 4. 13차 첫 사례 — '뽀뽀'(사용자 반려) 입력 → 전 → 후

전(사용자 판 기록 `app/logs/13a78f66-c90f-400b-9198-d42713776691.jsonl`, b08_gaze): 입력 "뽀뽀" → improv, 매력 6+5+2=13 hit → narrate 3회 모두 `beat/scene_forbid "입을 맞"` → fallback → 화면에는 b09 원작 줄 "이상한 여자군"만, 수치 집착 +1.

원인 3개와 고친 것:
1. `scene_forbid` 가 플레이어 행동까지 막았다 → `validate.ts` 에서 플레이어 입력·interpret 이 요약한 행동(`deed`)·건넨 말에 든 말은 state_guard·outcome_forbid·exposed·absent·echo_only·presume·tier_mismatch 검사에서 면제(스포일러·등급·말투·형식은 면제 없음). 면제 판단은 글자가 아니라 deed 뜻. b08 "입을 맞" 금지의 정체: 뒤 장면 예약어가 아니라 must_not "입맞춤이나 지나친 신체 접촉" 의 낱말판 — GM 이 지어내는 접촉을 막는 용도였고, 뒤 장면 어디에도 입맞춤 줄은 없다. must_not 은 '남자가 먼저 입맞춤·접촉' 으로 고쳤다.
2. fallback 이 범용 줄 → `gm.ts` `improvFallback` = 내레이션 "deed." + `lore.characters[상대].reactions[등급]` 중 시드로 고른 한 줄(베히다트 hit 3·mixed 2·miss 3, 근거 c050·c054·c041). 상대 없으면 중립 반응. "이상한 여자군" 은 fallback 이 아니라 b09 원작 줄(`!미소녀 && !눈_맞섬`) 이어서, b09 에 `flag:큰_행동` 변형 줄("죽기 직전에 그런 짓을 하는 여자는 처음 보는군." / 아시나 "…뭐, 뭐예요.")을 더하고 "이상한 여자군"은 `!큰_행동` 일 때만.
3. 큰 행동의 결과 크기 → interpret 이 `bold`(상대가 speech 화자로 있을 때만) 와 `deed` 를 내고, bold 면 상대 반응 필수 + 3줄 이상(`too_few`), 수치는 `free_defaults.improv_bold` = hit 집착+2 호감+1 / mixed 집착+2 의심+2 / miss 의심+2 (모두 flags 큰_행동). 근거: 베히다트 가치관 — 흥미를 끄는 상대에게 집착하고(c054 "마음이 바뀌었다"), 수상한 것은 의심으로 받는다(c041·c050). 등급별 2단계 이상.

### 9-1. 본 것(리드 판단 거리)

- **unmasked 경고와 끝이 같은 턴**: -2 효과(b06 dodge mixed, r3_dusk drink miss·shelter miss)로 귀찌 2 → 0 이 되면 `귀찌 <= 1` 경고가 끝과 함께 나온다. 기존 '3 이하' 여우 줄(수치 설명)은 그 전에 나오지만 '은발' 예고는 아니다. 경고 기준을 `<= 2` 로 올리거나 -2 를 -1 로 줄이는 것 중 하나는 리드 결정.
- **unmasked 는 단추만으로 못 닿음**: 무작위 단추 플레이 3000판에서 0회. 혼잣말로 미루는 사건(귀찌 -1, 최대 2회 — 3회면 collapse)이 두 번 있어야 8 을 다 깎는다. 설계 의도("여러 턴")대로지만, 플레이어가 자연스럽게 겪을 길은 "미루기 2번 + 나쁜 주사위"뿐이다.
