# 월흔 6화 원문 전사 감사

대사 포함 원본 16장·65컷 전체와 컷 밖 여백을 직접 다시 읽었다. 원본 높이를 3000px 연속 구간으로 나누어 페이지 시작·끝·컷 경계까지 확인했다. c026·c027·c052·c056·c062·c065의 모호하거나 작은 글은 원본 컷·구간으로 확대했다. 클린 자산·요약·OCR로 대사를 대신하지 않았다.

- 전수 대조: **65/65컷**, 원본 **16/16장**. 전사·말풍선 분리·지명·화자·사건·공개 조건 정정 **29컷**. 나머지 36컷도 원문과 직접 대조했다.
- 본문 문장 미판독 0건. 개인 화자 미확정은 c017 보고, c026 회색 말풍선, c027 한숨·이동 속마음이다. c026 회색 말풍선·c062 마지막 원형 말풍선의 발화/독백 구분도 미확정이다.
- 아래 각 행의 완료는 문장·화자·현재/회상/삽입·당시 지식·복장 근거를 확인했다는 뜻이다. 미확정은 확인 사실이며 창작으로 채우지 않는다.
- ID·PSD·y_range는 assets/ep06/cuts.json을 보존한다. 모든 좌표는 원본 픽셀 [시작, 끝)이며 정확한 현재 전사는 script.md를 따른다.
