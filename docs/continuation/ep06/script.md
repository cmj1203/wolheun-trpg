# 월흔 6화 원문 전사

대사 포함 원본 16장·65컷 전체와 컷 밖 여백을 재대조했다. 원본은 `work/ep06/merged/ep06_001.png`~`ep06_016.png`, 식별자·PSD·반열린 세로 범위 `[시작, 끝)`는 `assets/ep06/cuts.json`을 유지한다. 클린 자산·기존 요약·OCR를 정본으로 쓰지 않았다. 말풍선 안 줄바꿈만 합치며 말줄임표 모양은 …로 통일한다. 발화·속마음·독백·지도 글을 구분하고 문장은 요약하지 않았다.

복장·가림은 `wardrobe-audit.md`, 전사 변경과 공개 조건은 `transcription-audit.md`를 따른다. 제작자 식별명은 주인공의 새 지식 공개를 뜻하지 않는다. 화자나 발화/독백 구분이 확정되지 않는 말풍선은 미확정으로 보존한다.

`ep05_c055`와 `ep06_c001`의 인사는 반복 수록이다. 두 원문 전사에는 각각 남기되 연속 재생에서는 한 번만 말하고 6화 c002의 라 반응으로 이어간다. 6화 끝의 진실 판단은 여행 감상에 관한 나시르의 내면이다. 7화 c001–c006의 조사·짐 일부 반환으로 이어지며, 6화에서 조사 종료·석방·짐 반환을 먼저 만들지 않는다.

## 판독·여백

본문 문장 미판독은 0건이다. c017 보고자, c026 회색 말풍선, c027 한숨·이동 속마음의 개인 화자는 원본의 인물 연결이 불명확해 미확정이다. c026 회색 말풍선과 c062 마지막 원형 말풍선의 발화/독백 구분도 미확정이다. 이를 특정 인물의 지식·입력·관계 확정으로 쓰지 않는다.
