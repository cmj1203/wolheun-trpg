# 판정 문구 변경

사용자가 “아슬아슬한 성공” 변경안을 승인한 뒤 적용했다.

- 판정 표시 이름: `app/src/engine/types.ts`의 mixed 라벨.
- 첫 안내: `app/web/introduction.ts`.
- GM 고정 규칙 안내: `app/content/ep01_desert.yaml`의 행운·판정·결과·플레이 안내.

계산식·확률·성공 목표·비용은 변경하지 않았다.
`bunx tsc --noEmit` 종료 0. 격리 NO_LLM 서버 18251의 실제 캠페인 로딩과 번들 생성도 통과했다.
Ego 전용 공간 20에서 새 판을 시작하고 주사위 안내까지 실제 조작했다.
PC 캡처 `work/continuation/wording/introduction-pc.png`를 리드가 직접 열어 새 문구가 잘림 없이 보임을 확인했다.

추가 실제 판정 두 번은 모두 실패였다. 첫 판정의 행운 사용은 6→2로 실제 반영됐다.
행운 변환 뒤 결과 카드를 다시 표시하는 경로는 없었으므로 변환된 mixed 카드의 시각 증거로 세지 않는다.
`work/continuation/wording/roll-pc.png`도 실패 카드이며 mixed 카드 증거가 아니다.
이번 확인은 문구 수정 범위이며 실제 모델·전체 스토리 QA 완료를 뜻하지 않는다.

코드레빗 대기열 등록은 `crq add --note …`로 한 번 시도했으나,
현재 공유 작업의 변경 파일 734개가 150개 제한을 넘어 등록되지 않았다.
범위를 줄이려고 다른 작업을 커밋하거나 제외하지 않았다. 검토 대기열 등록은 미완료다.
