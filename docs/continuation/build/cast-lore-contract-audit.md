# 3~10화 배우와 로어 계약 대조

2026-11-09. 부모가 실제 YAML의 lore 참조를 전수 파싱했고, 모든 참조가 현재 `lore_wolheun.yaml`에 존재함을 확인했다. 인물별 감사와 단독 소유자의 최종 교정 근거를 아래에 연결한다. 이 확인은 원작 미술·대사 품질·관객 기억 런타임의 합격 판정이 아니다.

## 출력 매체와 표정

원작 CG를 임시 sprite로 선언하면 같은 lore의 정식 배우도 해당 sprite의 표정 자산을 요구하게 된다. CG 전용 speech/thought는 `presentation: cg`, sprite 없음, 실제 인물별 허용 face ID와 유효한 줄 CG를 사용한다. 원래 입식 배우의 파일 존재 검사는 유지한다.

`lore.characters.*.faces`는 표정 선택을 설명하는 문장 배열이다. 이 설명문 자체를 face ID 목록으로 비교하지 않는다. 실제 허용 ID는 정식 배우 선언·원작 인물 지침·공유 reactions의 표정 집합을 각각 대조한다.

| 인물 | 실제 허용 계약의 근거 |
|---|---|
| 아시나 | 정식1화 배우의9표정: neutral, smile, surprised, wary, flustered, scared, indignant, smug, tired |
| 베히다트 CG 별칭 | 실제 공유 reactions8줄의6종: dumbfounded, intrigued, wary, sneer, neutral, menacing |
| 카림 | 실제 인물 지침의 neutral, wary, flustered |
| 나시르 | 실제 인물 지침의 neutral, smile |
| 누르 | 실제 인물 지침의 neutral, smile, surprised |
| 신규 조연 | 해당 원작에서 확인된 표정만 선언하며 다른 인물의 목록을 복사하지 않는다. |

3화7개 CG 배우와8화 쿤/쿤독백/시하드/시하드독백은 부모가 교정했다.5화 남성/라쿤,6화 라/라독백,7화 은발 남성/독백,9화 전체15개 CG 별칭,10화 전체5개 CG 별칭은 각각 기존 단독 소유자가 교정했다.3·5·6·7·8화의 lore 배우에는 source 컷 번호를 sprite로 둔 별칭이 남아 있지 않았다.9화에서 발견한 같은 원인은 전체15역을 대상으로 수리했다.

## 정체성과 기존 배우 보존

- 7화 은발 남성·독백은 같은 베히다트 lore를 계승한다. 표시 별칭이 달라도 별도 인물 기억으로 만들지 않는다.
- 6화 보고자는 `ep06_도착보고자`다.3화 보고자나 다른 조연 lore를 복사하지 않는다.
- 9화 장발·대족장은 `ep09_장발대족장`, 동행은 `ep09_대족장동행`이다. 장발 대족장을 잘릴로 확정하지 않는다.
- 10화 아시나 speech 키는 `ep10_아시나`로 분리했다. 정식 `아시나` 배우의 `asina_hood` 입식·9표정과 기존 정의를 덮어쓰지 않는다. 표시 이름과 lore는 같은 아시나다.
- 관객 선언·본명/호칭 공개는 실제 발화 순서와 별도다. cast 교정 때문에 공개 플래그·대사·수치·소지품·지도·미확정 c070을 바꾸지 않는다.
