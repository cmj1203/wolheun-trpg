## 도구 상태 주의

장기 eval JS 커널에서 예전 `scenario.ts` 모듈이 캐시되어 승인 전 parser를 반환했다. `checkScenario.toString()`에 presentation이 없고 edgesOf에 conversation이 없는 것을 확인했다. 새 Bun 프로세스의 현재 로더는 정상이다. 이 캐시 실패를 현재 작업 파일 결함으로 세지 않는다. 커널을 무조건 초기화하거나 파일을 되돌리지 않는다.

원시 YAML 데이터는 `Bun.YAML.parse(await Bun.file(path).text())`로 읽을 수 있다. 파일 앞에 `#` 주석이 있어 JSON.parse는 실패했다. 파일 파손이 아니다. 해당 실패는 읽기뿐이며 원본을 바꾸지 않았다.
