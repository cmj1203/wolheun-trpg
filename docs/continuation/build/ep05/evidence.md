2026-11-09. 부모 세션 이동 지시에 따라 새 범위는 시작하지 않고 단독 적재·전용시험과 현재 의존성만 인계한다. YAML·전용시험 파일은 아래 최종 통과 뒤 더 수정하지 않았다.

## 통과한 범위

- 61비트, 원작 15장·55컷·9장면. 실제 엔진 원작 경로를 최신 `script.md`의 컷 순서·원문 발화와 대조했다. 같은 컷의 나눈 줄과 c045의 응답 분할에서도 같은 CG를 확인했다.
- 세 실제 문답 자리의 내부 선택 8조합이 끝까지 진행한다. 원작 응답과 대체 질문·소환 응낙·짧은 답이 각각 기록된다.
- 짧은 답에서는 하지 않은 지난밤 안부·되물음이 발화되거나 해당 공개 플래그가 생기지 않는다.
- 일반 대화·감정·자동 전환에 주사위·가격·장면 검사·임의 트랙 변화가 없다. 미사용 시간 비용이나 가짜 목표도 없다.
- 2화 `sheet.items` 정의와 정확히 동일하다. 실제 진입 전 만들어 둔 짐 미회수·갈색 변장·이름 지식·변경된 귀찌 잔여량·트랙·아이템·선행 선택을 초기화하지 않는 엔진 경로를 시험했다. 실제 4→5 캠페인 통합 시험을 대신하지 않는다.
- 누르 소개·아이라 뜻·소환 전달은 해당 줄 뒤에만 열린다. 자이드 보고와 조사 의향 등 관객 정보는 아시나의 활성 `facts`에 들어가지 않는다.
- 같은 남성의 이름표별 `lore`와 누르의 소개 전후 `lore`는 동일하다. c004 목소리에 개인 `lore`를 부여하지 않았다.
- 실제 경로의 지도 노드와 간선 및 5화 장 선언을 확인했다. 판정을 선택 노드로 가장하지 않았다.
- 참조하는 원작 CG 파일 55개가 모두 `assets/ep05/cuts/full_res/clean/`에 존재한다.

## 수정 이력과 한계

초기 적재에서 필수 `next_hook` 누락과, 실재 입식 없이 `faces`를 선언한 계약 오류를 발견했다. 결말 의미를 위 문구로 확정하고, 없는 입식·표정을 가짜로 선언하는 대신 원작 CG의 실제 모습으로만 진행하도록 고쳤다. 그 뒤 전사 비교에서 “대사 없음. 효과 …”의 효과를 발화로 세던 시험 오독도 바로잡았다. 최종 통과는 이 수정들을 모두 포함한다.

YAML 언어 서버가 설치되어 있지 않다. 테스트 파일 언어 서버 진단은 새 결과 대기 시간 초과였고, `bun check --no-script`는 현재 실행 환경에서 `Script not found "check"`로 실행되지 않았다. 타입 검사 통과를 주장하지 않는다. 부모의 범위 축소 지시 뒤 별도 검사기 설치·추가 타입 검사는 하지 않았다.

## 인계 자료와 미완료 의존성

- `source-audit.md`: 직접 복장 관찰 55개와 연속성 추론 24개를 분리했다. c004 화자 및 “누르하” 의미를 확정하지 않았고, 밝은 어깨 피부를 흰 옷으로 바꾸지 않았다.
- `bridge.md`: 정확한 4→5→6 비트·짐·변장·이름·시간 계승과 중복 인사 처리를 기록했다. 5화 마지막 두 인사와 현 6화 c001은 연속 재생에서 중복 제거가 필요하다. 짧은 답 분기는 원작 c002 반응으로 무조건 접속하면 안 된다.
- 그림 55개는 원작 크롭을 사용하는 검증 입력이며 완성 Astra 그림이 아니다. 궁정복 입식·표정 자산은 미완료다. 없는 입식을 여행복으로 대체하거나 가짜 표정 파일을 선언하지 않았다.
- 누르·나시르의 `lore` 연결 대상과 흑발 신하의 미확정 인물 처리는 부모의 공유 지식 통합 대상이다. 이 작업은 공유 lore를 수정하지 않았다.
- 세 고정 선택은 내부 구조다. 임의 대사·괄호 행동·무응답 처리·실제 입력의 다음 화 계승은 부모의 공유 대화 패치 의존이다.
- 캠페인 연결, 완성 그림, 실제 렌더 화면, 서버·모델 QA는 실행하지 않았다. 전체시험 통과나 사용자 플레이 준비 완료를 주장하지 않는다.
- 커밋·푸시·코드레빗·사용자 연락·서버·모델 사용은 하지 않았다. 예정된 부모 인계 문서 `docs/continuation/build/session-handoff-20261109.md`는 이 레인이 생성·수정하지 않는다.
