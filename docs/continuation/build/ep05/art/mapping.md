## 같은 그림 유지 근거

- ep05_c028 → ep05_c027_p01: 맨 앞 독백 풍선에는 새 현재 인물 그림이 없다. 직전 얼굴을 유지한 뒤 첫 신앙 삽화에서 전환한다.
- ep05_c031 → ep05_c030_p01: 정체를 되짚는 독백만 있는 여백이다. 바로 앞 c030 현재 모습을 유지한다. 하단 회상은 c032에서만 공개한다.
- ep05_c039 → ep05_c038_p02: 직전 결정에 대한 응답 풍선만 있는 인물 없는 여백이다. 직전 동일 별실 화면을 유지한다.
- ep05_c054 → ep05_c053_p02: 아시나의 생각만 있는 여백이다. 새 행동·얼굴·의상이 없어 직전 질문 화면을 유지하고 c055 응수는 뒤에 공개한다.

분기 문구가 달라도 같은 순간인 시녀 역할 질문, 소환 수락, 짧은 답은 각각 c021·c045/c046·c055_p01을 공유한다. 원작과 다른 사건·복장·인물을 그리는 근거로 사용하지 않는다. 거리 유지 분기 c052에는 과거 접촉을 보여 주지 않고 동일한 현재 장면 c052_p02를 쓴다. 이는 원작 경로와 같은 시점의 대체 재생이며 앞 장면으로 되감는 재사용이 아니다.

## 연결 담당 조정 항목

YAML·원작 문서는 읽기 전용으로 두었다. 현재 YAML과 source 해시를 저장했으므로 연결 직전 변경된 입력의 영향을 다시 대조해야 한다.

- **조정-01**: 실제 c030 하단에 하아아아…, 실제 c031에는 설마, 그 남자가 라 쿤이었을 줄이야.가 있다. 현재 전사와 YAML의 컷 번호가 이 두 발화에서 어긋난다. YAML 발화 순서를 바꾸지 않고 c031 한숨에는 c030을 유지, c032 정체 회고에는 원작 c031 여백을 대응한다. 거리 유지 분기의 cg033 선행 재사용도 c030 유지로 제안한다. 대상: `ep05_c031:L1`, `ep05_c032:L1`, `ep05_distance_c032:L1`.
- **조정-02**: 원작 c032는 접촉 회상 뒤 현재의 붉어진 얼굴과 …!를 담는다. 현재 YAML 한 줄 뒤에 무언 프레임 두 자리가 필요하다. 거리 유지 분기에는 이 접촉 회상을 넣지 않는다. 대상: `ep05_c032:무언-회상`, `ep05_c032:무언-현재반응`.
- **조정-03**: 실제 c052 상단은 접촉 회상이며 하단은 시선을 돌린 현재 아시나와 먼 좌석이다. 전사의 현재 얼굴·상체만이라는 설명과 다르다. 원작 경로는 L1 회상 → L2 현재로 분리한다. 거리 유지 경로는 기존 cg050을 되감아 재사용하지 않고 같은 현재 상태의 c052_p02를 공유한다. 대상: `ep05_c052:L1`, `ep05_c052:L2`, `ep05_distance_c052:L1`.
- **조정-04**: 실제 c044 상단에는 라 쿤의 얼굴·가슴·겉천·장신구가 보인다. 전사의 전반 명령 풍선에 의복이 없다는 설명은 실제 그림과 다르다. 상단 라 쿤만 관객에게 공개하고 식탁의 아시나는 시점 전환 뒤 하단 후보로 공개한다. 대상: `ep05_c044:L1`, `ep05_c044_asina:L1`.
- **조정-05**: 실제 c028은 처음 생각 풍선 뒤 리메아 신앙 인물·페시안 신앙 인물·물과 식물의 궁 삽화 순서다. 전사의 현재 아시나 상체 기록을 근거로 현재 인물을 새로 그리지 않는다. 첫 생각 동안 직전 c027을 유지하고 삽화를 세 후보로 분리한다. 대상: `ep05_c028:L1`, `ep05_c028:L2`, `ep05_c028:L2-페시안`, `ep05_c028:L3`.
- **조정-06**: 현재 YAML에 별도 줄이 없는 원작 무언·제목·반응 프레임이다. 생성 매핑에는 모두 포함했다. 연결 담당이 해당 위치에 시각 앵커를 추가해야 하며 현재 소유자는 YAML을 수정하지 않는다. 대상: `ep05_c005:무언-접촉직후`, `ep05_c009:무언-아시나얼굴`, `ep05_c010:무언-제목`, `ep05_c042:무언-찌릿`.
- **조정-07**: 같은 YAML 줄 안에서 실제 원작 그림이 바뀐다. 현재 CG 하나를 줄 전체에 쓰면 원작 순서가 사라진다. 문장 경계에 명시한 하위 앵커를 연결 담당이 반영해야 한다. 대상: `ep05_c042:L4-청발얼굴`, `ep05_c047:L1-보행`.
- **조정-08**: 실제 그림은 각각 방 전경과 차 준비 자리, 침대 위 기척 반응 구도, 누르를 포함한 방 전경, 문과 실내, 쥔 주먹과 보라색 앞판 근접이다. 전사의 손만·얼굴 근접·컵 정물 같은 표현보다 원본의 실제 프레임을 우선하며 다른 구도를 새로 만들지 않는다. 대상: `ep05_c011:L1`, `ep05_c012:L1`, `ep05_c014:L1`, `ep05_c025:L1`, `ep05_c033:L1`.
- **조정-09**: 6화 c001과 겹치는 답과 되물음은 경계 연결 시 한 번만 발화한다. 짧은 답 분기에는 c055_p01만 쓰고 뒤의 미소·되물음 장면을 앞당기지 않는다. 6화 전사 29컷 정정에서 제거한 애첩·구속·사막 필수 통과·맨등 요구를 5화 이미지로 역삽입하지 않는다. 대상: `ep05_c055:L2`, `ep05_c055:L3`, `ep05_reply_short:L1`.

5화 c004 개인 화자와 누르 하의의 치마/바지 구분은 미확정으로 유지한다. 청발·흑발 신하 이름, 자이드의 지위, “그 일”의 내용은 만들지 않는다. 밤의 장신구·검은 옷과 낮의 붉은갈색/흰 옷, 보라 복장과 분홍 복장을 섞지 않는다. 관객 전용 별실 대화는 아시나가 아는 사건이 아니다. 9→10의 생략된 공격·포획 등을 이 화의 그림에도 끌어오지 않는다.
