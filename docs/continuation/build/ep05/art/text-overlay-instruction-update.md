# 후속 native 호출의 문자 오버레이 지시 정정

2026-11-09 부모의 추가 지시에 따라 첫 호출 이후의 native 프롬프트에서 제목·원래 크레디트를 보존하라는 기본 문장을 제거한다. 원작 로고·화수 표제·제목·출판 크레디트·워터마크는 그림 위 문자 오버레이로 제거하며 새로 그리지 않는다. 원작 그림·얼굴·의복·장신구·소품과 패널 공개 순서는 보존한다.

첫 후보 `assets/ep05/gen/ep05_c001_p01.png`는 덮어쓰거나 재생성하지 않는다. 기존 첫 호출 argv는 실제 이력으로 보존하고 첫 후보를 독립 Claude 문자 오버레이 검사 대기로 기록한다. 원작 참조 PNG도 변경하지 않는다.

문자만 있는 다음 두 편집 창은 새 그림을 생성하지 않고 직전 이미지 유지로 해결한다.

- `ep05_c010_p01`: 제목·크레디트 창. 원작 경로는 `ep05_c009_p02` 유지 후 아침의 궁 `ep05_c010_p02`로 전환한다. 거리 유지 분기는 앞선 밤 그림을 보여 주지 않고 첫 실제 그림인 `ep05_c010_p02`부터 시작한다.
- `ep05_c042_p02`: 인물·장소 그림 없이 어두운 질감 위 대사가 이어지는 창. `ep05_c042_p01`을 유지하고 원작 청발 얼굴 공개 자리에서 `ep05_c042_p03`으로 전환한다.

기존 74개 매핑 위치는 모두 보존한다. 그중 실제 고유 생성 대상은 72개이고 문자 위치 2개는 직전 그림 유지다. 이는 이후 실행 지시만 바꾼 것이며 YAML·원작 입력·기존 매핑 파일은 수정하지 않는다. 유지할 이미지도 독립 그림 QA 전까지 후보 상태다.
