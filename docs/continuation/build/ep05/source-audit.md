- c004의 “으읏…!”는 `ep05_목소리`로 보존한다. 개인 이름·lore를 붙이지 않았다. 화자 미확정은 글자 판독 불가가 아니다.
- 요청에서 유보한 “누르하”의 의미는 확정하지 않는다. 최신 세 입력 문서에는 해당 표기가 없으며, 임의 뜻·직함·다른 이름을 새로 추가하지 않았다. 최신 c014의 자기소개 “누르”와 이 의미 유보는 별개다.
- 최신 c022의 “아시나님”은 그대로 수록한다. 누르가 이름을 알게 된 경위나 라 쿤에게 이름이 전달된 사건을 창작하지 않는다.
- c045의 밝은 어깨는 피부다. 흰 옷을 덧그리거나 글로 선언하지 않는다. c036은 실내 정물, c017은 손을 잡는 장면이다.
- 최신 5화 전사에는 컷 밖 별도 보충 대사 항목이 없다. c023 작은 곁말, c024 작은 반응, c041 작은 말, c048 비꼼, c051 속마음, c055의 세 발화까지 수록했다. 효과음은 대사와 구분하고 원문에 없는 발화를 채우지 않았다.
- c010의 표제·크레디트는 출처 정보이며 등장인물 발화로 만들지 않았다. 새소리는 아침 전환 서술에 보존했다. 원작 신앙 삽화는 현재 마법 사건으로 만들지 않았다.
