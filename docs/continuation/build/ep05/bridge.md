# 4→5→6화 연결 요구

2026-11-09의 각 화 `script.md`, `continuation.md`, 현재 `ep04_night.yaml`, `ep05_audience.yaml`, `ep06_library.yaml` 기준이다. 실제 캠페인 연결 코드는 이 작업에서 변경하지 않았다.

## 4→5

| 항목 | 실제 연결 요구 | 확정 범위 |
|---|---|---|
| 경계 | `ep04_c063` → `ep04_boundary` → `ep05_c001` | 4화의 눈동자 발언 뒤 5화는 이미 입맞춤 중이다. 접촉 개시 동작은 원작 사이에 생략됐다. 자발적 동의·추가 밤 사건을 만들지 않는다. |
| 짐 | 기존 `state.items`와 소지품 상태 플래그를 그대로 넘긴다 | 4화 첫 비트는 `magic_bag`, `map`을 잃는 효과가 있다. 원작 끝에도 짐·치부책 미회수다. `sheet.items`는 2화와 정확히 같은 정의이며, 새 게임 초기 소지품이 회수 증거가 되지 않는다. `newGame()`으로 다음 화를 시작하면 안 된다. |
| 이름·지위 | 실제로 받은 `ep04_name_known`, `ep04_ruler_known`, `ep04_title_known` 등 모든 기존 플래그를 보존한다 | 4화 c040~c043의 실명·통치자·라 쿤 연결을 5화에서 지우지 않는다. 5화 c032는 회고이며 최초 공개를 재연하지 않는다. |
| 변장·복장 | 실제 갈색 변장·귀찌 착용 상태와 잔여 수치를 그대로 보존한다 | 4화 끝은 젖은 청록 실내복이다. 5화 밤 컷은 가려진 부분이 많고 밝은 상의 일부만 확인된다. 중간 환복·짐 반환·변장 해제는 근거가 없다. 아침 보라색 상체와 뒤의 분홍 궁정복은 원작에 보이는 장면으로 전환한다. |
| 시간 | 밤의 침실에서 아침의 궁(c010), 낮의 알현실로 시각이 변한다 | 원작은 정확한 시각·경과 시간을 주지 않는다. 이 YAML의 `time: 0`은 자동 수치 차감 없음이며 시간이 멈췄다는 설정이 아니다. 귀찌를 7로 회복하거나 임의로 하루 차감하지 않는다. 캠페인의 기존 시계가 정산한다면 전환에서 한 번만, 실제 저장 상태에 적용해야 한다. |
| 선택·수치 | 기존 `state.flags`, `said`, `spoken`, 로그·난수·트랙·상태를 유지한다 | 탈출·거리 요구·침묵 등 실제 선행 선택을 기억한다. 5화 내부가 선행 선택과 충돌하는 판은 부모의 연결 처리 대상이며 원작 경로로 강제 덮어쓰지 않는다. |

5화는 `후속_시작` 등 선행 플래그를 임의로 생성하지 않는다. 본 작업의 독립 새 게임은 적재·내부 구조 검사용이며 캠페인 진입 계약을 대신하지 않는다.

## 5→6

| 항목 | 넘길 값과 다음 처리 |
|---|---|
| 경계 | `ep05_c055` 또는 `ep05_reply_short` → `ep05_boundary`. 낮의 알현실에 아시나와 라 쿤만 남아 있다. 새 아침·새 하룻밤·추가 식사·이동을 만들지 않는다. |
| 원작 마지막 답 | `ep05_시선답변`, `ep05_지난밤답변`, `ep05_지난밤되물음`은 각 실제 발화 뒤에만 참이다. `spoken`, 실제 로그의 정확한 말을 함께 넘긴다. |
| 겹치는 인사 | 원작 경로의 c055 마지막 두 문장은 6화 c001에 반복된다. 두 전사 원본은 보존하되 연속 재생에서는 한 번만 발화한다. `ep05_지난밤답변`과 `ep05_지난밤되물음`이 실제로 참인 판은 6화 c001을 다시 말하지 않고 c002 상대 반응으로 이어야 한다. 현 6화 YAML은 이를 아직 적용하지 않았다. |
| 되묻지 않은 판 | `ep05_reply_short`는 시선 설명만 말한다. 지난밤 안부·되물음 플래그를 만들지 않는다. 이 판을 무조건 6화 c001 또는 원작 c002로 연결하면 하지 않은 인사를 대신 발화하거나 “그렇게 마음에 들었다면”이라는 원인 없는 반응을 만든다. 부모의 공유 대화 패치가 실제 답에 맞는 라의 첫 응답을 만든 뒤 공통 문답으로 연결해야 한다. 이 YAML은 자동으로 다음 화를 접속하지 않는다. |
| 아시나 이름 | 누르의 c022 “아시나님”은 누르가 그렇게 불렀다는 사실뿐이다. 라·나시르가 이름을 들었다는 전역 플래그를 켜지 않는다. 현 6화 c024의 “아시나예요.” 뒤 `ep06_현장_아시나이름` 공개를 앞당기지 않는다. |
| 관객 비공개 정보 | `ep05_독자_*`는 원작 회고·궁정 별실 대화의 관객 정보다. 특히 자이드·대재상·족장·“그 일”·조사 의향·소환 명령은 아시나 지식으로 전환하지 않는다. 5화 `facts`에는 관객 전용 플래그 조건이 없다. |
| 인물 동일성 | `ep05_남성`, `ep05_라쿤`은 `lore: 베히다트`를 공유한다. 여성·누르는 `lore: 누르`, 청발 신하는 후속 6화와 같은 `lore: 나시르`이지만 이름표는 공개 전의 “푸른 머리 신하”다. 흑발 신하의 이름·자이드와 대재상의 동일인 여부는 미확정이다. |
| 짐·변장·트랙 | 회수·은발 노출·귀찌 충전·부상·호감 획득 사건이 없다. 실제 아이템·트랙·선행 플래그·갈색 변장을 그대로 넘긴다. 분홍 궁정복의 밝은 어깨는 피부이며 흰 옷이 아니다. |

## 공유 패치 입력

실제 질문 자리는 c020 뒤의 시녀 동행 질문, c045 소환 전달 뒤 응답, c053 두 질문 뒤 하나의 답변이다. 현재 고정 선택은 내부 구조다. 임의 대사·괄호 행동과 무응답 처리, 정확한 말·대상·속마음 여부의 계승은 공유 대화 패치가 담당한다. 선택지 문구를 자유 입력으로 몰래 바꾸거나 원작 발언을 대신 적지 않는다.

`goals`가 필요한 별도 불확실한 행동은 이번 원작 범위에 없다. 10화의 제거된 손목 판정처럼 모두 같은 성공인데 쓰이지 않는 지연 플래그를 가격으로 붙이는 방식을 사용하지 않았다.
