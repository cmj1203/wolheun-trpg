# 7·9화 정체성·소지품·관객 시점

2026-11-09. 이 작업은 두 화의 대본과 전용 테스트만 변경했다. 공유 로어 통합과 표시 시점 런타임은 다른 담당의 작업이다.

## 정체성과 소지품

- `ep07_은발남성`, `ep07_은발남성독백`은 모두 `베히다트`에 연결했다. 4화에서 공개된 이름과 같은 인물의 대화를 계승한다. 표시 이름은 그대로다.
- `ep09_장발`, `ep09_대족장`은 정확히 `ep09_장발대족장`, `ep09_동행`은 정확히 `ep09_대족장동행`에 연결했다. 잘릴과의 동일성은 미확정이다. 임시 키가 확정된 별개 인물을 뜻하지 않는다.
- `ep09_c001.effects.lose`의 가방·지도 재압수를 제거했다. 실제 엔진 진입에서 이전 재고 전체를 유지한다.
- `ep07_c003`의 마지막 줄은 기존대로 `ep03_짐_수중없음=false`, `ep07_짐_부분반환=true`만 적용한다. 반환품 목록은 만들지 않았다. 치부책은 실제 아이템 정의에 없으며 새로 추가하지 않았다. 4화 압수 효과는 수정하지 않았다.

근거는 `shared-lore-ep05-10-contract.md` 전체 배우 표, `docs/continuation/ep07/continuation.md`의 4화 이름 계승, 7화 원문 c002–c004, 9화 연결 문서의 소지품 상태와 원문 c033–c043·c063·c078–c084다.

새로 연결된 7화 두 배우에만 `presentation: cg`를 선언했다. 표정은 공유 베히다트의 기존 반응이 실제 요구하는 여섯 값인 `neutral`, `dumbfounded`, `intrigued`, `wary`, `sneer`, `menacing`으로 한정했다. 입식 별칭이나 가짜 파일은 추가하지 않았다. 회귀는 두 배우의 선언된 표정과 실제 대사 CG를 검사하며 미선언 표정·없는 CG·CG 없는 줄을 거절하는지 확인한다.

## 관객 시점 선언

`docs/lead_check63/viewpoint_types.md`를 직접 읽었다. 다음 선언은 원작 `script.md`와 `scenes.json`의 공개 대상에 근거한다.

| 관객 비트 | 근거 |
|---|---|
| `ep07_c008`–`ep07_c019` | s03은 아시나가 모르는 호위 배정 면담이다. 타무라 설명 삽화와 나시르·카림 발언을 포함한다. |
| `ep09_c078` | 감지자를 보여 주는 독자 전용 컷이다. |
| `ep09_c081`–`ep09_c084` | 아래쪽 장발 인물과 동행의 대화, 대족장 호칭·칼은 독자 정보다. |

9화 c079–c080과 두 반응 선택 비트는 주인공 시점을 유지했다. 아시나가 직접 시선을 느끼고 반응하는 자리다. c083에 아시나가 숨어 있는 그림이 있어도 발화는 아래쪽 인물들의 대화이며, 아시나가 들었다는 사실을 만들지 않았다. 화자 부재·빈 cast만으로 판정하지 않았다.

기존 비트 경계로 시점을 나눌 수 있어 새 ID나 비트 분할은 없다. 고정 대사·CG·줄 효과·이동 순서·아틀라스 연결은 그대로다.

선언 확인 시점에 `loadScenario`와 `checkScenario`는 두 화 모두 통과했지만 파싱된 관객 비트는 각각 0개였다. 원본 YAML에는 각각 12개·5개의 선언이 존재했다. 파서 전달과 관객 기억 제외 런타임은 담당자 통합 전이며, 이 결과를 시점 기능 검증 완료로 해석하지 않는다.

## 회귀와 검증

`app/tests/ep07-09_identity_inventory.test.ts`는 실제 Engine 진입의 소지품 보존, 실제 대화 문맥에 들어가는 동일 인물의 기억과 잘릴 대화의 제외, 독백 프롬프트의 인물 자료 선택, CG·표정 검증을 다룬다. 독백 검사는 구별 가능한 입력 자료를 전달하여 로어 선택을 확인하며 원작 문장을 고정하지 않는다. 모델·서버·브라우저 요청은 없다.

수정 전 재현은 3개 통과·6개 실패였다. 가방·지도 소실, 네 배우의 잘못된 로어 연결, 독백 인물 자료 누락을 재현했다. 한글 경로의 URL 인코딩 때문에 처음 실행이 실패한 것은 테스트 경로를 `join(import.meta.dir, ...)`로 고친 뒤 재현에서 분리했다.

기존 7화의 동일 인물 부정 기대는 동일성 유지로 고쳤다. 기존 9화의 귀찌·핀만 남는 기대는 이번에 제거한 재압수 효과를 고정하던 값이었다. 첫 진입은 실제 sheet 아이템 전체, 이후 경로는 진입 재고 전체를 보존하도록 정확한 배열 비교를 유지했다.

관객 선언 전 집중 검증은 세 파일에서 25개 통과·실패 0개였다. 선언 후 같은 세 파일의 집중 회귀도 종료 코드 0으로 통과했다. `tsc --noEmit`은 수정 전과 수정 후 모두 종료 코드 0이다. `bun check --no-script`는 이 환경에서 `Script not found "check"`로 실행되지 않아 설치된 `tsc`로 검사했다.

공유 로어가 동시 변경된 뒤에도 `withNotes` 오류 배열은 수정 전과 완전히 같았다. 7화 16건은 독립 화에 없는 기존 1화 지식 참조다. 9화 28건은 같은 참조 16건과 기존 황제·황제독백 표정 불일치 12건이다. 이번 변경으로 오류를 추가하지 않았으며 공유 반응·기존 검증을 삭제하거나 완화하지 않았다.
