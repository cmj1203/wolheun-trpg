# 6화 생성 전 그림 매핑

2026-11-09. 부모에게 넘길 생성 준비 매핑이다. 그림 READY가 아니며 생성·검수·설치를 승인하지 않는다. 부모의 명시 GO와 전역 슬롯 배정을 기다린다.

현재 YAML: `app/content/ep06_library.yaml` · SHA-256 `17cc7cc5578b9981ee75339ff6fb74c707433fc2e220fef9ce886455d28bd236`. 최신 원작·YAML 입력 해시는 mapping.json과 candidate-manifest.json에 보존했다. 원작 16장·65컷 및 컷 밖 발화 2곳을 포함한다. 현재 79비트·CG 참조 65개·실제 줄 앵커 157개(무언 7개·구현 분기 서술 6개 포함)와 선택지 12개를 모두 연결했다. 앞선 중간 보고의 163줄은 오기이며 실제 파싱 집계는 157줄이다.

고유 필수 후보는 **75개**다. 65컷에서 텍스트 전용 인접 컷 5곳은 이미지를 유지하고, 내부 패널의 사건·관점·복장 공개를 나누는 15개 후보를 더했다(65 − 5 + 15 = 75). 전체 443개 참조를 새 그림 수로 환산하지 않았다. c029 무언 한 줄의 두 번째 패널만 파생 표시 단계로 기록해 표시 앵커는 158개다. 실제 YAML에 두 번째 줄이 존재한다는 뜻이 아니다.

생성 트리 전체에는 원문 확인 크롭 4개만 있다. 생성 후보·진행 생성·완성 그림은 발견되지 않았다. 최상위만 조사한 결론이 아니다. gen 전체와 기존 6화 로그 7개를 조사한 경로·해시는 JSON의 inventory에 있다. 네 크롭은 보존했고 새로 만들거나 덮어쓰지 않았다. 생성 호출 0회, 취소 0회, 검수 통과 0개다.

## 근거와 읽는 법

- 최신 6화 29컷 전사 정정과 복장 감사가 우선이다. 원문에 없는 애첩·구속·필수 사막 통과·맨등 요구는 매핑에 넣지 않았다. 9→10의 포획·공격도 추가하지 않았다.
- 원본 경로와 반열린 컷 좌표는 cuts.json과 scenes.json으로 대조했다. 대사 포함 원본 SHA-256과 클린 입력 SHA-256을 모두 기록했다. 클린 세로 컷과 gen/source 크롭은 완성 자산이 아니다.
- mapping.json의 source_entries는 원작 순서, literal_yaml_anchors는 현재 YAML 157줄, display_anchors는 내부 무언 단계 1개를 더한 후보 연결이다. 각 앵커는 실제 파일 행·비트·배열 위치·화자·정확한 문장/빈 문자열·관점·분기·최초 공개·후보 파일명을 갖는다.
- 후보의 original_sources.crop은 원본의 확정된 전체 컷 범위다. 복합 컷은 내부 패널 순번·대상을 panel_provenance.selector로 지정했다. 내부 패널 경계 픽셀을 임의로 추정하지 않았다. 생성 입력을 준비할 때 해당 원본 패널만 분리한다.
- c010의 눈·흰옷 심상, c039의 사막 설명, c058의 북대륙 자연은 같은 시점의 원작 설명 합성이므로 원작 안 겹침을 유지한다. c028은 이어지는 같은 통로 그림이며 새 이동 사건이나 두 번째 필수 입력을 만들지 않는다.
- 후보의 earliest_reveal_anchor보다 앞에서 그 그림을 쓰지 않는다. 이전 화에서 인사가 끝난 경우 c001은 기존 조건대로 건너뛴다. 나시르 얼굴 인지 c018과 이름 소개 c021을 구별한다. c034 이전에 가림천을, c031 이전에 밀명 회상을, c062 이전에 사막 감상 회상을 먼저 보여 주지 않는다.
- 개별 후보는 모두 mapped다. 기존 후보 없음, 독립 Claude 검수 미실시, 연결 승인 없음. 생성 뒤 원작과 나란히 독립 Claude 검수하고 FAIL만 수정한다.

## 소유자 재조정과 대기 조건

이 매핑은 YAML을 수정하지 않았다. 현재 전체 컷 CG를 내부 패널 후보로 나누는 12컷, 텍스트 전용 유지 5컷, c014 앞 여백의 연결은 소유자가 반영해야 한다. c029는 실제 한 무언 줄에서 두 패널을 순서대로 보여 주는 계약을 소유자가 정해야 한다. 매핑 파생 단계를 실행되는 기능으로 보고하지 않는다.

공유 파일·GM·UI·서버·모델·브라우저·다른 화 그림은 건드리지 않았다. 11개 audience 비트와 분리된 질문/독백은 현재 YAML 관점을 그대로 기록했으며 원작 속마음을 현장 지식으로 승인하지 않는다. c026·c027 미확정 개인 화자, c062 마지막 말풍선의 발화/독백 미확정도 정본 그대로 남겼다.

YAML 소유자가 대사·화자·비트 ID·CG·분기·관점을 바꾸면 input_hashes를 비교하고 바뀐 앵커만 재조정해야 한다. 원문 정리 파일이 바뀌면 해당 컷·패널·공개 시점도 다시 대조한다.

다음 단계는 부모의 명시 GO와 전역 최대 3개 중 슬롯 배정이다. 슬롯을 받기 전에는 생성하지 않고, 배정 뒤에도 이 레인은 native 호출을 한 번에 하나만 시작한다. 정상 진행·완료 작업을 취소하거나 중복 생성하지 않는다. 현재 단계 종료 조건은 세 파일의 전 컷/앵커 매핑과 경로·해시·고유 후보 수 검증 및 ls 증거다. 검증 결과는 verification.json에 남긴다.
