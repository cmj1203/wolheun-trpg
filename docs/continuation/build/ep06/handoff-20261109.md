29행의 정본 위치·실제 코드·실행 회귀 대응은 `audit-correction-20261109.md`를 따른다. 정정 컷은 c001/007/008/011/024~027/029/032/046~049/051~065다. 원문 대사·화자·사건·공개 조건·기억을 교정했으며 원작에 없는 애첩 선언·구속·필수 사막 통과·맨등 요구를 제작 사실로 남기지 않았다. 최종 원작 미확정 표도 교정서에 그대로 보존했다.

## 5→6 최소 연결 계약

부모는 `ep05_boundary`의 `continue_ep06` 선택을 6화 `ep06_c001`에 연결하고 기존 상태와 실제 발화 플래그를 그대로 넘기면 된다. 새 장 `newGame`을 호출하지 않는다.

| 경우 | 실제 선행 상태 | 6화 진입·첫 입력 |
|---|---|---|
| 독립 새 판 | 5화 시선 답변·인사 플래그 없음 | c001 두 인사 → c002 제안 → c003 거절 입력 |
| 표준 답변 완료 | c055가 만든 시선답변·지난밤답변·지난밤되물음 모두 참 | c001 무발화 → c002 제안 → c003 거절 입력. 직접 c002 진입도 동일 |
| 짧은 답변 완료 | ep05_reply_short가 만든 시선답변만 참 | c001 무발화 → c005 접근 → c008 목적 입력. 직접 c005 진입도 동일 |

실제 플래그 이름은 `ep05_시선답변`, `ep05_지난밤답변`, `ep05_지난밤되물음`이다. 짧은 응답을 인사 미완료로 취급하지 않는다. 짧은 경로에서는 미선택 감사·되물음·하렘 칭찬·거절 문답을 전부 재생하지 않는다. 지도에서도 c002~c004·거절 분기를 방문한 것처럼 표시하지 않는다.

표준/짧은 양쪽 모두 실제 5화 Engine이 만든 플래그로 회귀를 실행했다. 현재 5화 시작 `ep05_entry`와 `ep04_distance_kept → ep05_c010`은 읽기만 했으며 수정하지 않았다. 출처 문서 양쪽의 인사는 보존했다.

기존 저장에 발화 플래그가 없다면 부모가 실제 발화 기록으로 표준·짧은 응답을 먼저 구별해야 한다. 두 경로를 구별할 수 없는 저장을 표준 인사 경로로 자동 추정하는 이행은 구현하지 않았다. 공유 경계 등록·로더 결합·전체 캠페인 지도·이 저장 이행은 부모 소유다.

6→7은 같은 도서실의 c001 조사 문답으로 이어진다. 일부 짐 제시·반환 설명은 7화 c002~c003, 오늘 조사 종료는 c005다. 6화에서 조사 종료·석방·출궁·짐 전부 반환을 만들지 않는다.
