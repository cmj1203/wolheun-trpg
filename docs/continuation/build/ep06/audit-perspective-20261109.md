추가 ID는 ep06_c045_question, ep06_c056_interior, ep06_c056_response, ep06_c060_interior, ep06_c061_question, ep06_c064_reply다. 각 분리는 원문 발화 순서·동일 cut·CG·줄별 sets를 그대로 보존한다. 해당 원본 비트의 진입 효과는 없고 시간은 모두 0이다. 동일 지도 노드 안에 새 ID를 순서대로 추가했으므로 지도는 21노드·27간선을 유지한다.

c056은 공개 질문 → 비공개 시험 독백 → 공개 응답 자리다. 원래 choices를 마지막 공개 ep06_c056_response로 옮겼다. 이 자리는 빈 서술 한 줄로 같은 CG만 유지하며 질문을 다시 읽거나 새 발화를 만들지 않는다. 독자 장면 자체에서 플레이어 답을 받지 않는다. c045/c061/c064는 독백 뒤 실제 공개 발화로, c060은 실제 공개 발화 뒤 속마음으로 잇는다.

## 미확정과 주인공 시점

화면 밖 도착 보고(c017), 회색 미확정 풍선(c026), 개인 연결이 미확정인 한숨·속마음(c027), 라·나시르의 눈짓(c029)만으로 audience를 선언하지 않았다. c029에 임시로 붙였던 독자 관찰 플래그도 제거했다. 인물 부재 그림만으로 주인공이 볼 수 없었다고 확정하지 않는다. 아시나 자신의 경유 속내(c037), 길 질문·탈옥 회상(c052), 사막 감상(c062)도 주인공 시점이다. c026/c062의 발화·독백 불확실성과 c017/c027의 개인 화자 미확정은 원작 표 그대로 유지했다.
