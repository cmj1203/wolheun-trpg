# 6화 전사와 실제 원본의 차이

원작 전사 문서의 c024·c025 및 두 번째 컷 밖 대사가 실제 원본과 다르다. 읽기 전용 원문 문서를 수정하지 않고 허용된 6화 구현에서 직접 확인한 문장을 반영했다. 풍선 줄바꿈만 이어 적었다.

| 위치 | 준비된 전사 | 실제 원본과 구현 |
|---|---|---|
| c024 아시나 독백 | 그래, 나한테 관심이 많기는 무슨… | 빨리도 물어본다, 나쁜 놈. |
| c025 나시르 첫 풍선 | 다시 뵙는군요. | 또 뵙게 되어 반갑습니다. 아시나님. |
| c025 나시르 둘째 풍선 | 옷을 갈아입으시니 | 옷을 갈아 입으시니 몰라보겠습니다. |
| c025 뒤 컷 밖 풍선 | 아주 어여쁘십니다. | 아주 어여쁘시네요. / 라 쿤께서는 좋으시겠습니다. |

원본 `work/ep06/merged/ep06_007.png`에서 [12620,18087), [18345,23014), [23014,24881)을 각각 잘랐다.

- `assets/ep06/gen/source/ep06_c024.png`
- `assets/ep06/gen/source/ep06_c025.png`
- `assets/ep06/gen/source/ep06_gap025.png`

첫 번째 컷 밖 대사 「말도 안 되는 소리.」는 원본 `work/ep06/merged/ep06_004.png`의 [12355,15183)에서 직접 확인했다. 검증 입력은 `assets/ep06/gen/source/ep06_gap014.png`다. c013 뒤·c014 본문보다 앞에 둔다.

위 네 입력 그림을 직접 열어 문장을 확인했다. c025 뒤 풍선은 전사 문서보다 문장이 하나 더 있으므로 「라 쿤께서는 좋으시겠습니다.」를 누락하지 않는다. 나머지 원작 컷의 대사는 준비된 전사 문서를 사용했으며 원본 16장 전체의 문장별 재검독은 완료 증거가 없다. 원작 전수 일치 판단 전에 원문 담당의 재검독이 필요하다.
