# 6화 독립 내부 구현과 연결 요구

`app/content/ep06_library.yaml`은 `ep06_library` ID의 독립 시나리오다. 65개 원작 컷, 질문·답변 분리 2개, 선택 태도 분기 6개로 총 73비트다. 7장면, 6개 비판정 선택, 지도 19노드·24간선·6화 장 구분을 선언한다. 현재 구현은 정해진 답변의 말투·몸짓 선택이다. 임의 대사·행동 입력은 부모의 공유 대화 패치 통합 전까지 미구현이며 자유 대화 완료가 아니다.

## 정확한 경계

| 구분 | 비트 | 장면·상태 |
|---|---|---|
| 진입 | `ep06_c001` | 전날 밤 이후 궁정에서 아시나가 라에게 아침 인사한다. 지난밤에 일어난 구체적 사건은 추가하지 않는다. |
| 첫 선택 | `ep06_c003` | 하렘 정주 권유를 듣고 거절하기 직전이다. |
| 이름 소개 | `ep06_c021`의 둘째 발화 | 서기관 나시르라는 소개를 직접 듣는다. c018의 얼굴 인지와 구별한다. |
| 비공개 회상 | `ep06_c031`~`ep06_c032` | 라와 나시르만 있는 앞선 대화다. 정체 조사 명령과 시하드 호칭은 독자 전용이다. |
| 최종 비트 | `ep06_c065` | 도서실에서 나시르가 여행 이유를 잠정적으로 이해하는 독백을 한다. |
| 내부 종료 | `ep06_internal_end` | 장 경계 표지다. 출궁·귀환·조사 완료·여행 재개 결말이 아니다. |

5화의 정확한 최종 비트와 7화의 정확한 첫 연결 비트는 이 작업에서 확정하지 않는다. 특히 5화 원작 감사가 미완료이므로 임의 다리 장면을 붙이지 않았다. 부모가 선행 종료 상태와 후행 시작 상태를 대조한 뒤 실제 경계와 지도 간선을 연결해야 한다. 6화 끝까지 곧바로 건너뛰는 연결도 만들지 않는다.

## 승계 상태

| 항목 | 6화 근거와 처리 |
|---|---|
| 소지품 | `sheet.items`는 현 병합 계약에 따라 2화의 정규 목록과 동일하다. 실제 소지품의 소유·컨테이너·손상·압수 상태는 선행 저장에서 승계해야 한다. 이 화에는 gain/lose가 없다. |
| 독립 새 판 | 엔진 `newGame`은 시트의 네 항목을 모두 넣는다. 이는 파서·행동 검사용 기본값이며 6화 시작 소지품이 네 개라는 원작 주장이나 캠페인 초기화 지시가 아니다. |
| 수치 | 선행 체력·정신력·귀찌·행운·의심·관계를 그대로 보존한다. 6화 비트는 time=0이고 수치 변화·판정·자동 주사위가 없다. 정확한 경과 시간은 이 화만으로 확정하지 않는다. |
| 외형 | 처음에는 갈색 머리·금색 머리 사슬·분홍색 궁정복이다. c034 이후 얼굴 가림천을 유지한다. 사막복으로 바꾸거나 은발 공개를 새로 만들지 않는다. |
| 과거 | 크라챠 여행 목적, 사막의 위협·간자 의심, 이전 청발 남자와의 만남은 6화 회상의 전제다. 구체적인 선행 사건·등장 비트·은발 남자의 정체 인지를 추측하지 않는다. |
| 라와 시하드 | 내부 `lore: 베히다트`로 같은 사람을 가리키되 표시명은 라다. c032 호칭은 아시나 부재 회상이며 기존 아시나 지식은 승계 상태에 맡긴다. |
| 나시르 | 이름 전의 청발 남자·회상·이름 후 발화·독백은 모두 `lore: 나시르`로 묶는다. c020 표시명은 푸른 머리 남자로 유지한다. |
| 아시나의 속내 | 시그렌은 경유지였다는 독백을 나시르가 들은 것으로 처리하지 않는다. 시그렌 국적·왕족 신분을 확정하지 않는다. |
| 끝 상태 | 현재 도서실에 아시나와 나시르가 있으며 라는 없다. 나시르의 칭찬만 발생한다. 애첩 동의·조사 해제·출궁 허가·완전한 신뢰·짐 반환·새 장비는 없다. |

## 부모가 소유한 통합 작업

1. `loadCampaignScenario`의 실제 전체 캠페인에 5→6→7 경계를 연결하고 기존 저장 재개와 지도 과거 재시작을 확인한다. `ep06_library`는 `ep01_desert`를 사칭하지 않으므로 단독 적재가 앞 화를 자동 연결하지 않는다.
2. 원본 16장 전수 문장 검독을 재확인한다. 준비된 전사에서 실제 원본과 다른 c024·c025·보충 대사를 발견해 구현에서는 고쳤다. `source-corrections.md`에 원본 좌표와 수정 문장을 남겼고 원문 소유 문서는 변경하지 않았다.
3. 공유 대화 패치를 여섯 실제 문답 지점에 통합한다. 입력하지 않은 말을 고정 답변으로 대신하지 말고, 말·침묵·혼잣말은 판정하지 않는다. 불확실한 시도에만 기존 goals 계약을 쓰며 hit/mixed 모두 행동 목표 달성을 유지한다. 현재 파일은 free/goals를 흉내 내는 빈 계약을 넣지 않았다.
4. 전체 캠페인과 원래 lore를 결합해 `withNotes`를 검사한다. 기존 lore의 앞 화 `after` 참조를 삭제해 단독 통과시키지 않는다. 나시르 캐릭터의 공유 lore 정의와 6화의 실제 공개 플래그 연결도 부모가 통합해야 한다.
5. 원작 컷의 Astra 보정·확장 그림을 마련하고 원본과 나란히 검수한다. 현 CG 65개는 실제 존재하는 원작 정리 입력이며 완성 자산이 아니다. 새 원본 크롭 4개도 검증 입력이다. 입식·배경 목록과 모든 출연 슬롯은 비워 다른 화 자산을 대체 그림으로 쓰지 않았다.
6. 통합 뒤 PC 브라우저·실제 GM 모델·저장 재개로 전체 흐름을 확인한다. 이 작업에서는 서버·브라우저·모델을 사용하지 않았다. UI 연출·줄을 읽는 동안 CG가 유지되는 실제 화면·임의 입력 반응은 미검증이다.

## 행동 검사 범위

`app/tests/ep06_library.test.ts`는 64개 태도 조합의 원작 컷 순서·실제 지도 간선·종료·수치/소지품 보존·판정 없음·모델 호출 없음·보충 대사 위치와 이름 전 표시명을 검사한다. 별도 지식 검사에서 실제 문답 지점 전후의 공개 플래그를 확인한다. 기존 화 검사에는 6화의 컷과 지식 경계가 없어 전용 파일을 추가했다. 엔진·테스트 공개 API를 새로 만들지 않았다.

검증 실행 결과는 `verification.md`와 실행 로그에 남긴다. 독립 검사 통과는 완성 자산·캠페인·화면·실제 모델 QA 통과를 뜻하지 않는다.
