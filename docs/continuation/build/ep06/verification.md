시나리오 적재와 검사, 자산 존재 확인, 전체 캠페인 적재 및 lore 결합은 실제 엔진 모듈을 직접 호출했다. 테스트는 원래 Engine과 FakeGm을 사용했다. 외부 모델·앱 서버·브라우저는 사용하지 않았다.

전체 프로젝트 타입 검사는 실행하지 못했다. 로컬 tsc가 없고 현재 실행기의 `bun check --help`도 `Script not found "check"`로 실패했다. 새 의존성은 설치하지 않았다. YAML 언어 서버도 설치되지 않아 엔진의 실제 적재·정합성 검사로 확인했다.
