## 입력과 기존 작업

YAML SHA-256: `82406d484ef74558c0589aa738d52ee89a51c54b9979d8f80df38a8e6bdb8d24`. 기준선 문서의 `80e8c9444197865580a88161a3ae8cf97601f99566f0b0baef563f75d61efe1f` 이후 c002 관객 비트 분리와 audience 시점 추가를 읽어 반영했다. YAML은 수정하지 않았다.

생성 폴더를 하위·숨김 경로까지 재귀 조사했다. 16개 파일 전부 source/의 원작 페이지이며 merged 원본과 바이트·SHA-256가 같다. 생성 후보·생성 로그·대기 작업은 발견하지 못했다. 최상위 0개만으로 판단하지 않았다. 독립 검수 통과·실패 0개, 이번 네이티브 호출 0회다. 다른 화의 진행 중 작업은 조회·취소·재생성하지 않았다.

입력 전체 해시·원본 16개 경로/크기/해시·생성 트리 16개 파일은 두 JSON에 기록했다. 원본 크롭은 페이지 좌표 [x,y,너비,높이]이며, RGB 픽셀 SHA-256도 기록했다. 후보 파일 존재와 원작 입력 존재를 구별한다.
