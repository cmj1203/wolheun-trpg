## 선택과 원작

고정 선택은 내부 검증용 임시 구조다. 선택적 자유 대화의 공유 최소 패치는 부모가 별도로 작성 중이며 이 수정에 포함하지 않는다.

c024에서 하렘 규모 질문 또는 거주자 질문을 선택한다. 거주자 질문은 제작 대사 한 줄을 추가하며 이후 c025–c029 원문 답변이 이어진다. c057에서 조용히 확인하거나 누르에게 인기척을 알리고 확인한다. 알림을 고르면 누르에게 말하는 제작 대사가 실제로 나오며 선택 플래그가 남는다. 모두 확실히 할 수 있는 문답·확인 행동이므로 판정하지 않는다. 회상·독백·궁정 알현에는 입력을 걸지 않는다. 자유 입력·goals 계약을 새로 만들거나 가짜 성공·혼합 결과를 선언하지 않는다. 지도는 10장면과 두 실제 선택 비트를 별도 노드로 구분하고 장을 선언했다.

## 지식과 화 경계

23개 공개 사건은 해당 컷 마지막 대사 sets에 기록한다. 공개 플래그는 독자 사건 기록이며 자동으로 아시나 지식이 되지 않는다. facts는 궁정 알현·순례 서술·베히다트 독백을 아시나가 듣지 못했다고 명시한다. 수첩이나 공유 lore를 이 파일에서 새로 주입하지 않는다. 상위 withNotes 통합 시 게디크·자키야·순례·연회 허가·거절 정보가 아시나 질문 모드에 새지 않는지 반드시 검증해야 한다.

7→8: 원작 정리 문서는 근접 접촉, 갈색 변장과 실내복, 카림 선행 통성명과 밖 대기 인식을 대조했다. 실제 7화 저장 상태·물품·수치는 미검증이다. 이를 진입 플래그로 새로 가정하지 않는다.

## 그림과 화면 의존성

원본 입력 16장을 assets/ep08/gen/source에 보존했다. 62개 CG는 원본 페이지와 컷 좌표를 참조하며 work 경로를 서비스에 넘기지 않는다. 이는 원작 입력이지 Astra 편집 완료 그림이 아니다. 말풍선 제거·16:9 확장·복장별 입식·표정·배경은 모두 미완이다. c002·c036·c040·c049의 긴 원본은 전체 좌표를 유지하며, 실제 화면에서 줄별 소화면 전환과 가독성을 검수하고 필요하면 Astra 결과를 하위 CG로 나눠야 한다. 동일 컷의 줄을 읽는 동안 CG를 비우지 않는다.

PC 브라우저 재생, 실제 GM 모델, 저장·재개·지도 클릭 복원, 앞뒤 저장 통합은 부모 담당이다. 서버나 모델을 실행하지 않았으며 FakeGm은 호출이 없음을 검사하는 감시 대역일 뿐 실제 GM 통과 증거가 아니다. yaml-language-server가 설치되지 않아 YAML LSP 진단은 수행할 수 없으며 실제 프로젝트 로더·검사로 검증한다.

## 행동 테스트 기준

실제 Engine 경계에서 두 선택 경로가 끝까지 원작 컷 순서를 유지하고 판정·난수·수치·소지품을 소비하지 않는지 검사한다. 잘못된 next, 선택 효과 누락, 강제 free 또는 판정 삽입이 회귀 원인이다. 기존 사막 테스트는 새 8화 콘텐츠를 로드하지 않아 이 계약을 대신하지 않는다. 생산 코드 공개 훅은 추가하지 않는다. 화자 미확정·지명 차이는 실제 line 이벤트에서 확인한다.
