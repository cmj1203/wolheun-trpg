## 소유자와 재대조할 앵커

원작/YAML 소유자가 동시에 작업하므로 다음은 연결 시 재대조 목록이다. 해당 파일은 이 작업에서 고치지 않았다.

- 컷내분할 · ep10_c005, ep10_c019, ep10_c027, ep10_c034, ep10_c045, ep10_c052, ep10_c056, ep10_c078 · 현재 YAML은 같은 컷의 모든 줄에 하나의 CG ID를 반복한다. 패널별 파일로 교체할 때 원문 순서의 줄별 참조를 소유자가 반영해야 함
- 줄내침묵앵커 · ep10_c005, ep10_c056, ep10_c078 · 같은 줄 안의 두 패널 또는 최종 줄 뒤 반응은 candidate_sequence.phase의 순서로 구분함. 현재 YAML에 별도 정지점은 없으므로 소유자가 원문을 유지한 줄/침묵 앵커로 조정할 대상
- 선택지상속 · ep10_c026, ep10_c029, ep10_c034, ep10_c052 · c026 머리 유보·c029 가족 유보·c034 이름만 확인 응답은 이제 각각 동일 CG를 명시함. 선택 메뉴 자체는 직전 그림 유지. c034 메뉴에 답변 그림, c052 메뉴에 호칭 제안 그림을 미리 띄우지 않음

## 이후 검수

모든 후보는 현재 mapped이며 실제 파일 없음·독립 QA 미실행이다. 생성·자가 검수로 qa-pass를 적지 않는다. 부모가 배정한 독립 Claude가 원작과 후보를 나란히 보고 얼굴·복장·소품·패널 순서·가림·공개 앵커·16:9를 판정한 뒤 FAIL만 보수한다. 마지막에는 candidate-manifest.json에 판정 근거·실제 파일·SHA-256을 넣고 실제 존재를 확인한다. 검수 없이 YAML에 연결하거나 그림 READY로 보고하지 않는다.

기계 판독 대장: `mapping.json`, `candidate-manifest.json`. 기준 입력 전체 해시와 원본 18장 해시는 두 대장에 포함했다. 현재 단계의 구조·존재 검증 기록은 `verification.json`에 남긴다.
