# 10화 원작 참조 입력 준비

승인된 92개 후보의 실제 참조 PNG 92개를 준비했다. 전체 컷 입력 70개와 분할 패널 입력 22개이며 원작 18장·78컷에 대응한다. 파일은 `assets/ep10/gen/inputs/<후보 ID>.source.png`에 있다. 합계 358,466,465바이트다.

모든 입력은 실제 원본 페이지에서 정수 좌표로 잘라 저장했다. 리사이즈·색 변환·알파 변경·글자 제거·가림 변경·새 인물/사건/신체 추가를 하지 않았다. 저장된 PNG를 다시 열어 원본 해당 영역과 모드·크기·디코딩 픽셀 SHA-256이 같은지 92개 모두 대조했다. 원본 PNG와 입력 PNG의 파일 SHA-256도 대장에 기록했다.

8개 컷을 나눈 22개 패널은 원본 내 위→아래 순서다. 각 컷에서 분할된 행을 모두 이어 붙이면 승인된 전체 원본 범위가 되며 누락·중복 행은 없다. 원작의 패널 경계가 겹친 곳에서 앞 패널의 꼬리나 배경이 뒤 입력에 남는 것은 원본 픽셀 그대로이며 새로 그린 부분이 아니다. 패널별 정확한 페이지 절대 좌표와 컷 상대 좌표는 대장에 있다.

현재 `ep10_아시나` 화자 메타데이터·133개 앵커·92개 예정 출력·최초 공개 시점은 승인 대장과 동일하다. c070은 원본 말줄임표 풍선을 보존하며 화자는 여전히 미확정이다.

기존 gen 경로와 후보 파일은 준비 전 없었다. 새 참조 파일만 배타적 생성으로 저장했다. 기존 승인 매핑·후보 대장·YAML·테스트·공유 코드·다른 화 자산은 수정하지 않았다.

이 PNG들은 대사·효과가 남은 세로 원작 참조 입력이다. 완성 16:9 그림이나 독립 검수 통과 후보가 아니다. Claude 검수 요청과 GPT 독립 PASS 판정은 하지 않았다. 네이티브 생성 호출은 0회다. 별도 전역 슬롯 GO 전에는 생성하지 않는다.
