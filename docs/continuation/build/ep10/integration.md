# 10화 내부 통합 계약

독립 파일은 `app/content/ep10_internal.yaml`이다. 고유 ID는 `ep10_internal`, 시작 비트는 `ep10_c001`, 내부 정지 비트는 `ep10_end`다. 88비트·78컷·원문 발화 93줄을 담는다. 캠페인에는 연결하지 않았다.

## 진입 조건과 9화 차단

9화 끝 비트나 그 세이브를 이 시작점에 자동 연결하지 않는다. 9화 밤 탈출·대족장의 칼과 10화 목욕 사이 연결은 원작 담당의 인접화 대조 대기다. 새 공격·포획·강제 귀환을 쓰지 않았다. 탈출 성공을 목욕으로 덮어쓰지 않는다. 9화 c042의 황제 발화/속마음 구분은 미확정이며, 아시나나 다른 인물의 지식으로 추가하지 않는다.

10화가 요구하는 실제 진입 상태는 궁정 욕실의 아시나, 갈색 머리·갈색 눈·귀찌 착용, 욕조 밖 옷과 가방이다. 앞서 들킬 뻔한 만남, 왕과 다른 남성의 시선에 대한 경험, 누르와 라 쿤을 아는 관계가 필요하다. 상대 남성의 정체·만남의 경위·왕 방문 횟수·관계 수치는 확정하지 않는다. 9화에서 짐 반환이 유보되므로 가방이 어떻게 목욕탕에 놓였는지도 경계 대조가 필요하다.

`sheet`는 단독 파싱용으로 기존 `ep02_captivity.yaml` 시트를 그대로 사용한다. 가방·귀찌·지도·핀 사전과 조건을 재작성하지 않았다. 실제 캠페인에서는 전 화 세이브의 수치·아이템 존재/손상·후드·부상·기억·시간을 보존하고 이 시트로 초기화하지 않아야 한다. 귀찌 변색·눈 마법 해제는 전용 플래그로만 기록하며 잔여 수명이나 수치 보상을 발명하지 않는다.

## 이탈 상태

원작 경로에서는 c078 마지막 줄에서만 `ep10_눈색인지_앎`이 켜진다. 갈색 머리·붉은 눈, 눈 마법만 해제, 왕과 같은 방이라는 상태다. 왕이 알아챈 시각·귀찌 원리 인지·정체 인지 범위는 미확정이다. c014의 은발은 조정 중 잠깐의 모습이다. 누르가 못 알아챘다는 것은 아시나의 추측이다.

접촉 회피 경로에서는 `ep10_접촉회피`·`ep10_접촉중단`을 보존하고 `ep10_입맞춤_발생`은 없다. 손을 놓으라고 말한 경로와 손목을 빼며 물러선 경로는 실제 반응 서술로 구별하며 둘 다 판정하지 않는다. 호감·관계 동의·경험 수치를 자동 부여하지 않는다. `ep10_머리이유_말함`, `ep10_사촌_말함`, `ep10_진명확인_말함`, `ep10_이름뜻_말함`, `ep10_베히님`은 실제 선택한 공개 범위만 보존한다.

`ep10_end`의 ending은 단독 시험의 정지점이다. 캠페인 합성 때 실제 다음 화 첫 비트·요구 상태를 원작으로 확인한 뒤 리드가 연결한다. 미완성 앞 화를 건너뛰거나 다음 화를 추측하지 않는다. base.id와 기존 저장 식별자는 리드가 유지한다.

## 상호작용과 지식

머리·가족·진명·여행·호칭·손목 대응은 선택 지점이다. 독백·마법 조정·머리 빗기·c070 침묵·c078 끝에 입력을 강요하지 않는다. c058에서 대응하므로 c066에 같은 요구를 다시 걸지 않는다. 거부와 손목을 빼며 물러서는 행동은 모두 비판정이며, 침묵은 원작 경로를 잇는다.

기존 손목 판정은 모든 등급에서 왕이 손을 놓고 접촉·거리가 같아져 불확실한 목표를 구별하지 못했다. 혼합 성공의 `ep10_대답지연`도 이후 반응이나 수치·기회를 바꾸지 않는 표시였다. 판정·시간 비용·해당 표시·실패 분기를 제거했다. 새 해악을 만들지 않았고 손목 해제와 거리 확보는 끝까지 보존한다. 선택하면 `ep10_withdraw`에서 실제 행동을 서술한 뒤 거리 확보와 눈색 대화까지 자동 진행한다.

왕의 발화와 속마음은 같은 lore=베히다트, 아시나 발화와 속마음은 lore=아시나다. 슬롯은 실제 장면의 아시나·누르·왕만 사용한다. 나시르는 c048 회상 CG 안에만 있다. c034·c035·c037·c071은 독자 전용 thought이며 facts에 그 내면 내용을 아시나의 지식으로 등록하지 않았다. 보호 facts로 구분을 명시했다. 기존 lore의 knowledge 잠금·모델 최근 문맥이 이 경계를 지키는지는 부모 통합/실모델 QA 대상이다. c051의 베히다트 진명 추정은 공식 확인으로 바꾸지 않았다.

## 그림과 남은 검증

78개 CG는 실재 `assets/ep10/cuts/full_res/clean/ep10_cNNN.png`를 참조한다. work 경로를 게임 자산으로 사용하지 않는다. 기존 원본 정제 컷이며 GPT 생성·보정·16:9 확장 완성품이 아니다. 입식 세 개는 제작 대기 placeholder이며 neutral만 선언했다. 없는 표정 파일을 지어내지 않았다. 아시나의 목욕/드레스·갈색눈/붉은눈 상태, 왕의 현재 어두운 겉옷과 인상 이미지의 예복, 누르의 복장, 원작 인체·겹침은 새 자산 제작 후 원본과 대조해야 한다.

원문 밖 분기는 입맞춤 그림을 재생하지 않고 c016 방 원본을 공간 컷으로 사용한다. 분기 행동을 그린 새 CG라는 뜻이 아니다. 해당 행동의 GPT 보정 그림은 대기다. 같은 컷의 모든 원문 대사에는 같은 CG를 직접 달았다. c070은 원본 확대에서도 화자 식별 근거가 없어 이름 없는 침묵으로 보존한다. `source_check.md`와 확대 그림을 참조한다.

브라우저·저장 재개·지도 복원·실제 모델 대사·캠페인 전체 경로 QA는 이 레인의 검증 범위 밖이며 부모가 수행한다. 사용자 포트 18080/18081·모델은 접속하지 않았다. 커밋·푸시·crq를 실행하지 않았다. 이 문서는 사용자 테스트 전달이나 캠페인 READY를 뜻하지 않는다.
