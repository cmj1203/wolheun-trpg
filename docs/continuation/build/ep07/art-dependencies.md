모든 출연 슬롯은 전용 CG 화자 별칭을 가리키며 별칭에는 입식 파일을 지정하지 않는다. 공유 사막 입식 사전은 파서의 같은 lore 표정 검증과 병합 호환성만 위해 유지한다. 실제 UI는 해당 별칭의 sprite가 없으면 슬롯을 숨긴다(`app/web/main.ts`의 `setScene`).

Astra 편집·확장 시 각 원작 컷을 입력으로 삼아 복장과 접촉 위치를 보존해야 한다. c060은 머리카락을 입가로 가져가는 동작, c063은 머리·뺨 옆을 감싼 구도다. 입술 입맞춤이나 동의를 추가하지 않는다.

이 레인은 그림 생성과 브라우저 QA를 실행하지 않았다. PC 1440 화면에서 첫 대사부터 동일 컷이 유지되는지, 무언 컷·설명 삽화·표제·근접 종료가 읽히는지는 부모의 생성 CG 교체 및 실제 모델 QA 뒤 확인해야 한다. 파일 존재·PNG 서명·assets 하위 실제 경로 검사와 엔진 이벤트의 컷 유지 검사는 내부 테스트 범위다.
