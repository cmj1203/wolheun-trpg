## 사실 플래그의 교체

공유 lore와 엔진을 수정하지 않고 7화 비트 효과에서 기존 사실의 조건을 종료한다.

- c001: `ep03_복장_청록복=false`, `ep07_분홍녹색복=true`, `ep07_얼굴가리개=true`. 현재 컷에 보이는 복장만 확정한다. 갈아입는 장면을 새로 만들지 않는다. 6화에서 이미 종료했다면 같은 false 적용은 상태를 다시 바꾸지 않는다.
- c003의 반환 설명 마지막 줄 뒤: `ep03_짐_수중없음=false`, `ep07_짐_부분반환=true`. 이때부터 기존의 “짐과 치부책은 돌아오지 않았다”라는 묶음 사실을 사용하지 않는다. 새 사실은 “이상 없는 짐만 일부 반환, 미심쩍은 물건은 계속 보관, 반환품 상세와 치부책 위치는 미확정”이다.
- `gain`·`lose`를 쓰지 않는다. 갈색 가방 그림만으로 공유 `magic_bag` 또는 그 안의 전 아이템이 반환됐다고 확정하지 않는다. 6화 재고 전수 대조 후 부모가 각 아이템의 실제 보유 상태를 연결해야 한다.
- c020: `ep07_얼굴가리개=false`, `ep07_방_복귀=true`. c044: `ep07_단화=true`. 기존 공유 시트·items·입식 사전은 그대로 둔다. 독립 새 판의 시트 수치는 파싱용 기본값이고 6화 종료 수치라는 뜻이 아니다.

## 지식과 화자

나시르·카림 면담 c008–c019, 카림 독백 c039–c040, 은발 남성 독백 c057–c060·c062는 독자 전용이다. 이 정보로 아시나의 수첩·입력 기억·공개 플래그를 만들지 않는다. c032의 표정 해석과 c051의 보고 예상도 사실 확인으로 저장하지 않는다.

아시나 말과 독백의 별칭은 공유 `아시나` lore와 표정 목록을 사용하되 실제 출연 별칭에는 사막 입식을 지정하지 않는다. 나시르·카림은 각각 같은 lore를 쓰는 말/독백 별칭이다. 은발 남성은 본화만으로 기존 `베히다트`와 동일하다고 단정하지 않고 화 내부 `ep07_은발남성` lore로 말/독백을 묶는다. 6화에서의 본명·직책 공개와 신원을 검증한 뒤 부모가 이 두 별칭의 lore를 함께 확정해야 한다. 나시르라는 이름도 c021에서의 회상이며 첫 공개 시점을 새로 만들지 않는다.

현재 엔진은 모든 대본 줄을 `recent`와 화자별 `spoken`에 넣는다. 이는 화면·대사 이력이며 아시나의 실제 경험이라는 보증이 아니다. 독자 전용 별칭과 상태 사실로 출처를 명시하되, 이 레인은 GM 모델의 의미 해석을 검증하지 않았다. 부모의 실제 모델 QA에서 타인 독백을 아시나의 기억으로 답하는지 확인해야 한다. 공유 엔진 변경을 요구하거나 완료했다고 보고하지 않는다.

## 진행과 지도

`ep07_harem` 고유 ID로 독립 로드한다. c001부터 c063까지 원작 순서로 자동 진행하고 화 내부 정지점으로 끝난다. c063의 `ending`은 내부 검증용 종료이며 8화 연결이나 캠페인 결말을 확정하지 않는다. 부모는 연결 때 이 종료를 걷어내고 검증된 다음 비트를 지정해야 한다.

원작에 불확실한 행동 시도가 없으므로 판정·goals·강제 입력을 만들지 않는다. c044의 선택적 관찰 제안은 구현 필수가 아니며, 이번 원작 경로는 입력 없이 진행한다. 지도는 실제 10장면의 선형 연결만 표시한다. 가짜 선택 노드·탈출 분기·자동 판정 갈림길은 없다.

## 부모에게 남는 의존성

6→7 및 7→8 원본 경계 대조, 실제 재고 연결, 은발 남성 신원과 공개 시점 확정, Astra 그림 제작·원작 대조, PC 화면과 실제 GM 모델 전 구간 QA는 미완료다. 사용자 서버·모델 포트·공유 코드·다른 화는 이 작업에서 변경하지 않는다.
