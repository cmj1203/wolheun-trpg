공유 native 실제 동시 상한은3이다. GO를 받은 화의 수를 실행 개수로 세거나 슬롯 점유로 간주하지 않는다. root의 새 머리 편집과 정상2화·3화 작업도 실제 수에 포함한다. 각 writer는 호출 직전 전체 argv의 실제 실행 파일을 기준으로 재확인하며 정상 호출·완료 PNG를 취소·덮어쓰기·중복 생성하지 않는다. 축약된 comm만 보고 누락시키지 않는다. GO 없는 화는 참조 준비를 마쳐도 자체 호출하지 않는다. 다른 writer에게 넘기려면 이전 writer의 종료와 파일 해제를 먼저 확인한다.
