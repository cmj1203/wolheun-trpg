# 4화 독립 검증 기록

2026-11-09, Bun 1.4.2. 독립 대본과 계약 검사 완료. 캠페인·그림 완성 판정은 하지 않았다.

## 산출물

- `app/content/ep04_night.yaml`: 독립 ID `ep04_night`, 84비트, 원문 63컷과 c053/c054 사이 보충 풍선.
- `app/tests/ep04_night.test.ts`: 4화 전용 원문·자산·실제 엔진 계약 검사.
- `docs/continuation/build/ep04/contract.json`: 진입·종료·상속·독립 공개 플래그·공유 lore 반영용 자료.
- `docs/continuation/build/ep04/integration.md`: 연결 및 Astra 그림 요구사항, 후속 상태 정리.
- `docs/continuation/build/ep04/test-output.txt`: 실행 원본 출력.
- `docs/continuation/build/ep04/evidence.md`: 이 기록.

공유 코드·기존 원작 문서·다른 화 파일은 수정하지 않았다. 자산은 기존 clean 63파일을 참조하므로 새 그림 파일을 만들지 않았다. 커밋·푸시·crq·서버 실행은 하지 않았다.

## 실행 명령과 결과

저장소 루트에서:

```sh
cd app
bun test ./tests/ep04_night.test.ts --timeout 10000
```

최종 지도 좌표 변경 후 종료 코드 0. **12 pass, 0 fail, 559 expect, 45ms**.

실제 `loadScenario("app/content/ep04_night.yaml")` 호출도 eval에서 실행했다. 결과는 `ep04_night`, 84비트, `checkScenario=[]`이다. 테스트에서도 같은 실제 파일을 `loadScenario`와 `loadCampaignScenario`로 읽어 2화 자동 합성이 일어나지 않는지 확인했다.

지도 좌표 변경 전 `lsp_diagnostics(app/tests/ep04_night.test.ts, all)` 결과는 **No diagnostics found**였다. 지도 검사 assertion 두 개를 추가한 뒤 최신 진단은 3000ms 응답 시간 초과로 확인하지 못했다. 최종 타입 진단 통과로 보고하지 않는다. YAML 언어서버도 설치되어 있지 않아 YAML 정적 진단은 실행하지 못했다. 실제 YAML 파서·시나리오 검사와 최종 런타임 테스트는 통과했다.

## 검증 범위

| 검사 | 결과 |
|---|---|
| 원문 컷 63개와 텍스트 105항목 대응 | 모든 원문 비트의 대사·독백·삽입 글자를 독립 전사 문서에서 추출해 순서 비교 통과 |
| 보충 풍선 | c053 → 별도 풍선 → c054 순서와 원문 일치 |
| 무언 컷·분할 대사 | 무언 컷은 그림 줄, 같은 컷의 모든 대사는 동일 CG 유지 |
| 자산 | 63/63 CG가 `assets/ep04/` 아래 실재 파일 |
| 복장 | 실제 슬롯은 입식 없는 ep04 별칭, 사막복 입식 배치 없음 |
| 동일 인물 | 실명 전후 별칭이 `lore: 베히다트`, 아시나 말·독백도 같은 lore |
| 세 신분 공개 | c040 실명, c041 통치자, c042 칭호의 독립 플래그 소유·이름표 |
| 귀찌 | c011 휴식과 c012 남은 일주일을 별도 플래그로 보존 |
| 지도 | 모든 84비트를 정확히 한 노드에 포함하고 실제 연결의 노드 간 간선과 일치. 32~44열에서 좌표 중복 없음 |
| 상속 | 탐색 진행 중 변경된 수치·핀·기억 보존, c014 청록 단화 상태 유지 |
| 후속 사실 | `ep04_active=false`이면 4화 facts 전부 비활성화 |
| 거리 성공 | 실제 엔진의 hit와 mixed 모두 거리 플래그·거리 종료·눈동자 칭찬 유지, 근접 CG 세 개 미출력 |
| 거리 실패 | 성공 플래그 없이 원작 경로 종료 |
| 무행동 | 실제 엔진의 idle 입력에 check 로그 없음 |
| 침묵 | 원작의 여행자 자기소개를 대신 말하지 않고 진행 |

원작 삽입 글자 중 영어는 화면의 한국어 요구에 맞춰 `LOADING… / YOU DIE`를 `불러오는 중… / 사망`, `Lv.999`를 `레벨 999`로 표시한다. 능력치·실제 사망 사건으로 해석하지 않는다.

테스트 판별력은 실제 로드 결과의 메모리 복사본을 변이하여 추가 확인했다. 거리 성공 목표의 도착지를 원작 근접 경로로 바꾸면 종료 경계 검사가 실패했고, c011 마지막 줄을 제거하면 원문 대응 검사가 실패했다. 원본 파일은 변이하지 않았다.

## 미실행·의존성

- Astra 원작 입력 편집, 완성 그림의 원작 나란히 대조, 거리 확보 전신 구도의 시각 검수는 미실행이다. 현재 얼굴 원작 컷은 검증용이며 완성 그림으로 보고하지 않는다.
- 리드가 공유 lore의 `남자_정체_앎` 단일 잠금과 정적 하렘 선공개를 수정하고 `contract.json`의 세 조건부 잠금을 통합해야 한다. 실제 GM 모델의 정보 누출 검사는 미실행이다.
- 3화 `ep03_c061`에서 4화 `ep04_c001`로의 캠페인 연결, 5화의 정확한 시작, 두 종료 거리의 후속 보존은 리드 통합 작업이다. 미완성 화 경계는 강제 연결하지 않았다.
- 실제 모델 전체 플레이, 브라우저에서 현재 보이는 대사 기준의 공개 시점·CG 유지, 저장 재개·전체 회귀·독립 화면 검수는 미실행이다. 사용자 포트 18080/18081을 조작하지 않았다.
