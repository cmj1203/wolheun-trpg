# 혼례 후보 손·프레이밍 교정

원작 입력은 `work/ep04/merged/ep04_002.png`의 `[0,344,2000,3600)`이며 `assets/ep04/gen/inputs/ep04_c007_a_wedding-selected.png`에 보존돼 있다.

선택 원작에서 꽃다발 아래 손의 모양과 위치는 큰 말풍선 때문에 확인할 수 없다. 옷에 가려진 손이라고 판정하지 않는다. 선택 창의 아래 경계와 원작의 실제 삽화 경계도 같다고 단정하지 않는다. 원작은 혼례 상상과 현재 아시나가 겹치는 구성이다.

첫 후보는 꽃다발 아래 손가락을 드러냈다. 이 부분은 보이는 원작만 보존하는 제한의 근거가 없어 보류했다. 손을 숨기려고 새 드레스·소매·천을 그리지 않는다.

교정은 원작에서 직접 보이는 두 사람의 머리·흉상·꽃 윗부분만 가까이 잡고 손과 줄기 아래를 화면 밖으로 두는 프레이밍 변경이다. 같은 장식 배경만 가로로 확장한다. 새 신체나 덮개를 만들지 않는다.

기존 후보와 로그·해시는 그대로 보존하고 별도 revision01 PNG와 영수증을 만든다. 전체 프레이밍 교정이므로 국소 마스크 밖 변경 0이라고 주장하지 않는다. 실제 결과의 변경 범위는 결과를 본 뒤 기록하며 독립 Claude 미술 승인과 설치는 계속 0이다.
