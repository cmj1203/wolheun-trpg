# 9화 내부 제작과 통합 요구

`app/content/ep09_palace.yaml`은 고유 ID `ep09_palace`를 쓰는 독립 내부 대본이다. 원작 18장·84컷을 66개 원작 비트와 4개 반응 비트로 연결했다. 18개의 빈 장식·시간 연결 컷은 다음 실제 장면으로 흡수한다. 대사가 있는 연결 컷은 생략하지 않는다. 원작 순서는 `source-map.json`에 전부 대응시켰다.

## 선택과 목표

반환 유보(c063) 뒤에는 승인 사실을 들어 항의하거나 말없이 바라본다. 시선 감지(c080) 뒤에는 숨소리를 낮추거나 시선 쪽을 바라본다. 두 자리 모두 자발적인 말·자세 선택이므로 주사위가 없다. 선택은 각기 다른 반응 비트와 플래그를 남기며 지도도 두 갈래를 따로 표시한다. 회상·독백·밤 전환·아래쪽 인물 대화에 입력을 강제하지 않는다. 궁 탈출·짐 강탈·은신 성공 같은 불확실한 목표를 이 내부 경로의 가짜 판정으로 만들지 않았다. 향후 이 목표들을 자유 입력으로 열려면 현행 `free.goals` 계약으로 성공·대가 있는 성공 모두 목표 달성을 보존하는 별도 이탈 경로가 필요하다.

## 정확한 진입 요구

8화 마지막 비트와 세이브는 미확정이다. 본 대본 시작은 `ep09_c001`(낮 궁 회랑·정원, 아시나와 카림)이다. 갈색 머리·보라색 궁정복, 짐 미소지 상태가 필요하다. 단독 실행에서는 공통 sheet를 그대로 두고 첫 비트에서 가방·그 안 지도를 소지품에서 뺀다. 캠페인 합성은 리드가 실제 이전 화 상태와 이 차이를 대조해야 한다. 압수 경위·내용물·이전 탈출 횟수·호칭을 배운 시점·밤 옷 입수 경위·지리 습득 경로·신분 공개를 발명하지 않는다. 아이템 사전과 능력·트랙·기본값은 기존 2화 sheet와 같다. 시간·귀찌 비용을 임의로 더하지 않는다.

## 정확한 이탈 요구

마지막 원작 비트는 `ep09_c084`, 내부 종료 ID는 `ep09_internal_end`다. 아시나는 밤 궁 안 높은 곳에 있고 탈출은 완료되지 않았다. 짐 반환 승인과 실물 반환은 다르며 가방은 여전히 미반환이다(c063 방 안 걸이). 아시나는 시선을 느꼈지만 아래쪽 대족장 호칭·실명·작은 칼·감지 원리는 알지 못한다. 칼은 독자에게만 보인다. 10화 욕실 첫 비트에 자동 연결하지 않았다. 두 화 사이에서 공격·투척·명중·부상·추격·포획·귀환이 실제 있었는지, 욕실로 이동한 시각과 이유, 밤 복장 교체, 기존 탈출 성공 경로의 독립 종료 처리가 필요하다. 근거 없이 추가 공격·재포획을 만들거나 성공한 탈출을 욕실로 되돌려서는 안 된다.

## 발화와 공개

c042는 `assets/ep09/gen/source/c041-c043-verification.png`로 원본 이웃 컷을 직접 확인했다. c041의 뾰족한 발화 풍선과 c043의 꼬리 있는 승인 발화 사이에서 c042는 꼬리 없는 둥근 풍선이다. 문장은 읽히지만 발화/속마음은 여전히 확정할 수 없다. `ep09_황제독백`으로만 재생하고 아시나에게 사실 플래그를 주지 않는다. c017·c034·c057도 비공개 독백이다. c068의 나시르는 아시나의 상상이며 실제 나시르 발화로 저장하지 않는다. 호칭이 바뀌어도 아시나/베히다트/나시르/잘릴 lore를 유지한다. 잘릴은 내부 lore 키일 뿐 화면에 실명을 공개하지 않는다. 나시르 이름은 c023 이후 쓴다.

## 그림 요구와 현재 한계

실제 서버 참조는 모두 `assets/` 아래의 기존 정제 원작이다. `work/` 참조를 런타임에 넣지 않았다. CG·입식 별칭은 검증 입력이며 Astra 완성 CG가 아니다. 현재 표현은 neutral CG 별칭만 선언했고 완성 표정 입식은 없다. 원작 57개 채택 그림을 재사용하며 나머지 대화 컷은 인접 CG를 유지한다. 원본 크롭은 전사/말풍선 확인용이고 게임 CG로 쓰지 않는다. `art-requirements.json`은 원작 정리 자료의 그림 요구를 보존한다.

아시나 낮은 갈색 반묶음·분홍 보석·금사슬·보라색 금장 궁정복, 밤은 풀어진 갈색 머리·남색 짧은 소매 덧옷·흰 긴 치마·무늬 허리띠다. 크롬웰 회상은 흰색·연푸른 여행복과 갈색 어깨가방이다. 카림·황제·나시르·대족장 모두 해당 화 원작 복장만 참조한다. 사막 복장으로 대체하지 않는다. Astra 편집 시 원작 얼굴·손·칼자루·장신구·겹침을 보존하며 말풍선 제거·16:9 확장만 허용한다. 로컬 SD 생성은 하지 않았다.

## 검증 범위

부모 담당: 캠페인 합성, 실제 브라우저/모델 전 경로 QA, 원작 대조 Astra 제작·시각 검수. 이 레인은 독립 로드·구조 검사·엔진 행동 회귀와 원본 대응을 검증한다. YAML 언어 서버는 미설치라 해당 진단은 실행하지 못하며 실제 엔진 파서로 대체한다. 커밋·푸시·crq·사용자 서버·모델 포트는 사용하지 않는다.
