- ep09_c021_반응삽화: 원본에는 나시르의 작은 얼굴이 있다. 현재 c020 CG 유지로 소실된 그림을 독립 후보로 복원한다. ep09_c021_native_v01.png 후보 연결은 부모 승인과 독립 QA 뒤에만 적용.
- ep09_c024_손무언: 내민 손은 북대륙 질문 뒤에 등장하는 별도 그림이며 현재 줄이 없다. 원문 대사를 새로 만들지 말고 손의 무언 앵커를 추가해 연결할 자리 조정.
- ep09_c068_밤무언: 상상 속 나시르 이후 실제 밤하늘로 바뀌는 원본 전환을 c073 얼굴보다 먼저 보존한다. 밤하늘 무언 앵커를 추가하고 c069–c072는 같은 밤하늘로 유지.
- ep09_c042_발화방식: 원문 발화·속마음 구분 미확정. 현재 황제독백 처리는 확정 전사로 취급하지 않는다. 그림에는 불필요한 입 움직임·새 발화 사실을 추가하지 않고 주인공 지식을 갱신하지 않음.
- ep09_동시작업해시: YAML 소유자가 병행 작업 중이다. 현재 해시 이후 바뀐 beat/line/화자/대사/시점/분기는 설치 전에 재대조해야 한다. 명세 해시와 달라지면 영향 앵커만 재조정. 소유 파일을 덮어쓰지 않음.

c024 손의 무언 전환은 ep09_c024:3 뒤·ep09_c027:1 앞이다. c068 이후 밤하늘은 ep09_c068:2 뒤·ep09_c073:1 앞이다. 두 전환은 현재 YAML 줄이 없다는 사실을 명시한 제안이며 이미 연결됐다고 보고하지 않는다. c021은 작은 나시르 얼굴이 있으므로 c020 그림에 흡수하지 않는다. 밤하늘 c069–c072는 앞선 밤하늘을 유지하지만 c073 얼굴 이후 c074는 c073을 유지한다. 얼굴 공개 전으로 돌아가는 비인접 재사용은 하지 않는다.

## 생성과 검수 계약

- 원본 얼굴·복장·소품·가림·패널 순서 보존. 새 인물·사건·노출 추가 금지.
- 정제 세로 그림·흐림·검은 띠 합성을 완성본으로 세지 않는다. 원본 참조 편집 후 16:9로 확장한다.
- 6화 최신 29컷 정정을 따름. 애첩·구속·사막 필수 통과·맨등 요구를 9화에 만들지 않는다.
- 9→10화 사이 공격·투척·명중·포획·귀환·짐 반환 경위를 발명하지 않는다.
- 미공개 얼굴·의상·칼·상상 소품을 앞 앵커로 가져오지 않는다.
- 생성 GO와 슬롯을 부모가 부여한 뒤 한 번에 네이티브 호출 한 건만 진행한다. 정상·완료 기존 작업은 취소·중복 생성하지 않는다.
- 각 후보의 Claude 독립 원본 나란히 QA 후 FAIL만 수리한다. 이 단계는 QA 승인이나 그림 READY가 아니다.
- 일반 원격 이미지 편집에 heavy를 붙이지 않는다. 실제 수 GB 로컬 작업에만 적용한다.

부모는 기존 2·3화·headjob을 포함해 전역 네이티브 동시 3개 한도를 관리한다. 이 레인은 명시 GO와 슬롯을 받기 전 호출 0개를 유지하고 이후에도 한 번에 한 호출만 한다. 선택된 원본 패널 크롭만 -i 입력으로 쓰며 뒤 패널까지 든 전체 정제 컷을 자동 입력하지 않는다. 원본 참조 편집으로 말풍선·효과 글자만 제거하고 16:9로 확장한다. 얼굴·의상·가림·소품·패널 순서를 보존한다.

독립 Claude는 후보마다 실제 원본과 나란히 확인한다. 원본 보존, 패널·공개 순서, 복장·소품·가림, 16:9, 글자 잔재와 새 사건 유무를 보고 PASS/FAIL을 남긴다. FAIL만 수리하며 정상 후보를 재생성하지 않는다. 파일 존재·해상도 검사나 생성 모델의 자기 판정은 QA를 대신하지 않는다. 최종 manifest와 실제 파일 존재 확인은 생성·QA가 끝난 뒤 별도 단계다.
