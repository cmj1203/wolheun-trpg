# 3화 연결 계약

상태: `app/content/ep03_palace.yaml` 독립 파싱 통과. 캠페인 연결·생성 CG·실제 모델 QA는 미완료다. 원작 전사 문서는 수정하지 않는다.

## 진입과 이탈

| 경계 | 실제 비트 | 조건 |
|---|---|---|
| 2화 이탈 | `ep02_court_boundary` | 왕궁 호송이 성립한 본선. 수행원의 크롬웰 정보 수집 제안은 관객 정보 |
| 3화 진입 | `ep03_c001` | 갈색 변장·귀찌 유지. 머리쓰개·베일을 더하지 않고 여행복으로 시작 |
| 3화 이탈 | `ep03_c061` | 시하드가 혼자 남아 석류즙을 핥고 발언. 잘릴은 살아서 퇴장 |
| 4화 진입 | 4화 담당 계약 대조 후 확정 | 밤, 아시나는 청록복·귀찌·갈색 변장을 유지하며 방에 남아 있음 |

`ep02_city_escape`와 사막 탈주·다른 계약 결말은 연결 대상이 아니다. `ep02/integration.md`의 감옥 접두어 설명과 달리 실제 감옥 시작은 `ep02_prison_wake`다. 기존 ID는 바꾸지 않는다.

독립 대본 ID는 `ep03_palace`다. `loadCampaignScenario`가 `ep01_desert` ID에 2화를 자동 합성하므로 독립 대본에 그 ID를 사용하지 않는다. 통합 캠페인은 기존 base의 ID·start·sheet·난수 상태를 유지한다.

## 소유 레인에 요청할 최소 통합

`app/src/engine/continuation.ts`는 이 레인에서 수정하지 않는다.

1. 기존 캠페인에 3화 cast/backgrounds/sprites/cgs/beats/facts/atlas를 충돌 검사 후 합성한다. 사막 종료용 `connectContinuation`을 3화 연결에 그대로 재호출하지 않는다.
2. `ep02_court_boundary`의 기존 대사·효과를 보존하고 ending만 제거한다. `continue_ep03` 선택과 next는 `ep03_c001`을 가리킨다.
3. 지도는 실제 `ep02_court`(17열)에서 `ep03_s01`로 잇는다. 3화의 12장면과 비판정 대화 선택 노드 2개는 18~31열에 놓여 있다. 고정 선택은 선택적 자유 대화 통합 전 임시 내부 구조다.
4. 기존 2화 종료 저장을 재개할 때 이미 읽은 궁정 대사·효과를 재생하지 않고 새 경계 선택을 한 번만 실행한다.
5. 4화 자료의 정확한 시작 ID와 합성 검증 결과를 받은 뒤에만 `ep03_c061`의 ending을 다음 장 경계로 교체한다.

## 상태와 기억

- 수치·부상·관계·귀찌 잔량·운명·난수·기존 획득/분실 플래그를 초기화하지 않는다. 3화에 주사위 판정·시간 수치 차감은 없다.
- c008에서 여행복과 가방이 손을 떠난다. `magic_bag`·`map`을 소지품에서 내리고 `ep03_짐_수중없음`을 기록한다. 보관 장소·처리자·치부책 반환을 확정하지 않는다. 핀의 이동은 원문에서 확인되지 않아 새로 처리하지 않는다.
- c027의 청록복 착용과 c048의 금색 신발 벗음은 별도 상태다. c031~c033 삽입은 물건 획득이 아니며 c036 은발 대비는 변장 해제가 아니다.
- c040 마지막 통보 줄 뒤 `ep03_하렘_앎`, c050 마지막 통보 줄 뒤 `ep03_유일한아이라_앎`을 켠다. 앞선 제목·목표에 이를 노출하지 않는다.
- c052~c061 및 붉은 휘장 방의 대화는 관객만 본다. 관객 플래그는 아시나·시녀의 기억이나 GM이 인물에게 알려 주는 지식으로 전환하지 않는다.
- 모든 궁정 화자는 전용 alias를 사용한다. 아시나와 시하드는 각각 기존 `아시나`·`베히다트` lore를 공유한다. 표정 사전은 기존 정의를 보존하되 실제 슬롯에는 궁정 CG 화자만 배치해 사막 입식을 표시하지 않는다.

## 남은 검증

현재 CG는 `assets/ep03/gen/source/ep03_cNNN.png`의 실재하는 원작 추출 61컷을 참조한다. 서버가 제공하는 경로로 교체했지만, 추출 컷을 Astra 편집 완성 자산으로 간주하지 않는다. 생성 후보는 별도 파일이며 원본과 나란히 검수한 뒤 교체한다.

c033의 비한글 소품글과 c054의 흘림풍선 2개는 원본·이웃 컷·PSD 문자 레이어를 재대조했다. 소품 문양과 픽셀 레이어만 확인되어 뜻·화자는 미확정으로 남긴다. 대본에 발화를 창작하지 않았다. 원작 감사는 `art/원문감사.md`와 `art/글자레이어.json`에 있다.

독립 `withNotes`는 기존 사막 비트에 대한 `knowledge.after` 참조 16개가 없어 실패한다. 기존 lore나 검사를 삭제하지 않고, continuation 담당의 전체 기존+2+3 합성 준비 신호 뒤 그 시나리오로 화면 검증한다.

실제 모델 시험은 별도 테스트 모델의 포트·소유자와 heavy 순서 조율이 필요하다. 사용자 18080/18081과 중단된 시험 18191/18192는 사용하지 않는다.
