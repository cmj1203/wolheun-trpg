## 파일 상태

- 위 표의 후보 41개가 `assets/ep03/gen/`에 존재한다.
- `source/`와 `inputs/`는 원작 확인·생성 입력이며 완성 CG가 아니다.
- `ep03_c012.png`는 기존 Claude 1차 검수에서 원작보다 노출이 넓어 연결하지 않는다. `ep03_c012_exact.png`를 쓴다.
- `ep03_c033.png`는 생성 과정에서 책 문양이 달라져 연결하지 않는다. `ep03_c033_exact.png`를 쓴다.
- `ep03_c036.png`는 생성 과정에서 설명 삽입의 복장 연속성이 달라져 연결하지 않는다. `ep03_c036_exact.png`를 쓴다.
- c046 개별 생성은 이미지 API 입력 판독·안전 필터로 실패했다. 같은 하렘 침실의 c045를 항의 발화 동안 유지하고 c047에서 시녀 반응으로 전환한다.
- 모든 실제 연결 후보의 좌우 대조본은 `docs/continuation/build/ep03/art/review-final/`에 있다. 새 후보의 Claude 최종 판정은 부모 세션 검수 의존 사항이다.
