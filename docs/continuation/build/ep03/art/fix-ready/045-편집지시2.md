기존 세션과 중복되지 않는 단일 이미지 편집 작업이다. 이전 시도는 이미지 파일 판독 오류 `invalid_image_file`로 그림을 만들지 못했다. 이번 입력은 내용 변경 없이 RGB PNG로 재저장하고 긴 원작만 비율 유지 축소한 실제 파일이다. 안전 필터 우회나 장면 재생성은 하지 않는다.

입력 1 `045-입력_편집대상.png`는 편집할 현재 후보 전체이며 원래 1672×941 픽셀이다. 입력 2 `045-입력_실제원작.png`는 실제 원작 c045 전체를 비율 유지 축소한 것이다. 입력 3 `045-입력_048원작침대.png`는 같은 침실 원작 c048의 실제 침대 부분을 무손실 추출한 것으로, 파란 침구와 파란 휘장 형태만 참고한다. 입력 3의 인물·소품·글자는 편집 대상에 추가하지 않는다.

내장 image_gen을 이용해 입력 1의 두 오류 부위만 편집한다. 왼쪽 가장자리 흰 주름 소매와 회색·검정 치맛자락 사람 조각을 지우고 원작 c045의 파란 커튼·문으로 복원한다. 오른쪽 위 붉은 금장 휘장 침대를 실제 원작 c048과 같은 파란 휘장·파란 침구 침대로 교체한다. 단순 색상 필터로 바꾸지 말고 실제 침대 형태를 따른다.

아시나의 파란 그늘 얼굴, 갈색 머리, 장신구, 주저앉은 자세, 손, 청록 치마와 바닥·카펫, 중앙 문, 조명, 그림체, 화면 크기를 전부 보존한다. 다른 부위를 다시 그리지 않는다. 새 인물·글자·말풍선·소품·워터마크를 만들지 않는다. 로컬 확산 모델·스크립트 필터·안전 필터 우회를 하지 않는다.

편집 결과를 이 폴더의 새 파일 `045-원격편집.png`에 저장한다. 다른 파일을 수정하지 않는다. 파일이 이미 있으면 덮어쓰지 않는다. 원격 도구가 실패하면 오류 원문만 보고하고 멈춘다. 결과 경로와 사용 도구를 한국어로 답하고 스스로 검수 통과를 선언하지 않는다.
