기존 그림의 한 물체만 원작에 맞추는 GPT/Astra 국소 편집 작업이다. 실제로 공급된 입력 이미지를 사용해 내장 image_gen 도구로 편집한다. 새 장면이나 전체 그림을 다시 그리지 않는다.

입력 순서:
1. 편집 대상: 현재 `ep03_c050.png` 전체, 1672×941. 왼쪽은 시녀, 오른쪽은 앉아 있는 아시나다.
2. 실제 원작 c050 전체를 내용 변경 없이 비율 유지 축소한 이미지.
3. 실제 원작 c050에서 손 아래 쿠션 부위를 원본 픽셀 그대로 추출한 이미지.
4. 실제 직전 원작 c049에서 같은 파란 쿠션에 기댄 모습을 원본 픽셀 그대로 추출한 이미지. 쿠션의 천 재질과 둥근 모서리만 참고한다.

입력 1의 오른쪽 아래, 아시나 손 아래에 있는 단단한 파란 책·상자 모양 물체만 입력 3의 부드러운 파란 쿠션으로 바꾼다. 원작처럼 부푼 천, 둥근 모서리, 손가락에 눌리는 면, 그 주변으로 퍼지는 천 주름을 살린다. 책등·종이 단면·직선으로 뻣뻣한 모서리·일정한 상자 두께를 없앤다. 쿠션의 크기와 위치는 기존 손 아래 물체 자리 안에서 최소한으로 조절한다.

손 피부의 윤곽과 손가락 자세는 그대로 유지한다. 손을 새로 그리거나 움직이지 않는다. 소매와 청록 옷, 장신구, 아시나 얼굴·표정·머리·자세, 꽃, 침대, 시녀, 기존 배경과 색조, 두 패널과 구분선은 모두 그대로 보존한다. 시녀 왼쪽 → 아시나 오른쪽 순서는 이미 정확하므로 절대로 바꾸지 않는다. 놀란 얼굴 칸이나 새 물체·새 인물·글자·말풍선·워터마크를 추가하지 않는다.

변경은 손 아래 파란 물체에만 한다. 전체 화면 재생성·로컬 확산 모델·안전 필터 우회를 하지 않는다. 도구가 차단되면 오류를 그대로 보고하고 멈춘다. 새 그림은 현재 폴더의 `050-원격편집.png`에 저장한다. 이 파일이 이미 있으면 덮어쓰지 않는다. 다른 문서·코드·원작·기존 후보는 수정하지 않는다. 결과 경로와 사용 도구를 한국어로 답하고 스스로 검수 통과를 선언하지 않는다.
