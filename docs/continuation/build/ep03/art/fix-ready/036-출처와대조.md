## 기존 합성 출처

수정 전에 `매핑.md`, `산출보고.md`, `claude-review-02.md`, `independent-final-qa.md`를 읽고 실제 원작과 정확 합성을 직접 비교했다. 기존 기록은 c036의 세 삽화를 원본 픽셀로 배치하고 문자 상자를 제거한 정확 합성이라고 설명한다. c037은 같은 설명 구간의 유지 컷으로 매핑돼 있다. 이번 수정은 이미지를 새로 그리거나 c037의 새로운 그림을 추가하지 않는다.

원래 정확 합성을 만든 실행 스크립트는 조사 범위에서 찾지 못했다. 기존 후보의 모든 전처리 단계를 새로 입증했다고 주장하지 않는다. 대신 실제 원작 c036의 가운데 구간과 기존 후보를 직접 대조했다. 원작을 폭 660으로 축소한 뒤 기존 후보의 `[800,700,1250,1000)` 패치를 대응시킨 정규화 상관 점수는 0.995349였다. 이 값은 원본 픽셀 유래를 보조하며 픽셀 완전 일치율은 아니다. 비교판의 원작 가운데 구간은 실제 원작 `[0,4200,2000,7200)`을 추출한 것이다.

## 이번 연산

원인은 가운데 그림의 크롭 상단이 앞 삽화의 머리칼까지 포함한 것이다. 기존 가운데 그림의 위치는 x `[694,1354)`, y `[80,1070)`이다. 상단을 y=80에서 y=410으로 내려 앞 삽화의 머리칼을 제외했다. 기존 캔버스의 흰 배경 픽셀을 드러내며 아래쪽 그림의 좌표와 배율을 그대로 유지했다. 원작 좌표로 환산하면 대략 y=5200 아래를 남기는 경계지만, 이번 실제 연산 좌표는 기존 후보의 픽셀 좌표다.

Pillow로 PNG를 읽고 위쪽 크롭 영역 `[694,80,1354,410)`만 제외한 뒤 새 PNG로 저장했다. 기존 합성에 이미 있던 축소·문자 제거는 다시 수행하지 않았다. 재그리기·재확대·재축소·생성형 편집·색 보정은 없다.

## 확인한 차이

- 새 후보는 기존과 같은 2048×1152, 정확한 16:9다.
- 실제 바뀐 픽셀은 57,360개다. 지정 크롭 밖의 변경 픽셀은 0개다.
- 왼쪽 그림, 오른쪽 그림, 중간 y=410 이하 픽셀은 기존 후보와 완전히 같다.
- 새 후보와 비교판을 직접 열어, 가운데 위쪽의 잘린 머리칼이 빠지고 귀찌 삽화와 나머지 두 삽화가 유지된 것을 확인했다. 이는 수정 부위의 작업 확인이며 미술 승인 판정은 아니다.

## 한계

기존 정확 합성에서 이미 제거된 문자 상자와 원래 배치는 이번 수정 범위 밖이므로 그대로다. 게임 연결·YAML·엔진·대사 타이밍·기존 매핑은 수정하거나 검증하지 않았다. 부모의 Claude 재검수 전까지 연결 승인으로 취급하지 않는다.
