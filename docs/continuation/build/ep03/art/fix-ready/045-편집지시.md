입력 순서:
1. 편집 대상: `assets/ep03/gen/ep03_c045.png`.
2. 실제 원작 기준: `assets/ep03/gen/source/ep03_c045.png`.
3. 같은 방의 파란 침대 기준 원작: `assets/ep03/gen/source/ep03_c048.png`.
4. 같은 방의 침실 공개 기준 원작: `assets/ep03/gen/source/ep03_c040.png`.

첫 번째 이미지의 구도와 크기를 보존한다. 새 장면을 만들지 않는다. 왼쪽 가장자리의 흰 주름 소매와 회색·검정 옷자락은 잘못 추가된 사람 조각이다. 이 조각만 제거하고 두 번째 원작에서 실제 보이는 파란 커튼·문 배경으로 복원한다. 오른쪽 위의 붉은 금장 휘장 침대는 잘못 추가된 물건이다. 세 번째·네 번째 원작에 실제 보이는 파란 휘장과 파란 침구 침대로 바꾼다. 붉은 침대 색만 파랗게 칠하는 것이 아니라 원작의 침대 형태와 침구를 따른다. 새 사람이나 소품은 추가하지 않는다.

주저앉은 아시나의 파란 그늘 얼굴, 머리, 장신구, 자세, 손, 청록 치마, 바닥·카펫, 중앙 문, 조명, 원래 그림체는 전부 그대로 둔다. 글자·말풍선·워터마크를 만들지 않는다. 다른 부위를 재생성하거나 필터를 우회하지 않는다. 실제 입력 이미지들을 사용해 내장 image_gen 도구로 편집한다. 로컬 확산 모델은 쓰지 않는다. 원격 편집이 차단되면 그 사유를 그대로 보고하고 멈춘다.
