- **c055 내부:** 잘릴의 하렘·혈통·소문 발화 동안 054의 아직 온전한 석류 화면을 유지한다. “정말 라 쿤의 총기가 흐려졌다는 소문이 사실인 줄 알고…” 뒤 석류 파열 시점에 055로 전환하고 056으로 잇는다. 파열을 대사보다 앞당기지 않는다.
- c036 본모습 대비는 귀찌 기능 설명 부분에서만 공개한다. 앞선 “그래도…” c035에서는 034를 유지한다. 실제 변장 해제 사건이 아니다.
- c021 여행복 회상, c031–c033 소지품 삽입은 현재 복장·실제 물건 회수와 구분한다.

## 원작 복장

c053 원본을 직접 확인했다. 시하드는 흰 터번과 밝은 크림색 옷을 입고, 잘릴은 짙은 터번·주황 어깨천을 착용한다. 앞선 c020의 남색 옷·터번 없는 차림을 접견 장면에 재사용하면 안 된다. 원작 정리 문서의 일괄 복장 기재와 다른 점은 부모에게 전달했다. 이 작업은 원작 정리 문서와 YAML을 수정하지 않는다.

## 검수 상태

기존 후보 11개는 발견한 파일이며 이번 세션이 생성했다고 주장하지 않는다. 생성 후보 전체는 Claude의 원작 나란히 대조 검수 전이다. 파일 존재·해상도 검사와 GPT의 확인은 Claude 검수를 대신하지 않는다.

원격 생성 실패 로그는 `cNNN-재개.log`와 `cNNN-재개2.log`에 구분한다. 첫 시도는 이미지 인자 뒤 지시문 구분자가 없어 CLI가 지시문을 이미지 인자로 흡수한 실패였고, 두 번째는 `--`로 원인을 수정했다.
