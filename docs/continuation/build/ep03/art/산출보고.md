## 생성과 검수 상태

- Codex CLI의 GPT/Astra 이미지 편집으로 기존 후보와 후반 후보를 만들었다. 로컬 SD는 사용하지 않았다.
- 원본 의미를 바꾼 생성본은 연결 대상에서 제외하고 원본 픽셀 보존 16:9 합성본(`012_exact`, `033_exact`, `036_exact`)으로 대체했다.
- 기존 1차 Claude 검수는 `claude-review-01.md`에 PASS 9·FIX 2로 기록되어 있다. FIX였던 c007은 `007_r2`, c012는 `012_exact`를 매핑한다.
- 새 후보 전부의 최종 Claude 대조 판정은 이 하위 세션의 중첩 한도로 실행할 수 없다. `review-final/` 41장을 부모의 Claude 검수에 넘기며, 검수 전에는 후보 상태로만 연결한다.
