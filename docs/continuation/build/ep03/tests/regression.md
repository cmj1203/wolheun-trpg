## 작성 근거

원작 `docs/continuation/ep03/script.md`, `continuation.md`의 공개 시점과 삽입 그림 구분을 독립적인 기대값으로 사용했다. 기존 continuation 테스트는 연결·목표·기존 지식 잠금을 다루지만 3화 선택 조합·컷 전환·공개 줄 경계를 실행하지 않는다.

가짜 GM은 호출하지 않아야 한다는 확인에만 사용한다. 3화 대본은 실제 `loadScenario`로 읽고 실제 Engine으로 실행한다. YAML 원문 검색, 전체 비트/자산 목록 복제, 임시 이미지 경로 단언은 없다.

이전 화 상태를 넣기 위해 3화 앞에 테스트용 입장 선택 하나를 둔다. 본 진행의 61개 비트는 변경하지 않는다. 공개 시점 검증만 대상 비트의 줄 접두 구간 뒤에 빈 선택 정지점을 두며, 앞선 실제 선택은 기본 경로로 통과한다. 엔진 내부 접근이나 공유 소스용 테스트 훅은 없다.

## 최초 실패와 원인

첫 실행은 9 통과·1 실패였다. 삽입 그림 테스트에서 `sprite: 아시나 → asina` 이벤트가 한 번 관측됐다.

원인은 테스트 입장 상태에서 `후드_벗음`을 빠뜨린 것이다. 2화 `ep02_prison_wake`의 “하아… 여기가 어디지…” 줄이 이미 그 플래그를 설정한다. 누락된 상태로 3화 c001에 진입하면 c001의 같은 플래그 설정 때문에 기존 cast의 `sprite_alt`가 작동한다. 귀찌 해제나 은발 삽입의 효과가 아니다.

실제 2화 계승 상태에 맞춰 fixture에 `후드_벗음: true`를 추가했다. 기대값을 완화하지 않았고 YAML·엔진·공유 파일은 수정하지 않았다. 재실행은 전부 통과했으며 현재 테스트 범위에서 부모에게 넘길 제작 코드의 실패는 없다.
