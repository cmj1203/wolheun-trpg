# 대실패 실제 PC 회귀

2026-11-09. NO_LLM 분리 서버 18251의 실제 새 게임과 행동 API를 PC 화면에서 진행했다. seed만 지정했고 상태나 응답을 주입하지 않았다. 실제 GM 생성 문장과 전 구간 스토리 QA를 통과했다는 보고는 아니다.

## 행운을 쓰지 않은 경우

`work/continuation/fumble-ui/seed75-decline.json`의 요청 3개는 모두 HTTP 200이다. 주사위 이벤트는 1개, 자연 눈 1·1, 합계 2, 대실패다. `sand_fall` 대가 1회와 별도 추가 체력 감소 1회가 적용됐다. 이후 세계 장면 효과까지 반영한 HUD는 체력 2/5, 정신력 3/5, 행운 6/10이다. 다음 행동 버튼과 입력창을 사용할 수 있었다.

`seed75-card.png`, `seed75-after.png`의 독립 화면 검수는 2/2 PASS다. `visual-review75.md`에 주사위·라벨·HUD·잘림과 겹침 확인을 남겼다. 숨겨진 DOM에 남은 행운 버튼 문자열을 화면에 보이는 버튼으로 세지 않았다.

## 행운으로 구제한 경우

`seed80-rescue-fixed.json`의 요청 3개는 모두 HTTP 200이다. 주사위 이벤트는 1개이며 자연 1·1이다. 행운 5를 사용해 합계 7로 구제하고 `open_sand` 대가 1회가 적용됐다. 추가 굴림이나 대실패의 추가 체력 감소는 없다.

첫 실행의 `seed80-rescue.json`에는 구제 이벤트가 있었지만 첫 세계 줄에서 안내가 사라졌다. 분기 맵 담당이 선행 효과의 소유권을 첫 세계 줄의 실제 반영까지 유지하도록 수정했다. 문자열 특례나 타이머를 추가하지 않았다.

수정 뒤 실제 화면 `seed80-rescue-fixed.png`에는 `대실패 → 아슬아슬한 성공`, `행운 5 사용 · 합계 7`, 남은 행운 1/10이 함께 보인다. 독립 검수 `visual-review80.md`는 PASS다. 이미 통과한 seed75 화면은 다시 검수하지 않았다.

효과의 다음 줄 정리·저장 복원·복원 다음 줄 정리·일반 대가 표시·다음 scene 정리는 `work/continuation/map/run/leading-change/after-check.json`의 6개 항목이 모두 true다. 해당 수정의 타입 검사는 같은 폴더 `typecheck-final.log`의 tsc exit 0이다. 이는 효과 수명의 집중 회귀이며 모든 scene/GM 조합의 전수 실행은 아니다.

## 종료와 남은 범위

검증용 Ego 공간 23을 닫고 리드가 띄운 18251 서버 감시를 종료했다. 사용자 18080/18081은 변경하지 않았다. 판정 엔진의 별도 집중 검증은 `docs/lead_check63/fumble64.md`를 따른다.

실제 GM 모델의 대실패 반응 문장과 전체 스토리 독립 검수는 남아 있다. 원화 승인도 이 화면 검수에 포함되지 않는다. 코드레빗 등록은 담당의 요청당 1회 시도가 변경 파일 수 한도로 거절됐으므로 검토 대기열에 등록됐다고 보고하지 않는다.
