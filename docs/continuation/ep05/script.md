# 월흔 5화 장면 대본과 컷별 전사

55컷 · 대사 포함 원본 15장. 게임 구현물이 아니라 후속 제작용 원작 기록이다.

## 읽는 기준

- `assets/ep05/cuts.json`의 55개 ID·PSD 이름·`y_range`를 그대로 따른다. 좌표는 원본 폭 2000px, 세로 `[시작, 끝)`이다.
- 전사 근거는 `work/ep05/merged/ep05_001.png`~`ep05_015.png`뿐이다. 글자를 지운 자산과 조사 메타데이터에서 대사를 가져오지 않았다.
- 15장 전체를 원본 해상도 5000px 이하 세로 크롭 78개로 빠짐없이 보았다. 글자가 경계에서 잘리면 다음 크롭과 이어 읽었다. 6쪽 호칭, 14쪽 독백·질문은 별도 원본 크롭으로 재확인했다. macOS Vision 결과는 보조 대조에만 썼다.
- 말풍선·독백의 줄바꿈은 문장으로 잇고, 길게 이어진 점은 `…`로 표시한다. 그림 속 효과는 대사와 분리한다. 보이지 않는 말을 채워 넣지 않는다.
- 초반 은발 남성을 아시나가 라 쿤으로 인식하는 대목은 c032다. 앞선 컷에는 실명·정체 설명을 덧붙이지 않는다.
- c037~c044 전반은 아시나가 없는 별실 장면이다. 독자가 본 정보를 아시나의 기억으로 넘기지 않는다.
- 청발·흑발 신하의 이름, 자이드의 지위·목적, “그 일”의 내용은 이 화에서 확정하지 않는다.

## 복장 표기

아래는 여러 컷을 모은 **참고 목록**이며 각 컷의 직접 확인을 대신하지 않는다. 각 컷의 `복장 직접 확인`만 그 컷의 관찰 사실이다. 화면 밖·얼굴·손 확대·무인 컷에서는 보이지 않는 부분을 미확정으로 적는다. `연속성 참고`는 근거 ID와 함께 적으며 **동일 장면 연속성 참고, 해당 부분 직접 확인 아님**을 뜻한다.

- **아시나 밤복장**: c002·c007에서 확인한 갈색 긴 머리의 일부 땋음·이마 파란 보석 줄·붉은 귀 보석·밝은 목둘레와 구슬 줄, 어깨가 드러나는 밝은 옷. 하의 구조는 이 근거들에서 미확정. 아침 옷과 구분한다.
- **아시나 A**: c013·c017·c023·c033에서 확인한 풀어 놓은 갈색 머리, 보라색 짧은 소매·흰 레이스·분홍 리본과 앞판. 전신 옷 구조·신발은 이 상체 근거만으로 확정하지 않는다.
- **아시나 B**: c045·c047·c048·c055에서 보이는 부분을 모은 참고. 갈색 긴 머리의 금빛 구슬 줄, 드러난 어깨·분홍 목띠·분홍 앞판과 금빛 문양 테두리, 연녹색 가슴 보석·검은 구슬 줄, 위팔의 금빛 테두리에서 길게 늘어진 분홍 천, 옆이 트인 긴 치마와 허리 줄 장식. 어깨의 밝은 부분은 피부이며 흰 옷으로 기록하지 않는다. 갈아입는 과정은 그리지 않았다.
- **은발 남성 / 라 쿤**: 은발·붉은 눈. 밤의 c001·c004 전신과 c002·c007·c009 근접을 합쳐 검은 긴 겉옷·밝은 바지·맨발·파란 보석 목걸이·여러 겹 금빛 줄·물방울형 귀 장식을 확인했다. 낮의 c037·c042 전신과 c049 근접에서는 붉은갈색 겉천·길게 늘어진 흰 천과 밝은 바지·황금빛 목천·붉은 보석·구슬 줄을 확인한다. 드러난 가슴을 흰 천으로 채우지 않는다. 전신과 근접 근거를 서로 다른 컷에 복사하지 않는다.
- **누르**: c014·c017·c047에서 보이는 부분을 모은 참고. 살구빛 짧은 머리의 윗부분을 뒤로 모음. 배가 드러나는 연두색 상의와 긴 소매, 회보라색 목둘레·테두리, 금빛 손목 장식. 폭이 넓고 길게 내려오는 연두색 하의와 보라색 계열 신발. 하의가 치마인지 바지인지는 주름만으로 단정하지 않는다. 쟁반·찻잔은 소품이다.
- **청발 신하**: c038·c040·c042에서 보이는 부분을 모은 참고. 청보라색 머리, 이마와 머리 옆의 금빛 줄, 푸른 긴 옷과 어깨 천의 금빛 문양, 초록 가슴 보석, 연두색 허리 천·구슬 줄, 갈색 신발.
- **흑발 신하**: 뒤로 모아 묶은 검은 머리, 가슴이 열린 검은 민소매 긴 옷, 금빛 사슬·노란 보석 허리 장식과 긴 귀 장식, 바지·장화.
