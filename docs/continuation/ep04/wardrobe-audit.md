# 4화 컷별 복장 검수

대사 포함 원본 15장·63컷을 직접 대조했다. 원본을 높이 3000px의 연속 조각으로 표시하고 컷 시작·끝 선을 겹쳐 확인했다. 전체 페이지 높이를 빠짐없이 보았으며 4화 c015·c028·c062는 컷 범위로 추가 확대했다. 기존 임시 조각 위치는 `/tmp/wolheun-source-ep04/`이며 아래 영구 원본 경로·좌표가 재현 기준이다. 클린 이미지·공통 의복 약기를 직접 관찰 근거로 쓰지 않았다.

- 인물·복장 정정: **4컷**. 전체 63컷의 복장·가림을 구체화했다. 단순 표현 보강과 장신구·하의 미확정 표기는 정정 수에 중복 산입하지 않았다.
- 세로 범위는 원본 픽셀 `[시작, 끝)`이다. 각 행은 해당 범위만의 직접 관찰이다. 앞뒤 컷은 ID와 함께 연속성 참고로 구분하며 숨은 부위를 확인했다고 쓰지 않는다.
- 기존 대사·사건·지식 공개 조건은 보존했다. 확인된 시각 배정과 복장 근거만 고쳤다.
