# 월흔 9화 후속 제작 입력

원본 전사·장면 설계 문서다. 게임 구현·실행·입식 제작 완료를 뜻하지 않는다.

## 근거와 범위

- 대사 포함 원본 18장, 컷 인덱스 84개, 대응 정제 그림 84개를 시각 확인했다. 긴 원본은 원래 좌표의 세로 분할로 읽고 작은 글씨는 원본 해상도로 확대했다. 컷 밖 여백까지 확인했다.
- 원문과 복장·지식 경계: `script.md`. 구조화 장면: `scenes.json`. 모든 ID는 `assets/ep09/cuts.json` 기준이다.
- 8장면·84컷을 순서대로 연결했다. 글·장식·전환 전용 컷도 `scenes.json`의 `cut_ids`에 포함하며, 독립 장면이나 CG로 만들 필요가 없는 컷은 인접 대화·전환으로 재생한다.
- 정제 그림은 `assets/ep09/cuts/full_res/clean/`에서 참조한다. 새 그림·가짜 대사·새 설정을 만들지 않는다.

## 의미 있는 입력 자리

후속 제작 후보이며, 전부 필수 입력으로 늘리라는 뜻이 아니다. 한 반응을 받은 뒤 장면을 진행한다. 동일 질문을 다시 걸지 않는다. 인접한 원작 대사가 이미 반응을 충분히 보여 준다면 입력 없이 이어도 된다. 아래 문구는 입력 목적을 설명하며 새 캐릭터 대사가 아니다.

| 입력 ID | 위치 | 플레이어가 답할 내용 | 고정 전개와의 경계 |
|---|---|---|---|
| ep09_i01 | c006 뒤, c009 앞 | 감시하는 듯한 카림에게 말을 거는 방식 | 장난·수다의 표현. 무기를 빼앗았다고 확정하지 않음 |

## 복장 재감사

대사 포함 원본 18개·84컷을 원본 좌표와 기존 크롭으로 대조했다. 전 컷 직접 관찰·가림·원본 경로·y_range는 `wardrobe-audit.md`에 있다. 확정 오류는 10컷이며, 전체 84컷의 관찰 범위를 다시 기록했다. 머리·모자·의상 일부가 잘렸으면 '해당 컷에 보이지 않음/미확정'으로 남긴다. 손·얼굴·여백 컷에 장면 전체 차림을 붙이지 않는다.

- ep09_s01: 아시나 낮 차림은 c009·c013, 카림 차림은 c001·c011·c013에서 범위를 나눠 참조한다. c021에는 나시르 얼굴 삽화가 있다.
- ep09_s02: c016은 황제 옷자락·발만, c018은 상반신, c019는 원경이다. 나시르 c023의 긴 하의는 해당 컷에 보이지 않음; 연속성 참고: ep09_c019·ep09_c027.
- ep09_s03: c038 나시르 목 브로치, c040 황제 몸통 의상은 해당 컷에 보이지 않음. 연속성 참고: ep09_c035·ep09_c041.
- ep09_s04: c048은 얼굴만, c052는 펜 든 손만이다. 전신 의상은 해당 컷에 보이지 않음. 연속성 참고: ep09_c047·ep09_c049.
- ep09_s05: c051 회상은 흰색·연푸른색 차림과 푸른 머리리본·분홍 목띠를 사용한다. 낮의 보라 궁정복과 분리한다. c053의 왕좌는 비어 있고 예복·갑옷 인물은 없다.
- ep09_s06: c066의 흰 어깨 장식은 해당 컷에 보이지 않음. c068은 작은 나시르 삽화로 실제 의상 전환이 아니다.
- ep09_s07: c073은 입·귀 일부만, c075는 남색 밤 차림과 흰 긴 안옷·무늬 허리띠, c077은 상반신이다. 연속성 참고: ep09_c075; c077의 치마 전체 직접 관찰 아님.
- ep09_s08: c078은 검은 실루엣·푸른 눈만. c081의 대족장 얼굴 상부·터번은 부분 노출, c082 눈색은 그늘로 미확정이다. 연속성 참고: ep09_c084의 푸른 눈·남보라 터번·은사슬. c080에는 아래 인물이 보이지 않는다.
