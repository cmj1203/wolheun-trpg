# 월흔 9화 컷별 복장 감사

대사 포함 원본 18개·84컷 전수 대조. 좌표 기준: `assets/ep09/cuts.json`. 기존 `/tmp/wolheun-source-ep09/` 원본 크롭을 재사용하고 긴 그림은 기존 분할 타일로 확대했다. 정제 자산으로 대사·착의를 보충하지 않았다.

확정 오류 10컷, 전 컷 관찰 범위 정비 84컷. 오류 수는 컷 단위이며 여러 필드·문서에 반영해도 한 번 센다. 나머지는 관찰 범위 보완이다.

## 관찰 기준

직접 관찰 열은 그 컷에 보이는 것만 적었다. 가려진 머리·모자·의복·신발은 '해당 컷에 보이지 않음/미확정'으로 둔다. 인물 없음은 화면에 없다는 뜻이며 실제 장소 부재를 뜻하지 않는다. 연속성 참고는 명시한 인접 컷의 정보이며 해당 컷의 직접 관찰로 옮기지 않는다. 장면 전체 의상을 얼굴·손·여백 컷에 붙이지 않는다.

## 남은 불확실성

가림·원경·그늘·머리카락 아래의 세부는 각 행에 남겼다. 가려진 부분을 새로 설계하거나 앞뒤 컷과 같다고 확정하지 않았다. c078의 터번·의상, c081·c082의 눈색은 각각 직접 관찰 미확정이다. c084의 공개된 차림을 이전 부분 컷으로 소급하지 않는다. 8→9→10 상태와 9→10 공격·귀환·짐 반환의 생략은 기존 문서대로 보존했다.
