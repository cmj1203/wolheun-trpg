# group_b 가방 손실 차분

배정 목록 `work/continuation/ep02/bag-variants/group_b_assignment.json`의 정확한 13개 파일만 대상으로 한다. 결과는 `assets/ep02/gen/no_bag/group_b/`, 작업·마스크·검증 자료는 `work/continuation/ep02/bag-variants/group_b/`에 있다.

최종 판정과 CG 키 연결은 작업 폴더의 `manifest.json`을 따른다. 통과하지 못한 항목은 통합하지 않는다. 이 문서는 전체 프로젝트 READY 선언이 아니다.

- 입력은 배정된 정확한 원본 파일과 그 파일에서 잘라낸 ROI다. `sources.json`에 시작 해시, 크기, 원작 `source_file`·`source_box`를 기록했다.
- Codex CLI native `image_gen`을 트랙당 한 번에 하나씩 실행했다. `stdin=DEVNULL`, `start_new_session=True`이며 각 실행 폴더에 argv·PID·PGID·로그·완료 기록을 남겼다.
- 원격 생성에는 `heavy`를 사용하지 않았다. 로컬 작업은 한 번에 한 이미지씩 읽는 Pillow 크롭·마스크 합성으로 제한했다.
- 생성물 전체를 결과로 쓰지 않는다. `masks.json`의 도형에서만 복원 ROI를 합성한다. 원본 얼굴·표정·머리·손·옷·시민의 보존 영역은 원본 픽셀로 유지한다.
- `mask.png`는 ROI 좌표, `mask_full.png`는 원본 전체 좌표다. 확장 폭과 제외 도형도 기록돼 있다. 최종 알파는 원본 알파를 그대로 사용한다.
- `comparison.jpg`는 왼쪽부터 원본 ROI, 생성 복원 ROI, 합성본, 마스크 표시다. `overview.jpg`는 원본 전체와 합성본 전체다.
- 정량 검증은 원본·원작 해시 불변, 출력 디코딩, 캔버스·알파 동일, 마스크 외 변경 픽셀 0을 확인한다. 정량 통과만으로 가방 제거·경계 품질을 통과시키지 않는다.
- 원작 c009 전체를 확인해 목매듭의 가느다란 리본 꼬리와 의상 파이핑을 가방끈과 구분했다. 녹색 독립 천은 보존하며 별도 옷깃 분기는 수행하지 않았다.
- `ep02_c034_wrist`의 오른쪽 아래 갈색 부분은 남자의 소매이므로 제거하지 않았다. `ep02_c040_return`에는 배정표의 `bag=no`와 달리 허리 밖 가방 몸체도 있어 별도 국소 복원을 시도했다.
- 초기 감독 프로세스의 감시 제한 종료가 한 번 있었다. 분리된 손목 컷 생성은 취소·재실행하지 않고 끝까지 보존했다. `ep02_c034_wrist/recovery.json`에 종료 코드 미확인 사실을 기록했다. 이후 감독 프로세스 자체도 분리하고 완료 파일을 지속 감시했다.
- `ep02_lockpick` 첫 생성은 출력 안전 검사에 거부됐다. 기구·손을 변경하지 않는 천 영역의 작은 크롭으로 다시 제작했으며 기존 실패 로그를 보존했다.

후속 독립 검수는 부모/리드가 맡는다. 하위 작업을 추가로 만들지 않았고 정상 원본·초기 작업자의 산출물·root 인물 작업·앱 연결을 변경하지 않았다.

## r4 복구와 제한 수리

- 기존 실행 26개의 PID·PGID와 실제 프로세스를 대조했다. 살아 있는 이전 작업은 없었고 원본 13개와 기존 결과 13개의 해시가 이전 기록과 일치했다. 손목 컷의 종료 코드는 기존 복구 기록대로 미확인 상태를 유지했다.
- 이번 그림 변경은 `ep02_c032_raise_veil`, `ep02_c032_leave` 두 파일뿐이다. 원본 13개와 나머지 결과 11개는 해시가 그대로다. 수리 전 후보·마스크·보고 기록은 `recovery_backup/`에 보존했다.
- `raise_veil`: 기존 GPT 천 복원을 재사용했다. 머리 끝 보호 도형이 실제 머리보다 넓어서 남긴 가방색을 원작 4배 확대의 윤곽에 맞춰 제거했다. 새 생성은 0회다.
- `leave`: 원본의 205×220 가방 크롭을 벽으로 복원했다. 앞쪽 검은 세로선은 망토 테두리가 아니라 벽 이음선이었다. 벽 받침까지 포함한 240×400 크롭으로 원래 위치를 유지했고, 실제 끈 윤곽에서 놓친 2픽셀 구간만 추가했다. 원격 생성 3회는 모두 직렬 실행했고 종료 코드 0이다. 중간 후보도 보존했다.
- 두 결과 모두 출력 디코딩·원본 및 원작 해시 불변·캔버스 및 알파 동일·마스크 밖 변경 0을 확인했다. 자세한 원본·결과·마스크 해시는 `recovery_r4.json`과 각 `verification.json`에 있다.
- `c050`은 c048·c049·c051·c052까지 원작 전체를 확인했다. 앞뒤 컷은 남성 인물과 문장이며, c050 여주인공의 가방과 긴 머리 연결을 더 드러내지 않는다. 미확정·원본 보존을 유지하며 새 생성이나 삭제를 하지 않았다.
- 스크립트의 JSON 값 종류를 경계에서 확인하도록 바꾸고, 파일 쓰기·이미지 읽기의 반환값과 문자열 연결을 명시했다. Pillow의 NumPy 타입이 있는 기존 환경을 검사에 지정했다. 경고 억제·검사 완화·새 의존성 설치는 하지 않았다. 수정 전 161경고·종료 1은 실패이며, 수정 후 오류 0·경고 0·종료 0과 별도 로그로 구분한다.
- 새 worker나 독립 검수는 만들지 않았다. 수리 두 컷은 부모의 기존 Claude QA `st_01a1bdfa` epoch8 승인 대기다. 기존 자체 통과 10개도 독립 승인이 아니다. `cg_map` 또는 `usable_map`을 앱에 설치하지 않았다.
