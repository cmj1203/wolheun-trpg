혼합 입력은 `（그의 눈을 피하지 않고 손목을 잡은 손을 내려다본다） 잡은 손부터 놓아 주세요.`다. 모델은 압박에 대한 반응과 요구라고 설명하면서도 `kind: action`, `target: local`, `stat: 매력`으로 분류했다. 생성 문장에는 “그의 움직임을 읽어낸 남자가 내 손을…”이라는 주체가 꼬인 지문도 있었다. 단어 하나를 바꾸는 대신 입력 종류와 반응 경로를 바로잡아야 한다. 증거는 `work/continuation/ep02/run/mixed-speech-quality-proof.json`이다. 이후 실행 파일의 혼합 입력 검사를 실제 무판정 계약으로 강화했으며, 아직 강화본으로 모델을 다시 호출하지 않았다.

공개 뒤에도 페시안·감옥·시하드 질문은 “그건 아직 몰라.”로 돌아왔다. `loreFor`가 열린 conditional hidden 항목의 tier를 유지하고, 질문 해석 목록·스키마는 원본 lore에서 hidden을 제외한다. 실제 감옥 상태에서 fesian/jail이 열려도 질문 대상 enum에는 둘 다 없음을 `work/continuation/ep02/run/opened-knowledge-proof.json`으로 재현했다. 공개 시점별 미래 정보 누출과 별개로, 공개된 정보를 계속 질문할 수 없는 결함이다.
