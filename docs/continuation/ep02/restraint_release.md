# 감옥 첫 팔 붙들림 종료 근거

호위가 손을 놓는 동작은 원작에 나오지 않는다. 아래 시점에서 현재 붙들림이 더 이상 성립하지 않는다는 사실만 반영한다.

| 원작 | 직접 확인한 근거 | 적용 |
|---|---|---|
| ep01_c076 | 감옥 탑 외관. 아시나의 손이나 호위는 보이지 않는다. | 더 이른 해제를 추정하지 않는다. |
| ep01_c077 | 아시나가 감방 바닥에 혼자 쓰러져 있다. 양손과 손목이 자유롭게 바닥에 놓여 있고 누가 붙들고 있지 않다. 벽의 사슬·수갑은 손목에 연결되지 않았다. | 현재 `팔_붙들림`만 false. |
| ep01_c078 | 전사상 몸을 일으키며 사람을 부른다. | 최초 확인은 이미 c077이므로 이 줄까지 늦추지 않는다. |

1차 그림: `assets/ep01/cuts/full_res/text/ep01_c077.png`를 직접 열어 확인했다. 전사: `assets/ep01/ep01_script.md` S11/c076~c078.

실제 적용은 `app/content/ep02_captivity.yaml`의 `ep02_prison_wake.lines[1]`이다. 기존 “하아… 여기가 어디지…”와 `ep02_prod_ep01_c077_floor`, `후드_벗음`을 유지하고 `effects.flags.팔_붙들림=false`만 추가한다. 첫 scene 진입과 앞 c076 외관 줄에서는 붙들림을 지우지 않는다.

기존 guard_grip/guard_hold는 체력 -1·의심 +1과 붙들림을 적용한다. 현재 붙들림 종료가 체력·의심을 돌려주거나 통증의 과거 기록을 삭제하는 것은 아니다. 다른 비용·플래그·소지품·능력·난수·발화/로그를 초기화하지 않는다. 새로운 해제 대사는 쓰지 않는다.

집중 회귀는 두 옛 포획 종료 저장을 실제 저장/읽기로 넘겨 scene/c076에서는 true, c077 첫 fresh line에서 false를 확인한다. 기존 비용·기억·로그·RNG 보존과 이후 다른 시점의 재개가 다시 해제를 수행하지 않는 것도 검사한다. 단위 fixture이며 실제 전 구간 완주 증거가 아니다.

이 변경 전 이미 c077을 지나간 구형 중간 저장에 해당 효과를 소급 재생하지 않는다. 이후 다른 붙들림까지 지우는 일반 재개 보정은 하지 않았으며, 그런 구형 저장 이행이 필요하면 실제 지나간 줄과 이후 상태 증거를 구분한 별도 계약이 필요하다.
