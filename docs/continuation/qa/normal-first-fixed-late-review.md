- UI 렌더링, 화자 이름표의 실제 표시, 텍스트 잘림·배치·가독성은 확인하지 않았다.

- 원본 웹툰 그림 전체를 다시 읽은 검수가 아니다. 필요 구간의 기존 원작 전사와 YAML을 대조했다.
- 다른 행동 경로, 자유 입력과 모델 생성 대사 전체, 게임 전체 품질은 승인하지 않는다.
- 모델 엔드포인트·브라우저를 호출하지 않았고 서버를 재시작하지 않았다. 소스·기존 대사는 수정하지 않았다.
