# b08 의도 구분 실험 준비

아직 모델을 호출하지 않았다. 현재18196은 branch-map 독점 창이다. 공유 분류 수리와 리드의 별도 배정 뒤에만 실행한다.

원점은 첫 실제 판 `real-1794202058383`의 실제 획득 저장이다. 처음 b08에 도달한 `canonical_first_4`와, 앞선 말 두 번 뒤 `canonical_first_7`을 섞지 않는다. 색인·파일hash·rootSession/seed·행동 로그를 확인하고 저장 값을 그대로 사용한다.

첫 판은 행운 확인이 없는 엔진 설정이었다. 그 저장을 정상 앱 설정의 완주 계보로 승격하지 않는다. 아래는 그 실제 상태에서 해석과 반응을 비교하는 집중 실험이며 정상 설정의 정사 대표판은 별도 새 newGame이다.

| 구분 | 같은 실제 상태에서 줄 입력 | 확인할 사항 |
|---|---|---|
| 기존 기준 | 첫 판 행동5의 눈맞춤+길 잃었다는 말 | 기존 결과 person/target none을 보존한다. 수리 뒤 비교할 때도 새로운 관측으로 구분한다. |
| 의도 있는 사회적 시도 | `(붙들린 팔은 그대로 둔 채, 상대가 압박해도 끝까지 시선을 피하지 않으며 겁먹지 않았음을 보여 살려둘 가치를 납득시키려 한다)` | 현재 저항·압박 아래 시도하는 사회적 성취로 읽는지 확인한다. stare 낱말만으로 판정을 강제하지 않는다. 실제 target·판정·대가·전이를 기록하며 원하는 tier를 주입하지 않는다. |

| 화면 예시 | `(똑바로 눈을 마주본다)` | YAML hint와 example이 시도하는 도전으로 안내되는지, 아니면 단순 순간 반응으로 읽히는지 검수한다. 실패하면 예시/목표/분류의 UX 계약 문제로 남기고 문구 목록만 늘리지 않는다. |

각 분기는 같은 실제 저장을 읽어 독립적으로 시작한다. flags/items/RNG/beat/free/기억을 수정하지 않는다. 해석만 검사한 결과와 실제 act로 진행한 결과를 분리한다. 다른 진짜 결말이면 그대로 끝내며 자동 선택이나 정사 합류를 넣지 않는다.

## 호위 연속성

첫 판 행동3의 guard_grip과 행동4의 guard_hold는 모두 실제 miss 비용이다. 새로운 호위를 등장시킬 근거가 아니라 기존 구속을 강화하는 근거다. 잡힌 팔을 둔 회피 입력과 서술이 연결되는지 확인한다. 손목 통증·이미 지불한 체력과 의심은 붙들림 종료와 별개다.

후속 c077은 원작에서 양손이 바닥에 자유롭게 놓인 첫 확인 시점이다. 해당 줄의 `팔_붙들림=false`만 적용한다. c076 외관이나 chapter 전체를 이유로 지우지 않는다. 현재 사실 투영·공유 source 변경은 demo-slice 소유다.
