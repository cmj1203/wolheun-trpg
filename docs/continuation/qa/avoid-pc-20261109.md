# 회피 성공 경로 PC 검증

2026-11-09. 실제 새 게임 seed 1에서 행동 버튼으로 진행했다. 상태·판정·응답을 주입하지 않았다. NO_LLM 서버이므로 생성 대사나 자유 입력 의미 해석의 품질을 검증한 실행은 아니다.

## 실제 경로와 결과

정본은 `work/continuation/avoid-ui/attempt2/final.json`이다. 새 게임과 두 행동 요청은 모두 HTTP 200이며 실제 결과 조회 `/api/result`도 200이다.

| 행동 | 실제 판정 | 후속 |
|---|---|---|
| 몰래 돌아서 피해 간다 | 자연 2·4 + 재치 1 = 7, 아슬아슬한 성공 | `mind_strain` 대가 1회, `r3_slip → r3_dusk` |
| 바람을 피할 곳을 찾는다 | 자연 6·6, 대성공 | `r3_night → e_road`, ending `road` |

실제 scene 전체는 `b00_open → b01_sand → b02_people → r3_slip → r3_dusk → r3_night → e_road`다. 길 묻기·칼·감옥·강제 포획 비트는 이 경로에 없다. 결말 이벤트는 `bad:false`, 제목은 `크라차로 가는 길`이다. 결과 화면에는 두 판정과 긴장으로 인한 정신력 대가가 기록되고, 다음 장면은 잠겨 있다. 포획 본선으로 계속하는 버튼은 없다.

첫 회피 뒤의 실제 화면에서 멀어졌다는 대사와 황혼의 다음 행동 버튼을 확인했다. 밤에 남자가 물주머니를 남기는 기존 분기 대사는 있지만 아시나를 잡는 결과로 바뀌지 않는다. 마지막 대성공의 회복까지 적용한 최종 체력·정신력은 각각 5/5다. 이를 회피 대가가 없었다는 뜻으로 해석하지 않는다.

## 화면 증거와 실패 보존

- `avoid-mixed-card.png`: 2·4 + 1 = 7과 아슬아슬한 성공, 독립 검수 PASS.
- `after-avoid-dusk.png`: 황혼의 실제 행동 자리, 독립 검수 PASS.
- `road-ending.png`: 결말 제목은 확인됐지만 한 장만으로 후속 전체를 증명하지 못하므로 독립 검수 PARTIAL. 위 실제 이벤트와 결과 조회를 함께 사용한다.
- 최초 `road-summary.png`: 리드의 서버 감시 기본 기한이 끝나 결과 API를 조회하지 못한 인프라 FAIL. 삭제하거나 PASS로 바꾸지 않았다.
- `attempt2/road-summary-fixed.png`: 기한 없는 분리 서버에서 새 게임부터 같은 두 행동을 진행한 최종 결과 화면. 실제 결과 조회 200을 확인했다. 독립 검수 `attempt2/visual-review-summary.md`는 제목·본문·혼합 회피 기록·오류 없음·잘림과 겹침 없음 PASS다.

첫 실행의 새 괄호 표현은 NO_LLM에서 목표를 확인하지 못해 rewrite됐다. 이후 화면의 정식 행동 버튼으로 진행했다. 이 실패를 자유 입력 품질 PASS로 세지 않는다. `progress1.json`, `progress2.json`, 원래 `visual-review.md`에 첫 실행의 기록을 보존했다.

두 번째 실행에서는 결과 요소 선택자를 잘못 적은 검증 스크립트가 대기 시간 초과됐다. 게임은 이미 정상 결과 화면에 도달해 있었다. 새 게임이나 행동을 다시 실행하지 않고 실제 `#result` 요소에서 캡처·응답 기록만 마쳤다.
