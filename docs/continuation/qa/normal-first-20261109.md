## 발견 사항

### P1. 없는 외모 조롱을 후반에 회상

행동21 `ep04_c058`의 “하, 대체 어디가 미소녀냐면서 비웃었으면서!”는 이번 사막 이력에 없는 조롱을 기억한다. 원래 미인계 대화는 이번 plead 입력과 생성문에서 전달되지 않았다. c047에서 아시나가 “미소녀를 이렇게 대하다니!”라고 말한 것은 있지만, 남자가 외모를 비웃은 과거까지 만들지는 않는다. 뒤 c061의 새 반응은 앞선 회상의 근거가 아니다.

원작 회상 자체를 거짓이라고 판단한 것이 아니라, 다른 실제 자유 입력 경로에 원작 회상이 무조건 이어지는 계약 문제다. 실제 발화·사건에 따른 회상 분기가 필요하며 이번 보고에서는 원문·소스를 고치지 않았다.

### P2. 정상 동사를 숨긴 이름으로 오인해3회 반려

행동4 b05 narrate 시도1~3에서 “목을 짓누르던”을 포함한 정상 서술이 `lore/spoilers: 누르`로 반려됐다. 원시 추적5·6·7 모두 같은 유형이며 실제 누르라는 인물을 소개한 문장이 아니다. 최종적으로 고정 대사 fallback이 전달됐다. 유효 반응의 재생성과 지연을 만들었다. 단어 목록을 늘리거나 재시도 수를 올리는 방식으로 해결했다고 세지 않는다.

### P2. 잘린 해석 JSON 때문에 자연스러운 반박이 진행되지 않음

- 행동17: “듣지도 않고 도둑으로 몰지 마세요. 물건을 훔친 적 없어요.”에 대한 원시 해석은 ep04_heard/action으로 시작했지만 마지막 difficulty 문자열이 닫히지 않았다. 실제 `Unterminated string` 뒤 rule talk으로 내려가 판정이 일어나지 않았다.
- 행동18: “(또렷하게 상대를 바라본다) 무슨 근거로 그런 말을 하는 거죠?”도 사회적 도전이라는 reason 도중 JSON이 끊겼다. GM은 “행동의 성공 목표를 확인하지 못했어…”라는 재입력 안내를 전달했다.
- 행동19의 세 번째 계획 입력 “제 이야기를 먼저 들어 주세요.”에서야 ep04_heard mixed로 진행됐다.

### P2. 제작용 미확정 표시가 전달 화자 필드에 남음

## 고정1175줄과 남은 범위

고정539줄(행동0~25)과636줄(행동26~46)은 서로 다른 검수 작업에서 전부 읽고 필요한 전사·YAML 구간과 대조했다. 전반의 없는 조롱 회상과 후기의 제작 메모 표시, 비문·표기 후보를 인수해 위에 통합했다. 원본 그림 전수 재판독을 했다는 뜻은 아니다.

- `docs/continuation/qa/normal-first-fixed-early-review.md`
- `docs/continuation/qa/normal-first-fixed-late-review.md`

이번 실행에 대실패는 없었다. 다른 결말, 모든 대가·소지품 분기, 단순 idle 및 큰 행동, 새 세이브의 실제 HTTP 재개와 UI/frame, 그림·복장·시각 전환·소리는 검증하지 않았다. 두 옛 guard 비용의 연속성과 구형 중간 저장 이행도 이 완주로 승인하지 않는다. 확인한 것은 정상 설정 첫 엔진 완주와 전달된 전 대사 검수이며, 결함 없는 전체 게임 인계가 아니다.
