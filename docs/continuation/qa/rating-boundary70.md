# 단어 경계의 등급어 오탐

실제 검수 69의 입력 `(순찰병에게 들키지 않도록 금속 소리를 죽이며 핀으로 잠금쇠를 풀고 문밖으로 나간다)`가 판정 없이 대화로 처리됐다. 모델 interpret 호출은 없었고, `ruleInterpret`를 같은 입력으로 직접 실행하자 `{kind:"deflect", reason:"gore: 고문"}`이었다.

`ratingIn`이 공백을 모두 없애면서 `풀고 문밖`의 두 단어 조각을 `고문`으로 합쳤다. 기존 `자, 해 봐요` 예외로는 다른 단어 경계의 오탐을 막을 수 없었다.

등급어가 붙어 있는 입력은 기존처럼 검사한다. 띄어 쓴 등급어를 찾을 때는 단어 중간에서 검사를 시작하지 않도록 문자·숫자 경계를 적용했다. 새 예외 낱말은 추가하지 않았다.

| 검증 | 수정 전 | 수정 후 |
| --- | --- | --- |
| `잠금쇠를 풀고 문밖으로 나간다.` 입력·출력 | 실패 | 통과 |
| `문을 열고 문턱을 넘는다.` 입력·출력 | 실패 | 통과 |
| `치마 약간만 접어 올린다.` 입력·출력 | 실패 | 통과 |
| 기존 등급어의 띄어쓰기 우회 탐지 | 변경 없음 | 통과 |
| 기존 `자 해보자` 등 무해 문장 | 변경 없음 | 통과 |

관련 회귀는 7 통과, 0 실패, 단언 35개였다. 타입검사는 종료 코드 0, 진단 0바이트였다. 전체 시험을 다시 실행한 결과는 아니다.

실제 검수 70은 검수 69의 획득 저장 `canonical_resume_0`에서 같은 입력 계획으로 재개했다. 저장은 `ep02_unlock`, 루트 세션 `qa-canonical_first-1794244329776`, seed 913이며 SHA-256은 `8e8838b2f1bb965e0bb1f733a62dd75aad2fc9e5c542b3f5196e90bdcb9bc975`이다. 파일 해시와 최초 newGame 계보를 검사한 저장 재개이며 상태 주입은 없다.

같은 후속 입력에서 실제 모델 해석과 `[6,5] + 손재주 1 = 12`의 성공 판정이 발생했고 `ep02_question`까지 진행했다. 단어 경계 결함의 실제 재현은 통과했다. 이후 추궁 장면의 세 입력을 소진해 69.14초, 종료 코드 1로 멈췄다. 전체 완주 통과는 아니다.

생성 네 줄을 직접 읽었다. 잠금 성공 문장에는 `달칵, 소리 없이`라는 모순이 있었고, 추궁 장면에는 현재 문맥에 근거 없는 칼날 위협이 추가됐다. 기존 교열 요청 재현에서도 둘을 그대로 통과시켰다. 이 문제는 등급어 경계 수정과 별개로 진단 중이다. `grounding71-probe.log`에서 문맥 대조 지시를 추가한 진단은 소리 모순만 찾았고 칼날 전제는 놓쳤다. 아직 둘을 모두 해결했다고 간주하지 않는다.

검수 69의 생성 문장 두 줄은 직접 읽었다. 입력한 잠금 해제와 문밖 이동이 완료되지는 않고 손끝을 집중하는 묘사만 나왔다. 따라서 생성 문장이 있다는 사실을 행동 성공으로 보지 않는다.
