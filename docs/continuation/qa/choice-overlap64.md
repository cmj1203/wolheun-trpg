# 선택지와 대사창 겹침

2026-11-09. 6화 실제 경계 화면에서 계속 버튼 아래쪽이 대사창에 가렸다.

## 원인과 수정

대사창은 아래 입력줄 간격과 실제 내용 높이로 배치되지만 선택지는 `bottom: 27%`로 따로 배치됐다. 따라서 두 요소의 높이 계산이 달랐고, 버튼의 일부가 나중에 그려지는 대사창 뒤로 들어갔다.

`app/web/style.css`에서 대사창을 CSS 앵커로 지정하고 선택지 아래쪽을 실제 대사창 위쪽에서 `2cqw` 떨어뜨렸다. `app/web/index.html`에서는 앵커를 참조하는 선택지 요소를 대사창 뒤로 옮겼다. 글·색·버튼 동작·장면 데이터는 변경하지 않았다. z-index나 타이머로 가림을 덮지 않았다.

## 실제 검사

같은 실제 획득 저장의 6화 경계와 정식 지도 체크포인트 c30의 10화 세 선택지를 사용했다. 상태·대사·판정을 주입하지 않았다.

| PC 크기·장면 | 선택지 아래 | 이름표 위 | 대사창 위 |
|---|---:|---:|---:|
| 1440×1000 · 6화 계속 | 641.67 | 649.88 | 670.47 |
| 1280×900 · 6화 계속 | 575.94 | 583.34 | 601.53 |
| 1440×1000 · 10화 세 선택지 | 641.67 | 이름표 없음 | 670.47 |

각 버튼은 화면 안에 있고 대사창과 분리됐다. 두 PC 폭의 계속 버튼과 세 선택지 캡처는 독립 화면 검수 3/3 PASS다. 10화 가운데 버튼 `ep10_contact_refuse`도 실제로 눌러 HTTP 200 한 번과 다음 대사 `손 놔요.`를 확인했다. 중복 제출은 없었다.

증거는 `work/continuation/campaign-ui64/choice-overlap/`의 `after-1440.png/json`, `after-1280.png/json`, `three-choices-1440.png/json`, `click-proof.json`, `visual-review.md`다.

## 결과 화면과 검증 스크립트의 한계

별도 최초 10화 결과 캡처는 하단 버튼 일부가 화면 끝에 걸려 독립 검수 PARTIAL이었다. 결과 화면은 긴 돌아보기 열과 짧은 수치·버튼 열이 나란히 있고 수직 스크롤을 지원한다. 실제 버튼 묶음으로 스크롤한 1508×887 화면에서는 네 버튼 모두 결과 영역 안에 표시됐다. `result-controls-1508.png`, `result-controls-proof.json`에 기록했다. 보충 캡처의 독립 검수는 PASS이며 최초 캡처의 PARTIAL은 그대로 보존했다. 결과 화면의 CSS나 동작은 수정하지 않았다.

최대 아래로 스크롤하면 긴 왼쪽 돌아보기의 끝으로 가므로 짧은 오른쪽 열의 버튼은 위로 벗어난다. `result-scroll-settled.json`의 이 관찰을 버튼이 접근 불가능하다는 뜻으로 세지 않는다. 처음 스크롤 시도는 smooth 이동 중 값을 읽었으므로 확정 근거가 아니다.

검증 스크립트는 처음에 시작 화면 뒤의 헤더 불러오기를 누르려다 실패했다. 실제 시작 화면의 이어하기로 수정했다. 버튼을 누른 뒤에는 숨은 요소를 “보이는 요소”로 기다리는 잘못된 선택자 조건도 시간 초과됐다. 실제 요청은 이미 200이었으며 다시 클릭하지 않고 원래 응답과 숨김 상태만 보존했다.

## 기계 검사와 검토 대기열

Impeccable 검사는 1회 실행해 종료 코드 2였다. 기존 제목 대비 2건, src 없는 이미지 태그의 정적 경고 5건, 기존 그림자 1건, 기존 모션 권고 1건이 남았다. 이번 배치 변경이 건드리지 않은 색·이미지·모션까지 수정하지 않았다. 이를 검사 전체 PASS로 보고하지 않는다. 원문은 `detector.json`이다.

코드레빗 등록도 1회 시도했지만 변경 1378개가 한도 150개를 넘어 종료 코드 1로 미등록됐다. 원문은 `code-review-queue.log`다. 공유 작업을 임의로 커밋하거나 숨겨 우회하지 않았다.

JS·TS 제품 코드와 게임 규칙을 바꾸지 않아 기존 타입 검사를 반복하지 않았다. 새 HTML·CSS는 실제 브라우저 적재와 계산된 앵커·좌표로 검증했다. 다른 브라우저와 모바일은 이번 검사 범위가 아니다.
