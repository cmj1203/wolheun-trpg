# 분기 맵 장면 이미지

2026-11-09. 사용자가 10화 지도에 `방 안의 대화`만 반복되고 장면 그림이 없는 문제를 지적했다.

기존 지도는 비트 제목만 그렸고 이미지 데이터와 렌더링이 없었다. 각 노드 안에서 마지막으로 표시한 비트의 첫 줄 CG를 지도에 연결했다. 첫 줄이 조건부이거나 CG에 상태별 대체 그림이 있으면 해당 비트의 배경을 사용한다. 미표시 비트나 뒤쪽 대사에서 그림을 가져오지 않는다. 미방문 노드에는 이미지 식별자를 보내지 않는다. 표시 이력이 있으면 엔진 선처리 로그보다 표시 이력을 따른다.

그림 URL과 크롭은 기존 manifest와 `paint` 함수를 그대로 사용한다. 그림이 있는 지점은 이미지 카드, 그림이 없는 연결·결말 지점은 작은 원으로 표시한다. 선택한 카드의 그림은 오른쪽에도 표시한다. 지도가 길어져도 자동 축소가 75% 아래로 내려가지 않게 해 장면 그림을 읽을 수 있도록 했다. 가로·세로 스크롤과 확대·축소, 방문 기록별 재시작은 유지한다.

성세천하의 공식 Steam 참고 그림은 `work/continuation/map-thumbnails64/reference-steam.jpg`다. 이전 `docs/research/seongse_ending_study.md`는 엔딩 구조 조사였고 실제 지도 그림 검증 자료는 아니었다. 이번에는 공식 화면에서 장면 이미지 카드와 작은 연결 지점을 직접 확인했다.

집중 시험은 수정 전 썸네일 누락으로 7개 실패했고 수정 후 7개 통과, 8개 검증이다. 이후 최근 표시 비트를 고르는 회귀 한 건을 추가해 수정 전 실패와 수정 후 1개 통과를 확인했다. 기존 7건은 반복하지 않았다. 최종 strict 타입 검사는 종료 코드 0이다. 단일 시험 필터를 처음 잘못 지정해 0건 실행된 실패는 실제 이름으로 바로잡았다. 별도 코드 규칙 검사기는 프로젝트에 TypeScript 패키지가 없어 종료 코드 2로 실행 불가였다. 이를 타입 검사 통과와 혼동하지 않는다. 기존 전체 시험이나 모델 캠페인은 반복하지 않았다.

실제 획득한 캠페인 지도로 격리 서버 18253에서 확인했다. 최종 10화 표시 노드 24개 중 이미지 카드 19개, 서로 다른 그림 17개다. 나머지는 이미지가 없는 연결·결말 지점 또는 미방문 지점이다. 1440×1000, 1280×900에서 선택 노드 n139의 그림과 오른쪽 미리보기는 같은 `ep10_c007`이다. n140을 누르면 미리보기도 `ep10_c014`로 바뀐다. 끝 지점 n164를 실제로 누르면 가로 스크롤 762에서 화면 안에 표시된다. 상태·대사·판정을 주입하지 않았다.

최초 화면 검수는 연결 원 바깥에 큰 카드가 남아 FAIL이었다. 원 자체를 48×48로 배치하고 연결선 끝도 실제 원의 크기에 맞춰 수정했다. 최종 화면의 원은 75% 배율에서 36×36이다. 최초 실패 캡처와 보고는 보존했다.

증거는 `work/continuation/map-thumbnails64/`의 `test-thumbnail64.log`, `test-green.log`, `test-latest-green.log`, `strict-final.log`, `ui-final-proof.json`, `ep10-after-1440.png`, `ep10-after-1280.png`, `visual-review.md`다. 기존 체크포인트 n154 재시작 후 세 선택지 복원도 `restart-proof.json`에 기록했다. 이미지 자체의 새 미술 승인이나 모델 대사 품질 통과를 뜻하지 않는다.
