## 입력을 받을 자리

각색안이다. 원작 대사와 입력 뒤 생성한 말을 혼동하지 않는다. 다음 두 자리만 선택적 입력으로 두고, 입력하지 않으면 원작 대화로 이어 간다.

| 입력 ID | 위치 | 실제로 답할 문제 | 바뀌는 범위 | 바뀌지 않는 사실 |
|---|---|---|---|---|
| ep03_i01 | c046, 시녀가 하렘을 영광이라고 말한 뒤 | 자신의 거부 이유를 밝히거나 시녀의 생각을 묻기 | 발화 내용·시녀의 개인적 응답·뒤 대화에서 기억할 거부 의사 | 시녀의 가치관, 하렘 입실 상태, 귀찌 기능의 비밀 |
| ep03_i02 | c049, 방의 조용함을 알아차린 뒤 | 다른 입실자나 자신이 놓인 처지를 묻기 | 질문 표현·재확인 방식 | c050의 유일한 아이라 통보, 시녀가 아직 설명하지 않은 세부의 미공개 |

- i01은 원작 항의 대사를 대신한다. 입력 뒤 원작 항의를 다시 읽고 같은 질문을 반복하지 않는다. 단순한 발화에 판정을 붙이지 않는다.
- i02는 실제 정보를 얻는 질문이다. 질문 문구를 정답으로 맞히게 하지 않는다. 응답은 c050의 확인된 정보 범위 안에 둔다. 다른 여성의 명단·시하드의 연애사·아이라의 별도 신분 체계는 만들지 않는다.
- 목욕·강제 착의·정원 이동·짐 걱정·귀찌 독백은 자동 진행한다. 성공해도 바뀌지 않을 행동을 성공 가능한 판정으로 포장하지 않는다.
- c052 이후에는 아시나의 입력 자리가 없다. 잘릴의 목숨이나 시하드의 분노를 플레이어가 조절하는 선택지를 붙이지 않는다.

## 고정 전개와 변경 범위

고정: 왕궁 안내 → 목욕·착의 → 짐에 대한 걱정 → 귀찌 설명 → 하렘 통보 → 가치관 충돌 → 유일한 아이라 통보 → 잘릴 접견 → 위협과 퇴장이다. 시하드의 궁정 장면이 중간에 끼는 순서도 유지한다.

변경 가능: 아시나의 항의 방식, 시녀에게 묻는 말, 질문 이력과 시녀의 말투다. 변경은 실제 발화에 근거해 기록한다. 조용히 있거나 감정만 표현했다고 주사위를 굴리지 않는다. 이 화에서 짐 회수·탈출·귀찌 제거가 성립했다고 추가하지 않는다.

짐은 c031에서 아시나가 강탈당했을까 의심할 뿐이다. 시녀가 맡았는지, 별도 보관소에 있는지, 누가 조사했는지는 이 화에서 확정되지 않는다. 치부책은 신분 증명에 중요하다는 독백만 제공하며 타인이 읽거나 출신을 알아낸 사건은 없다.
