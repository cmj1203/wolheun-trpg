# 월흔 10화 후속 제작 입력

원작 18개·78컷을 읽은 전사와 장면 설계다. 게임 구현·테스트 완료를 뜻하지 않는다. 대사는 `script.md`, 구조와 자산 요구는 `scenes.json`을 따른다.

## 이전 상태와 원작의 장면 생략

`../ep09/script.md`·`../ep09/continuation.md`와 대조했다. 9화는 아시나의 야간 탈출 시도와 아래쪽 대족장의 칼(c075–c084)로 끝나고, 10화는 목욕 장면으로 시작한다. 사이의 이동·접촉 결과는 두 화 사이에 그려져 있지 않다. 공격·투척·포획·탈출 성공이나 구체적인 귀환 경위를 이어 쓰지 않는다.

- 아시나는 궁정 욕실에서 목욕할 수 있는 상태다. 갈색 머리·갈색 눈으로 변장 중이며 귀찌를 착용한다. 욕조 밖에는 옷과 가방이 있다(c001–c003).
- 9화 c080에서 아시나는 높은 곳의 자신을 누군가 알아챈 듯한 시선을 느낀다. 10화 c003–c005는 들킬 뻔했다는 말과 좋지 않은 인상을 잇지만, 두 장면 사이의 구체적인 만남·대화를 추가하지 않는다. 9화 c082의 대족장 호칭·c084의 칼은 독자 정보이며 아시나의 지식으로 계승하지 않는다.
- 왕의 시선과 다른 남성의 시선을 비교할 경험이 있다(c005). 뱀 그림은 옥죄는 인상을 표현하며, 실제 뱀 공격을 저장 상태에 추가하지 않는다.
- 누르와 라 쿤을 아는 관계이며, 왕이 자주 찾아온다고 느낀다(c018–c022). 이전 방문 횟수나 관계 수치를 새로 정하지 않는다.
- 귀찌 상태가 원래 한계에 가까웠다는 것은 c011의 아시나 독백으로 확인된다. 9화에는 귀찌의 충전·소모 수치가 없으므로 임의의 수치를 계승하지 않는다.
- 9화 c063까지 짐은 나시르 방의 걸이에 있고 실물 반환은 확인되지 않는다. 10화 c003에는 욕조 밖 옷·가방이 보인다. 10화의 화면에 보이는 물건을 기록하되, 짐 전부를 돌려받았다거나 치부책을 회수했다는 사건·소지품 갱신은 만들지 않는다.

## 장면 순서

아래의 `c`는 모두 `ep10_c`다. 독백·여백·효과 글자만 있는 ID도 순서에 포함한다.

| 장면 | 컷 | 전개와 끝 상태 |
|---|---|---|
| S01 | c001–c007 | 목욕하며 두 남자의 인상을 비교한다. 현재 욕실과 인상 이미지를 구분한다. |
| S02 | c008–c014 | 귀찌 변색을 발견하고 임시로 마법을 조정한다. 은발이 잠시 보인다. |
| S03 | c015–c020 | 방에서 누르가 머리를 빗는다. 갈색 머리는 유지되고 붉은 눈이 드러난다. 왕의 대기를 듣는다. |
| S04 | c021–c030 | 잦은 방문을 따진 뒤 머리·가족을 이야기한다. 외동이며 사촌들과 자랐다고 말한다. |
| S05 | c031–c041 | 진명 질문에 작명 과정과 이름 뜻을 밝힌다. 왕은 사랑받고 자랐다고 말한다. |
| S06 | c042–c050 | 가출 이유 질문에 반문하다 호칭 이야기로 옮긴다. 시하드의 뜻을 듣는다. |
| S07 | c051–c054 | 이름과 칭호를 속으로 정리하고 베히님이라 부른다. 왕이 웃으며 받아들인다. |
| S08 | c055–c061 | 관심 이유를 묻자 왕은 반해서라고 답한다. 손목을 잡고 접근한다. |
| S09 | c062–c071 | 원작에서는 입맞춤 뒤 아시나가 벗어나려 하고 왕이 먼저 중단한다. 왕의 속마음이 붙는다. |
| S10 | c072–c078 | 아시나가 이유를 추궁한다. 왕은 바뀐 눈색을 알아챘다고 마지막에 밝힌다. |

## 실제 입력이 필요한 자리

다음은 원작 문장을 바꾸라는 지시가 아니라 상호작용을 붙일 때의 자리다. 반응의 말투·행동은 원문 전사와 분리해 기록한다. 답변·행동이 달라졌다면 그 결과도 달라져야 하며, 원문을 강제로 대신 발화시키지 않는다.

| 위치 | 입력의 의미 | 처리 범위 |
|---|---|---|
| c026 | 여행 중 긴 머리의 불편을 묻는 질문에 답한다. | 불편함·머리를 기른 이유·답변 유보. 새 가족사를 덧붙이지 않는다. |
| c029 | 외동 여부를 묻는다. | 사촌 관계를 말하거나 유보. 앞 입력에서 답했으면 반복 질문·입력을 생략한다. |
| c034 | 진짜 이름인지 확인받는다. | 확인·유보. 다른 진명을 자동 설정하지 않는다. |
| c043 | 집을 떠난 이유를 묻는다. | 원작처럼 반문하거나 답변 범위를 정한다. GM이 가출 동기를 대신 만들지 않는다. |
| c052 | 자신이 사용할 호칭을 정한다. | 원작 경로는 베히님. 다른 호칭·유보를 택하면 원문 밖 분기로 구분하고 수락 대사를 원문인 것처럼 쓰지 않는다. |
| c058 | 손목을 잡는 행동에 대응한다. | 거부·손 빼기·거리 확보·무반응. 거부 입력 후에도 입맞춤 CG를 자동 재생하지 않는다. |
| c066 | 접촉이 실제 이어졌을 때 벗어나려 한다. | 밀어내기·몸 빼기·거부 표현. c058에서 이미 대응했다면 같은 요구를 다시 걸지 않는다. |

물소리·한숨·귀찌 발견·마법 조정·머리 손질·웃음에 매번 입력을 강요하지 않는다. c070의 침묵과 마지막 c078 뒤에도 다음 화 근거 없이 입력 과제를 만들지 않는다. 무반응·감정 반응만으로 주사위를 굴리지 않는다.

## 고정과 가변

- 고정은 **원작 재현 경로의 사실·정보 순서**다. 귀찌 변색, 눈의 마법만 푸는 조치, 갈색 머리 유지, 이름·칭호의 정보, 마지막 눈색 인지 공개가 연결의 기준이다. 플레이어가 행동을 거부해도 똑같은 사건을 강제한다는 뜻은 아니다.
- 말투·불만의 강도·공개 범위·반문·거리 확보는 가변이다. 말하지 않은 가족 정보를 왕의 기억에 넣지 않는다. 다른 호칭을 골랐는데 베히님에 대한 원작 응답을 그대로 붙이지 않는다.
- 손목 잡기와 입맞춤은 원작에서 관찰한 사건이다. 아시나의 내면에는 벗어나려는 의사가 명시된다(c066). 호감·합의로 자동 환산하지 않는다. 원작에서는 왕이 먼저 물러나며(c069), 중단을 플레이어의 주사위 성공에 매달지 않는다.
- 접촉을 피한 경로라면 접촉했던 사실·당황의 원인·관련 대사를 실제 행동에 맞춰 따로 집필해야 한다. 이 문서에는 그런 새 대사나 완성된 분기를 발명하지 않았다.
- 새로운 대응 대사는 원작 대사와 구분해 집필·검수할 대상이다. 원작에 없는 도주 성공·구조자 등장·관계 해결·수치 보상을 이 화의 확정 사건에 넣지 않는다.

## 복장 재감사

대사 포함 원본 18개·78컷을 원본 좌표와 기존 크롭으로 대조했다. 전 컷 직접 관찰·가림·원본 경로·y_range는 `wardrobe-audit.md`에 있다. 확정 오류는 32컷이며, 전체 78컷의 관찰 범위를 다시 기록했다. 머리·모자·의상 일부가 잘렸으면 '해당 컷에 보이지 않음/미확정'으로 남긴다. 손·얼굴·여백 컷에 장면 전체 차림을 붙이지 않는다.

- ep10_s01: c003–c009는 목욕 중의 얼굴·어깨·물 가림이다. c005는 인상 삽입으로 현재 욕실 동석이 아니다. 왕의 붉은 예복·금 머리사슬, 다른 남성의 푸른 옷·이마 금사슬은 현재 방 차림과 분리한다.
- ep10_s02: c011은 가방과 팔, c013은 손바닥과 귀찌뿐이다. c014는 은백발·흰 긴소매 가운·손의 마법진이며 맨등이 아니다.
- ep10_s03: c017은 두 사람 뒷모습, c018은 누르 목 아래만, c019는 누르와 왕이다. c019에 아시나는 보이지 않는다. 남색 차림·붉은 눈 상태는 c018 직접 관찰에 따른다.
- ep10_s04: c023에 두 사람이 보인다. c025는 풍선·꽃 장식, c026은 갈색 머리카락만이다. c027은 가족 회상 차림을 현재 의상과 분리한다. c029에 원경의 두 사람이 있다.
- ep10_s05: c031은 아시나, c032는 왕 몸통·손이다. c033·c036은 인물 없음. c037은 맨손·팔만, c038·c039에서 왕 의상은 보이지 않는다. 연속성 참고: ep10_c041의 두 사람 차림.
- ep10_s06: c043·c045는 얼굴 확대여서 전신 의상을 보충하지 않는다. c048 나시르는 푸른 머리·금색 깃 회상복이다. c049는 크림 터번·크림 겉천의 칭호 삽입으로 현재 왕의 실내복과 분리한다.
- ep10_s07: c051은 왕 입가·깃, c053은 얼굴·깃 일부이며 꽃·빛으로 몸통이 가려진다. 연속성 참고: ep10_c055의 현재 방 차림; c053에서 가슴 사슬 전체를 관찰했다고 하지 않는다.
- ep10_s08: c058은 손·팔만이다. c060은 왕의 뒤통수·어깨이며 손은 해당 컷에 보이지 않음. 연속성 참고: ep10_c059.
- ep10_s09: c063은 천장·풍선·효과, c066·c069는 아시나 얼굴만, c067은 효과 글자만이다. c071 왕 눈은 앞머리로 가려져 눈색 미확정. 연속성 참고: ep10_c068의 차림.
- ep10_s10: c072의 왕은 손·팔만, c073은 아시나 허리·팔·치마만이다. c075·c077에 왕 의상은 보이지 않음. 연속성 참고: ep10_c078.

## 필요한 그림

모두 제작 요구이며 신규 파일이 이미 존재한다는 뜻이 아니다. 기존 그림 재사용은 해당 원작 컷과 복장·자세를 대조한 뒤 정한다.

| 종류 | 요구와 근거 |
|---|---|
| 입식 | 아시나: 남색 짧은 소매 긴 드레스, 금색 가장자리·장식, 흰 안쪽 치마·문양 허리띠. 눈색은 얼굴이 보이는 c004·c018·c021에서 갈색/붉은 상태를 분리한다. c030은 허리·치마·팔만 보이므로 눈색 근거로 쓰지 않는다. |
| 입식 | 베히다트: 은회색 머리·붉은 눈, 가슴이 열린 어두운 긴 겉옷·금갈색 무늬 테두리·가슴 사슬·허리 장식. 현재 방에서는 c005의 예복·머리장식을 혼용하지 않는다(c022·c041·c053). |
| 입식 | 누르: 초록 짧은 상의·맨허리·초록 긴 치마·청회색 띠, 갈색 단발 반묶음(c017–c019). |
| 배경 | 푸른 타일 욕실·아치창·욕조, 방 입구, 화장대·거울·의자, 침상. 같은 방 내부의 구도 변화다(c001·c003·c016–c017·c041). |
| CG | 두 남자의 인상 대비와 뱀 비유(c005), 변색 귀찌 두 개(c013), 은발·흰 긴소매 가운·마법진(c014), 머리 빗기(c017). |
| CG | 갈색 머리카락 확대(c026; 손은 보이지 않음), 침상 끝 두 사람(c041), 웃는 왕(c053), 손목 잡기(c058), 입맞춤·중단(c062·c068), 왕의 내면 반응(c071), 눈색 인지를 밝히는 왕과 입술 부근의 손가락(c078). |
| 회상 삽입 | 나시르를 말하며 떠올리는 c048의 작은 모습. 현재 장소에 입식으로 새로 세우지 않는다. |
