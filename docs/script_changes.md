# 원작 대사 변경 기록

리드 결정(11-03): 게임 흐름을 위해 원작 대사와 순서를 고칠 수 있다. 인물 말투, 남자의 이름과 왕 신분 숨김, 아시나 변장, 15세 이용가, 갈래 5개 구조는 그대로 둔다.

| 장면 | 전 | 후 | 이유 |
|---|---|---|---|
| b09_verdict 마음이 바뀌었다 | 남자: 도대체 어디가 아름답다는 거지? / 아시나: 뭬야?! (언제나 나옴) | 미소녀라고 내세운 판(`flag:미소녀`)에서만 원작 두 줄이 나온다. 아닌 판: 남자: 끝까지 눈을 피하지 않는군. / 아시나: …뭐, 뭐예요. | 미소녀라고 말하지 않았는데 "어디가 아름답다는 거지?"가 나와 앞뒤가 맞지 않았다(리드 QA D3). |
| b09_verdict 마음이 바뀌었다 | (위 D3 수정의 '아닌 판') 남자: 끝까지 눈을 피하지 않는군. / 아시나: …뭐, 뭐예요. | b08 에서 눈을 끝까지 마주한 판(`flag:눈_맞섬`, 눈 맞서기 성공)에서만. 둘 다 아닌 판: 남자: 이상한 여자군. / 아시나: …네? 뭐가요? | 눈을 피한 판에도 "끝까지 눈을 피하지 않는군"이 나왔다(입력 무관 대사 전수 조사). |

| 자유 입력 9곳의 판정 대사(직접 입력하고 GM 이 실패한 판) | 판정 대사를 그대로 씀. 예: 입력 "저 귀족이에요" → 아시나: 저는 귀한 집안 사람이에요… / 남자: 사막 한복판에서 집안 타령이라. | 아시나가 플레이어 대신 하는 말과, 특정 말·몸짓을 전제로 한 반응 18줄(`tie`)은 빼고 남은 결과 묘사만 쓴다. 남는 줄이 없으면 중립 줄(예: 남자는 대꾸 없이 나를 재는 듯 내려다보았다.) | 플레이어가 하지 않은 말이 화면에 나왔다. 버튼으로 고른 판은 버튼 문장이 곧 행동이라 그대로 쓴다. |
| 자유 입력 9곳의 판정 대사(직접 입력하고 GM 이 쓰는 판) | GM 에 줄거리 요지만 넘김 | 원작 판정 대사를 '뜻과 말투의 기준'으로 함께 넘기고, 플레이어가 하지 않은 말·주장·몸짓을 쓰지 말라고 지시. 장면별 금지어(echo_only)에 미소녀·상단·집안·친척·장사·훤하·몸값을 더해, 플레이어가 먼저 말하지 않으면 GM 대사에서 막는다 | GM 이 원작 대사를 그대로 옮기거나 하지 않은 주장을 끌어오지 않게 한다. |
| b05_why 신분과 교양 (GM 요지) | 남자는 사막 한복판에서 집안 타령이냐며 비웃는다. / 아시나의 몸에 밴 예법에 남자의 눈빛이 달라진다. | 남자는 사막 한복판에서 신분을 내세우는 것을 비웃는다. / 아시나의 말과 태도에 밴 교양에 남자의 눈빛이 달라진다. | 플레이어가 집안을 말하거나 절을 하지 않았는데 GM 이 그렇게 썼다. |
| b05_why 마법 가방 (GM 요지) | 가방에서 꺼낸 낡은 지도가 … | 가방에서 꺼낸 물건이 … | 지도가 아닌 것을 꺼내도 지도로 썼다. |
| r4_walk 크라차까지 | 아시나: 네, 네! 걱정 마요. 제가 얼마나 쓸모 있는 사람인데요! (언제나 나옴) | r4 에서 쓸모를 내세우는 행동(길 읽기·말솜씨·당돌함)을 한 판에만. 아닌 판(즉흥 행동, 쓸모없다고 털어놓기): 아시나: …네? 저를 데려가겠다고요? | 쓸모가 없다고 고백한 판에도 쓸모를 자랑했다(전제 검사 T38·T39). |
| r5_price 값을 매기다 | 남자: 진짜라면 쓸모가 있다… / 나레이션: …귀한 물건을 대하는 거리였다. / 속마음: …내 입으로 내 값을 매겨 버린 거 아니야? | r5 에서 신분을 밀고 나간 판(예법·제국 이야기·호통)에만. 아닌 판: 남자: 귀하다는 말이 진짜인지는 크라차에서 가려 보지. / 나레이션: 호위들이 말없이 내 양옆에 섰다. / 속마음: 살았… 나? 대체 나를 어디로 데려가는 거야? | 평민이라고 고백하거나 엉뚱하게 도망친 판에도 신분을 내세운 것처럼 받았다(T43·T45). |
| e_value 값을 매긴 여자 | 남자: 데려가라. 귀한 몸이라니, 귀하게 모셔야지. | r5 에서 신분을 밀고 나간 판에만. 아닌 판: 남자: 데려가라. 값은 크라차에서 매기지. | 위와 같다. |
| r2_bind 결백 주장 성공 | 남자: 눈은 피하지 않는군. (GM 실패 때 대신 씀) | 직접 입력한 판에서는 쓰지 않는다(특정 몸짓 전제). 버튼을 누른 판에만 그대로 | 말만 했는데 눈 맞춤을 전제했다(T26). |
| r3_dusk 남은 물로 버틴다 | "물"만 들어가도 이 행동으로 읽음 → 나레이션: 물통을 기울이자 마지막 몇 방울이… | "마신다·모금·물통" 같은 말이 있을 때만 이 행동으로 읽는다 | "모래를 파서 물을 찾는다"에 물통을 기울이는 대사가 나왔다(T34). |
| b03_ask 길을 물어봤을 뿐인데 | (b02 에서 다가가지 않아도) 바로 아시나가 길을 묻는다 | b02 에서 다가가거나 살피거나 피하는 행동을 하지 않은 판(모래성 쌓기, 울기 등)에는 앞에 나레이션: 그러는 사이, 세 사람이 먼저 내 앞까지 와 있었다. | 모래성을 쌓다가 갑자기 길을 묻는 꼴이 됐다(경계 사례). |
| b06_swing 몸을 던져 피한다 · 대가 있는 성공 | 나레이션: …후드가 벗겨지고… (입식은 후드를 쓴 채) | 대사는 그대로 두고, 이 결과에서 후드를 벗은 상태로 바꾼다(입식·CG 도 맞춘다) | 서술과 화면이 어긋났다. |
| 즉흥 행동 · 대가 있는 성공 (남자 장면 공통) | 나레이션: 비웃음 섞인 목소리였지만, 붉은 눈은 내 손끝을 놓치지 않았다. | …붉은 눈은 나를 놓치지 않았다. | 손을 쓰지 않은 행동(노래, 외면)에도 손끝을 썼다(경계 사례). |
| b02_people 살피기·피하기 · 대가 있는 성공 (GM 요지) | 살피다가 붉은 눈과 마주친다. 들킨 김에 웃으며 나간다. / 돌아가려다 … 어쩔 수 없이 웃으며 길을 물으러 나간다. | 살피다가 붉은 눈과 정확히 마주친다. 숨어 있던 것을 들켰다. / 돌아가려다 붉은 눈과 마주쳐 들킨다. (속마음 "이렇게 된 이상 웃으면서 나가는 수밖에", "그냥 길 묻는 척해야지"는 직접 입력한 판에서 빼는 줄로 표시) | 숨기만 했는데 GM 이 아시나가 웃으며 나가 인사하는 것까지 썼다(26B 전제 검사 7번). |
| b06_swing 피하기·막기·달아나기 (판정 대사) | 행동별 서술(칼날이 머리카락 끝을 스쳤다, 가방이 칼날을 비껴 냈다 …)을 GM 실패 때 그대로 씀 | 버튼을 누른 판에만 그대로. 직접 입력하고 GM 이 실패한 판은 장면 공통 중립 줄: 칼날이 아슬아슬하게 비껴갔다. / 칼바람에 휘청이다 모래 위로 나동그라졌다. 후드가 벗겨졌다. / 칼끝이 코앞에서 멈췄다. 숨이 턱 막혔다. | "남자를 향해 달려든다"에 "간신히 피했지만"이 붙었다(26B 전제 검사 19번). |
| GM 서술 규칙(모든 자유 입력 장면) | 플레이어가 하지 않은 말·주장·몸짓을 쓰지 않는다 | 더해서: 아시나의 대사는 입력을 다듬은 말만 쓰고 새 주장·자기 자랑·인사·질문을 보태지 않는다. 몸짓은 입력에 있는 동작과 그 결과(넘어짐·들킴·다침)만 쓴다 | GM 이 "제 목소리가 꽤 예쁘거든요"(40번), "두 손을 가슴팍에 모아 쥐었다"(18번)를 덧붙였다. |
| r5_claim 귀하신 몸 | 남자: 사막 한복판의 귀하신 몸이라. | 남자: 귀한 몸이 호위도 없이 사막을 헤맸다? | b05 신분 주장(대가 있는 성공)의 "사막 한복판에서 집안 타령이라." 바로 뒤에 같은 뜻의 대사가 이어졌다(리드 QA D5). |
| r5_claim 귀하신 몸 | 나레이션: 비웃음 섞인 목소리였다. 그러나 칼끝은 움직이지 않았다. | 나레이션: 칼끝은 한 치도 물러나지 않았다. | b05 의 "비웃음 섞인 목소리였지만, …"과 같은 문장이 두 번 나왔다(리드 QA D5). |
