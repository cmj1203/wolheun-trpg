## 원인과 적용

귀찌는 패널만 숨겨도 효과·가격 서술·기본 설명·GM 도움말에서 비밀이 새었다. 기존 수첩 기반 reveal에 flag 조건을 더하고, flag로 잠근 수치는 공개 전 시간·대가 적용도 멈추게 했다. 남자 마음처럼 수첩으로 가리는 수치는 이전처럼 숨긴 채 변한다.

- 3화 독백의 연결점은 `귀찌_변장_설명`이다. 변장 수첩만 연다.
- 4화 일주일 독백의 연결점은 `귀찌_설명`이다. 귀찌 수명 7칸·단위 일을 열고 최초 flag 전환 효과에서 `새 수치: 귀찌 수명`을 한 번 낸다. 여우 설명은 없다.
- 현재 1화 콘텐츠는 두 flag를 켜지 않는다. 3·4화 자체를 만들지 않았다. 공개 뒤 시험은 원작 독백을 넣은 시험 장면과 flag를 켠 격리 저장본으로 했다.
- 귀찌 운명·대가·결말·보정은 삭제하지 않았다. 운명·보정·열감 가격에는 공개 조건이 있다. 복합 공개 조건에서도 첫 경고 턴의 문턱 유예가 유지되도록 `holdBefore`를 고쳤다.
- 소지품은 마법 장신구까지만 보인다. 수첩·GM 답의 아시나 배경은 원작 1화 범위다. 플레이어가 먼저 웰든·공녀를 밝히는 57차 경로와 GM만 아는 의심 동기는 유지했다.
- 변화 누적의 원인은 대사 경계 없이 `game.changes`에 계속 더하던 UI였다. SSE 한 건씩 대사를 기다린 뒤 효과를 받던 흐름도 원인 줄과 효과를 떨어뜨렸다. 줄과 바로 뒤 효과(가격 포함)를 묶고, 장면 진입 효과는 첫 줄에서 보여 준다. 다음 줄부터 지우되 기록에는 남긴다.
- 숫자와 delta가 같은 grid 영역을 쓰던 것을 별도 위치로 옮기고 같은 행의 이전 delta를 교체한다. 캐릭터 줄의 GM 배지는 숨긴다. 여우 질문 모드는 유지한다.
- 모델의 짧은 남자 반응에 원작 말투 의미 검사를 넣었다. 어긋나면 다시 쓰며, 끝내 실패하면 아직 쓰지 않은 원작 짧은 반응·침묵으로 받는다. 대체 줄을 다 써도 이전 줄을 재활용하지 않는다. 출력 검증은 고정 대본을 포함해 이번 판에 이미 한 말을 참고한다.
