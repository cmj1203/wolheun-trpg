미디어 에셋 올리기

미디어 메뉴에서 배경·상황·비디오 세 종류의 에셋을 관리해요. 에셋은 이름으로 연출 씬에서 불러오고, 형식과 용량 제한이 정해져 있습니다.

여기서 배울 내용은?

에셋 세 종류와 각각의 동작 방식
세로형·가로형 이미지와 여러 파일 한 번에 올리기(일괄 업로드)
에셋이 플레이 화면에 실제로 보이는 방식
AI 도구로 배경·상황 이미지와 BGM을 직접 만드는 법
에셋 세 종류
#

미디어 메뉴에서 관리하는 에셋은 세 가지예요.

종류	구성	연출 씬에서	특징
배경 에셋	이미지 + BGM	{bg::이름}	다른 배경으로 명시적으로 바꾸기 전까지 이미지와 BGM이 함께 유지돼요(턴 수 제한 없음). BGM만 바꾸고 싶으면 같은 이미지에 다른 BGM을 넣은 배경 에셋을 하나 더 만들어 {bg::}로 전환하세요
상황 에셋	이미지 + 효과음	{media::이름}	이미지는 잠깐 보였다가 사라지고, 효과음은 한 번만 재생돼요
비디오 에셋	영상 + 내용 설명	{media::이름}	재생 중 UI가 숨겨져요. 오프닝, 시네마틱용. 1회만 재생되고(반복 없음), 끝나면 직전 배경·캐릭터가 복원된 화면이 이어지며 거기서 선택지·입력창이 나와요. 'AI가 자유롭게 사용 가능'이면 AI가 맥락에 맞게 골라 재생하기도 해요. 내용 설명(100자)에 영상 내용을 간단히 적어두면 AI가 맥락을 파악하는 데 써요

배경은 무대, 상황은 순간 효과, 비디오는 컷신 — 이렇게 생각하면 쉬워요. 상황 에셋은 아이템 획득, 충격 장면, 회상처럼 잠깐 보여주고 사라져야 하는 것에 씁니다. 계속 떠 있어야 한다면 배경으로 등록해주세요.

에셋 이름은 최대 20자이고 : { } [ ]는 쓸 수 없어요. 같은 에피소드 안에서 중복될 수 없고, 연출 씬에서 부를 때 정확히 같아야 해요. 에셋은 배경·상황·비디오를 합쳐 최대 300개까지 등록할 수 있어요. {bg::}·{media::}는 한 줄에 토큰만 두세요 → 연출 씬 쓰기.

화면에서 어떻게 보이나
#

에셋을 만들기 전에 알아두면 좋은 동작 방식이에요. 여기서 이미지의 규격과 구도가 결정됩니다.

배경 이미지는 화면에 꽉 차게 나와요. 기기마다 잘리는 영역이 달라서 중요한 요소는 가운데에 두는 것이 안전합니다. 세로형·가로형 이미지는 아래에서 설명해요.
상황 이미지는 원본 비율 그대로 카드처럼 표시돼요. 배경과 달리 잘리지 않으니, 보여주고 싶은 것만 담은 단순한 이미지가 좋아요.
배경이 바뀌면 무대가 정리돼요. 새 배경이 등장하는 순간 이전 캐릭터·상황 이미지는 모두 사라지고 배경만 단독으로 보여주는 화면이 먼저 나옵니다. 장면 전환 연출이 자연스러운 이유이자, 배경을 너무 자주 바꾸면 캐릭터가 계속 사라지는 이유예요.
BGM과 효과음은 동시에 재생될 수 있어요. 배경의 BGM이 흐르는 위에 상황 효과음이 얹히는 구조입니다.
세로형 이미지와 가로형 이미지
#

배경 에셋과 상황 에셋 편집 화면에는 이미지 칸이 세로형 이미지와 가로형 이미지 두 묶음으로 나뉘어 있어요.

항목	내용
세로형 이미지	최대 10장. 드라마 화면과 모바일 크기 화면에서 먼저 쓰여요.
가로형 이미지	최대 10장. 노벨 본문 그림과 PC·태블릿 크기 화면에서 먼저 쓰여요. 스튜디오 안내대로, 가로형 이미지를 등록하면 주인공들이 데스크탑에서 더 깊게 몰입할 수 있어요.
오디오(BGM·효과음)	최대 5개

먼저 쓰이는 쪽이 비어 있으면 다른 쪽 이미지가 쓰여요. 두 묶음은 서로 독립이라 한쪽만 등록해도 에셋을 만들고 발행할 수 있어요. 비디오 에셋도 세로형 비디오와 가로형 비디오를 각각 최대 5개까지 따로 등록해요.

한 에셋에 이미지나 오디오를 여러 개 올리면 각각 그중 하나가 무작위로 나와요. 같은 장소의 시간대·분위기 변주를 한 에셋에 모아두고 싶을 때 쓰세요.

일괄 업로드
#

에셋이 많다면 일괄 업로드로 여러 파일을 한 번에 올릴 수 있어요. 파일명을 에셋이름_순번.확장자 형식으로 지으면 같은 이름의 파일이 한 에셋으로 묶여요:

복사
아침배경_01.png
아침배경_02.png
동굴입구_01.webp


눈여겨보세요. 앞의 두 파일은 '아침배경' 에셋 하나의 이미지 두 장으로, 세 번째 파일은 '동굴입구' 에셋으로 들어가요. 순번은 01부터 시작하는 두 자리 숫자이고, 한 장뿐이어도 _01을 붙여주세요.

이때 벌어지는 일:

한 번에 최대 100개 파일을 올릴 수 있어요.
이미지는 비율에 따라 자동으로 나뉘어요. 가로가 세로보다 길면 가로형, 정사각형을 포함한 나머지는 세로형으로 들어가요. 세로형·가로형 탭에서 직접 올리면 그 탭으로 들어갑니다.
같은 이름의 에셋이 이미 있으면 기존 에셋에 추가할 수 있어요. 다른 종류의 에셋과 이름이 같으면 올릴 수 없으니 이름을 바꿔주세요.
파일명의 띄어쓰기와 특수문자는 _로 바뀌어 에셋 이름이 돼요. 연출 씬에서 부를 이름이니 처음부터 짧고 알아보기 쉽게 지어주세요.

AI 프롬프트 복사하기를 누르면 파일명 규칙이 담긴 안내문이 복사되니, 외부 AI 도구에 붙여 파일명을 정리하는 데 쓰세요.

사용 설정
#

에셋도 캐릭터 이미지처럼 두 가지 모드가 있어요.

설정	동작
AI가 자유롭게 사용 가능	AI가 이야기 흐름에 맞게 에셋을 자동으로 골라 써요
연출 씬에서만 사용	디렉터가 연출 씬에서 지정했을 때만 나와요

'AI가 자유롭게 사용 가능'으로 둘 수 있는 에셋은 배경·상황·비디오를 합쳐 최대 150개예요. 한도에 닿으면 안내가 뜨니, 일부를 '연출 씬에서만 사용'으로 바꾸거나 지운 뒤 다시 설정하세요.

특정 이벤트에서만 쓰이게 할 수도 있어요. 사용 가능한 이벤트에서 메인 이벤트를 체크하면 체크한 메인 이벤트가 진행되는 동안에만 등장해요. '동굴 탐험' 이벤트를 체크해 동굴 배경을 그 구간에서만 쓰는 식이죠. 메인 엔딩도 체크할 수 있어서, 엔딩 장면에서만 쓰는 배경을 따로 둘 수 있어요.

여러 개 한 번에 지우기 — 에셋을 여러 개 골라 최대 300개까지 한 번에 삭제할 수 있어요. 하나라도 지울 수 없는 에셋이 섞여 있으면 전부 취소되고 안내가 떠요. 삭제는 복구되지 않아요.

형식과 용량
#
유형	형식	최대 크기
이미지	jpg, png, webp, gif	올릴 때 자동으로 줄어들어 크기 걱정 없음
동영상	mp4, mov, avi	500MB
오디오	mp3, wav, m4a	20MB

배경 제거는 캐릭터 이미지뿐 아니라 미디어 이미지에도 쓸 수 있어요. 에피소드 썸네일은 발행 화면에서 등록하고 4:5 비율을 권장해요.

AI로 직접 만들기
#

그림이나 음악을 못 해도 괜찮아요. 요즘은 AI 도구에 문장으로 요청하면 쓸 만한 에셋이 나옵니다. 종류별로 어떤 도구에 어떻게 요청하면 되는지 볼게요. 예시는 그대로 복사해서 시작점으로 써도 됩니다.

배경 이미지#

챗지피티(이미지 생성), Midjourney, NovelAI 같은 이미지 생성 도구를 써요. 요청할 때 세 가지만 챙기면 됩니다 — 세로 구도, 사람 없음, 글자 없음.

복사
여름 낮의 한적한 시골길, 애니메이션 배경 일러스트 스타일,
세로 9:16 비율, 사람 없음, 텍스트 없음, 밝고 따뜻한 색감


이건 세로형 이미지용이에요. 가로형 이미지도 함께 올리려면 같은 문구에서 비율만 가로(16:9)로 바꿔 요청하세요.

한 에피소드의 배경들은 화풍이 같아야 몰입이 유지돼요. 마음에 드는 스타일이 나왔다면 스타일 문구("애니메이션 배경 일러스트 스타일, 밝고 따뜻한 색감")를 고정해 두고 장소만 바꿔서 세트로 만들어주세요.

상황 이미지#

아이템, 편지, 획득 연출처럼 잠깐 보여줄 컷이에요. 원본 비율 그대로 표시되니 대상 하나만 담은 단순한 이미지가 좋습니다.

복사
갓 캐낸 감자 한 알, 클로즈업, 애니메이션 일러스트,
단순한 배경, 텍스트 없음

BGM#

Suno 같은 음악 생성 도구에 분위기를 문장으로 요청해요. 보컬 없는 곡으로 만들어야 대사 읽기에 방해가 안 됩니다.

복사
잔잔한 어쿠스틱 기타, 여름 시골의 오후, 보컬 없음,
반복 재생해도 어색하지 않은 배경음악

효과음#

효과음은 생성보다 라이브러리에서 찾는 편이 빨라요. Pixabay 같은 무료 사운드 라이브러리에서 "door knock", "item get"처럼 영어로 검색하면 됩니다.

만든 다음에#
위의 형식·용량 표에 맞는지 확인해주세요.
에셋 이름은 연출 씬에서 {bg::이름}으로 부르게 되니, 낮의 시골길처럼 짧고 알아보기 쉬운 한글 이름을 권해요(최대 20자).
소재 구하기
#

직접 만들지 않는 길도 있어요.

프론티아 무료 에셋 — 배경 이미지, BGM, 효과음을 무료로 제공해요. → 무료 에셋
무료 소스 — Unsplash, Pixabay. 라이선스는 꼭 확인하고 출처 표기 의무가 있으면 소개글에 명시해주세요.
저작권은 이것만 기억하세요
#
직접 만들었거나 사용할 권리가 있는 에셋만 올릴 수 있어요.
AI 생성물은 도구마다 상업적 이용 조건이 달라요. 사용하는 도구의 약관을 한 번은 확인해주세요.
2차 창작 에셋이라면 에피소드 소개글에 2차 창작 허가 문구를 함께 적어주세요.
