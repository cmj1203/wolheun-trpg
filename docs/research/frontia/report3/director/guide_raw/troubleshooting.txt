이미지가 안 나와요
#

확인 순서대로 점검해보세요.

이름 불일치 — 연출 씬에 쓴 이름과 등록된 이름이 정확히 같은지 확인합니다. 하나_카페_기본에서 한 글자만 달라도 표시되지 않아요. 씬 에디터의 @ 자동완성을 쓰면 오타를 막을 수 있습니다.
의도와 다른 이미지가 나옴 — 등록하지 않은 상황·감정 조합을 쓰면 오류 없이 대표 이미지(또는 가까운 상태의 이미지)로 대신 표시돼요. 캐릭터 이미지 탭에 그 조합이 있는지 확인하세요.
"연출 씬에서만 사용" 설정 — 이미지가 "연출 씬에서만 사용"으로 설정되어 있으면 AI가 자유롭게 쓰지 못해요. 자동으로 나오길 원하면 설정을 바꿔주세요.
이벤트 연동 — 사용 가능한 이벤트를 체크해 둔 이미지는 체크한 메인 이벤트가 진행되는 동안에만 나옵니다.
같은 씬에서 이미지가 안 바뀜 — 한 씬 안에서는 같은 이미지가 유지돼요. 정상이에요.
이름만 나오고 이미지가 없음 — 이미지를 올리지 않은 캐릭터나 등록되지 않은 이름이면 이름만 표시돼요. 이미지 없는 캐릭터는 그대로 발행할 수 있으니, 이미지를 보여주고 싶을 때만 올리면 됩니다.
배경·이미지가 매번 달라요
#

정상이에요. 배경 에셋이나 캐릭터 이미지 칸 하나에 이미지를 여러 장 올리면 그중 한 장이 무작위로 나와요(배경은 세로형·가로형 각각). 늘 같은 그림을 보여주고 싶다면 그 칸에 한 장만 남기세요. → 미디어 에셋 올리기

배경 뒤 나레이션이 사라져요
#

{bg::}나 {media::} 토큰이 나레이션과 같은 줄에 있을 거예요. 토큰이 든 줄은 배경만 바뀌고 같은 줄의 글은 표시되지 않아요. 연출 씬 미리보기에서도 똑같이 보여요. 토큰을 한 줄에 혼자 두고, 나레이션은 다음 줄에 쓰세요. 배경 자체가 안 바뀐다면 배경 이름이 미디어 에셋 이름과 정확히 같은지 확인하세요. → 연출 씬 쓰기

다음 이벤트로 안 넘어가요
#

가장 흔한 문제입니다. 트리거 쓰기의 진단 순서를 따라가 보세요. 요약하면 다음과 같아요.

진행 가이드의 마지막 흐름이 트리거 상황으로 이어지는지
트리거가 "분위기가 무르익으면"처럼 판정 불가능하게 쓰여 있지 않은지
스토리 설계 메뉴에서 다음 후보가 2~3개를 넘지 않는지
띄어쓰기만 다른 이벤트 이름을 같이 두지 않았는지(전환이 안 될 수 있어요)
트리거가 비어 있거나 50자를 넘겨 저장이 안 됐는지
캐릭터 말투가 다 비슷해요
#
확인할 것	해결
프로필에 대사 예시가 있는지	대사 예시 한 줄이 성격 서술 열 줄보다 힘이 셉니다. 대사 예시를 추가해주세요.
캐릭터끼리 어미와 문장 길이가 갈리는지	전원이 반말에 비슷한 리듬이면 AI도 구분하지 못해요. 캐릭터 만들기의 예제를 참고해 차이를 만들어주세요.
AI가 주인공을 이상한 이름으로 불러요
#

세계관이나 프로필 어딘가에 {user} 대신 실제 이름이 적혀 있을 가능성이 큽니다. 세계관, 캐릭터 프로필, 진행 가이드에서 주인공을 지칭한 곳을 전부 찾아 {user}로 바꿔주세요.

상태값이 안 움직여요
#
확인할 것	해결
출력 규칙이 구체적인지	"어떤 행동에 몇이 움직이는지"가 적혀 있어야 합니다. 상태값 만들기의 예제와 비교해보세요.
상태값 이름이 일치하는지	진행 가이드나 이벤트 트리거에서 상태값을 다른 이름으로 부르고 있지 않은지 확인해주세요.
게이지·단위가 갑자기 사라짐	값이 유형을 이겨요. AI가 숫자 아닌 값을 쓰면 문자로 표시돼요. 출력 규칙이 숫자만 쓰게 하는지 보세요.
상단에 안 보임	플레이어에게 표시 ON만으론 상단에 안 떠요. 플레이용 상태값에 넣었는지, 주인공·캐릭터 합산 5개를 넘지 않았는지 확인하세요.
예전 상태값에 유형이 없음	유형 도입 전 상태값은 자동 변환되지 않아요. 직접 유형을 정하세요.
필수 항목을 채웠는지	주인공·캐릭터 상태값 모두 출력 규칙이 필수예요. 비어 있으면 발행도 막혀요.
세계관을 안 지켜요
#
확인할 것	해결
규칙이 너무 많은지	규칙이 많으면 AI가 우선순위를 잃어요. 꼭 지켜야 할 규칙만 남기고 줄여주세요.
내용이 중복되는지	같은 내용이 세계관과 프로필에 함께 있으면 오히려 품질이 떨어집니다. 한 곳에만 남겨주세요.
주인공에게 뭐든 허용되는지	편향 제거 조각을 세계관에 넣어보세요 — AI의 무조건적 호의를 풀고 모든 행동을 '시도'로 보게 해요.
수정했는데 반영이 안 돼요
#
저장은 자동이지만, 앱에 반영되려면 발행 버튼을 다시 눌러야 합니다.
이미 진행 중인 플레이는 시작 시점의 버전을 유지해요. 주인공이 플레이 메뉴에서 버전 업데이트를 하거나 새로하기를 해야 수정본이 적용됩니다. 진행 중인 주인공에게 알리고 싶다면 발행할 때 업데이트 알림 보내기를 체크하세요 → 발행하기.
대표 프롤로그·썸네일 구성을 바꾼 것도 다시 발행해야 반영돼요.
공개 범위를 나만 보기→전체 공개로 바꿨다면 발행 버튼을 다시 눌러야 앱에 보여요.
소울 설정 변경과 채팅 가능 여부는 소울을 다시 발행해야 반영돼요.
작업이 사라졌어요
#

같은 에피소드를 여러 탭이나 기기에서 동시에 편집하면 마지막 저장만 남아요. 사라진 작업은 그 때문일 수 있어요. 한 탭에서만 편집하고, 저장됨 표시를 확인하세요.

발행이 안 돼요
#

발행 화면이 알려주는 미입력 항목을 확인해보세요. 필수 조건은 세계관·프롤로그·기본 정보(제목·소개글·대표 썸네일·특징·장르) 세 가지예요. 배경과 캐릭터는 없어도 발행할 수 있어요. 그 밖에 걸리는 것:

"연결되지 않은 이벤트가 있어요" — 스토리 설계에서 들어오거나 나가는 연결이 하나도 없는 이벤트가 있어요. 연결하거나 지우세요.
"대표 에셋이 없는 캐릭터가 있어요" — 이미지를 올린 캐릭터인데 대표 이미지가 지정되지 않았어요. 안내에 나온 캐릭터의 대표 이미지를 정해주세요. 이미지를 하나도 올리지 않은 캐릭터는 해당되지 않아요.
"선택 후 연출 씬을 발행하려면 등장 주인공이 1명 이상 배정되어 있어야 해요" — 대표 프롤로그에 선택 후 연출 씬이 있는데 등장 주인공이 없어요. 프롤로그에서 주인공을 골라주세요. 디렉터 주인공의 이미지 세트에 대표 칸이 없을 때도 막혀요. → 주인공 만들기
소개글이 비어 있음("에피소드 설명을 입력해 주세요") / 특징(태그)·장르가 하나도 없음 / 제목이 2자 미만
트리거가 비어 있는 이벤트 / 출력 규칙이 비어 있는 상태값 / 활성화 단어나 설명이 빈 키워드
썸네일 구성(110장, 대표 1장, 대표는 '전체') / 프롤로그 개수(15개)
글자수 초과(제목 20·소개글 500·트리거 50·미션 30 등) / 제목 등 소개글 외 입력란의 URL / 제목·소개글 앞뒤 공백
"이미 발행 중이에요. 잠시 후 다시 시도해주세요" — 발행이 진행되는 중이에요. 잠시 기다렸다가 다시 눌러주세요.

자세한 요건은 발행하기에, 글자수는 글자 수와 개수 제한에 정리되어 있습니다.

발행 버튼이 안 눌려요
#

정상이에요. 에피소드 발행 버튼은 마지막 발행 뒤에 수정한 내용이 있을 때만 눌려요. 이미 발행한 상태 그대로라면 다시 발행할 것이 없다는 뜻이에요. 공개 범위나 내용을 바꾸면 다시 누를 수 있어요. → 발행하기

"사용할 수 없는 단어가 포함되어 있어요"가 떠요
#

제목이나 소개글에 '프론티아', 'Frontia', '딥그로브', 'deepgrov'가 들어 있어요. 욕설 같은 단어가 들어가면 "부적절한 단어는 포함할 수 없어요"가 떠요. 해당 단어를 빼면 저장돼요. → 발행하기

다른 마켓 유저에게 안 보여요, 랭킹에 없어요
#

에피소드는 에피소드를 처음 만들 때 정해진 마켓의 목록·검색·랭킹·추천에만 나오고 랭킹도 마켓별이라 정상이에요. 상세 링크를 직접 열면 다른 마켓에서도 볼 수 있어요. 다른 마켓 목록에 내려면 그 마켓 계정으로 만들어 발행해야 해요. 정책 위반으로 차단된 에피소드는 홈·검색·추천·랭킹에서 빠지고 재발행이 막힐 수 있어요. → 콘텐츠 기준

1:1채팅 버튼이 안 보여요
#

캐릭터에 소울이 연결돼 있는지, 소울을 발행했는지, 채팅 가능 여부가 발행본에서 켜져 있는지 순서로 보세요. → 소울 만들기

새 캐릭터를 만들었더니 빈 칸이 잔뜩 생겼어요
#

정상이에요. 새 캐릭터는 에피소드에 정의된 감정·상황 전부를 갖고 만들어져요. 필요 없는 상태는 태그 일괄 적용 팝업에서 체크를 풀면 사라져요(그 상태의 이미지도 같이 삭제되니 주의). → 캐릭터 이미지 올리기

일괄 업로드에서 "확인 필요"가 떠요
#

파일 이름이 규칙과 다를 가능성이 커요. 순번은 01부터 두 자리로 붙이고, 한 장이어도 _01을 붙여주세요.

대상	파일 이름
캐릭터 이미지	캐릭터이름_상황_감정_01.png
미디어 에셋	에셋이름_01.png (한 번에 최대 100개)

캐릭터 이미지는 등록되지 않은 캐릭터 이름, 같은 순번 중복, 한 칸 10장 초과도 확인 필요로 분류돼요. 미디어 에셋은 다른 유형(배경·상황·비디오)에 같은 이름이 있으면 올라가지 않아요. 전체 규칙은 문법 정리에 모아뒀어요.

에셋을 더 못 만들어요
#

미디어 에셋은 배경·상황·비디오를 합쳐 300개, 그중 AI가 자유롭게 사용 가능으로 둔 것은 합쳐 150개까지예요. 쓰지 않는 에셋을 지우거나 일부를 "연출 씬에서만 사용"으로 바꿔주세요. → 글자 수와 개수 제한

주인공 선택 화면이 안 떠요
#

주인공 선택 화면은 프롤로그 1씬이 끝날 때, 고를 수 있는 후보가 2개 이상일 때만 떠요. 프롤로그 편집 화면의 주인공 프로필 선택에서 등장시킬 주인공이 체크돼 있는지 확인하세요. → 주인공 만들기

선택 후 연출 씬을 수정할 수 없어요
