발행 요건
#

에피소드를 공개하려면 사이드바의 에피소드 설정 메뉴에서 정보를 채우고, 왼쪽 사이드바의 에피소드 발행 버튼을 눌러주세요. 발행 필수 조건은 세 가지예요. 빠진 항목은 발행 화면이 알려주니 거기서 하나씩 채우면 됩니다.

세계관(기본 프롬프트)
프롤로그
기본 정보(제목·소개글·대표 썸네일·특징·장르)

배경 이미지와 캐릭터는 필수가 아니에요. 장면을 꾸미고 싶을 때 넣으면 됩니다.

세 가지를 채웠어도 발행 버튼을 누르면 아래 항목을 한 번 더 검사해요. 하나라도 어긋나면 발행되지 않고 안내가 떠요.

검사 항목	조건
이벤트 연결	프롤로그를 뺀 모든 이벤트가 스토리 설계의 플로우에 연결돼 있어야 해요. 들어오거나 나가는 연결이 하나도 없는 이벤트가 있으면 "연결되지 않은 이벤트가 있어요" 안내와 함께 막혀요.
이벤트 트리거	프롤로그를 뺀 이벤트는 트리거가 있어야 해요.
제목·소개글	제목 2~20자, 소개글은 꼭 입력(최대 500자). 둘 다 앞뒤에 공백을 둘 수 없고, 금지어가 있으면 막혀요(아래 기본 정보 항목 참고).
특징(태그)·장르	특징 1개 이상, 장르 1개 이상
썸네일 구성	1~10장, 대표 1장, 대표의 노출 대상은 '전체'
프롤로그 개수	1~5개
상태값 출력 규칙	등록한 주인공·캐릭터 상태값에는 출력 규칙이 있어야 해요.
키워드북	키워드마다 활성화 단어 1개 이상과 설명이 있어야 해요. → 키워드북
이벤트 프롬프트	이벤트에 배정한 프롬프트는 내용이 있어야 해요. 비어 있으면 "'(프롬프트 이름)' 프롬프트 내용을 입력해 주세요" 안내와 함께 막혀요. 배정하지 않은 빈 프롬프트는 상관없어요. → 엔딩 만들기
캐릭터 대표 이미지	이미지를 올린 캐릭터만 대표 이미지 1장이 필요해요. 이미지 없이 이름만 쓰는 캐릭터는 그대로 발행할 수 있어요. 대표가 빠지면 "대표 에셋이 없는 캐릭터가 있어요" 안내에 해당 캐릭터 이름이 나와요.
디렉터 주인공	주인공을 준비했다면 주인공 이미지 칸마다 이미지 1장 이상, 이미지 세트마다 대표 칸 1개가 필요해요. 대표 프롤로그에 선택 후 연출 씬이 있으면 그 프롤로그에 등장 주인공이 1명 이상 배정돼 있어야 해요("선택 후 연출 씬을 발행하려면 등장 주인공이 1명 이상 배정되어 있어야 해요").

빠르게 시작하기를 따라오셨다면 이미 다 갖춰져 있을 거예요.

기본 정보 항목
#

에피소드 설정 메뉴에서 채우는 항목이에요.

항목	내용과 요령
제목	검색과 노출에 영향을 줍니다. 에피소드의 핵심 긴장이 드러나게 지어보세요. 2~20자, URL은 넣을 수 없어요. 제목에 넣은 {user}는 닉네임으로 바뀌지 않고 그대로 보이니 넣지 마세요.
소개글	플레이 전에 읽는 글이고 발행하려면 꼭 입력해야 해요("에피소드 설명을 입력해 주세요"). 최대 500자. {user}를 넣으면 보는 주인공의 닉네임으로 바뀌어 보여요(없으면 콘텐츠 언어의 기본 호칭 '당신'). 외부 링크를 넣을 수 있고 주인공이 누르면 외부 링크 확인 안내가 떠요(댓글·프로필 소개의 링크는 허용 사이트만 되는 것과 달라요). 어른용 에피소드라도 소개글은 전체이용가 기준으로 써야 합니다.
썸네일	홈과 검색 결과에 노출되는 이미지예요. 4:5 비율의 고화질 세로 이미지를 권장하고, 등급과 무관하게 전체이용가 기준입니다. 최대 10장. 첫 장이 자동으로 대표 썸네일이 되고 노출 대상은 항상 '전체'예요. 각 장에 노출 대상(전체/남성/여성)을 정해요. 대표는 삭제하거나 대상을 바꿀 수 없고, 바꾸려면 다른 장을 대표로 지정하세요(이전 대표는 '전체' 일반 썸네일로 남아요). 노출 대상은 '누구에게 보여도 되는가'이지 주인공 성별 정보가 아니에요.
미리보기 이미지	에피소드 상세 화면에서 플레이 전에 보여요. 최대 10장, 드래그로 순서를 바꿀 수 있고 주인공은 크게 볼 수 있어요. 등급별 기준은 아래 등급과 콘텐츠 기준 참고.
등장 캐릭터 미리보기	에피소드 상세에 보일 캐릭터 순서를 드래그로 바꾸고, 보여줄지 정해요. 메인 캐릭터를 앞에 두세요.
특징(태그)	에피소드를 설명하는 검색 키워드예요. 발행 화면의 특징 칸에 입력하고, 발행하려면 1개 이상이 필요해요. 1~10개, 각 10자. 문자와 숫자만 쓸 수 있고 띄어쓰기·특수문자는 안 돼요("특징은 다국어 문자 및 숫자만 입력할 수 있어요"). 주인공이 실제 검색할 단어로 표기를 통일해 다세요. 입력칸 아래 추천 태그는 고른 장르에 맞춰 뜨고, 누르면 바로 추가돼요.
장르	1~3개를 선택해요(발행에 1개 이상 필요). 앱에는 첫 번째 장르만 노출되니 가장 대표적인 것을 첫 번째로 골라주세요.
넘김 방식	드라마(프레임이 자동으로 넘어가 영상처럼 연출) 또는 노벨(웹툰처럼 내리면서 읽기, 가로형 이미지가 잘 어울림). 새 에피소드를 만들 때 고른 종류가 기본으로 들어가 있어요. 발행본에 저장돼 주인공의 첫 설정이 되고, 주인공은 플레이 중 바꿀 수 있어요. 캐릭터 연출 유형과 짝을 맞추세요.
기본 AI 모델	발행 화면이 아니라 세계관 메뉴 하단의 AI 모델 설정에서 정해요. 주인공이 처음 쓰게 될 모델이고, 주인공은 플레이 중 바꿀 수 있어요. 지정하지 않으면 기본 모델(오로라)이 적용되고, 바꾼 뒤에는 다시 발행해야 반영돼요. 모델 종류는 세계관 쓰기에 있어요.
상태값 변화 표시	플레이 중 상태값이 바뀔 때 화면에 잠깐 띄울지(표시/숨김) 정하는 기본값이에요. 상태값 변화가 잦거나 게임 요소가 있는 에피소드라면 표시를 권해요. 숨김으로 둬도 주인공이 직접 켤 수 있어요.
플레이 연령 제한	전체 이용가 또는 어른용. 아래 등급과 콘텐츠 기준을 보고 골라주세요.
공개 범위	전체 공개 / 링크 공개 / 나만 보기 중 선택해요. 전체 공개일 때만 앱에 노출·검색되니, 테스트 중이라면 나만 보기나 링크 공개로 발행해주세요.

제목과 소개글에는 쓸 수 없는 단어가 있어요. '프론티아', 'Frontia', '딥그로브', 'deepgrov'가 들어가면 "사용할 수 없는 단어가 포함되어 있어요", 욕설 같은 부적절한 단어가 들어가면 "부적절한 단어는 포함할 수 없어요" 안내가 떠요. 해당 단어를 빼면 저장돼요.

캐릭터 소개 탭
#

에피소드 설정 메뉴의 캐릭터 소개 탭에서는 플레이 전에 보이는 캐릭터 소개를 꾸밉니다. 에피소드 상세 페이지의 캐릭터 버블이 여기서 만들어져요.

항목	내용
캐릭터 소개	플레이 전에 읽는 글이에요. 최대 400자. 반전·결말 같은 스포일러는 넣지 말고 매력 포인트를 앞에 둬주세요. 예: "왕국의 마지막 기사. 말수가 적지만 한번 마음을 연 상대에게는 끝까지 함께한다."
캐릭터 썸네일	비워 두면 캐릭터의 대표 이미지가 대신 쓰여요. 등장 캐릭터 소개 이미지도 공개 영역이라 전체이용가 에피소드는 썸네일과 같은 기준, 어른용은 미리보기와 같은 기준이 적용돼요. 대표 이미지가 기준에 안 맞으면 대표 교체·썸네일 지정·등장 캐릭터 미리보기 표시 끄기 중 하나로 조치하세요.
캐릭터 배경 이미지	소개 뒤에 깔리는 이미지예요. 설정하지 않으면 기본 색상으로 보여요.
등급과 콘텐츠 기준
#

에피소드의 등급은 전체이용가와 어른용 둘 중 하나예요. 본편의 수위에 맞는 쪽을 직접 고르면 됩니다.

등급	이럴 때 고릅니다
전체이용가	본편 전체가 연령 제한 없이 볼 수 있는 수위일 때
어른용	본편에 성인 독자를 전제로 한 표현이 들어갈 때

어른용으로 설정하려면 디렉터 본인의 성인 인증이 먼저 필요해요. 인증 전에는 어른용 에피소드를 새로 만들거나 기존 에피소드를 어른용으로 바꿀 수 없어요.

소개글과 썸네일은 등급과 무관하게 전체이용가 기준이에요. 플레이 전에 앱 목록과 검색 결과에 그대로 노출되기 때문이에요. 미리보기 이미지는 다릅니다 — 전체이용가 에피소드는 썸네일과 같은 기준이고, 어른용 에피소드는 어깨·등·허벅지 같은 부분 노출과 속옷·수영복 차림까지 허용되지만 성기·전라·성행위 연상 장면과 신체 부위를 노골적으로 강조하는 연출은 안 돼요.

어른용이라고 해서 수위에 제한이 없는 건 아니에요. 어른용으로 설정하더라도 금지된 표현이 들어가거나 허용 수위를 넘어서면 수정 권고를 받거나 에피소드가 차단될 수 있습니다. 전체이용가는 SafeNet 2등급 이하, 어른용은 3~4등급 일부까지예요. 콘텐츠와 맞지 않는 등급을 고르면 제재를 받을 수 있어요.

영역별로 어떤 표현이 금지되고 어디까지가 허용 수위인지는 콘텐츠 기준에 정리해뒀어요. 원문은 프론티아 커뮤니티 가이드에서 확인할 수 있어요.

에피소드 발행 버튼 누르기
#

준비가 끝났다면 왼쪽 사이드바의 에피소드 발행 버튼을 눌러주세요. 최종 발행 설정 확인창에서 공개 범위와 등급을 확인하고 발행하면 끝이에요.

발행 버튼은 마지막 발행 뒤에 수정한 내용이 있을 때만 눌려요. 이미 발행한 상태 그대로라면 버튼이 비활성화돼 있어요. 공개 범위를 바꿨을 때도 바꾼 상태에서 다시 눌러야 반영돼요.
캐릭터 이름은 발행하면 바꿀 수 없어요. 확인창에도 "한 번 발행하면 캐릭터의 이름을 변경할 수 없어요"라는 안내가 떠요. 이름은 첫 발행 전에 확정해주세요.
처음 전체 공개로 발행할 때 디렉터님을 팔로우하는 주인공에게 신작 알림이 한 번 자동으로 가요.
발행 후 수정
#

발행한 에피소드도 언제든 수정할 수 있어요. 수정 내용은 자동으로 저장되지만, 앱에 반영되려면 발행 버튼을 다시 눌러야 합니다. 적용 범위는 플레이 상태에 따라 다릅니다.

대상	적용 방식
새로 시작하는 주인공	수정된 버전으로 플레이합니다.
이미 플레이 중인 주인공	시작할 때의 버전 그대로 이어서 플레이해요. 주인공이 플레이 메뉴에서 버전 업데이트를 하면 그 시점부터 최신 발행본이 적용되고, 새로하기를 하면 처음부터 최신 발행본으로 시작해요. 주인공이 진행 중이던 이벤트를 지우고 다시 발행하면 그 플레이는 버전 업데이트를 할 수 없으니, 이벤트 삭제는 신중하게 해주세요.

변경 사항은 자동으로 저장되고 저장됨 표시로 확인할 수 있어요. 같은 에피소드를 여러 탭이나 기기에서 동시에 편집하면 마지막 저장만 남아 작업이 사라질 수 있으니 한 탭에서만 편집하세요. 발행 후 대표 프롤로그나 썸네일 구성을 바꿔도 다시 발행해야 반영되고, 상세의 프롤로그 미리보기·선택 화면은 최신 발행본 기준이에요.

수정 범위가 크다면 나만 보기로 돌린 뒤 고치고 다시 공개하는 것이 안전해요.

발행 번호와 업데이트 알림
#

발행 확인창(최종 발행 설정)에는 이번 발행 버전과 이전 버전 발행일이 함께 보여요.

항목	동작
발행 번호	발행할 때마다 1씩 올라가요. 공개 범위와는 상관없어요. 주인공은 플레이 메뉴에서 자기 플레이의 번호와 최신 번호를 비교해요. 번호가 생기기 전에 발행한 에피소드는 다음 발행부터 번호가 매겨져요.
업데이트 알림 보내기	발행 확인창에서 업데이트 알림 보내기를 체크하면, 이 에피소드를 진행 중인 주인공에게 "(에피소드 제목)이 업데이트됐어요" 푸시와 알림센터 알림이 가요. 체크하지 않으면 보내지 않아요. 첫 발행에는 이 체크박스가 없고, 전체 공개·링크 공개로 다시 발행할 때만 보여요(나만 보기 발행에는 보낼 수 없어요). 디렉터 본인은 받지 않아요.
주인공 쪽 반영	알림을 받아도 자동으로 바뀌지 않아요. 주인공이 플레이 메뉴에서 직접 버전 업데이트를 해야 최신 발행본이 적용돼요.

알림은 진행 중인 주인공에게 꼭 알리고 싶은 변경(새 이벤트·엔딩 추가 등)이 있을 때만 켜세요. 오탈자 수정처럼 알릴 필요가 없는 재발행은 알림 없이 발행하세요.

발행 후 관리
#

공개 범위 바꾸기 — 나만 보기나 링크 공개로 발행해 둔 에피소드를 열려면 공개 범위를 전체 공개로 바꾼 뒤 에피소드 발행 버튼을 다시 눌러야 앱에 반영돼요. 공개 범위만 바꾸고 발행을 안 누르면 그대로예요. 반대로 내릴 때도 같아요.

제목·소개글·썸네일·대표 프롤로그 바꾸기 — 자동 저장된 뒤 다시 발행해야 반영돼요. 진행 중인 플레이에는 적용되지 않고, 상세의 프롤로그 미리보기는 최신 발행본을 보여줘요.

에피소드 복제 — 스튜디오 대시보드의 에피소드 카드에서 복제를 누르면 기존 에피소드의 캐릭터·이벤트·미디어가 새 에피소드로 복사돼요. 시리즈 다음 편에 유용해요. 복사본 제목은 "원래 제목 앞 10자... copy"로 시작하니 발행 전에 바꿔주세요. 복사본은 원본과 별개라 복사본을 발행·재발행해도 원본의 플레이 기록·이벤트 발견·이벤트 정보 구매엔 영향이 없고, 캐릭터·미디어의 이벤트 연동 설정도 복사본 이벤트로 옮겨져요. 복사본은 발행 이력과 발행 번호 없이 새로 시작하고, 마켓·언어는 원본을 그대로 따라요.

참고 에피소드와 다른 디렉터의 작품 — 스튜디오에서 제공하는 참고 에피소드는 개인 플레이용으로 자유롭게 써도 되지만, 이를 바탕으로 만든 에피소드를 공개 발행할 수는 없어요. 그 밖에 다른 디렉터의 작품을 활용하려면 원작자의 동의가 필요해요.

삭제 — 에피소드 설정 메뉴 하단의 에피소드 삭제를 누르고, 화면에 나온 삭제 문구("찬란했던 나의 세계, 안녕!")를 그대로 따라 쓴 뒤 삭제를 누르면 지워져요. 삭제는 복구되지 않아요. 플레이 중인 주인공의 진행이 제한되고, 소속 캐릭터도 함께 삭제되며 그 캐릭터에 연결돼 있던 소울의 연결 목록에서도 제거돼요. 삭제 대신 나만 보기/링크 공개 전환을 먼저 고려해주세요.

정책 위반으로 차단됐을 때 — 차단된 에피소드는 홈·검색에서 제거되고 추천·랭킹에서 빠지며, 다시 발행할 수 없어요("차단된 에피소드는 발행할 수 없어요"). 기준은 콘텐츠 기준을 봐주세요.

해외 마켓과 노출
#

마켓·언어는 자동으로 정해져요. 에피소드의 콘텐츠 마켓과 콘텐츠 언어는 에피소드를 처음 만들 때 디렉터 계정의 마켓 기준으로 지정되고, 직접 고를 수 없어요. 이후 계정 마켓이 바뀌어도 이미 만든 에피소드는 그대로예요. 복제한 에피소드는 원본의 마켓·언어를 이어받아요. 소울도 같아요.

목록·검색·랭킹·추천은 같은 마켓에만 보여요. 랭킹도 마켓별로 따로 집계돼요. 다른 마켓 유저의 목록에 안 보이는 건 정상이에요. 다만 에피소드나 소울 상세 링크를 직접 열면 다른 마켓에서도 볼 수 있어요. 다른 마켓 목록에 내려면 그 마켓 계정으로 만들어 발행해야 해요.

AI는 콘텐츠 언어로 써요. 플레이에서 AI가 생성하는 언어는 에피소드의 콘텐츠 언어를 따라요. 시간 상태값의 요일 표기, {user} 기본 호칭, 이벤트 라벨 같은 파생 문구도 콘텐츠 언어예요. 주인공의 입력 상한은 주인공 계정 언어 기준이에요.

영어 등 일부 해외 언어는 글자수 2.5배예요. 영어·스페인어·포르투갈어·인도네시아어·태국어 콘텐츠는 스튜디오의 모든 텍스트 입력 상한이 한국어 기준의 2.5배예요(일본어·중국어 번체는 한국어와 같아요). 개수 제한은 언어와 무관하게 같아요. 항목별 수치는 글자 수와 개수 제한에 모아뒀어요.
