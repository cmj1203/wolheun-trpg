연출 씬 미리보기

씬 에디터의 연출 씬 미리보기 버튼을 누르면 쓴 장면이 실제 플레이와 같은 화면으로 재생돼요. 빠르게 확인할 수 있지만 AI 동작은 보여주지 않아요.

여기서 배울 내용은?

미리보기로 확인할 수 있는 것과 없는 것
실제 플레이와 다르게 보이는 부분
연출 씬 미리보기란
#

연출 씬을 쓰다가 실제 화면에서 어떻게 보일지 궁금하다면, 씬 에디터의 연출 씬 미리보기 버튼을 눌러보세요. 미리보기 창이 열리고 작성한 장면이 실제 플레이와 같은 화면으로 재생됩니다. 배경·캐릭터·대사·선택지가 앱에서와 같은 모양으로 나와요.

항목	내용
여는 곳	씬 에디터의 연출 씬 미리보기 버튼
화면 크기	모바일 / 태블릿 / 데스크톱 중에서 골라요. 기기 크기에 맞춰 세로·가로 그림으로 보여요
넘기기	창 왼쪽(약 30%)이나 ← 키를 누르면 이전, 나머지 영역이나 → 키를 누르면 다음 프레임으로 가요
처음으로	처음부터 버튼을 누르면 첫 프레임부터 다시 재생돼요
고친 내용 반영	창을 연 채로 연출 씬을 고치고 버튼을 다시 누르면, 보던 위치에서 고친 내용이 반영돼요
동작 방식	씬 텍스트를 그대로 해석해 보여주는 화면이에요. AI는 개입하지 않아요

프롤로그를 미리 볼 때는 실제 플레이 순서대로 1씬 → 주인공 선택 → 프로필 선택 이후 연출씬 → 선택지가 이어져요. 주인공 선택과 그 뒤 장면은 주인공 만들기에서 다룹니다.

확인 포인트
#

연출 씬을 쓰는 중간중간 열어 보며 다음을 점검하면 좋아요.

확인할 것	기준
이미지 배치	배경과 캐릭터 이미지가 의도한 프레임에 나오는지
배경 뒤의 글	{bg::}·{media::}와 같은 줄에 쓴 글이 사라지지 않았는지
프레임 분량	한 프레임에 담긴 글이 너무 길지 않은지
화면 크기	모바일과 데스크톱에서 모두 자연스러운지
마무리	마지막 프레임이 주인공의 입력을 기다리며 끝나는지

배경이 바뀌지 않거나 캐릭터가 대표 모습으로만 나온다면 연출 씬에 쓴 이름과 등록된 에셋 이름이 정확히 같은지부터 확인해보세요. 배경·미디어 이름이 틀리면 그 장면이 나오지 않고, 캐릭터의 상황·감정 이름이 틀리면 대표 이미지로 대신 나와요. 자주 나는 문제는 문제 해결에 정리되어 있습니다.

실제 플레이와 다르게 보이는 것
#

미리보기는 빠르게 확인하려고 몇 가지를 고정해서 보여줘요.

한 상태에 그림을 여러 장 올렸다면, 실제 플레이에서는 그중 하나가 골라지지만 미리보기에서는 첫 장으로 고정돼요.
자동 생성 장면이나 선택지를 비운 자리에서 AI가 만드는 선택지는 "(AI가 생성한 선택지 1)" 같은 자리표시로만 나와요.
미리보기가 확인하지 못하는 것
#

미리보기에서는 AI가 실제로 개입하는 부분이 하나도 돌지 않아요. 아래 항목은 직접 플레이해야만 확인할 수 있습니다.

자유 대화가 자연스럽게 이어지는지
자동 생성 이벤트의 실제 장면과 AI가 붙이는 선택지
진행 가이드대로 이야기가 흘러가는지
이벤트 트리거가 제때 충족돼 다음 이벤트로 넘어가는지
상태값이 의도대로 움직이는지
