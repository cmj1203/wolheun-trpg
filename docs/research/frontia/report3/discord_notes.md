조사 기준일: 2026-11-10. 날짜는 별도 표시가 없으면 한국 시간(KST). 중단된 연구자의 기존 세션과 `/tmp/fd`의 렌더링 DOM 캡처를 복구해 작성했다. 이번 복구에서는 브라우저를 새로 조작하지 않았다. 기존 조사에서 채널을 열어 사용자 계정의 읽지 않음 표시가 지워질 수 있었다. 글·답글·반응·투표·스레드 참여·연령 확인은 하지 않은 것으로 기존 실행 기록에 나타난다.

## 7. 디렉터·플레이어 관점의 시사점

### 디렉터 관점

1. **제작 흐름과 프롬프트 적용 시점을 함께 설계해야 한다.** 10-27 공지의 이벤트별 세계관과 다음 턴 반영, 프롤로그 재정렬·재발행 조건을 구분해야 한다. 글로벌 라운지에도 직전 프롬프트가 무엇을 뜻하는지 질문이 남는다.
2. **자료 공유가 있지만 온전한 튜토리얼로 이어지지는 않는다.** 팁 17개 중 검토 중 본문 9개, 시스템 줄만 남은 글과 미독해 첨부가 있다. 현재 볼 수 있는 모델 대응·압축·공식 음원 시트부터 참고하는 것이 근거가 분명하다.
3. **규칙이 긴 이야기를 자동으로 보장하지 않는다.** 제작자 모델 대응 글은 진행 속도·비밀·오류 누적을 경고하고, 제안 포럼은 기억·인과 개선을 요청한다. 노트 2,000자는 저장량 개선이며 장기 서사 품질 보증은 아니다.
4. **편집 도구는 개선되고 있으나 자동화 요청은 남아 있다.** 공식 개편은 출시 안내가 있지만 JSON 입출력·모든 노드 일괄 작업은 완료 증거를 확보하지 못했다. 연출 미리보기는 별도 완료 응답이 있는 사례다.
5. **콘테스트는 작품 유통과 플레이어 참여까지 연결한다.** 스타뿐 아니라 배너·광고·번역·파트너 혜택과 댓글 참여 보상이 공지된다. 실제 매출·유입 효과는 확보하지 못했다.

### 플레이어 관점

1. **무료 이벤트와 상시 무료를 구분해야 한다.** 11-05 공식 답변은 Spark 무료를 11-14까지로 설명하고 연장은 검토 중이다. 구독은 10-22 답변 기준 없으며 실제 11-10 결제 화면은 확인하지 않았다.
2. **유저 노트는 용량뿐 아니라 반복 비용을 봐야 한다.** 웹 2,000자 확장은 공식 안내됐지만 500자를 넘겨 저장한 플레이는 장면마다 20스타 추가이며 앱은 당시 예정이었다.
3. **오류처럼 보이는 현상에 서로 다른 원인이 있다.** 미션 조건 설명, 이미지 유형 설정, 공급자 안전 필터, 실제 수정 완료 답변을 구분해야 한다. 18개 표본을 하나의 서비스 불안정 지표로 합칠 수 없다.
4. **계정·재화 문의는 공개 포럼보다 전용 문의가 본래 동선이다.** start-here가 안내하지만 라운지에도 비밀번호·스타 질문이 남아 있어 안내의 발견성과 계정 복구 경로를 살펴볼 필요가 있다. 이는 본 보고서의 해석이다.
5. **TRPG 수요는 확인되지만 구현 범위는 별도 확인이 필요하다.** 주사위·엔딩 힌트·통계·장기 기억 요구가 보인다. 실제 공정한 판정·분기·기억 보존을 플레이로 검증하지 않았다.
