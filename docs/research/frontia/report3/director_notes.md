## 2. 제작 흐름(새 에피소드 만들기)

### 2-1. 단계 [봄]
1. `새 에피소드 만들기`를 누르면 「어떤 에피소드를 제작할까요?」 창이 뜬다. **드라마**(프레임을 한 장씩 넘기는 방식)와 **노벨**(웹툰처럼 내려 읽는 방식) 중 하나를 고르고 `제작`을 누른다. 근거: `director/01_new_episode_dialog.png`
2. 바로 초안이 생기고 편집기로 이동한다. 주소는 `/studio/episodes/<id>/settings/general`이다. 상단에 "자동 저장 · 모두 저장됨 / 나만 보기 / 미발행 / 에피소드 발행"이 보이고, 저장 버튼은 따로 없다(자동 저장). 근거: `director/02_editor_world.png`
3. 왼쪽 메뉴는 아래와 같다.
   - **기본 구성**: 세계관 / 캐릭터 / 미디어(배경 에셋·상황 에셋·비디오) / 프롤로그
   - **에피소드 설정**: AI 설정 / 연출 설정 / 발행 설정
   - **고급기능(Beta)**: 스토리 설계 / 이벤트 프롬프트 / 키워드북 / 상태값 / 주인공
4. 발행에 꼭 필요한 것은 세 가지다: 세계관, 프롤로그, 기본 정보(제목·소개글·대표 썸네일·특징·장르). 캐릭터와 배경은 없어도 발행된다. 근거: `guide_raw/publish.txt`
5. 발행 버튼을 누르면 한 번 더 검사한다. 모든 이벤트가 연결돼 있는지, 프롤로그 외 이벤트에 트리거가 있는지, 상태값마다 출력 규칙이 있는지, 키워드에 활성화 단어가 있는지, 이미지를 올린 캐릭터에 대표 이미지가 있는지 등을 본다. 그다음 최종 확인창에서 공개 범위와 등급을 확인하면 발행된다. **운영팀 사전 심사는 없다.** 근거: `guide_raw/publish.txt`, 가이드 첫 화면 문구

| 프롤로그 | ① 연출 씬(필수, 4,000자) ② 주인공 프로필 선택 ③ 고른 뒤 연출 씬(선택) ④ 선택지 3칸(각 200자)·주인공 미션(30자) / 미리보기(모바일·데스크톱) | 프롤로그는 1~5개 | `07_editor_prologue.png` |

| 키워드북 | 특정 단어가 나오면 AI에게 추가 설정을 건넨다 | 20개. 한 번에 AI에 전달되는 것은 3개, 키워드당 활성화 단어 5개 | `guide_raw/keyword-book.txt`, `limits.txt` |
| 상태값 | 주인공 상태(시간은 필수 내장, 최대 5개), 캐릭터 상태(최대 3개), 플레이용 상단 고정(0/5), 유형(문자·숫자·시간), 출력 규칙(필수, 300자), 시작값(30자), 플레이어 표시 켜기/끄기, 대표 상태값 | 시간의 시작값은 만든 시각(2026.11.10.)으로 자동 입력된다 | `05_editor_status.png` |
| 주인공 | 디렉터가 준비하는 주인공. 최대 5명, 이름은 "플레이어 이름 사용"(기본) 또는 "직접 설정"으로 고정, 소개 200자(플레이어에게 보임), 특징 200자(AI에게 전달), 감정×상황 이미지 | 디렉터 이미지가 있는 주인공을 고르면 플레이어는 이미지를 바꿀 수 없다 | `guide_raw/protagonists.txt` |

### 2-3. 요청받은 항목별 정리
| 항목 | 내용 | 구분 |
|---|---|---|
| 에피소드 종류 | 드라마(프레임 넘김, 배경 없는 입식과 어울림) / 노벨(스크롤, 가로형·배경 포함 그림과 어울림). 플레이어가 플레이 중에 바꿀 수 있다 | [봄] `guide_raw/publish.txt`, `character-images.txt` |
| 세계관 | 3,000자. {user} 변수 필수. "AI의 긍정 편향 제거" 문구를 권장 | [봄] `guide_raw/world.txt` |
| 캐릭터("소울"과 구분) | 에피소드 캐릭터는 에피소드 안에서만 쓴다. 소울은 그 캐릭터를 1:1 채팅용으로 따로 등록한 것이다 | [봄] |
| 그림 | 캐릭터 이미지는 감정×상황 칸(각 20개, 칸당 10장, 투명 배경 권장). 업로드 때 webp(2048px)로 자동 축소, gif는 10MB | [봄] `limits.txt` |
| 영상·소리 | 비디오 에셋(오프닝·컷신), 배경 BGM과 상황 효과음(에셋당 5개). **성우·TTS 기능은 가이드와 편집기 어디에서도 보지 못했다** | [봄] / 음성 없음은 [추정, 못 찾음] |
| 인트로 영상과 프롤로그 | 프롤로그는 필수이고, 대표 프롤로그는 로그인 안 한 사람에게도 무료 미리보기로 재생된다. 영상은 프롤로그 연출 씬에서 `{media::이름}`으로 넣는다. "프롤로그 웹툰"이라는 별도 기능은 없다 | [봄] `guide_raw/events.txt`, `media.txt` |
| 상태값 | 위 표 참고. 숫자형은 최대값을 넣으면 게이지가 생긴다. 숨은 수치(표시 끔)도 가능 | [봄] |
| 선택지와 자유 입력 | 선택지는 최대 3개이고 강제가 아닌 제안이다. 플레이어는 늘 직접 입력하거나 "알아서 진행하기"를 쓸 수 있다. 직접 쓴 장면에서 선택지를 비우면 AI가 채우지 않고 자유 입력이 된다 | [봄] `choices-and-missions.txt` |
| 엔딩·분기·목표 | 메인·서브 이벤트 각 100개, 메인·서브 엔딩 각 50개. 메인 엔딩 뒤에는 "이어하기"(자유 플레이)가 되고, 서브 엔딩(배드 엔딩)에서는 "이전 선택 다시하기"가 된다. 미션(30자)이 목표 역할을 한다. 플레이어는 300스타를 내고 잠긴 이벤트의 트리거 문구를 볼 수 있다 | [봄] `events.txt`, `endings.txt` |
| 주사위 | AI 설정에서 켜고 범위를 정한다(1~10,000). 판정 규칙은 프롬프트에 "Dice"로 직접 쓴다. 참고작 "7회차 용사"는 1~20 범위로 D20식 판정을 쓴다 | [봄] `dice.txt`, 참고작 AI 설정 화면 |
| 기억·요약 설정 | **편집기에 따로 없다.** 장기 설정은 키워드북(단어가 나오면 주입)과 상태값이 맡는다 | [봄: 메뉴에 없음] / 내부 요약 방식은 미확인 |
| 모델 선택과 비용 부담 | 디렉터는 기본 모델만 정한다. **비용은 플레이어가 턴마다 스타로 낸다.** 플레이어는 플레이 중에 모델을 바꿀 수 있다 | [봄] `world.txt`, `limits.txt` |
| 연령 등급 | 전체 이용가(SafeNet 2등급 이하, 만 14세 이상) / 어른용(3~4등급 일부, 디렉터 본인 성인 인증 필요) | [봄] `content-standards.txt` |

## 6. 디렉터에게 걸리는 규칙

### 6-1. 콘텐츠 기준 [봄] (`guide_raw/content-standards.txt`)
- SafeNet(방송통신심의위원회) 기준을 준용한다. 전체 이용가는 2등급 이하, 어른용은 3~4등급 일부까지다. 성기 노출과 위법 행위는 4등급이어도 금지다.
- 제목, 소개글, 썸네일, 소울 프로필, 커뮤니티 글은 **등급과 상관없이 전체 이용가 기준**이다.
- 등급과 상관없이 금지: 미성년자 성적 대상화, 저작권 침해, 불법 행위 옹호, 어뷰징·스팸, 실존 인물을 다룬 부정적 콘텐츠, 불법 촬영물·딥페이크, 마약·테러.
- 제재 단계: 경미(경고, 비공개, 24~48시간 작성 제한) → 중대(삭제, 생성 제한, 3일~영구 정지) → 심각(즉시 영구 정지와 수사 협조). 차단된 에피소드는 다시 발행할 수 없다.
- 플레이 중 "부적절한 내용"으로 응답이 막히는 것은 제재가 아니라 AI 모델 공급사의 필터다.
- 제목과 소개글 금지어: 프론티아, Frontia, 딥그로브, deepgrov, 욕설(`publish.txt`).

### 6-2. 저작권과 IP [봄]
- 가이드:
  - 직접 만들었거나 쓸 권리가 있는 에셋만 올릴 수 있다.
  - AI 생성물은 도구마다 상업 이용 약관을 확인해야 한다.
  - 2차 창작이면 소개글에 허가 문구를 적는다.
  - 다른 디렉터 작품을 쓰려면 원작자 동의가 필요하다.
  - 참고 에피소드를 바탕으로 한 작품은 공개 발행할 수 없다.
  - 근거: `guide_raw/media.txt`, `reference-episodes.txt`, `content-standards.txt`
- 서비스 이용약관(`frontia.ai/terms/service`, 사본 `director/terms_service.txt`), 운영사 딥그로브(주):
  - **제12조 1항**: 회원이 입력한 콘텐츠와 그것으로 만든 캐릭터·에피소드의 저작권은 회원이나 원권리자에게 귀속하는 것이 원칙이다.
  - **제12조 라이선스**: 회원은 회사에 서비스 운영, 개선, 홍보, 신규 서비스 연구를 위해 유저 콘텐츠와 생성물을 저장, 복제, 수정, 공중송신, 배포, **2차적 저작물 작성**에 쓸 수 있는 "비독점적, 전 세계적, 무상, **양도 가능, 재라이선스 가능**" 라이선스를 준다. 제3자 제공도 포함된다.
  - **제12조 공개 시**: 작품을 공개하면 다른 회원에게 서비스 안에서 이용하고 **2차적 저작물을 작성할 수 있는 무상 라이선스**를 준 것으로 본다. 외부 유출과 상업 이용은 금지된다. 회원은 정책에 따라 라이선스 범위를 제한하거나 유료로 설정할 수 있다.
  - **제12조의2**: 공개 콘텐츠는 회사가 번역, 현지화, 각색, 더빙을 하고 현재나 장래의 제휴 플랫폼에 배포할 수 있다(재라이선스 가능). 회원은 그 범위에서 저작인격권을 행사하지 않는다.
  - **존속**: 라이선스는 공개를 해제하거나 삭제한 뒤 처리 기간이 지나면 끝난다. 다만 일부는 존속한다.
  - **보증**: 회원은 제3자 권리를 침해하지 않음을 보증하고, 분쟁이 나면 회사를 면책하고 배상한다.
  - **제8조의4**: 유저 콘텐츠와 대화를 범용 AI 모델 학습이나 미세조정에 쓰지 않는다.
- IP 보유사가 판단할 때의 의미[추정]: 공식 IP를 올리면 회사가 번역·각색·재라이선스를 할 수 있고, 다른 회원은 서비스 안에서 2차 창작을 할 수 있다. 공식 IP 제휴 계약이나 별도 조건 안내는 가이드와 스튜디오에서 보지 못했다. 공식 IP로 공개 발행하려면 사전에 별도 협의가 필요해 보인다.
