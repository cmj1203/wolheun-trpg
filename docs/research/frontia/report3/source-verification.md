## 2. 조사 노트를 합칠 때 바로잡을 표현

1. 디렉터 노트의 “순수익 정의·출금 최소액 미확인”은 외부 노트와 약관 직접 확인으로 보완한다. 두 노트의 조사 범위가 달랐던 것이지 정의가 없는 것은 아니다.
2. 외부 노트의 “사용하는 LLM 회사 미확인”과 편집기 모델명 표시는 구분한다. 편집기에는 제공 모델명이 표시됐지만, 실제 요청 라우팅·모델 버전·내부 구현은 확인하지 않았다.
3. “키워드북·상태값이 기억을 맡는다”를 내부 기억 전체의 설명으로 쓰지 않는다. 설정 공급·상태 추적 기능만 확인했다. 대화 요약·자동 사건 저장·검색 방식은 미확인이다.
4. 약관 제11조는 참여하며 알게 된 비공개 정보의 기밀유지 의무다. 이 조항 하나만으로 원가가 어떻게 산정되는지, 회사가 어느 정보를 반드시 숨기는지까지 추론하지 않는다.
5. 상위 작품의 큰 누적 표시를 이용자 수·독자 수·매출로 환산하지 않는다. 집계 단위가 불확실한 UI 숫자는 원 표시 이상의 의미를 붙이지 않는다.
6. 소수 작품의 V8·V33·V93 표시는 버전 표본이다. 서비스 전체의 평균 업데이트 빈도나 성공 원인으로 일반화하지 않는다.
7. 11월 6일 무료 스파크 62턴과 11월 10일 일반 가격표는 시점·행사 조건이 다르다. 예전 무료 체험을 상시 무료 정책으로 쓰지 않는다.
8. 엔딩 도달·대조군·모델 간 동일 입력 비교가 없는 시험으로 전체 분기 품질이나 장기 기억 성공률을 제시하지 않는다.
9. 한국 앱스토어 RSS 최근 1~5쪽을 리드가 다시 받아 ID 중복을 제거했다. 250건(2026-10-08~11-08), 별점 5점 217·4점 17·3점 9·2점 3·1점 4는 재확인했다. 제목+본문에 `스타/비싸/가격/과금/현질/충전` 중 하나가 있는 글은 23건, 3점 이하 16건 중 해당 글은 5건이다. 외부 조사자의 가격 관련 29건·저평점 7건은 분류 기준이 달라 그대로 합치지 않는다. 키워드 언급에는 칭찬도 들어가므로 “가격 불만 23건”이라고 바꾸지 않는다. “저평점 대부분이 가격 불만”이라는 초기 요약은 이 표본으로 뒷받침되지 않는다. 익명 집계 기록: `source-verification/appstore-review-sample.json`.

## 3. 조사 중 계정에 남은 것

디렉터 조사 중 생성된 미발행·나만 보기 초안 “새로운 에피소드” 1개는 보존했다. 자동 생성된 항목이지 최종 보고서 제작물이 아니다.

`https://frontia.ai/studio/episodes/6af27c0b99ec4a487ca75ab8/settings/general`

스튜디오 조사에서 삭제·발행·업로드·유료 생성·결제는 하지 않았다. 별도 플레이어 조사에는 강호록 재접속 기억 질문 3회와 응답 3개가 있다. 기본 모델 무료 표시는 확인되지만 해당 플레이의 확장 노트·추가비·상세 거래내역은 검증하지 못했으므로 총 청구액 0까지 확정하지 않는다. 디스코드 채널을 읽으며 안 읽음 표시가 해제될 수 있다.

## 4. 브라우저 종료 기록

리드가 전용 공간 45에서 `task.finish({ keep: [] })`를 한 번 실행했다. 실행 뒤 `listTaskSpaces()`에는 45번이 사용자 소유로 남았다. 완전히 닫혔다고 보고하지 않으며, 보호된 탭의 종류는 확인하지 못했다. 사용자 소유로 바뀐 공간을 재점유하거나 추가로 닫지 않았다. 다른 사용자 공간 0·1도 그대로 보존했다.
