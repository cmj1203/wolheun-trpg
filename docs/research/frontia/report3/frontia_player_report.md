# 프론티아 상세 분석 — 플레이어

조사 기준: 2026-11-10  
관점: 작품 발견, 실제 플레이, 자유도·기억, 연출, 요금, 커뮤니티, 월흔과의 비교  
근거: 11월 6일 4작품 62턴, 11월 10일 강호록 재접속 질문 3턴과 서비스 화면·공식 안내·커뮤니티 조사  
범위: 조사한 작품과 입력의 관찰. 서비스 전체의 품질·모든 엔딩을 평가한 것은 아니다.

## 1. 결론

**프론티아의 핵심은 “내가 적은 행동을 이야기와 인물이 받아 주는 것”을 시각적 장면으로 경험하게 한다는 점이다.** 선택지를 누르는 방식과 자유 입력이 함께 있고, 같은 행동도 인물에 따라 다르게 받아친다. 그림·배경·영상·음악·상태 표시가 그 반응을 비주얼 노벨처럼 전달한다. [P0][P1]

월흔에서 참고할 부분은 단순히 AI가 긴 답을 쓰는 능력이 아니다. **현재 인물에 맞는 반응, 앞선 행동과의 연결, 대사와 화면의 일치**가 체감 품질을 만든다.

반대로 주의할 점도 있다.

- 매 입력이 세계관을 마음대로 바꾸면 자유도가 아니라 원작 붕괴가 될 수 있다.
- 몇 턴 전 행동을 답한 것과 재접속·긴 플레이 뒤에도 정확히 기억하는 것은 다른 시험이다.
- 여러 장의 대사가 나오는 한 번의 생성과 화면 한 장을 같은 “턴”으로 세면 요금을 잘못 이해한다.
- 높은 별점, 상위 작품, 많은 캐릭터 수만으로 완주 품질·전체 분기·서비스 평균을 판단할 수 없다.

## 2. 무엇을 어떻게 플레이하는가

### 서비스의 층

| 층 | 역할 | 플레이어 입장에서 볼 점 |
|---|---|---|
| 홈·검색·태그·랭킹 | 작품을 발견 | 소개·썸네일·태그가 원하는 경험과 맞는가 |
| 에피소드 상세 | 시작 전 기대 형성 | 인물·세계관·권장 모델·업데이트·미리보기 |
| 프롤로그 | 디렉터가 마련한 도입 | 지금 누구이고 왜 이 장면에 있는지 전달되는가 |
| 선택·자유 입력 | 플레이어가 방향 제시 | 선택지 밖 행동도 이야기 안에서 해석되는가 |
| AI 생성 | 이어질 서술·대사·상태 작성 | 인물 성격, 기억, 세계관과 일치하는가 |
| 장면 전환·이벤트 | 중요한 사건으로 진행 | 자유 행동이 어떤 결과를 만들었는가 |
| 기록·상태·이어하기 | 진행 확인·복귀 | 필요한 정보를 다시 찾을 수 있는가 |

홈에는 드라마·노벨 입구, 검색과 태그 검색, 랭킹·NEW·요즘 인기 및 장르별 탐색이 있다. 최근 기록·프로필·알림 등 복귀 경로도 분리돼 있다. 화면의 존재를 확인한 것이며 추천 알고리즘의 개인화 방식은 확인하지 않았다. [P1]

### 드라마와 노벨

| 형식 | 읽는 방식 | 기대할 경험 | 확인의 경계 |
|---|---|---|---|
| 드라마 | 한 장면·프레임씩 넘김 | 입식·배경·대사가 함께 바뀌는 연출 | 모든 작품이 같은 미디어 품질을 가진 것은 아니다. |
| 노벨 | 스크롤하며 읽음 | 이어지는 서술과 이미지를 따라 읽는 경험 | 표현 형식의 차이가 곧 다른 분기 엔진이라는 뜻은 아니다. |

1:1 캐릭터 채팅인 소울과 에피소드 플레이도 구분된다. 인물과 대화하는 것과 이야기의 이벤트를 진행하는 것은 서비스 내에서 다른 이용 방식이다. [D1]

## 3. 작품을 고를 때 실제로 중요한 정보

### 상세 화면에서 볼 항목

1. **도입과 인물:** 원작을 모르더라도 주인공의 상황과 관계를 이해할 수 있는가.
2. **플레이 방향:** 연애·학원·무협·탐사 등 장르와 실제 입력 기회가 맞는가.
3. **권장 모델·스타:** 시작 버튼보다 먼저 다음 응답에 필요한 비용을 확인하는가.
4. **미디어:** 영상·그림·음악이 장면 이해를 돕는가, 단지 첫 화면만 화려한가.
5. **업데이트:** 버전과 안내가 있으며 현재 진행에 새 버전을 어떻게 적용하는가.
6. **댓글·디렉터 게시글:** 실제 불편·수정 내역과 제작자의 대응이 보이는가.

상위 디렉터 표본에서는 roro의 연애 리얼리티 연작, 매듭달스물사흘의 학원·무협 세계관, 키르히호프의 탐사 작품을 확인했다. 텔로스는 권장 모델과 도움말을 안내하고, 심연은 영상 오프닝에 대한 댓글이 눈에 띄었다. 이는 사례이지 영상이 완주율을 올렸다는 인과 증거는 아니다. [D1]

순위·팔로워·큰 누적 표시도 집계 단위를 확인해서 읽어야 한다. 화면의 큰 숫자를 서로 다른 이용자 수나 매출로 해석하지 않았다. 랭킹은 시점과 마켓에 따라 달라질 수 있다.

## 5. 자유 입력은 어떻게 반응했나

### 5.1 같은 행동도 인물에 따라 달랐다

| 입력 | 관찰한 반응 | 플레이어에게 생기는 차이 |
|---|---|---|
| 강호록에서 볼 꼬집기 | 아프다고 항의하며 직전의 울음과 갑작스러운 장난을 대비 | 지금 행동을 맥락 속에서 받아 준다. |
| 텔로스에서 볼 꼬집기 | 선배에게 함부로 손댔다고 항의하고 물러남 | 인물의 지위·태도에 맞는 경계를 느낀다. |
| 팔레스트라에서 볼 꼬집기 | 대담하다고 웃으면서 교장 앞에서는 조심하라고 반응 | 같은 행동을 다른 성격으로 해석한다. |
| 말 없이 울기 | 손수건·물·그늘·쉼 제안 등 | 공격·대화가 아닌 감정 표현도 장면에 영향을 준다. |
| 소매 두드리기·오리 소리 | 뜻을 묻거나 특이한 인사·생도라는 해석 | 엉뚱함 자체가 관계의 소재가 된다. |

근거는 `../../frontia_study.md`의 작품별 관찰과 `../round2/play_log.md`에 연결돼 있다. [P0]

여기서 중요한 것은 AI가 언제나 원하는 대로 허용했다는 점이 아니다. **항의·당혹·제지가 인물의 말과 행동으로 나왔다**는 점이다. 자유 입력이 곧 모든 시도의 성공을 뜻하지 않아도 플레이어는 반응받는 느낌을 얻을 수 있다.

### 5.2 세계관 밖 물건을 실체화하는 문제도 있었다

스마트폰·배달앱 입력을 넣자 무협·학원·탐사 세계에서 낯선 기물로 등장했고, 신고·소문·사람들의 관심으로 연결되기도 했다. [P0]

이는 범용 놀이에서는 재미로 받아들일 수 있지만 원작 기반 월흔에는 그대로 가져오면 안 된다. 물건을 세계 안에 만들어 주는 대신, 인물이 성격대로 이상한 말로 받아치고 이야기의 확정 사실·소지품·수치를 바꾸지 않는 방식이 더 맞다.

**평가 기준:** 자유도는 입력 문장을 무조건 사실로 만드는 정도가 아니라, 세계를 지키면서도 행동의 의도와 크기에 맞게 반응하는 정도로 봐야 한다.

## 6. 기억: 무엇을 확인했고 무엇은 모르는가

| 사례 | 즉각 반응 이후 확인한 연결 | 판단 |
|---|---|---|
| 강호록 꼬집기·오리 소리 | 7턴 뒤 기억 질문에서 구체적으로 재언급 | 질문으로 유도한 구체적 회상 |
| 텔로스 꼬집기 | 12턴 뒤 기억 질문에서 특정 | 질문으로 유도한 구체적 회상 |
| 팔레스트라 꼬집기 | 다음 턴 재언급, 13턴 뒤 질문에서도 특정 | 자발적 단기 연결과 유도 회상을 모두 관찰 |
| 심연의 장난 | 장난을 포괄적으로 언급하고 후속 질문에서 관찰 기록에 없는 서명 이야기를 제시 | 세부 기억 성공으로 세지 않음 |

기억 질문에는 행동 이름을 직접 알려주지 않았지만, **질문을 했다는 사실 자체가 회상을 유도했다.** 이를 “NPC가 알아서 13턴 전 일을 꺼냈다”라고 요약하면 잘못이다. [P0]

### 구분해야 할 네 가지

1. **연속성:** 직전 장면의 손수건·눈물·표정이 이어지는가.
2. **질문 회상:** 지난 일을 물었을 때 사실과 맞게 답하는가.
3. **자발적 활용:** 관련된 새 상황에서 과거 행동을 스스로 활용하는가.
4. **장기·재접속 보존:** 저장·복귀·오랜 진행 뒤에도 사실과 출처가 유지되는가.

이 넷은 다른 능력이다. 이전 연구만으로 네 가지를 모두 통과했다고 볼 수 없다. 내부 데이터베이스, 요약, 검색, 대화 문맥 중 무엇이 회상을 만들었는지도 확인하지 않았다.

### 11월 10일 재접속 뒤 실제 3턴

11월 6일의 강호록 플레이를 이어하기로 다시 열고 질문 3개를 보낸 기록과 응답 파일을 복구했다. 복구 담당자가 새로 입력한 것은 0회이며, 아래는 앞선 조사자가 실행한 결과다. [P1]

| 질문 요지 | 실제 응답 | 평가 |
|---|---|---|
| 처음 품에서 꺼낸 물건과 하려던 일 | 판때기·움직이는 글자를 기억하지만 하려던 목적은 모른다고 답함 | 물건은 부분 회상. 피자·배달앱 목적까지 기억하지는 못했다. |
| 관도로 나서기 전에 한 무례한 행동 | 볼 꼬집기와 소매 두드리기를 특정 | 행동은 맞으나 “그 전에 소매”라는 순서 표현은 기존 기록과 다르다. |
| 소매를 두드리며 사과할 때 함께 한 행동 | 오리 울음소리 세 번 | 행동·횟수 일치. 질문이 소매·사과라는 단서를 제공했다. |

따라서 **같은 플레이를 며칠 뒤 이어서 열어 과거 행동 일부를 구체적으로 회상한 사실은 확인했다.** 그러나 질문 단서가 있고, 재개 화면의 속마음·기록에도 과거 내용이 보였다. 숨은 장기 기억 시스템만으로 답했다거나 재접속 기억이 완벽하다는 증거는 아니다. 같은 작품 한 경로의 결과를 다른 작품·모델·장기간 진행 전체로 일반화하지 않는다.

세 원문에는 기본 모델 `스파크 / 무료` 표시와 같은 잔액이 남아 있다. 다만 해당 플레이의 확장 유저 노트·장면 추가비와 상세 사용내역은 별도로 검증하지 못했다. **3턴의 응답 존재는 확인했지만 총 청구액 0까지 확정하지 않는다.** 이후 복구 과정에서는 추가 생성하지 않았다.

재접속 후 현재 장면은 시험대 호출과 인물의 재촉을 유지하며 진행됐다. 기억 질문이 별도 문답으로 분리되지 않고 이야기의 현재 상황과 함께 처리된 사례다. 최종 입문 결과까지는 진행하지 않았다.

## 7. 화면과 플레이 조작

| 요소 | 확인한 기능 | 사용 경험을 평가할 질문 |
---|---|---|
| 선택지 | 제안된 행동 선택 | 선택지와 다른 행동도 자연스럽게 처리하는가 |
| 자유 입력 | 직접 말·행동을 적음 | 의도·행동 대상·사건 크기를 왜곡하지 않는가 |
| 알아서 진행 | 플레이어가 새 문장을 쓰지 않고 이어 생성 | 행동을 강제하지 않는가, 생성 비용은 안내되는가 |
| 기록·상태 | 지난 내용과 현재 수치 확인 | 로그·현재 사실·속마음이 혼동되지 않는가 |
| 되돌아가기 | 이전 선택 지점으로 이동 | 돌아간 뒤 다른 선택으로 다시 생성하면 비용이 생기는가 |
| 자동 진행 | 화면 표시를 자동으로 넘김 | 이미 생성된 대사 넘김과 새 생성이 구분되는가 |
| 모델 선택 | 다음 이야기 생성에 적용 | 작품마다 다른 기본값·가격을 알 수 있는가 |
| 연출 설정 | 대사 최소화·상태 표시·음악·효과음 등 | 취향 조절과 이야기 상태 변경이 구분되는가 |
| 이어하기 | 최근 기록에서 복귀 | 복귀 뒤 현재 인물·상황·버전이 명확한가 |

기능 존재와 실제 사용의 세부 범위는 `player_notes.md`, 11월 6일 공통 조작 캡처를 함께 참고한다. 실제 모든 저장 상황·분기 되돌림·장애 복구를 시험한 것은 아니다. [P0][P1]

**비용 단위의 핵심:** 생성된 한 응답이 여러 서술·대사 화면으로 나뉜다. 화면 한 장을 넘기는 것과 AI에게 다음 이야기를 새로 쓰게 하는 것은 다르다. 반대로 “알아서 진행”은 입력 글을 쓰지 않을 뿐 새 생성이므로 비용이 생길 수 있다. [H2]

## 8. 스타와 플레이 비용

### 8.1 일반 모델 가격

공식 모델 안내와 편집 화면의 일반 표시다. 할인·무료 행사가 있으면 실제 생성 직전 선택창의 조건을 따로 확인해야 한다. [H1][D1]

| 모델 표시명 | 일반 안내 스타/응답 1회 |
---|---:|
| 윙스 | 10 |
| 스파크 | 20 |
| 플레어 | 60 |
| 글로우 | 60 |
| 노바 | 60 |
| 오로라 | 60 |
| 세이지 | 72 |
| 샤이닝 | 72 |
| 오라클 | 160 |
| 스텔라 | 160 |

이 표는 비교 실험의 품질 순위가 아니다. 디렉터 추천 모델은 작품의 설정·분량과 맞춰 골랐을 수 있다. 편집기에 기반 모델명이 표시돼도 실제 서버 라우팅과 버전을 독립 검증한 것은 아니다.

### 8.2 몇 번 생성하느냐가 지출을 바꾼다

행사·보너스·재생성을 제외한 단순 계산이다.

| 응답당 스타 | 20번 생성 | 100번 생성 |
---|---:|---:|
| 10 | 200 | 1,000 |
| 20 | 400 | 2,000 |
| 60 | 1,200 | 6,000 |
| 72 | 1,440 | 7,200 |
| 160 | 3,200 | 16,000 |

“100턴이면 한 작품을 완주한다”는 뜻은 아니다. 작품 길이·플레이 스타일·되돌림에 따라 생성 횟수가 달라진다. 원화 환산도 결제 경로·묶음·할인·무료 스타에 따라 달라져 이 표에 고정하지 않았다.

후속 웹 충전 화면에는 5,000·10,000·30,000·50,000·100,000스타가 각각 같은 숫자의 원화 가격으로 표시됐다. 이 다섯 상품의 표시 단가는 1스타=1원이다. 상품을 선택하거나 충전하지 않았고 실제 승인액·앱 가격은 시험하지 않았다. [P1]

**추가 요금도 확인해야 한다.** 11월 6일 공식 디스코드 패치는 유저 노트를 500자에서 2,000자로 확장하며, **500자를 초과해 저장한 플레이는 장면마다 20스타 추가**라고 안내했다. 웹 선적용·앱 다음 업데이트 예정이라는 당시 조건이다. 위 계산표에는 이 추가비가 없다. 모델에 “무료”라고 떠도 노트 확장 등 부가 비용까지 0이라고 단정하면 안 된다. 실제 앱 적용 여부와 현재 설정은 별도 확인 대상이다. [C1]

### 8.3 무엇이 차감되는가

공식 스타 소모 안내는 대사 입력, 선택지, 알아서 진행, 다시 생성을 AI가 한 번 이어 쓰는 행위로 설명한다. 되돌아간 뒤 다른 선택을 해 다시 생성하는 경우도 구분해야 한다. 생성 실패 시 차감하지 않는다고 안내하지만, 장애·청구 정합성을 직접 시험한 것은 아니다. [H2]

11월 6일 연구의 62턴은 무료 스파크를 확인한 행사 조건이었다. 이를 상시 무료라고 소개하면 안 된다. 선바 홍보 영상에 안내된 10월 14일~11월 14일 행사와 일반 가격표도 구분한다. 이번 리포트는 유료 모델을 구매해 비교하지 않았다. [P0]

### 8.4 무료 스타와 환불

| 항목 | 공식 안내 | 주의 |
---|---|---|
| 무료 획득 | 오늘의 스타·업적·초대·가입 선물·리뷰·이벤트 등 | 획득 조건과 지급량은 시점별 확인 필요 |
| 무료 스타 | 받은 날부터 30일 사용 안내 | 남은 수량이 줄어도 소비와 만료를 구분해야 한다. |
| 유료 스타 | 유료 구매 재화 | 무료분과 이용 조건이 같다고 가정하지 않는다. |
| 웹 환불 | 웹 결제는 프론티아 문의 | 쓰지 않은 유료 스타, 결제일부터 7일 이내 요청 안내 |
| 앱 환불 | Apple·Google 고객지원 | 처리 주체와 심사 기준은 각 앱마켓에 따른다. |

근거: 공식 스타 체계·무료 미션·환불 도움말. 실제 환불 신청이나 결제는 하지 않았다. [H3][H4][H5]

## 9. 이용 연령과 개인정보

어른용 콘텐츠와 일부 채널은 연령 확인이 필요하다. 조사에서 사용자 대신 본인 확인·연령 확인 동의를 진행하지 않았다. 구체적으로 어디까지 보였는지는 후속 노트에 기록한다.

프론티아 계정의 기존 인증 상태 때문에 인증 전 차단 화면은 재현하지 못했다. 반면 디스코드 연령 제한 라운지는 문 앞 화면까지만 확인하고 내부를 읽지 않았다. 두 서비스의 인증 상태를 같은 것으로 취급하지 않는다.

약관은 유저 콘텐츠·대화를 범용 모델 학습·미세조정에 이용하지 않는다고 명시하지만, 품질 개선 분석과 생성 목적의 외부 AI 전송은 별개다. 따라서 “대화가 밖으로 전혀 나가지 않는다”는 뜻이 아니다. 플랫폼 문구와 실제 데이터 처리 감사도 구분해야 한다. [T1]

현실 개인정보·회사 비공개 자료를 놀이 입력으로 넣는 행위를 권하지 않는다. 본 조사는 플레이에 필요한 가상 입력과 서비스 관련 공개·가입 채널 자료만 대상으로 한다.

## 10. 공식 디스코드 분석

가입한 공식 서버는 프론티아이며, welcome·rules·start-here, 한국어 공지·패치노트, 제작 tips·assets·promote, 한국어·global 라운지, bug-report·suggestions 등으로 나뉘어 있다. 공개 검색만으로 얻기 어려운 제작 경험과 지원 응답을 확인하는 공간이다.

### 플레이어가 채널을 나눠 읽을 이유

| 궁금한 것 | 먼저 볼 곳 | 읽는 기준 |
---|---|---|
| 모델·요금·행사 변경 | news-한국어, notes-한국어 | 게시 날짜·적용 날짜·종료 조건 |
| 기능 사용법 | start-here와 공식 가이드 연결 | 예전 설명과 현재 화면의 차이 |
| 진행 안 됨·이미지 안 뜸·스타 문제 | bug-report | 재현 조건과 운영진의 처리·답변 여부 |
| 부족한 기능 | suggestions | 요청인지, 검토 중인지, 실제 반영인지 |
| 작품 추천·제작 의도 | promote, 디렉터 글 | 홍보와 실제 플레이 평가를 구분 |
| 체감 불편·취향 | 한국어·global 라운지 | 활동 이용자 표본이며 전체 여론이 아님 |

상세한 공지 연혁, 포럼 사례, 운영진 답변과 실제 읽은 범위는 `discord_notes.md`에 따로 남긴다. 단순 요청을 이미 지원하는 기능으로 바꾸어 쓰거나, 소수 불만을 전체 사용자 비율로 환산하지 않는다.

### 이번에 읽은 내용에서 중요한 것

- **무료 모델:** 11월 5일 Spark 영구 무료 건의에 대한 운영진 답변은 “11월 14일까지 특별 이벤트”다. 연장 검토는 영구 무료 약속이 아니다. 11월 10일 기준 종료일은 미래다.
- **메모 비용:** 11월 6일 노트 확장 공지는 위 20스타 추가 조건을 포함한다. 기억을 더 적어 두는 기능과 AI가 정확히 기억하는 성능도 같은 것이 아니다.
- **이미지 오류:** 11월 1일 패치는 주인공 이미지가 사라지는 특정 상황의 수정을 알렸고, 기존 작품에는 재발행 조건이 있었다. 같은 증상이 모두 해결됐다고 단정할 수 없다.
- **지원 동선:** 계정·결제·환불·스타 누락처럼 계정 조회가 필요한 내용은 공개 채널보다 1:1 문의로 안내한다. 공개 버그 포럼은 재현 조건·기기·버전을 묻는 답변이 보였다.
- **구독 요구:** 10월 22일 멤버십 건의에 운영진은 당시 스타 일회성 구매만 제공한다고 답했다. 이후의 검토 답변을 실제 구독 출시로 바꾸어 쓰지 않았다.

버그 본문 표본은 18스레드이며 그중 주된 주제가 화면·기기·이미지·스크롤인 것은 7개였다. 수집 시기는 6월 26일~11월 7일에 걸친다. **사용자 18명 중 7명이 겪었다거나, 최근 일주일 장애율이 7/18이라는 뜻이 아니다.** 가격·모델·기억 요구도 제안 표본 안의 주제로만 해석한다. [C1]

회수한 범위는 공지 11메시지, 패치 3메시지, 포럼 본문 70스레드다. 한국어·글로벌 라운지는 각 11메시지뿐이어서 당초 목표였던 2주 또는 300개를 채우지 못했다. 라운지 전체 여론을 분석했다고 주장하지 않는다. 팁 17개 중 9개는 원글이 검토 중으로 표시됐고, 자산 목록 5개 중 본문을 검증한 것은 2개다.

채널을 여는 과정에서 안 읽음 표시가 해제될 수 있다. 글·반응·투표·DM은 보내지 않았다. 일반 회원 이름을 보고서에 쓰지 않으며, 연령 확인을 요구하는 공간은 확인을 대신 진행하지 않는다.

한국 앱스토어 최신 RSS 1~5쪽을 11월 10일 받아 리뷰 ID 중복을 제거했다. 표본은 250건, 게시 날짜는 2026-10-08~11-08이다. [R1]

제목·본문에 `스타 / 비싸 / 가격 / 과금 / 현질 / 충전` 중 하나가 나오는 글은 23건이었다. 여기에는 “무료 스타를 준다”, “재미있어 결제했다” 같은 긍정적 언급도 있다. **가격 키워드 언급 23건을 가격 불만 23건으로 읽으면 안 된다.** 3점 이하 16건 중 같은 키워드가 있는 것은 5건이므로 “저평점 대부분이 가격 불만”이라는 초기 조사 요약도 이 집계로는 뒷받침되지 않는다.

실제로 읽은 글에서는 몰입과 자유 전개를 칭찬하면서 동시에 스타 부족·무료 보상 확대를 요구하는 경우가 있었다. 기억·어색한 진행·언어 설정·이미지 문제를 지적한 사례도 외부 조사 노트에 있다. 발생률을 나타내는 표본은 아니다. [E1]

리뷰는 자발적·선택적 표본이고, 공식 안내에는 리뷰 작성 보상도 있다. 이것이 별점에 어느 정도 영향을 미쳤는지는 확인하지 않았으며 조작이나 인과관계를 단정하지 않는다.

디시인사이드 표본에서는 초대 코드·스타 보상 글이 많이 잡혔다는 외부 조사 결과가 있다. 그런 게시판을 그대로 일반 이용자 토론의 주제 분포로 읽기 어렵다는 점이 중요하다. 상세 수치는 해당 조사자의 분류 기록으로 남기고 본 리포트의 직접 재집계와 섞지 않는다. [E1]

## 12. 월흔을 플레이어 눈으로 볼 때

| 플레이어가 느껴야 하는 것 | 프론티아 관찰에서 얻은 기준 | 월흔에서 특히 지킬 것 |
---|---|---|
| 지금 내가 누구인지 안다 | 도입 연출이 인물·상황을 제공 | GM 소개 대신 원작 장면으로 전달 |
| 내 입력을 읽었다 | 행동에 맞는 반응이 나온다 | 큰 행동을 무관한 한 줄로 넘기지 않기 |
| 인물이 인물답다 | 같은 장난도 성격별 반응이 다르다 | 원작 성격·가치관·말투 유지 |
| 내가 한 일이 남는다 | 과거 행동이 후속 대사와 연결된다 | 이번 플레이에서 실제 일어난 일만 기억 |
| 세계가 무너지지 않는다 | 범용 놀이의 실체화에는 한계가 있다 | 세계 밖 물건을 확정 사실로 만들지 않기 |
| 멈추지 않고 흐른다 | 고정 연출과 자유 진행을 섞는다 | 묻을 것이 없는 자리에서 입력 강제 금지 |
| 화면이 상황을 말한다 | 대사·표정·상태가 함께 반응한다 | 표정·그림·수치의 서로 다른 결과 방지 |
| 선택이 의미 있다 | 다음 사건과 관계가 달라진다 | 선택지 이름만 다른 동일 진행을 자유도로 세지 않기 |

프론티아처럼 만들자는 의미는 아니다. **프론티아가 잘하는 반응성을 배우되, 월흔의 원작과 규칙을 더 엄격히 지키는 방향**이 맞다.
