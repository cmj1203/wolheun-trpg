# 프론티아 모작 분석 (clone)

투니온이 프론티아와 같은 성격의 인터랙티브 AI 스토리 플랫폼을 새로 만들기 위한 분석. 기존 `../report3/`의 디렉터/플레이어 상세 리포트를 "모작(비슷한 제품 자체 제작)" 관점으로 재구성한 것이다.

- `01_what_to_know.md` — 알아야 할 것: 제품 구조, 스토리 엔진, 제작 도구 사양, 모델·요금, 정산 55% 구조, 기술 스택 추정, MVP 제안.
- `02_weaknesses_and_risks.md` — 취약점·차별화 기회·리스크: 기억/트리거/상태 약점, 요금 체감, 정산 진입장벽, 운영·버그 이력, 법/IP 리스크, 모작이 더 잘할 7개 공략점.

근거 자료(그대로 보존): `../report3/frontia_director_report.md`, `frontia_player_report.md`, 조사 노트 4종, `source-verification.md`, `../../frontia_study.md`.

주의: "취약점"은 제품·사업·UX의 약점과 경쟁 공략점을 뜻하며 보안 침투가 아니다. 모든 수치는 부분·자발적 표본(앱리뷰 250건 등)이라 발생률·전체 여론이 아니다. 가격·한도·정책은 2026-11-10 시점. 법적 쟁점은 법무 검토 필요.
