## 4. 생성 과정과 계산

1. 00:09:31 이후 온라인 플레이 화면의 채팅 팔레트에서 특성치 이름을 눌러 굴린다. 예를 들어 채팅에는 근력의 `3D6*5`, 개별 눈과 합계가 나온다. **시트 안에서 굴리는 버튼을 확인한 것은 아니다.**
2. 구글시트로 돌아와 큰 특성치 셀에 결과(근력 50 등)를 직접 적는다. 반값·5분의1과 해설이 함께 바뀐다. `docs/trpg_ref3_transcript.txt:20–21`.
3. 건강 85, 크기 80, 민첩 45, 외모 80, 지능 45, 정신 45, 교육 60, 행운 75 순으로 이야기한다. 자동 자막의 건강 “15”는 뒤의 “85” 발언과 화면의 85에 의해 바로잡는다. `:22–28`.
4. 계산 예: 건강 85 + 크기 80 → 최대 체력 16, 정신 45 → 마력 9·초기 이성 45. 민첩 45 → 회피 기본 22. 근력 50·민첩 45가 모두 크기 80보다 작아 이동력 7. 17세 설정은 특성치를 만든 뒤에 붙이며, 정식 나이 보정을 다시 적용하는 장면은 확인되지 않았다.
5. 시트가 직업기능점수 240과 관심기능점수 90을 계산한다. 교육 60×4, 지능 45×2와 일치한다. 성장 점수는 빈칸이다. **이 예시의 330은 모든 캐릭터의 고정 예산이 아니다.**
6. 점수 칸은 최종 기능 수치가 아니라 기본값에 더할 투자분이다. 격투 기본 25에 100을 넣어 125가 되고, 수정한 50은 합계 75가 된다. “50이면 아마추어”라는 진행자의 발언을 최종 시트 값 50으로 옮기면 잘못이다.
7. 회피는 기본 22 + 투자 50 = 72(반 36, 5분의1 14). 매혹은 기본 15 + 투자 45 = 60. 마지막에 남은 점수 0. 표에 별도 직업/관심 투자 열은 없고 합쳐진 점수 한 칸이다.
8. 이름·성별·나이·체격·직업·외관·흉터·성격 등을 능력치에서 연상해 적는다. 수치 입력 → 인물 상상 → 기능 배분이라는 왕복 과정이다.

## 6. 이번 데모와 후속 기능

사용자 최종 결정: **아시나의 기본 특성·기능·시작 자원은 고정**. 주사위 생성·교환·추천값 선택을 넣지 않는다. 도입 중 완성된 시트를 잠깐 보여 준다.

플레이어가 직접 인물을 만드는 화면은 `coc_conversion_plan.md`의 **플레이어 캐릭터 만들기(나중)**에 별도 명세로 둔다. PC 전용이며 1440 기준, 1280·1920에서도 읽을 수 있게 한다.
