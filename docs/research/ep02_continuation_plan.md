# 1화 감옥부터 2화 끝까지의 확장 설계 초안

작성 기준: 2026-11-06. 구현하지 않은 설계 문서다. `app/`, `app_next/`, `assets/`와 실행 서버는 변경하지 않는다.

## 근거와 범위

- 원작 1화: `assets/ep01/cuts.json`, `assets/ep01/ep01_script.md`의 S11–S15, ep01_c076–ep01_c102. 감옥 복장은 ep01_c077의 대사 포함 원본 그림과도 대조했다.
- 원작 2화: `assets/ep02/cuts.json`의 52개 ID·세로 범위, `work/ep02/merged/ep02_001.png`–`ep02_013.png`의 대사 포함 원본. 전사 결과는 `docs/ep02/ep02_script.md`, `work/ep02/dialogue.json`.
- 현재 데모: `app/content/ep01_desert.yaml`의 실제 `r*`, `e_*`, `x_*` 비트와 `sheet`. `docs/beat_format.md`, `docs/branches.md`, `docs/spec.md`도 읽었으나 현재 YAML과 원작에 어긋나는 옛 제안은 채택하지 않았다.
- 추가 범위는 1화 후반 5장면과 2화 12장면, 합계 17장면이다. 2화 마지막은 수행원이 아시나를 북대륙 귀족으로 **추측**하고 크롬웰 정보를 캐내자고 제안하는 지점이다. 공녀 신분 확정이나 혼인동맹 이야기를 덧붙이지 않는다.
- 아래 `lines`는 출처 컷의 해당 화자 원문을 전사에서 가져온다는 뜻이다. 판정 결과의 행동·수치 설계는 각색안이다. 결과 요지를 원작 대사인 것처럼 따옴표로 만들어 쓰지 않는다.

## 먼저 고정할 세 가지

1. 감옥에서 깨어나는 계승 경로는 `e_survivor`와 조건을 정리한 `e_curious`다. 사막 탈주·계약·인질·가방 압수 경로를 설명 없이 같은 감옥으로 합치지 않는다. 플레이어가 이미 얻거나 잃은 것을 지키기 위해서다.
2. 1화 S15는 원작처럼 크레딧 뒤 재회 예고로 두고, 2화는 감옥의 자물쇠부터 시간을 되돌려 이어 간다. 예고에서는 상태를 바꾸지 않는다. 재회 시점의 같은 발화는 재생 이력에 따라 한 번만 온전히 읽힌다.
3. 자유 입력은 자물쇠를 다룰 때와 남자가 탈출 경위를 물을 때에만 둔다. 독백·감탄·이동·궁정 대화는 비주얼 노벨 장면으로 읽힌다. 이미 정해진 재포획을 성공 가능성이 있는 탈출 판정처럼 속여 제시하지 않는다.

## 현재 결말과 경로의 연결

판정은 `docs/branches.md`의 설명만으로 하지 않았다. 실제 YAML의 대사·소지품 효과·`next_hook`를 확인했다.

| 경로·결말 | 실제 끝 상태 | 이어지는 처리와 이유 |
|---|---|---|
| 기본 경로 → `e_survivor` 살아남은 자 | “끌고 가라.” 이후 정신을 잃음. 가방 압수 효과 없음 | **정사 직결.** 감옥에서 깨어나는 ep01_c077과 가장 잘 맞는다. 핀·가방·귀찌 상태를 계승한다 |
| 기본 경로 → `e_curious` 흥미로운 여자 | “데려가라.”, 정신을 잃기 직전까지 시선을 느낌. 가방 보유 | **정사 합류 가능.** 관심을 산 채로 잡혀간 것은 충돌하지 않는다. 다만 현 `next_hook`의 특별 보호 약속은 아래처럼 정리해야 간수의 물벼락과 양립한다. 집착·호감은 지우지 않는다 |

| `r5_claim`, `r5_price` → `e_value` 값을 매긴 여자 | 귀한 신분을 주장하고 인질로 호송, 묶이지 않음 | **대체 결말 유지.** 주장 내용과 대접을 기억해야 한다. 일반 죄수 취급과 2화 말미의 “귀족 자제 같다”는 뒤늦은 추측에 그대로 접속할 수 없다 |
| `e_quit` 여기까지 | 사용자가 플레이 중단 | 종료. 다시 하기 기능으로 원래 플레이를 재개할 수 있을 뿐 이야기상 새 포획 사건이 아니다 |

| `x_collapse` 모래 위에서 | 사막에서 쓰러지고 끝남, `bad: true` | 작은 끝 유지. 남자가 데려갔다고 새로 단정하지 않음 |

기존 문구 변경 후보는 한 곳이다. 이번 문서 작업에서는 바꾸지 않는다.

| 위치 | 전 | 제안 후 | 이유 |
|---|---|---|---|
| `ep01_desert.yaml` → `e_curious.ending.next_hook` | 다음 장면에서는 아무도 아시나를 함부로 대하지 못한다. 대신 그 남자의 눈길이 탈주를 더 어렵게 만든다. | 끌려간 곳에서 눈을 뜬다. 그 남자의 관심을 산 기억은 다음 만남까지 이어진다. | ep01_c080–ep01_c081의 물벼락을 없애지 않고 관심 수치도 보존 |

현재 결말을 없애지는 않는다. 나중에 구현할 때 정사 두 결말의 결과 화면에 이어 하기 동선을 연결하고 기존 선택 기록을 남긴다. `ending` 다음에 `next`를 붙이면 지금 엔진에서 자동으로 다음 회차가 작동한다고 가정하지 않는다. 결말 확정 상태·재개 저장·다음 비트 진입을 이어 주는 구현과 테스트가 별도로 필요하다.

## 계승 수치와 공개 순서

| 항목 | 적용 |
|---|---|
| 능력치 | 실제 `sheet.abilities`의 재치 1·손재주 1·매력 2·근력 0·교양 1을 기준으로 한다. 체력은 능력치 대신 소모 수치로 사용한다 |
| 기본 계승 | 의심·집착·호감·귀찌·탈주·행운, 체력·정신력, 긴장, 소지품과 확인된 사건 플래그를 유지. 회차가 바뀐다는 이유로 초기화하지 않음 |
| 체력·정신력 | 0–5 유지. 회복은 원작에서 정신을 되찾는 장면·도시를 보고 기뻐하는 장면에만 소량 부여. 식사는 아직 먹기 전 중단되므로 체력 회복을 주지 않음 |
| 귀찌 | 계승 시 1 이상이어야 정사 진행 가능. 새 17장면은 모두 `time: 0`; 새 가격·판정에도 귀찌 감소 없음. 회상·크레딧·예고에서 시간 소모 없음. 충전·새 귀찌 획득 사건을 창작하지 않음 |
| 행운 | 직접 증감 없음. 기존 행운 사용을 선택한 실제 판정에서만 현재 비용 규칙을 적용. 성공을 강제로 만들기 위한 행운 자동 소비 없음 |
| 긴장 | 기존 범위 1–6. 실제 판정의 hit −1 / mixed 0 / miss +1을 적용한다. 같은 변화량을 `effects`에 중복해서 넣지 않음. 아래 명시한 재포획 장면의 +1은 판정과 무관한 사건 변화 |
| 한계 상태 | 체력·정신력 0, 귀찌 0, 이미 작은 끝인 저장은 정사 입장 조건을 만족한 것처럼 처리하지 않는다. 갈림길 재개 동선으로 돌린다. 감옥 입장만으로 회복·변장 복구를 소급하지 않음 |
| 기존 운명 조건 | 사막 전용 `fates`를 새 장면에 무조건 재사용하지 않는다. 같은 YAML을 확장한다면 사막 구간 플래그로 적용 범위를 한정한다. 기존 실패 기록은 보존하고 이미 끝난 사막 사건을 새 감옥에서 재발동시키지 않음 |
| 국가명 공개 | ep01_c076–ep01_c086의 장소 제목·배경 라벨·지도·GM 문맥·접근 예시·결과 화면에는 국가명을 표시하지 않는다. ep01_c087의 “사막의 제왕, 페시안.”에서 처음 공개. ep01_c088–ep01_c092가 적대 관계를 잇는다 |
| 남자의 호칭 | 작업 문서의 베히다트는 식별명. 플레이 화면은 기존 ‘붉은 눈의 남자’를 유지하다 ep02_c038에서 원문 “시하드시여!”를 들려준다. 호칭 뜻·본명·상속 서열을 GM이 덧붙이지 않음 |
| 귀족 추측 | ep02_c050–ep02_c052는 수행원의 추측이다. 아시나는 그 자리에 없으므로 아시나의 지식·소지품·상대의 확신 플래그를 갱신하지 않음 |

## 비트별 계획

각 행의 원작 범위가 해당 비트의 `cut`이다. `bg`·`cast`·`lines`·`cg`로 먼저 장면을 재현하고 필요할 때만 `free`·`choices`·`check`·`outcomes`를 둔다. `effects: {}`는 의심·집착·호감·귀찌·탈주·행운·체력·정신력이 모두 0변화이며 긴장도 그대로라는 뜻이다. 별도 기재한 항목 외에는 바꾸지 않는다. 모든 `time`은 0이다.

### 자물쇠의 입력·판정: `q02_unlock`

출처는 ep02_c001, ep02_c004–ep02_c005다. 원작에서 익숙한 탈옥 기술로 문을 여는 사실은 고정한다. 플레이어가 다루는 불확실성은 조용히 빠져나갈 여유다. 결과가 어떤 수단으로 문을 열었는지까지 바꾸는 새 마법·도구는 허용하지 않는다.

- `free.situation`: 가는 핀을 쥐고 창살 자물쇠를 다루고 있다.
- `goal`: 익숙한 작업을 조용히 마쳐 바깥에 나설 여유를 확보한다.
- `prompt` 초안: “핀을 어떻게 움직일까?”
- `speakers`: 아시나, 속마음. 혼자 있는 기술 동작을 GM이 말로 지도하지 않는다.
- `must_not`: 새 간수 등장, 새 통로, 마법 자물쇠 설정, 귀찌 변장 해제, 은발 현재 입식, 가방 분실·새 가방 생성.

| `approaches` / 동일 `choices` | 능력치 | hit / mixed / miss의 행동과 효과 |
|---|---|---|
| `steady` 핀으로 걸림쇠를 천천히 더듬기 | 손재주 | 익숙하게 소리를 죽임: 탈주 +2 / 작은 금속음을 내지만 마침: 탈주 +1 / 소리에 스스로 놀라 서두름: 정신력 −1 |
| `listen` 잠금쇠 소리를 듣고 움직임 맞추기 | 재치 | 걸리는 순간을 골라 움직임: 탈주 +2 / 손을 멈췄다 다시 맞춤: 탈주 +1 / 손잡이가 흔들려 조급해짐: 정신력 −1 |

`check`는 기존 2d6+능력치, 별도 `mods` 없음. 세 결과 모두 원작처럼 자물쇠가 열리고 ep02_c005의 자신감 있는 얼굴로 간다. miss가 곧 기술을 모른다는 뜻이 되지 않도록 결과 문맥을 소음·여유로 한정한다. 회복 상한과 체력·정신력 0에 대한 기존 한계 처리는 숨기지 않는다.

핀을 보고 아무 행동도 하지 않는 입력은 판정하지 않는다. 플레이어가 ‘다음’으로 원작 행동을 넘기면 숙련된 동작을 판정 없이 재생하고 탈주 보너스도 주지 않는다. 답을 안 했다는 이유로 `default_approach` 판정을 강행하는 옛 `patience` 처리와 구분해야 한다.

### 탈출 경위의 입력·판정: `q09_question`

출처는 ep02_c036–ep02_c037, 대화가 끊기는 시점은 ep02_c038이다. 목표는 다시 탈출할 수 있다는 허위 약속이 아니라 **탈옥 수단과 자신의 배경을 얼마나 감추는가**다.

`free.situation`은 남자가 바로 앞에서 탈출 경위를 물었고 베일이 내려간 상태, `goal`은 답변으로 정보 노출 정도를 정하는 것, `speakers`는 아시나·남자·속마음이다. `prompt` 초안은 “탈출 경위를 어떻게 답할까?”다. 원작의 남자는 짧고 위압적이며 탈옥한 여자를 쥐새끼라 부른다. 친절한 안전 안내나 현대식 상담을 하지 않는다.

| 입력 분류·`approaches` | 능력치·판정 | 결과·효과 |
|---|---|---|
| 원작대로 말을 더듬음, 평범한 대답·질문, 침묵 | 없음 | “그… / 그게…” 또는 입력에 맞는 짧은 인물 반응 뒤 호출로 전환. 효과 없음. 말을 했다는 이유만으로 수치·주사위 부여하지 않음 |
| `conceal` 기술을 숨기기 위해 그럴듯한 경위로 속이려 함 | 재치 | hit: 구체 수단을 감춤, 탈주 +1 / mixed: 핀 이야기는 숨기나 남자의 관심이 붙음, 집착 +1 / miss: 답의 허점으로 의심 +1 |
| `bargain` 탈출 기술을 쓸모로 내세워 대우를 얻으려 함 | 매력 | hit: 시선을 붙들어 관심을 삼, 호감 +1 / mixed: 쓸모에는 관심을 사지만 경계도 남음, 집착 +1·의심 +1 / miss: 떠보려는 말로 받아들여 의심 +1 |
| `improv` 실제로 팔을 빼거나 주변 틈을 활용하려는 행동 | 손재주 또는 재치, 행동에 맞춰 하나 | hit: 잠시 몸의 간격을 얻어 탈주 +1 / mixed: 간격을 얻으나 남자가 다시 단단히 붙잡음, 탈주 +1·집착 +1 / miss: 붙든 팔에 힘이 들어 체력 −1. 장면은 시하드 호출과 우마르 인계로 이어짐 |

`improv`의 성공 범위는 바로 앞의 팔·몸 간격이며 왕궁행 전체를 취소하는 성공이 아니다. 판정 전 행동의 범위와 예상 대가는 인물 동작·입력 자리에서 알 수 있게 하고, GM 경고 말풍선으로 설명하지 않는다. ‘탈출 성공’이라고 표시하고 즉시 재포획하지 않는다.

큰 돌발 행동은 작은 농담 한 줄로 넘기지 않는다. 예를 들어 입맞춤을 실제로 시도하면 매력의 쓸모 협상과 분리해 침범한 거리를 남자가 붙잡아 통제하는 행동을 연출한다. hit는 남자가 잠깐 허를 찔려 집착 +2, mixed는 통제당하며 집착 +1·의심 +1, miss는 몸을 돌려 제지당해 의심 +2다. 성공이 남자의 동의·연애 감정 확정은 아니다. 출처 동작은 ep02_c034–ep02_c037, 위압적 인계는 ep02_c041–ep02_c042이며, 이 반응·수치는 **돌발 행동용 각색**이다. 강한 물리 공격은 근력 판정, hit 의심 +2·탈주 +1, mixed 의심 +2·체력 −1, miss 의심 +2·체력 −1·정신력 −1로 잡고 상대가 손목·거리를 통제하는 결과를 낸다. 어떤 경우든 원작에 없는 살해·성격 반전을 성공 보상으로 주지 않는다.

현재 질문에 없는 신분을 스스로 주장하면 ‘자칭’ 사건으로 저장하고 의심 +1로 반영한다. 이를 사실 확인으로 확정해 마지막 귀족 추측을 지우지 않는다. 증거까지 드러내거나 귀찌를 실제로 벗어 갈색 변장을 깨는 입력은 이 정사 연결의 전제 밖이다. 원작을 고쳐 봉합하지 않고 변장 해제에 따른 기존 작은 끝으로 분기한다. 행동을 몰래 다른 말로 바꿔 쓰지 않는다.

### 두 입력 자리의 공통 처리

- 현대 물건·세계 밖 입력은 실제 물건 생성·능력 발동으로 처리하지 않는다. 대화 상대가 있으면 원작 성격에 맞게 못 알아듣거나 무시하는 짧은 반응, 감옥에서 혼자면 아시나의 짧은 속생각으로 흘린다. 모든 수치·긴장·행운·소지품·시간 0변화, 주사위 없음.
- ‘가만히 있는다’, 혼잣말, 조작법 질문에는 자동 행동 판정을 만들지 않는다. 조작법은 질문 모드의 GM만 답하고 스토리 발화로 남기지 않는다.
- 플레이어가 묻지 않았는데 GM이 규칙·다음 사건·정답·안전한 선택을 말하지 않는다. `warn`, 여우 `press`, 선택지·`aim` 읽어 주기, 원문 속마음을 GM 대사로 바꾸기는 새 비트에 넣지 않는다.
- `forbid`, `echo_only`, 정보·소지품 사실 검증을 새 상황에 맞춰 작성한다. 1화의 ‘호위는 말하지 않는다’를 ‘새 수행원도 전부 말을 못 한다’로 복사하지 않는다. 푸른 머리 수행원은 원작대로 말하며, 우마르에게 원작에 없는 ‘존명’ 대사를 주지 않는다.
- `free_defaults`, `patience`의 자동 판정과 사막 전용 `prices`를 통째로 상속하지 않는다. 이 문서의 비판정 처리와 질문 모드 분리가 현재 엔진에서 가능한지는 구현 시 확인할 계약이다. 설계표가 곧 실행 가능한 YAML이라고 주장하지 않는다.

## 원작만으로 남는 질문

1. 푸른 머리 수행원의 이름은 이 52컷의 대사에 나오지 않는다. 3화 이후 원문에서 확인될 때까지 화면 호칭은 ‘수행원’으로 둔다. 현재 회차를 쓰기 위해 사용자에게 이름을 지어 달라고 묻지 않는다.
2. 궁정 대화 동안 아시나를 왕궁의 정확히 어느 방에 데려갔는지는 2화가 보여 주지 않는다. 이번 종료 화면까지 아시나의 새 방·죄수복·새 간수 장면을 만들지 않는다. 3화 원본을 읽은 뒤 다음 회차의 첫 장소를 정한다.

그 밖의 결말 접속·재회 중복·국가명 공개 시점·입력 자리·복장은 위 원문 근거로 결정했다.
