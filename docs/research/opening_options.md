## 있는 것

- `opening/screen_flow.md`: 하위 작업 보고. 지금 b00_open → b05_why 입력칸까지 화면에 나오는 글과 흐름, 줄 수, 읽기 시간 추정, 고칠 때 지켜야 할 엔진·시험 제약.
- `opening/research_cases.md`: 하위 작업 보고. 비주얼 노벨 도입부 사례 조사. 세션 네트워크 제한으로 웹 페이지를 열지 못해, 출처는 검색 요약이나 기억에 기댄 것이다(미검증 표시 참고).
- `opening/research_craft.md`: 하위 작업 보고. 도입부 작법(회상 몽타주, 칼끝에서 시작하고 되감기, 선택으로 성격 보여주기, 속마음, 온보딩, 읽기 속도). 이것도 페이지를 열지 못해 전부 미검증이다.
