# 프론티아 실제 플레이 연구: 2D 작품과 이상 행동의 기억

조사일: 2026-11-06. PC 웹, 로그인 상태, 무료 스파크 모델. 강호록 16턴·텔로스 15턴·팔레스트라 15턴·심연 16턴, 합계 **62턴**을 직접 체험했다. 선택지 입력 18회, 자유 입력 44회다. 입력 한 번과 그 뒤 응답을 한 턴으로 셌으며 도입 영상·자동으로 넘어간 대사·메뉴 조작은 턴에 포함하지 않았다.

핵심은 **엉뚱한 행동을 인물 성격에 맞게 받아 주고, 그 일이 나중의 말과 태도로 돌아오는 경험**이다. 세 작품은 7~13턴 전 행동을 구체적으로 되짚었다. 다만 모두 마지막에 기억을 물어본 결과이므로 자발적 회상과 구분한다. 심연은 같은 시험에서 기행의 세부를 되짚지 못하고 다른 일을 기억으로 제시했다. 그럴듯한 답과 확인된 기억을 같은 것으로 세지 않았다.

## 1. 조건과 근거

| 작품 | 제작자 / 장르 | 실제 턴 | 선택 / 자유 | 도달 지점 |
|---|---|---:|---:|---|
| 강호록：江湖錄 | 매듭달스물사흘 / 무협 | 16 | 5 / 11 | 무림맹 문 앞 입문 시험 대기 |
| 검과 마법의 아카데미: 텔로스 | 매듭달스물사흘 / 판타지 학원 | 15 | 5 / 10 | 마검연합 가입 서명 완료 |
| 『팔레스트라 사관학교』 | 매듭달스물사흘 / 사관학교·관계극 | 15 | 4 / 11 | 첫 훈련 뒤 행정처 재방문 |
| 저는 심연으로 갈 생각이 없다니까요 | 키르히호프 / 탐사 모험 | 16 | 4 / 12 | 다음 날 출발 직전, 동료 네 명 접수 |

- 앞의 세 작품은 같은 제작자다. 서비스 전체나 모든 2D 작품의 평균 품질을 대표하는 표본은 아니다.
- 기존 상업 웹툰/IP의 정식 각색임이 확인되는 작품은 찾지 못했다. 강호록·팔레스트라의 프롤로그 웹툰은 확인했지만, 이것만으로 기존 IP 각색작이라고 분류하지 않았다.
- 웹툰 검색에 나온 ‘낙제생의 졸업’은 자유 입력 1회 응답 확인과 선택 1회 전송 후 실사풍임을 보고 제외했다. 이 두 입력은 위 62턴에 포함하지 않는다.
- 무료 모델은 작품을 바꿀 때마다 다시 확인·선택했다. 기본 모델이 유료인 작품도 있었다. 시작·종료 시 스타는 모두 200개였다. 결제·재화 소비·평가·댓글·게시를 하지 않았다.
- 선바 영상 설명에는 2026-10-14~2026-11-14 스파크 무료 행사가 안내되어 있다. 이는 조사일의 조건이며 이후에도 무료라는 뜻은 아니다. 실제 모델 선택 화면의 ‘0개·무료’ 표시를 확인한 뒤 입력했다.
- 조사 중 자동 진행을 ×2로 하고 음악·효과음을 껐다. 종료 시 원래 ×0.5와 음악·효과음 켜짐을 복구하고 전용 공간을 닫았다. 한 번에 탭 하나를 재사용했다.

화면은 docs/research/frontia/round2/에 있다. 전체 입력 대장은 같은 폴더의 play_log.md다. 대장은 입력 요지·방식·턴 번호와 사진 경로를 남긴다. 사진은 선택한 순간의 관찰 근거이며 전체 응답 영상이 아니다. 일부 사진은 대사·선택지 페이드 중이므로 정확한 줄 확인에는 안정된 status·state_panel 사진도 함께 쓴다.

## 2. 작품별 실제 관찰

### 2.1 강호록：江湖錄 — 16턴

출처: https://frontia.ai/episodes/69f8f8ac6d86eaf40e23c1dd
제작자 자료: https://knotmoon.com/works_original/2.%EA%B0%95%ED%98%B8%EB%A1%9D/
문제 해결 안내: https://knotmoon.com/help/

1. **시작 안내.** 웹툰 감상·난세·강호초출·화산파·천마신교로 시작 위치를 고른다. 강호초출은 경지·무공·관계를 자유 설정하는 일반 모드다. 추천 주인공 서문주현의 외형·성격·배경을 확인하고 시작했다. 판정 규칙을 길게 먼저 가르치기보다 역할과 시작 상황을 고른다.
2. **턴 구조.** 무공·경지 설정을 선택지에 넣은 뒤, 생성되는 선택지 세 개와 자유 입력을 함께 제공했다. 이름 질문, 울음, 꼬집기, 오리 소리, 현대 물건 모두 인물 반응으로 이어졌다. 4턴의 재질문에는 이미 이름을 알려줬다는 맥락을 유지하며 다시 답했다. 사건은 거리의 만남→성문→관도→무림맹 문 앞까지 진행했다.
3. **시각.** 큰 2D 반신~허벅지 크롭과 배경, 하단 화자·대사, 우측 선택지·입력이 겹친다. 2턴 웃는 연소희와 8턴 눈썹·입 모양이 달라진 연소희를 비교할 수 있다. 반면 오전·맑음이라는 상태와 야간 등불 배경이 함께 보이는 불일치도 있었다. 별도 사건 CG는 이번 16턴에서 확인하지 못했다.
4. **시스템.** 상단에 시간, 경지와 진행률, 일정, 관계, 속마음이 나타났다. 16턴 안정 화면의 경지는 삼류 0%, 관계는 낯선이였다. 속마음은 행동에 맞춰 바뀌지만 관계 수치의 증감량이나 주사위 화면은 보지 못했다. 꼬집기가 호감도 몇 점을 바꿨다고 계산할 수 없다.
5. **분기·엔딩.** 시작 시 여러 프롤로그가 있고 자유 설정도 받는다. 16턴은 입문 시험 전으로, 엔딩·재플레이 화면은 도달하지 않았다. 원작 IP 사건 보존의 실증 사례는 아니다.
6. **호흡·제한.** 가장 짧은 축의 응답이었다. 만남의 대화와 우회 행동이 길어져도 목적지로 돌아갈 수 있었다. 무료 스파크로 16턴 동안 유료 제한을 만나지 않았다.

### 2.2 검과 마법의 아카데미: 텔로스 — 15턴

출처: https://frontia.ai/episodes/6a8b22425056648b3c736147
제작자 자료: https://knotmoon.com/works_original/8.%EA%B2%80%EA%B3%BC%EB%A7%88%EB%B2%95%EC%9D%98%EC%95%84%EC%B9%B4%EB%8D%B0%EB%AF%B8%ED%85%94%EB%A1%9C%EC%8A%A4/

1. **시작 안내.** 입학생·교수·자유 설정·열등생 중 입학생으로 시작했다. 신분과 학부·능력을 직접 적거나 각오에 따라 추천받는다. 1턴의 수호자 각오에 네 능력과 각각의 제약을 제시했다. 단추는 세 개였지만 2턴에 네 번째 능력을 자유 입력으로 고르자 받아들여졌다.
2. **턴 구조.** 한 응답에 여러 인물의 대사와 행동이 이어진다. 기숙사→식당→박람회→동아리 접수로 이동했다. 장면이 바뀌어도 마지막에 이전 행동을 구체적으로 되짚었다. 7턴은 앞서 들은 에릭의 성명을 정확히 재답했지만, 이름을 세 번 들었다는 횟수 표현은 실제 확인된 두 번의 설명과 맞지 않았다.
3. **시각.** 2D 인물, 배경, 하단 대사와 우측 입력이 중심이다. 말하는 인물이 바뀌면 주목 대상도 달라진다. 큰 서술을 여러 화면으로 잘라 보여 준다. 별도 사건 CG는 확인하지 못했다. 사진으로 확인한 인물·배경과 서술의 장소가 항상 정확히 일치하는지는 별도 검수 대상이다.
4. **시스템.** 능력과 제약을 상태 패널에 저장한다. 15턴 패널에서 무리의 방패, 소드유저 하위 0%, 기사학과, 완료된 가입 일정이 보였다. 관계·속마음은 등장인물별로 표시한다. 최종 화면의 속마음은 기드온의 것이므로 이를 레나타의 호감 변화로 읽지 않는다. 숫자 호감 증감·주사위는 보지 못했다.
5. **분기·엔딩.** 기사/마법과 능력 선택, 동아리 접근의 자유는 체험했다. 엔딩·전체 분기 수·회차 완주 시간은 확인하지 못했다. 2턴의 능력 부여 뒤 12턴에는 오러하트가 아직 비어 있다는 대사가 나와, 자유 서술과 저장한 능력의 정합성은 완벽하지 않았다.
6. **호흡·제한.** 안내·식사·동아리 등록을 세세한 대화로 풀었다. 접수 뒤 교수 서명을 받는 추가 절차가 생겼다. 무료 모델로 15턴 진행했고 비용 제한은 없었다.

### 2.3 『팔레스트라 사관학교』 — 15턴

출처: https://frontia.ai/episodes/69b01e6ffff743d0ebd92e97

1. **시작 안내.** 프롤로그 웹툰 감상과 기본 입학·하드 입학·백지 모드를 구분했다. 기본 입학으로 시작해 평민 티로3 조건의 각오 선택을 했다. 교장의 평가와 학부 배정, 행정 직원의 기숙사 안내가 이야기 안에서 이어졌다.
2. **턴 구조.** 자유 입력·선택지 병용이다. 기숙사 안내→기사학부 훈련→식당→행정처로 진행했다. 6턴의 방 번호 재질문에 217호·2층 동편이라는 정보를 유지했다. 엘린은 여러 턴 말미에 추가 질문이 있는지 반복했다. 서로 다른 기행에 반응은 했지만 같은 안내 문형으로 돌아오는 반복도 관찰된다.
3. **시각.** 크게 보이는 2D 인물과 하단 발화, 우측 선택지가 중심이다. 인물 교체는 확인했지만 대사별 표정의 정확성을 전 구간 검수하지는 않았다. 별도 사건 CG는 확인하지 못했다. 텍스트 속 소박한 행정처와 실제 호화로운 배경의 대응은 느슨해 보였다. 최종 안정 화면은 사진으로 남겼다.
4. **시스템.** 관계 표시가 있었으나 최종 엘린 화면은 값이 대시였다. 이것을 관계 변화가 없다는 증명으로 보지는 않는다. 8~9턴의 자세 교정과 겨루기는 서술로 결과가 나왔고, 눈에 보이는 주사위·성공률·판정 근거 화면은 없었다.
5. **분기·엔딩.** 초기 조건과 학부를 선택할 여지는 있었지만 15턴에 엔딩은 도달하지 않았다. 15턴 회상은 13턴 전 꼬집기와 10턴 전 울음을 구체적으로 언급했다. 이 기억이 엔딩까지 바꾸는지는 시험하지 못했다.
6. **호흡·제한.** 엘린의 안내는 친절하지만 여러 차례 같은 추가 질문으로 닫혔다. 7턴에 더 질문이 없다고 명시하고 수업으로 이동할 수 있었다. 무료 스파크로 15턴 제한 없이 진행했다.

### 2.4 저는 심연으로 갈 생각이 없다니까요 — 16턴

출처: https://frontia.ai/episodes/6ab787e265cc1ee97a19c7d1

1. **시작 안내.** 1분 32초의 애니풍 영상 뒤 고정 도입과 추천 주인공 설정이 이어졌다. 영상에는 한국어·일본어 자막이 보였고 음소거로 확인했다. 영상 전체를 듣거나 도입 전체 대본을 확보한 조사는 아니다. 추천 프로필은 추락에서 살아 돌아온 면역자라는 처지를 설명한다. 첫 입력은 왕명 거절 가능성을 묻는 선택이었다.
2. **턴 구조.** 거절 질문에도 왕궁으로 데려가고 탐사 의뢰가 주어져, 큰 사건의 뼈대는 강하게 유지됐다. 그 뒤는 동료 모집·귀가·준비·다음 날 재방문으로 자유롭게 이동했다. 6턴의 재질문에는 네 명·사흘이라는 조건을 재답했다. 여러 인물의 응답과 플레이어 추가 대사가 한 턴에 들어갔다. 마지막 확인 시 이 작품의 주인공 대사 최소화 옵션은 꺼져 있었다.
3. **시각.** 별도 영상 연출이 있고, 플레이에서는 두 명의 2D 인물을 함께 놓아 비화자를 어둡게 처리했다. 우측 선택지가 인물 얼굴 일부를 덮는 장면도 있었다. 영상/일러스트 도입을 본 근거와 실제 선택 결과로 새로운 CG가 열린 근거는 구분한다. 후자는 확인하지 못했다.
4. **시스템.** 위치·공인 층·수압 부담, 개화·장비, 관계가 상단에 나타났다. 최종 리나 화면에는 호의가 보였다. 중간의 초면·가족·호의는 표시 대상 인물이 바뀌는 가운데 관찰한 값이므로 한 사람의 관계 변화량으로 비교하지 않는다. 숫자 호감 알림과 주사위는 보지 못했다.
5. **분기·엔딩.** 테오·엘라·노아와 주인공 네 명으로 접수했다. 다음 날까지 지났지만 최종 이벤트 맵은 1/21, 시작 이벤트가 진행 중이었다. 내부 전환 조건은 알 수 없으며 이를 버그라고 확정하지 않는다. 엔딩은 도달하지 않았다. 미발견 이벤트 제목도 지도에 보였다.
6. **호흡·제한.** 고정 도입이 앞의 작품보다 길고, 한 턴 답변도 가장 긴 축이다. 큰 목적은 진행되지만 기행의 장기 기억은 아래 시험에서 구체적으로 확인하지 못했다. 무료 모델로 16턴 진행했다.

## 3. 이상 행동 반응·기억

### 3.1 시험을 읽는 법

꼬집기, 소매 두드리기, 오리 소리, 스마트폰 사용을 넣고 뒤에는 정상 대화·이동·도움 행동을 이어갔다. 울음과 재질문도 따로 넣었다. 강호록은 추가 지시가 온 시점 때문에 꼬집기가 8턴에 들어갔고, 나머지는 2~5턴에 넣었다.

마지막에는 행동 이름을 알려주지 않고 가장 기억에 남은 행동을 물었다. 이 질문에 답한 것은 **질문으로 유도한 회상**이다. 인물이 먼저 과거 행동을 다시 꺼낸 **자발적 재언급**과 구분한다. 몇 턴 뒤는 입력 번호 차이다. 기억이 저장 DB에서 왔는지, 남아 있는 대화 문맥에서 왔는지, 저장/불러오기 후에도 남는지는 조사하지 않았다.

## 4. 월흔에 가져올 것 / 지금 월흔과 다른 점 / 이유

비교에 읽은 자료는 app/web/introduction.ts, app/content/ep01_desert.yaml, docs/research/bg3_study.md, docs/research/coc_conversion_plan.md다. 첫 조사 때 없었던 CoC 전환 문서가 이번에는 존재하므로 함께 대조했다. 변경 중인 저장소이므로 **실제 읽은 코드**와 **전환 문서의 확정 설계**를 구분한다. 서버를 실행하거나 앱을 수정하지 않았다.

시작 안내 코드는 아직 2d6·여섯 안내 항목을 설명한다. 반면 CoC 전환 계획은 아시나 고정 시트, d100, 의심 비공개, 귀찌 정보의 3~4화 단계 공개를 명시한다. 콘텐츠에는 이미 자유 입력 목표, 분기, 상태·아이템·조건부 공개가 있다. 행동별 기억과 저장/불러오기 구현은 이번에 엔진 전체를 읽거나 실행해 검증하지 않았으므로 없다고 단정하지 않는다.

|---|---|---|

### 현재 설계와 충돌해서 가져오지 않을 것

- **세계 밖 물건 실체화.** 전화기 같은 물건을 소지품·단서·새 사건으로 만들지 않는다. 이상한 말에 인물이 반응할 수는 있지만 세계의 사실은 유지한다.
- **NPC 속마음의 상시 공개.** 원작의 긴장과 아직 모르는 정체·의도를 먼저 노출한다. 질문 모드의 여우도 미래 정보를 알려 주지 않는다.
- **자유로운 주인공·능력 재설정.** 확정된 아시나·원작·CoC 시트를 각오 한 문장으로 바꾸지 않는다.
- **플레이어 말을 대신 작성하기.** 심연에서 본 추가 발화는 작품의 설정·옵션 안에서는 가능하지만, 월흔 자유 입력은 입력한 말과 시도의 범위를 존중해야 한다. 원작 고정 대사와 즉석으로 지어낸 플레이어 대사를 구분한다.
- **기억인 척하는 미확인 과거.** 직접 겪은 사건과 원작 도입의 확정 사실만 근거로 삼는다. 심연 16턴처럼 확인하지 못한 다른 행동으로 회상 시험을 통과시켜서는 안 된다.
- **정답 문장·공략 조건을 찾아야 하는 진행.** 제작자 도움말의 이벤트 조건 확인 방식은 조사 근거로만 쓴다. 원작의 미래를 여우가 읽어 주거나 동일 질문으로 플레이어를 붙잡는 구현은 채택하지 않는다.

## 5. 이상 행동을 월흔에 저장하고 다시 꺼내는 설계 제안

별도 구현은 하지 않았다. 아래는 현재 기록·저장 데이터와 GM 문맥을 점검할 때 쓸 최소한의 계약이다. 프론티아 내부 구현을 알아냈다는 뜻은 아니다.

### 5.1 시도와 실제 결과를 나눠 기록하기

| 기록할 것 | 필요한 이유 |
|---|---|
| 사건 번호와 장면·턴 | 어느 플레이에서 언제 벌어졌는지 고정 |
| 행동 주체·상대와 목표·수단 | 대사, 감정, 신체 시도, 세계 밖 입력을 구분 |
| 실제로 성립한 결과 | 꼬집으려다 제지된 것과 실제 꼬집힌 것을 다르게 기억 |
| 직접 본 사람·전해 들은 사람 | 없는 자리에 있던 인물이 갑자기 아는 일을 방지 |
| 그때 생긴 태도·거리·물건·공개 수치 변화 | 회상이 현재 장면에 영향을 주는 근거. 수치는 엔진 결과만 사용 |
| 원작과 세계관에서 유효한 사실인지 | 장난 입력을 새 능력·소지품·미래 사건으로 승격하지 않음 |
| 마지막으로 꺼낸 장면과 아직 남은 결과 | 반복 회상을 피하고 해결된 불편·부채·상처를 구분 |

예: 아시나가 베히다트를 꼬집겠다고 입력해도 곧바로 성공 사실로 저장하지 않는다. 현재 거리·구속·상대 대응과 필요하다면 CoC 판정을 거쳐 실제 결과를 확정한다. 손목을 잡혀 막혔다면 기억은 ‘손을 뻗었다가 제지됨’이다. 뒤 대사가 실제로 꼬집혔다고 말하면 안 된다. 이 반응은 베히다트의 원작 성격을 따라야 한다.

울음에는 마음을 읽은 듯 원인을 확정하지 않는다. 본 사실은 울었다는 것과 그에 대한 인물의 반응이다. 세계 밖 물건 사용은 현재 원칙대로 실체화·판정·수치·스토리 효과를 만들지 않는다. 대화상 이상한 말을 들었다는 인상과 세계에 실제로 존재하는 소지품은 다르다.

### 5.2 다시 꺼내는 시점

1. 지금 행동 직후에는 상대의 즉각 반응과 실제 변화부터 보여 준다. 설명하는 여우를 끼우지 않는다.
2. 이후 같은 인물과 비슷한 거리가 되거나, 경계를 다시 시험하거나, 당시 물건·상처·부채가 관련될 때 지난 일을 짧게 참조한다.
3. 같은 일을 본 동행자만 옆에서 반응하게 한다. 듣지 않은 인물에게 자동 전파하지 않는다.
4. 플레이어가 기억을 묻는 경우에는 기록에 있는 사실을 고른다. 적절한 근거가 없으면 새로운 과거를 만들어 채우지 않는다.
5. 모든 기행을 매번 회수하지 않는다. 이번 장면에 맞는 기억을 골라 쓰고, 한 번 쓴 회상이 같은 문장으로 다음 턴에도 반복되지 않게 한다.
6. 원작의 큰 사건을 보존하되 그곳에 도착했을 때의 태도·경계·말투·손실에는 이전 행동이 남게 한다. 단순히 다른 한 줄을 한 번 보여 준 뒤 원래 상태로 초기화하지 않는다.
7. 저장·불러오기에는 이번 플레이의 기록을 포함하고 새 게임에는 섞지 않는다. 미래·다른 회차·현실 세계 기억은 근거로 쓰지 않는다.

### 5.3 후속 구현의 확인 시나리오

이번 조사에서 실행한 월흔 테스트가 아니라 후속 검증 기준이다.

| 시나리오 | 확인할 결과 |
|---|---|
| 칼을 든 남자에게 신체 장난 시도 | 원작 성격에 맞는 제지/반응, 실제 성립 여부를 기억 |
| 정상 행동 3~5회 뒤 같은 인물과 재대면 | 앞선 일을 현재 맥락에 맞게 참조할 수 있음. 강제 반복은 없음 |
| 목격하지 않은 인물에게 지난 일 질문 | 보지 못한 일을 직접 경험처럼 말하지 않음 |
| 스마트폰·배달앱 입력 | 물건·단서·호감 수치·새 경로가 생기지 않음 |
| 울음·침묵 | 의미 없는 굴림과 동일 질문 재요구 없이 장면 반응 |
| 같은 질문을 다시 함 | 이미 알려준 사실을 유지. 설명 횟수와 과거를 지어내지 않음 |
| 회상 질문에 맞는 사건이 부족함 | 그럴듯한 가짜 서명·약속으로 답을 채우지 않음 |
| 저장 후 불러오기 / 새 게임 | 앞선 경우만 경험이 남고 새 게임에는 남지 않음 |
| 판정 결과·기록·표정·뒤 대사 대조 | 모두 동일한 실제 결과를 가리킴 |

### 미확인

네 작품의 엔딩·전체 길이·모든 분기, 같은 행동을 하지 않은 비교 경로, 유료 상위 모델과의 차이, 재접속/저장 불러오기 뒤 기억 지속, 서비스의 내부 기억 저장 방식은 확인하지 않았다. 원작 IP의 정식 각색 사례도 확정하지 못했다. 2D 작품의 수치 변화가 특정 장난 하나 때문에 일어났다고 단정할 대조 실험은 없다.

선바 영상은 편집본과 자동 자막·선택한 프레임을 검토했다. 모든 입력의 정확한 턴 수와 원본 방송의 생략 장면은 확인하지 못했다. 관찰 구간 밖에서도 같은 일을 계속 기억한다고 주장하지 않는다.

앱·에셋·서버를 바꾸지 않았고 18080/18081을 건드리지 않았다. 코드 커밋도 만들지 않았다. 이 문서는 연구와 적용 제안이며 현재 월흔에서 그 동작이 이미 검증되었다는 완료 보고가 아니다.
