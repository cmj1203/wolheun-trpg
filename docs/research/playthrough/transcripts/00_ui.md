# 00. 화면 고정 글 (갈래와 무관)

출처: `app/web/index.html`, `app/web/main.ts`, `app/src/engine/types.ts`(TRACK_INFO), `app/content/ep01_desert.yaml`(atlas). 그림이 없는 환경이라 글만 적는다.

## 타이틀
- 월흔 / 비주얼 노벨 TRPG · 피칭 데모 / 15(이용가 표시)
- 그림 하나비 / 각색 미예 / 원작 윤슬 / 채색 및 보정 루라키 / 도움 팀 나비, 파아란
- 단추: [처음부터] [이어하기] [이야기 지도] [기록 지우기]

## 이야기 화면 위 막대
- 월흔 TRPG 데모 · 1화 사막 조우 / [수첩] [기록] [저장] [불러오기]
- "그 남자의 마음" 칸(의심·집착·호감, 남자를 수첩에 적기 전엔 숨김)
- 수치 이름과 마우스 올림 설명:
  - 의심 — 그 남자가 아시나를 첩자로 의심하는 정도
  - 집착 — 그 남자가 아시나에게서 눈을 떼지 못하는 정도
  - 호감 — 그 남자가 아시나에게 품은 호감
  - 귀찌 수명 — 변장 귀찌의 남은 힘. 0이 되면 변장이 풀려 은발이 드러나고, 낮아질수록 마음이 급해져 판정에 불리해진다
  - 탈주 준비도 — 탈주에 쓸 정보, 도구, 기회를 모은 정도(포로가 된 뒤에 보임)
  - 행운 — 판정 실패를 모자란 만큼 메우는 데 쓴다

## 대사창·입력
- 대사창 아래: 클릭 · Space 넘기기 ▼
- GM 말상자(사막여우) / 🦊 GM 단추(질문 모드: 입력칸 안내 "🦊 GM에게 묻기", 단추 글 "묻기")
- 입력 자리: 비트의 prompt 한 줄 + 입력칸 안내("예: …") + "또는 행동 고르기" + 접근 단추(이름 · 능력치 ±n) + [말하기]
- 처리 중: GM이 장면을 쓰는 중…
- 대가 줄 머리: 대가 / 장면 검사 줄: 긴장 n · 주사위 n → 그대로·달라진 결·끼어드는 일
- 주사위 창: `이름 · 능력치 판정` / `a + b +능력치(이름) +보정(이름) = 합 / 목표 10` / 성공·대가 있는 성공·실패 / `10 이상 · 원하는 대로 된다` 등
- 확인 창: [끝낸다] [계속한다]
- 알림(토스트): `수첩에 적었다 · 이름`, `얻음: 이름`, `잃음: 이름`, `질문은 오른쪽 🦊 GM 단추로 물어 봐.`, `피드백을 보냈어`

## 결말·결과
- 결말 카드 머리: 결말 / 작은 끝 · 눌러서 결과 보기
- 결과 화면: 결과 · 1화 · 사막 조우 / 제목 / 요약 / 다음 장면 · 잠김(next_hook) / 돌아보기 / 최종 진행 수치 / 플레이 기록(플레이 시간·판정 n회·선택과 입력 n회)
- 단추: [마지막 갈림길에서 다시](작은 끝만) [다시 하기 또는 처음부터] [이야기 지도] [피드백] [타이틀로]

## 이야기 지도 (atlas, 안 가 본 칸은 이름이 가려진다)
칸 힌트(1단계 / 2단계):
- 사람?!: 사막 한가운데서 누군가를 만나면 갈라져. / 사람을 보면 어떻게 할지 한번 네가 정해 봐.
- 왜지?: 칼끝이 목에 닿았을 때가 큰 갈림길이야. / 왜 살려 둬야 하는지 네 나름대로 말해 봐.
- 칼날: 칼 앞에서 잘 넘기면 그다음이 있어. / 억울하다고 버텨 보는 건 어때?
- 판결: 칼을 넘기고 눈이 마주친 다음에 정해져. / 그 사람 눈을 피할지 말지 골라 봐.
- 신분·값을 매긴 여자: 칼끝이 목에 닿았을 때 갈라져. / 네가 얼마나 대단한 집안 사람인지 내세워 봐.
- 증명·길잡이 계약: 칼끝이 목에 닿았을 때 갈라져. / 살려 두면 뭐가 좋은지 말해 보면 어때?
- 결박·수상한 이방인: 끝에 그 사람이 널 어떻게 보느냐로 갈려. / 수상하게 굴수록 이쪽으로 가까워져.
- 사막의 밤·크라차로 가는 길: 사람을 본 순간이나 칼끝 앞에서 갈라져. / 맞서지 말고 달아나 봐.(해가 질 때까지.)
- 흥미로운 여자: 칼을 넘기고 눈이 마주친 다음에 갈라져. / 그 사람 눈길을 끝까지 붙잡아 봐.
- 살아남은 자: 칼을 넘기고 눈이 마주친 다음에 갈라져. / 너무 튀지 말고 조용히 넘겨 봐.
- 여기까지: 어디서든 갈 수 있어. / 그만하고 싶다고 말하면 돼.
