# 솔로 TRPG 원리 적용 계획 (19차 설계안, 2026-11-04)

사용자 지시: "trpg 제대로 조사하고 공부해 … 게임에 어떻게 적용해야 될지 신중하게 고민하고 넣어. 대충하지 말고", "지금은 솔로 trpg니까 그거 중점으로 조사하고 지금 뭐가 잘못됐는지 어떻게 고칠 건지 생각해".
근거 문서: `docs/research/solo_trpg_study.md`(1차 자료 17개 대조 공부 문서), `docs/research/demo_structure_2026-11-04.md`(지금 데모 구조), `docs/research/sources/`(원문 저장본), 사용자가 준 보드라이프 글(`sources/boardlife_solo_trpg_2025.txt`), 기존 `docs/orpg_ref_notes.md`(16차 오라클·대가 표 제안).

## 0. 한 줄 진단

지금 데모는 **게임북(분기 서사) + 자유 입력 분류 + 숨은 판정**이다. 판정(2d6, 3단계)·행운·작은 끝·압박 장치는 이미 있다. 그런데 TRPG의 한 턴을 이루는 고리

> 상황 → 플레이어 선언 → **무엇이 걸렸는지 확인(위험·효과)** → 굴림 → **결과가 허구를 바꿈** → 새 상황

에서 굵게 쓴 두 단계가 플레이어에게 보이지 않는다. 그래서 플레이어는 "뭘 적든 GM이 알아서 정한다"(사용자 말로 '보정')로 느끼고, 입력을 요구받는 자리가 이야기가 묻는 자리와 어긋나면(b01) 숙제처럼 느끼며, 여우가 화면에 있는 것을 또 읽어 주니 서술 목소리와 규칙 목소리가 섞인다. 솔로 TRPG가 '살아 있다'고 느끼게 하는 세 가지 — **불확실성이 눈에 보이고, 대가가 허구에 남고, 플레이어가 고른 것이 뒤에 되돌아온다** — 중 지금은 셋 다 반쯤만 있다.

## 1. 이상 상태 — 처음 하는 사람 한 명이 겪는 한 턴

| 단계 | 화면에서 일어나는 일 | 원리(출처) |
|---|---|---|
| ① 장면 열기 | 내레이션 + 인물 대사만 흐른다. 입력 없음. 여우 없음. 단, 서술은 반드시 다음 '진짜 물음'(②)으로 내려간다 — 서술만 길게 이어지면 비주얼 노벨이 된다. | Alexandrian 'Art of Pacing': 빈 시간은 건너뛰고 다음 의미 있는 선택으로 간다. DW: 어떤 무브든 끝에 "What do you do?" |
| ② 물음 | 이야기가 실제로 답을 요구하는 자리에서만 멈춘다. 화면에 **지금 걸린 것 한 줄**(예: "칼끝이 목에 닿아 있다. 한마디면 베인다") + 접근 단추(각 단추에 쓰는 능력치·위험 정도) + 자유 입력. | PbtA "What do you do?"는 진짜 결정점에서만. 사용자 반려(11-04 15:3x 첫 장면 강제 입력). |
| ③ 선언·의도 확인 | 입력을 해석한다. 애매하면 여우가 아니라 **의도 확인 카드**로 되묻는다("칼을 피하는 거야? / 다른 뜻"). | 솔로 AI GM 논문(arXiv 2502.19519): 가장 큰 불만은 의도 오해로 여러 번 다시 쓰게 되는 것. DW 원칙 "Ask questions and use the answers". |
| ④ 위험 확인 | 굴리기 전에 **위험 카드**: 위치(안전/위험/절박), 쓰는 능력치, 성공하면 한 줄, 실패하면 한 줄, [그만둔다]. | Blades 'position & effect'는 굴리기 전에 합의한다. Alexandrian: 피해 전에 위험을 예고해야 결과가 공정하게 느껴진다. |
| ⑤ 굴림 | 2d6 눈이 화면에 보인다(이미 있음: dice 단계, 합계 + 능력치 → 10+ / 7~9 / 6-). 눈 옆에 ④의 '성공하면/실패하면'이 그대로 남아 결과와 대조된다. | DW 2d6 판정. 보이는 주사위(BG3·Disco)는 "GM 마음대로"라는 느낌을 없앤다. |
| ⑥ 결과 | 서술은 LLM, 효과는 코드. 7~9의 대가와 6-의 결과는 **장면별 대가 표**에서 뽑히고, 대가는 수치만이 아니라 허구(소지품 잃음·자리가 나빠짐·상대가 먼저 움직임·시간이 감) 중 하나 이상이다. mixed와 miss의 효과가 같은 접근은 금지. **7~9의 대가는 성공 자체를 뒤집지 않는다**(Blades 원문 "Don't inflict a complication that negates a successful roll"). | Ironsworn 'Pay the Price', Blades 결과 5종(효과 감소·복잡·기회 상실·더 나쁜 위치·피해; 시계 진행은 '복잡'의 한 형태), Fate 실패 결과의 'at a serious cost'. 사용자 지적(행운으로 바꿨는데 결과가 실패와 같음). |
| ⑦ 소프트 → 하드 | 6-이면 먼저 **위협이 보이는 소프트 무브**(아직 피할 수 있다). 같은 위협을 무시하고 또 6-이면 하드 무브(작은 끝·피해). 작은 끝 4개의 warn 1회 규칙을 이 일반 규칙으로 통합. | DW GM moves: soft(위협 예고) → hard(돌이킬 수 없는 결과). 14차 "경고 없이 끝나는 길은 없다". |
| ⑧ 막힘 | 판정 없는 말이 patience를 넘으면 여우 힌트가 아니라 **세계가 먼저 움직인다**(GM 무브 표: 위협의 징조 / 상대가 압박 / 대가 붙은 기회 / 시간이 감). 힌트는 GM 단추(질문 모드)에서만. | DW "when they look to you to find out what happens, make a move". 사용자 규칙(여우 메타 말은 질문 모드에서만). |
| ⑨ 장면 전환 | 장면 시작 때 **긴장값**(1~6)과 d6을 비교해 눈 ≤ 긴장이면 장면이 바뀝다: 홀수면 '변형'(같은 장면이 다른 결로), 짝수면 '끼어듦'(작가가 미리 써 둔 사건 1개, 원작 안에서). 긴장은 장면 목표 성공 -1, 실패 +1. | Mythic GME 카오스 팩터(d10 ≤ CF이면 홀수 altered / 짝수 interrupt). 보드라이프 글: "서사적 리듬을 만드는 … 이 글의 핵심". |
| ⑩ 오라클 | 대본에 없는 세계 사실을 물으면 GM이 지어내지 않고 가능성 등급 + 2d6으로 예/아니오. 원작 사실(lore)은 그냥 답. | Ironsworn 'Ask the Oracle', 16차 제안 7(사용자 OK). |
| ⑪ 목소리 | 내레이션 / 인물 대사 / 여우(규칙·메타·질문 답) 셋이 섞이지 않는다. 위험 카드·주사위·대가는 UI이지 여우 말풍선이 아니다. | 사용자 규칙(11-04 14:57 "이미 아래에 있는 걸 왜 또 말하냐"). AI GM 공통 처방: 규칙 목소리와 서술 목소리 분리. |
| ⑫ 선택의 무게 | 자유 입력 자리마다 '뒤에 되돌아오는 것'이 하나는 있다(줄거리 갈림 / 되받기 callback / 허구 대가). 없으면 입력 자리를 없앤다. | Emily Short·Ashwell: 가짜 선택(어느 쪽이든 같은 결과)은 없애거나 지연 결과를 단다. |
| ⑬ 끝 | 판이 끝나면 '선택·주사위 눈·대가' 리플레이를 보여 준다. | 솔로 저널 방식(orpg 노트). 기록창은 이미 있음. |

## 2. 지금과의 차이 (증거는 demo_structure 문서 기준)

| # | 지금 | 이상 | 왜 문제인가 | 고칠 것 |
|---|---|---|---|---|
| 1 | 접근 단추에 능력치(`재치 +1`)는 붙지만, 고르기 전에 **무엇이 걸렸는지**(성공하면/실패하면)와 **위험 정도**가 안 보인다. 칼 앞 danger 1건·risky(그만두기)만 있음. 자유 입력(improv)은 그마저 없음 | ④ 위험 카드 | 플레이어가 결과를 모른 채 굴리니 결과가 임의로 느껴진다("보정") | approach에 `risk`(안전/위험/절박)·`stake.win`·`stake.lose` 한 줄 추가. 단추를 누르거나 자유 입력이 해석된 뒤, 굴리기 전에 카드 + [그만둔다] |
| 2 | 주사위 눈은 이미 보인다(web/main.ts dice 단계: 눈 2개·식·등급). 다만 굴린 뒤 '이 결과가 무엇을 뜻하는지'가 서술에만 있어 수치 변화와 대조가 안 된다 | ⑤ 굴림 + 결과 대조 | 공정함은 있는데 읽히지 않는다 | dice 칸에 ④의 성공/실패 한 줄을 남기고, 결과 뒤 '대가: …' 한 줄(⑥) 표시 |
| 3 | 대가가 거의 귀찌 -1·의심 +1이고, mixed와 miss 효과가 같은 접근이 3개 이상 | ⑥ 장면별 대가 표, 허구 대가 | 성공과 실패의 차이가 안 느껴진다(사용자 지적) | 비트마다 `prices:` 4~6개(종류 태그), 테스트로 mixed≠miss 전수 검사 |
| 4 | 작은 끝 4개만 warn 1회, 일반 실패는 예고 없음 | ⑦ 소프트→하드 | 예고 없는 손해는 불공정하게 느껴진다 | miss 1회 = 위협 표시 플래그, 같은 위협 2회 = 하드 |
| 5 | 막히면 여우가 힌트(movesLine) → nudge 사건 | ⑧ 세계가 먼저 움직임, 힌트는 질문 모드 | 여우가 이야기 화면에 끼어든다(사용자 규칙 위반) | movesLine을 질문 모드로 이동, nudge를 GM 무브 표 4종으로 |
| 6 | 난수는 판정뿐, 장면은 항상 예상대로 | ⑨ 긴장값·끼어드는 사건 | 솔로 TRPG의 '살아 있음'이 없다 | 사막 장면 2곳·남자 앞 1곳에 작가가 쓴 사건 표(원작 안) — **사용자 OK 필요** |
| 7 | 자유 입력 11곳 중 줄거리를 바꾸는 곳 4곳, b01은 장식 | ⑫ 선택의 무게 | 가짜 선택 | 18차 감사표에 '되돌아오는 것' 열 추가, 없으면 삭제 또는 callback 추가 |
| 8 | 여우가 aim·선택지를 읽어 준다(18차에서 삭제 중) | ⑪ 목소리 분리 | 사용자 반려 | 18차 그대로 + 위험 카드·주사위는 UI 요소로만 |
| 9 | 의도 해석이 틀리면 그대로 판정된다 | ③ 의도 확인 카드 | 논문·사용자 경험 모두 가장 큰 불만 | LLM 해석 confidence 낮음 또는 improv_bold일 때만 카드 |
| 10 | 의심·집착·호감은 남자를 만난 뒤 숫자로 | 의심·귀찌는 **시계(클록)**, 집착·호감은 숨김 | 위험이 쌓이는 게 보여야 예고가 된다 | Blades 클록 UI — **사용자 OK 필요** |
| 11 | 오라클 없음 | ⑩ | 세계 사실을 GM이 지어낸다(보드라이프 댓글: "창작 의지를 꺾지 않는다") | 16차 제안 7 유지 |

## 3. 19차 작업 묶음 (레인 지시 초안)

순서: 15차 READY → 18차(첫 장면 흐름·여우 aim 삭제·입력 자리 감사표) → **19차** → 16차(오라클·대가 표는 19-B에 합침) → 17차 → 12차-a → 나머지.

- 19-A 턴 구조: yaml approach에 `risk`·`stake` 필드, 엔진 resolve를 '선언 → 카드 → 확인 → 굴림 → 결과' 순으로, 주사위 눈 표시, [그만둔다]. 스키마·검증·테스트.
- 19-B 대가 표(16차 #8 흡수): 비트별 `prices`(수치/소지품/자리/상대행동/시간 태그), mixed≠miss 전수 테스트, LLM은 뽑힌 대가를 서술만.
- 19-C 소프트→하드 일반화: `threat` 플래그, fates warn을 이 규칙으로 통합, 문서 bad_endings.md 갱신.
- 19-D 막힘 = GM 무브 표: nudge 4종, movesLine 질문 모드 이동.
- 19-E 의도 확인 카드(조건부).
- 19-F 긴장값·끼어드는 사건 — 사용자 OK 뒤.
- 19-G 클록 UI — 사용자 OK 뒤.
- 19-H 리플레이 화면(작음, 마지막).

QA(처음 하는 사람 기준): 6입력 시나리오를 26B로 플레이해 (1) 이야기 화면에 여우 말풍선 0건 (2) 모든 판정 앞에 위험 카드·뒤에 주사위 눈 (3) 같은 접근의 mixed/miss 결과가 다름 (4) 6- 뒤 바로 작은 끝이 나오지 않고 위협 표시가 먼저 (5) 막힘 3회에 세계가 움직임 — 각 항목 사진 1장과 대조표 docs/lead_check19/.

## 4. 사용자 답 (2026-11-04)

- 위험 카드: **안 보여 준다** → 19-A 취소. 접근 단추의 능력치 표시와 dice 단계는 지금 그대로. 위험 예고는 19-C(징조 서술)와 19-G(클록)로만 한다.
- 클록: **의심·귀찌만 클록** → 19-G 진행(집착·호감은 지금처럼).
- 끼어드는 사건: **사막 장면 2곳만** → 19-F 진행(남자 만나기 전 사막 장면에만 사건 표 2개, 원작 대면 장면은 그대로).
- 되묻기: **애매할 때만** → 19-E 그대로.

최종 19차 묶음: B 대가 표, C 소프트→하드, D 막혔=세계가 움직임, E 의도 확인 카드(애매할 때만), F 긴장값·끼어드는 사건(사막 2곳), G 의심·귀찌 클록, H 리플레이(마지막). A 취소.

## 5. 리드 결정 (2026-11-04, 사용자 반려 "여우가 붉은 눈 전에 경고하는 건 스포" / "여우가 자꾸 훈수 두는 건 TRPG GM 행동과 다르다")

근거(docs/research/sources/dw_gm.txt, Dungeon World GM 장 원문):
- GM 무브 "Show signs of an approaching threat" — 위협은 미리 보인다. "A soft move ignored becomes a golden opportunity for a hard move." (14차 '경고 없이 끝나는 길 없음'의 원형)
- 원칙 "Address the characters, not the players", "Never speak the name of your move" — "Your moves are not mechanical actions happening around the table. They are concrete events happening to the characters in the fictional world."
- 따라서 경고는 **캐릭터에게 일어나는 사건**이어야 하고, 플레이어에게 결과 이름(끝·은발·쓰러짐)을 대거나 "다른 수를 찾아 봐" 같은 훈수를 하는 건 GM 행동이 아니다.

결정 — 19-C 범위 확정(묻지 않고 리드가 정함):

| 어디 | 전(여우 말풍선) | 후 |
|---|---|---|
| fates spy_cut warn(의심 ≥ 7) | "저 사람 손이 칼자루에 갔어. 더 수상해 보이면 끝이야." | 나레이션 "남자의 손이 칼자루로 내려갔다. 눈은 아시나에게서 떨어지지 않았다." |
