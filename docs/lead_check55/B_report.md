# 55차 B — 아시나 가방 크기

54차 귀찌 후보 8장을 입력으로 삼아, 가방 입구 아래에 있는 **기존 주머니 픽셀만 세로 확대**했다. 새 가방·장화·옷을 그리지 않았다. 55차 원문과 `work/art/gpt/round6/bible/full_audit.md` 108·253행, 원작 1-c052·4-c058을 읽고 대조했다.

## 치수와 방법

머리 기준은 비후드 입식의 정수리 y298부터 턱 y452까지 154px다. 삐침과 후드 천은 머리 높이에서 제외했다. 후드는 정수리를 가리므로 같은 위치·크기의 비후드 얼굴 기준을 사용한다. 이 부분은 가려진 정수리를 직접 잰 값이 아니라 같은 인물·그림 위치를 이용한 기준이다.

가방 측정 구간은 y759~921의 162px에서 y759~949의 190px로 늘렸다. 경계 페더를 포함한 편집 구간 기준이며, 선 자체를 어디까지 세느냐에 따라 1~3px 차이가 난다. 190 / 154 = **1.2338배**로 요청한 1.1~1.3배 안이다. 선 경계 3px를 제외해도 187 / 154 = 1.2143배다.

입구·끈 연결을 그대로 두고 `(523,788,629,921)` 아래쪽 주머니를 106×161px로 세로 확대했다. 비는 옛 테두리 일부만 같은 행 바로 옆 옷 픽셀로 메웠다. 가방 앞면과 주름은 원래 그림 픽셀이다. 경계는 0.55px 페더, 확대는 bicubic이다. 폭은 바꾸지 않았다.

## 후보와 검증

아래 후보에는 **54차 귀찌 보정이 이미 포함**되어 있다. 아스트라 장화 편집은 이 파일들을 입력으로 사용하면 된다. 모두 1024×1536 PNG/RGBA다. 마스크 bbox는 전부 `(523,788,628,948)`이며, 마스크가 0인 픽셀의 RGBA 최대차는 모두 0이다.

입력과 출력의 y0~699 전체가 같아서 머리·표정·귀찌·목끈·어깨끈 상부가 보존된다. y1000 이후 전체도 같아서 장화·치마·겉옷 밑단을 보존한다. 가방 외부 보존은 마스크 밖 최대차 검사로 확인했다. 원본 알파 채널을 그대로 다시 넣고 알파 최대차 0을 확인했다.

`uv run --with pillow --with numpy python work/demo-slice/lane55/resize_bags.py`는 종료 코드 0으로 완료했다. `B_verification.json`에 입력 해시, 마스크 경로, 개별 보존 검사 결과가 있다. 편집기 기본 환경의 PIL/numpy 미설치 진단과 별개로 uv 지정 의존성 환경에서 정상 실행됐다.

## 직접 판독

`B_bag_compare.jpg`의 8행과 `B_measure_1440.jpg`를 직접 열었다. 입구 위치와 너비는 유지되고, 아래 주머니만 자연스럽게 길어지는 것을 확인했다. 손 옆에서 가방이 내려오지만 손·소매 형태를 새로 만들지 않았다. 주머니 세로 주름도 기존 픽셀의 확대다.

`B_original_before_after.jpg`는 원작 1-c052·4-c058과 전후 가방 확대다. `B_measure_1440.jpg`는 **파일을 올려놓은 1440 측정판이며 게임 화면 캡처가 아니다**. assets 설치 권한이 없으므로 실제 게임의 후보 설치·화면 확인은 레인이 이어서 해야 한다.
