# 월흔 TRPG 피칭 데모 명세

작성: 2026-11-02, 도리 리드(딥인터뷰 결과). 결정이 바뀌면 이 파일을 고친다.

## 한 줄

웹툰 「월흔」의 아시나가 되어 페시안에서 탈주를 꾀하는 1인용 비주얼 노벨형 TRPG다. 작성한 시나리오가 뼈대이고, 자유 입력은 로컬 AI GM이 원작 말투로 받아 주며, 판정은 코드가 주사위로 굴린다. 권리사 피칭 자리에서 노트북으로 시연한다.

## 사용자가 정한 것

| 항목 | 결정 |
|---|---|
| 목적 | 권리사 피칭 데모. 완성도 높은 한 챕터 |
| 피칭에서 노리는 반응 | 1순위는 "독자가 좋아하겠다"(원작 말투, 작화, 관계의 긴장감 재현). 여기에 "사업이 되겠다"(확장과 수익 구조)를 데모 안에서 함께 보여 준다 |
| 진행 방식 | 혼합. 시나리오 비트는 사람이 쓰고, 대사와 돌발 행동은 AI GM이 받고, 판정은 코드가 굴린다 |
| 인원 | 1인 먼저. 멀티는 구조만 열어 둔다 |
| 플레이어 | 아시나. 오리지널 캐릭터는 다음 확장 |
| 화면 | 비주얼 노벨형: 배경, 인물 입식, 대사창 |
| 재미의 축 | 탈주가 뼈대이고, 베히다트와의 장면이 보상 |
| 실패 처리 | 선택에 따라 이야기가 달라진다. 실패는 의심과 집착을 키우고 다음 장면을 바꾼다 |
| 인물 그림 | AI로 원작풍 입식 생성 |
| AI GM | 사내 로컬 모델. 게임 실행 중 원작 텍스트가 외부 AI 서비스로 나가지 않는다 |
| 나스 | 빌드와 에셋 보관. 시연은 노트북 |
| 원고 | 1화 PSD 보유. 2~10화는 사용자가 나스에서 받아 `~/Downloads/월흔_002` ~ `월흔_010` 에 푼다 |

## 리드가 정한 기본값

- 그림 생성도 이 맥 안에서 한다. 원작 그림을 외부 생성 서비스에 올리는 일은 되돌릴 수 없으므로 사용자가 허락할 때만 한다.
- 시연 기기는 이 MacBook Pro(M5 Pro, 통합 메모리 48GB)다. 데모는 인터넷 없이 돌아야 한다.
- LLM과 이미지 모델은 라이선스를 확인해 상업적 이용이 막힌 것을 제외한다. 피칭은 사업 목적이다.
- 등급은 원작 웹툰과 같은 15세 이용가다.
- 판정은 2d6 + 능력치다. 10 이상은 성공, 7~9는 대가가 있는 성공, 6 이하는 실패다. 선택에 따라 이야기가 달라진다. 주사위는 화면에 보인다.
- 자유 입력은 상대 인물이나 사건이 플레이어에게 답을 요구하는 자리에만 둔다. 혼자 있는 서술 장면은 입력 없이 흐른다. 자유 입력의 안내 줄(prompt)은 그 장면이 실제로 묻는 것을 적는다.
- 아시나 시트: 능력치 4~5개(예: 재치, 손재주, 매력, 체력, 교양)와 장비(마법 가방, 머리색과 눈 색을 바꾸는 마법 귀찌). 진행 수치는 베히다트의 의심, 집착과 호감, 귀찌 수명, 탈주 준비도다. 귀찌 효력은 원작에서 데모 구간보다 훨씬 뒤에 다하므로, 데모 안에서는 수명이 줄어도 변장이 풀리는 전개를 넣지 않는다(출처는 독자 리뷰이고, 2~10화 원고가 오면 다시 확인한다).
- 한 판은 15~25분이다. 범위는 1화 전체에 원작이 건너뛴 탈옥을 더한 구간이다. 사막 조우(PSD 005~014)로 시작해, 감옥(015~018)에서 플레이어가 탈옥을 직접 풀고, 크레딧 후 장면(019, 시가지 재회 "저 인간이 왜 여기 있어?")으로 끝난다. 웹툰 1화는 018 끝에서 핀을 꺼내며 끝나고 탈옥은 화면 밖으로 넘어가므로 원작과 충돌하지 않는다. 2~10화는 입식 학습, 말투, 확장 로드맵의 재료로 쓴다.
- 배경과 이벤트 CG는 원작 컷의 클린본(대사·효과음 제거)을 우선 쓴다.
- 사업성: 데모 끝에 결과 화면(선택, 판정, 플레이 시간 기록), 다음 에피소드 잠금 화면, 10화까지의 확장 로드맵 한 장을 넣는다. 결제 기능은 만들지 않는다.
