# 46차 시작 전 안내 검증

새 게임 전용 여섯 줄 안내. 불러오기는 저장한 장면으로 바로 간다.

| 어디 | 새 글 |
| --- | --- |
| 시작 전 안내 1 | 난 이 판을 진행하는 사막여우야. |
| 시작 전 안내 2 | 넌 아시나가 돼. |
| 시작 전 안내 3 | 장면이 오면 아래 입력창에 아시나가 할 말이나 행동을 적어. 뜬 단추를 골라도 돼. |
| 시작 전 안내 4 | 결과가 확실하지 않은 행동이면 주사위 두 개에 능력치를 더해 굴려. 주사위 둘이 다 6이면 대성공, 10 이상은 성공, 7~9는 대가 있는 성공, 6 이하는 실패야. |
| 시작 전 안내 5 | 결과에 따라 오른쪽 판의 체력·정신력·귀찌 수명이 오르내리고, 바뀐 건 이야기 창에 적혀. 행운은 실패를 메울 때 써. |
| 시작 전 안내 6 | 막히거나 궁금하면 입력창 오른쪽 내 얼굴 단추를 눌러 물어봐. |
| 안내 오른쪽 아래 | 건너뛰기 |
| 안내 4의 주사위 자리 | 주사위 2개 + 능력치 |
| game_help의 play | 위 안내 2~6과 같은 글. |

화면에서 체력·정신력·귀찌 수명·행운 이름과 입력창 안 오른쪽 여우 얼굴 단추를 확인했다. 안내에서 바꾼 이름은 없다.

1~2줄은 위치를 지칭하지 않는다. 3줄은 입력창, 4줄은 주사위 자리와 능력치, 5줄은 체력·정신력·귀찌 수명·행운, 6줄은 여우 얼굴 단추를 강조한다. 5줄의 이야기 변화 칸은 실제 변화가 없으므로 빈 칸을 새로 드러내지 않는다. 안내 중 메뉴와 입력을 잠그고, 안내 글은 스토리 기록·저장 화면에 섞지 않는다. 기존 스토리의 여우 설명 규칙은 바꾸지 않았다.
