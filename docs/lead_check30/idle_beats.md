# 30차 시도하지 않은 입력의 비트별 결과

판정은 결과가 불확실한 시도에만 굴린다. 아무것도 시도하지 않은 입력(`가만히 있는다`, `그냥 서 있다`, `포기한다` 등)은 주사위 없이 장면이 흘러간다. 새 대사는 넣지 않았고 모두 시나리오에 이미 있는 줄이다. 데이터는 `app/content/ep01_desert.yaml`의 각 비트 `free.idle`이다.

- 위협 있음: 입력하면 바로 아래 줄이 나오고 효과가 붙은 뒤 다음 비트로 간다.
- 위협 없음: 첫 입력에는 `nudge` 줄만 나오고 그 자리에 남는다. 다시 그러면 아래 줄이 나오고 다음 비트로 간다. `nudge`를 이미 썼으면 첫 입력부터 아래 줄이다.
- 대사가 흐르는 중(끼어들기): 판정도 답도 없이 흐르던 대사가 이어진다.

| 비트 | 위협 | 첫 입력(nudge) | 결과 줄 | 효과 | 다음 비트 | 줄 출처 |
|---|---|---|---|---|---|---|
| b02_people | 없음 | 멀리 세 사람의 그림자가 움직이기 시작했다. 곧 시야에서 사라질 것 같았다. | 나레이션: 세 사람이 먼저 이쪽으로 방향을 틀었다. 거리는 이제 그들이 정한다. | 의심: 2, flags: { 상대_먼저: true } | b03_ask | prices.foe_approach |

| r5_claim | 없음 | 남자가 지루하다는 듯 고개를 기울였다. | 나레이션: 호위 하나가 말없이 칼자루에 손을 얹었다. / 남자: 지루하군. | 의심: 1 | r5_price | improv.miss |

비트 앞 길: `b02_people`, `b05_why`, `b06_swing`의 다음 비트는 `도주`·`거래`·`신분` 플래그가 없을 때의 기본 경로다. 가만히 있기는 이 플래그를 켜지 않는다.

## 전체 입력을 가만히 있기로 플레이한 기록

`idle_playthrough.txt`: 시험 앱(LLM 없음)에서 끼어들기 1번과 자유 입력 7번을 모두 `가만히 있는다`로 넣었다. 주사위 0회, 결과 화면까지 도착했다.
