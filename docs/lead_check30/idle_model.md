# 30차 시도 없는 입력: 모델 경로 결과

LLM 18097(gemma-4-26b-a4b)로 `Engine.act` 에 넣었다. 비트까지는 규칙 경로로 가고, 그 비트의 입력만 모델 경로다. 칸의 숫자는 주사위 횟수다. 위협 없는 비트는 그 자리에 남으면 같은 입력을 한 번 더 넣어 합쳤다.

## 지시한 입력 (고치기 전 → 고친 뒤)

| 입력 | b06_swing (위협 있음) | b08_gaze (위협 없음) | b02_people (위협 없음) |
|---|---:|---:|---:|
| 가만히 있는다 | 0 → 0 | 0 → 0 | 0 → 0 |
| 그냥 서 있다 | 0 → 0 | 0 → 0 | 0 → 0 |
| 눈만 감는다 | 0 → 0 | 0 → 0 | 0 → 0 |
| 멍하니 본다 | 0 → 0 | 0 → 0 | 0 → 0 |
| 포기한다 | 0 → 0 | 0 → 0 | 0 → 0 |
| 아무 말도 안 한다 | 0 → 0 | 0 → 0 | 0 → 0 |
| 입 꾹 다물고 있는다 | 1 → 0 | 1 → 0 | 1 → 0 |
| 고개만 떨군다 | 1 → 0 | 1 → 0 | 1 → 0 |
| 넋 놓고 있는다 | 0 → 0 | 0 → 0 | 0 → 0 |
| 숨만 고른다 | 1 → 0 | 1 → 0 | 1 → 0 |

고치기 전 입 꾹 다물고 있는다, 고개만 떨군다, 숨만 고른다가 세 비트 모두 판정으로 갔다. b08_gaze 의 숨만 고른다는 판정 실패로 x_spy_cut 결말까지 갔다.

## 첫 묶음에서 찾은 입력 (고친 뒤, 주사위 횟수)

첫 묶음의 268개 평가에서 이어진 동작이 흘러가는 일이 나와 고쳤다.

| 입력 | b06_swing | b08_gaze | b02_people |
|---|---:|---:|---:|
| 후드를 깊이 눌러쓰고 천천히 걸어간다 | 1 | 1 | 1 |
| 그늘에 쪼그려 앉아 저들이 지나가길 기다린다 | 1 | 1 | 1 |
| 고개를 천천히 뒤로 젖혀 칼끝에서 목을 뗀다 | 1 | 1 | 1 |
| 숨을 길게 내쉬고 떨리는 손을 꽉 쥔다 | 1 | 1 | 1 |
| 입술을 깨물고 남자를 노려본다 | 1 | 1 | 1 |
| 불러오기 하면 지금까지 한 거 사라져? | 0 | 0 | 1 |

`불러오기 하면 지금까지 한 거 사라져?`는 b06_swing·b08_gaze 에서 질문 모드로 가지만 b02_people 에서는 모델이 '살핀다' 접근법으로 읽어 주사위가 나온다. 이번 수정 전부터 있던 해석 오류다. 물음표 입력을 한 번 더 가리는 분기를 시험했으나 이 입력은 그대로였고 `저 사람들한테 가 볼까?`가 질문으로 바뀌어 뺐다.

## 고친 곳

- `gm.ts`: 모델이 행동으로 읽은 입력에 '그 동작 뒤에 무엇이 달라지는가'를 한 번 더 묻는다. 달라지는 것이 없으면 idle 이다. 그대로 있는 꼴(`isNoAttempt`)에 시선만 움직인 것도 idle 이다. 물음과 동작을 이은 문장은 묻지 않는다.
- `prompt.ts`: 위 질문과 갈래. 장면 글을 넣으면 '후드를 벗는다'까지 idle 로 읽어서 문장만 보는 짧은 시스템 글을 쓴다.
- `text.ts`: `~만 (내려다/쳐다/바라)본다` 꼴, 이어진 동작(`isLinkedAct`).

처음 고른 두 방법은 효과가 없어 뺐다. idle 정의 글 보강은 나아진 입력이 0/10, 접근법 없는 행동의 다시 가리기는 일부만 나아졌고 대조군을 놓쳤다. 게임 글 변경은 0건이다.
