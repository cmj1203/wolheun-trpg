# 22차 LLM 대조표: 문서 밖 입력의 대체 문구

시험 포트 18192(앱)·18193(21차 이전 사본)·18190(LLM), 모델 gemma-4-26B-A4B UD-IQ4_XS, LLM 은 `heavy` 로 돌렸다. 사용자 포트 18080·18081 은 건드리지 않았다. 측정 중 1분 부하 평균은 1.4~1.7(최대 2.32)로, 다른 큰 작업은 없었다.

## 결론

- 21차가 대체를 늘렸는가: 같은 입력에서 4/44 → 6/44, 다시 쓰기 8회 → 14회였다. 장부 위반 6회 중 대체로 바로 빠진 것은 1건이고 재확인은 0회다. 다시 쓰기는 분명히 늘었고, 대체 2건 차이는 표본이 작아 우연일 수 있다.
- 예산 `budgetMs` 는 그대로다. 낱말 목록도 늘리지 않았다.
- 대체는 줄었다. 다만 판별력이 있는 수치는 아래 첫 표(튜닝에 안 쓴 입력)이고, 2건에서 1건으로의 변화는 표본이 작아 단정할 수 없다. 나머지 표는 입력을 보며 고친 뒤의 값이라 효과가 부풀어 있을 수 있다.
- 시드를 판마다 고정했다. 코드 사이의 비교에는 맞지만 독립 표본이 많은 것은 아니다.

## 안 고친 것

- 해석의 첫 시도는 여전히 프롬프트를 중앙값 2969토큰(2324ms), P90 5799토큰(4185ms) 다시 처리한다. 쓰기와 다른 프롬프트를 한 슬롯에 번갈아 넣기 때문으로 보인다. 슬롯을 나누면 줄 수 있지만 메모리와 실행 설정이 바뀌어 손대지 않았고, 효과도 재지 않았다.
- `왕이라` 스포일러 막힘: 플레이어가 먼저 `왕`을 말해도 인물이 되받으면 막힌다. 대체 줄 `시간을 끌 셈인가?` 가 말투에 맞아 그대로 뒀다.
- `lore/modern`: 세계 밖 낱말을 되받으면 첫 시도가 막히고 다시 쓰기로 풀린다. 대체로 빠지지 않아 그대로 뒀다.
- `와이파이 비번 뭐예요`처럼 곁에 사람이 없는 장면의 세계 밖 물음은 안내로 빠진다. 받아 줄 상대가 없어 이번에는 바꾸지 않았다.
