## 원인과 필요한 결정

보통 정책은 b02의 기본 `run`, b05의 기본 `plead`, b06의 기본 `dodge` 경로를 따른다. 반면 무리 정책은 b02에서 `watch`를 골라 `road`로 빠지는 판이 많고, 전체 판정 수도 보통 1326회보다 적은 1042회다. 같은 hard 부상 -2를 공통 적용하면 보통의 체력 0 도달이 오히려 더 많아진다. hard 단독 실험에서 몸 0은 보통 67판, 무리 52판이었다.

정신력 감소도 b04와 b05가 한 번의 행동 뒤 연이어 진입하는 구간에 누적된다. 정신력 단독 실험에서 마음 0이 보통 64판으로, 목표 최대 24판을 넘었다.

물 플래그는 기존 b01의 `꿀꺽` 줄에서 `sets: 물_마심`으로 세웠다. 전체 플레이는 이 줄을 반드시 지나므로 낮 손실이 면제된다. 이 사실을 무시하고 물을 안 마신 것으로 처리하면 원작의 기존 행동과 모순된다. 해당 실험용 sets와 낮 손실도 되돌렸다. 48차의 기존 `Line.sets` 계약과 b06 변경은 보존했다.

정책을 그대로 두고 세 손잡이의 수치·발동 범위를 모두 고정하면, 실측상 목표를 맞추지 못했다. 목표를 보존하려면 정책별 행동 선택 변경, 장면 손실을 한 위협당 한 번만 적용, 일부 hard 대가만 강화 등 허용 범위에 대한 상위 판단이 필요하다. 이 선택을 임의로 적용하지 않았다.
