## 원인과 수정

기존 해석은 감정 반응을 `idle`로 읽어도 사람이 곁에 있으면 `talk(shown: true)`로 다시 바꿨다. 그래서 위협을 진행시키는 `letSceneFlow`를 타지 않고 같은 자유 입력 자리에 남았다. 이 역변환을 제거했다.

입력 종류의 정의도 함께 고쳤다. 상대에게 실제로 건넨 말과 무언가를 해내려는 시도가 모두 없으면 감정·몸 반응은 idle이다. 말이 섞이면 건넨 말과 해당 접근법을 따른다. 문장의 어미만 보고 인용·서술된 말을 행동 판정으로 덮어쓰던 부분도 고쳤다. 감정 표현 낱말 목록은 추가하지 않았다. 규칙 경로에서도 기존 문장 문법 판독기 `readInput`을 재사용해 말·행동 정보를 전달한다.

첫 16건 실제 검증에서 “다리에 힘이 풀려 모래 위에 털썩 앉는다”가 b05·b06에서 판정으로 간 것을 확인했다(`gm_initial.jsonl`). `action` 정의의 “몸으로 하는 일은 action”과 보조 분류의 “무엇이 물리적으로 달라졌는가”가 idle 정의와 충돌했다. 모델은 입력에 없는 설득·회피 의도를 붙였다. 두 정의를 의도한 시도와 저절로 나온 변화의 구분으로 맞췄다. 보조 분류에서 위험 장면이라는 선입견을 없애고, 이어진 절의 앞 몸 상태가 뒤 움직임의 원인인 경우도 함께 보게 했다. 같은 문장을 외우게 하는 낱말 규칙은 넣지 않았다.

위협 비트는 idle 입력을 주사위 없이 받고, 검증된 남자 반응 한 줄→기존 위협 결과→다음 비트로 진행한다. 이미 이야기한 뒤 다음 입력도 접근·시도가 아니면 같은 방식으로 위협이 진행된다. idle의 고정 나레이션은 이미 본 줄이면 다시 내보내지 않는다. 모델 반응의 화자는 남자 하나이며 나레이션·여우 줄을 생성하지 않는다. 새 결말은 만들지 않았다.
