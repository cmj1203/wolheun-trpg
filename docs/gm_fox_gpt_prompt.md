# GM 여우 — GPT 그림 생성 지시 (GPT 주간 한도가 다시 차면 리드가 실행)

사용자: "gm 캐릭터는 지피티가 그리는걸로하자" (11-03). 코드로 그린 후보 A~D(candidates, candidates2)는 반려.

## 그릴 것
사용자 추가 지시: "gm 그릴때 이런식으로 그려 얼굴만 나오게" (11-03). 참고 그림: `docs/ref/gm_fox_style_ref.png`. GPT에 이 그림을 함께 넣는다. 이 지시가 아래 내용의 기준이다.

- 귀여운 사막여우(페넥여우) 마스코트, 게임 진행자(GM). **얼굴만** 그린다. 몸, 발, 꼬리는 없다.
- 참고 그림의 그림체를 따른다: 굵고 고른 검은 외곽선, 그림자 없는 한 색 채색, 말랑하게 둥근 형태, 살짝 삐뚤한 손그림 선.
- 얼굴은 검은 점 눈 두 개와 작은 타원형 코만 둔다. 볼터치와 장식은 없다. 색은 참고 그림의 연한 살구색 계열이다.
- 여우로 읽히게 하는 것은 귀다. 얼굴보다 크고 위로 선 큰 귀를 그리되, 끝은 둥글게 한다. 참고 그림의 처진 강아지 귀는 따르지 않는다.
- 배경 투명(또는 단색 흰 배경 → 우리가 따냄). 정사각형 1024px.

## 표정 4종 (같은 얼굴, 같은 크기)
1. 기본: 점 눈과 코만, 참고 그림과 같은 무표정
2. 웃음: 눈을 아치 모양 선으로 감는다
3. 생각 중: 한쪽 눈을 선으로 감고 고개 갸웃, 물음표 하나
4. 놀람: 점 눈을 조금 키우고 귀 쫑긋, 작은 O 입

먼저 기본 1장으로 생김새를 사용자에게 고르게 한 뒤, 같은 그림을 기준(참조)으로 나머지 3표정을 만든다.
