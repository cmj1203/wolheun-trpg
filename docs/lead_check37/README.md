## 원인

- 칼 장면처럼 보이던 그림은 `cg_earring` 이다. 원작 1화에 맞는 컷이 없어 c056(칼바람 속 공포 표정, 검은 속도선)을 바탕으로 만든 그림이었다(work/art/gpt/cg_opening/source_map.md 5번).
- 이 그림을 쓰던 두 줄 `남대륙은 적국 페시안의 땅. 크롬웰의 공녀라는 게 들키면 끝이다.`, `그래서 귀찌로 은발과 붉은 눈을 갈색으로 바꿨다.` 는 원작 1화 인트로(c001~c027)에 없는 줄이다. 원작은 c026 `남대륙으로 향하는 건 당연한 수순이었다.` 다음 바로 c027 `그렇게 남대륙의 크라차로 가기 위해 사막을 횡단하던 중이었다-` 로 간다. 그래서 맞는 원작 컷이 없다.
- 원작 인트로 회상(c015~c021)의 아시나는 모두 갈색 머리다. 은발은 c014 얼굴 가린 귀족 실루엣뿐이다.

## 바꾼 것

- `app/content/ep01_desert.yaml`: 언덕 두 줄 `cg_hill_silver` → `cg_hill`. 남대륙·귀찌 두 줄의 `cg`, `cg_from` 삭제. 쓰지 않게 된 CG 목록 항목 `cg_hill_silver`, `cg_earring`, `cg_earring_silver` 삭제. 대사 글은 그대로.
- `app/tests/engine.test.ts`: 여는 글 시험을 원작 순서 CG 4장(cg_cromwell, cg_manor, cg_hill, cg_travel)만 쓰고 cg_from 이 없으며 두 줄은 CG 없음으로 바꿈. cg_from 표 검사 시험의 예시 CG 를 cg_hill 로 바꿈.
- 그림 파일(cg_hill_silver.png, cg_earring_silver.png, cg_earring.png)은 지우지 않고 assets/ep01/gen/cg/ 에 남김. cg_from 전환 코드도 남김(대본에서만 안 씀).
- 새 그림은 만들지 않음.
