## 생성과 합성

생성은 Codex CLI만 썼으며 관심·위협 각각 1회다. stdin은 DEVNULL, 각 호출의 제한은 240초다. 실제 프롬프트 전체는 `prompt_intrigued_1.txt`, `prompt_menacing_1.txt`, 전체 명령과 종료 코드는 `run_*_1.json`, 응답은 `codex_*_1.log`에 있다. 두 로그 모두 프롬프트가 전달되었고 종료 코드 0으로 지정 PNG가 저장된 것을 확인했다.

```sh
uv run --with pillow --with numpy python work/demo-slice/lane59b/art_prepare.py
uv run --with pillow --with numpy python work/demo-slice/lane59b/art_scale.py
uv run --with pillow --with numpy python work/demo-slice/lane59b/art_generate.py intrigued 1
uv run --with pillow --with numpy python work/demo-slice/lane59b/art_generate.py menacing 1
uv run --with pillow --with numpy python work/demo-slice/lane59b/art_compose.py
uv run --with pillow --with numpy python work/demo-slice/lane59b/art_evidence.py
uv run --with pillow --with numpy python work/demo-slice/lane59b/art_verify.py
```

생성기의 명령은 `codex exec --skip-git-repo-check -s workspace-write -C <후보폴더> -i <기본얼굴6배> -i <원작1> -i <원작2> -i <그림체> -- "<프롬프트>"`다. 마지막 `-i`가 프롬프트를 삼키지 않게 `--`를 넣었다.

관심 프롬프트는 오른쪽 눈썹 약 3px 올리기, 양 눈을 세로로 조금 더 열기, 오른쪽 입꼬리만 2~3px 올리기다. 반쯤 감긴 냉소·벌어진 어이없음과 구분하도록 지시했다. 위협은 양 눈썹 안쪽을 약 3px 내리기, 미간 좁히기, 눈 가늘게 노려보기, 굳게 다문 입과 약간 내려간 입꼬리다. 턱 당김은 외곽선 이동 없이 입 아래 긴장과 작은 음영으로 제한했다. 얼굴 전체 음영·상징·땀·홍조는 금지했다.

원본 얼굴을 `[440,198,578,310]`으로 잘라 828×672로 확대했다. 생성본의 네 눈꼬리를 닮음 변환으로 정렬했으며 가중치는 바깥 1·안쪽 16이다. 좌표와 마스크 다각형은 `art_registration.json`에 있다. 눈별 독립 늘이기는 하지 않았다.

눈·눈썹·입과 위협의 작은 미간·턱 내부만 독립 다각형으로 합성했다. 기존 선과 새 선을 모두 포함시켜 중립 입이나 눈썹이 겹쳐 남지 않게 했다. 페더는 다각형 안쪽 0.65px다. 원본 윗변에 연결된 앞머리와 1px 가장자리를 제외하고 네 기준 눈꼬리 반경 2px는 원본 그대로 보존했다. 마스크는 `mask_<표정>.png`와 부위별 PNG다. 몸·귀·장신구·머리와 알파는 원본을 유지했다.

위협 생성본은 정렬 확대 후 축소 과정에서 왼쪽 눈 선명도가 중립의 65.8%까지 내려갔다. 정렬한 얼굴에 반경 0.6px·55%·임계 1의 약한 언샤프를 적용한 뒤 마스크 안에서만 합성해 94.2%로 복구했다. 관심은 별도 선명도 보정을 하지 않았다.

## 육안 판정

관심은 오른쪽 눈썹·눈 개방과 작은 비대칭 미소가 생겼다. 중립의 일자 입과 구별된다. 냉소와는 웃는 입만 보면 가깝지만 냉소의 낮은 양 눈꺼풀과 관심의 오른쪽 열린 눈·눈썹이 다르다. 이 둘과 중립의 차이는 어이없음보다 작으며, 그중 관심과 중립이 가장 가까운 쌍이다. 실배율에서도 관심의 미소가 읽혀 조건을 충족한다고 판단했다.

위협은 양 눈썹 안쪽 하강·미간과 굳게 내려간 입꼬리로 다른 네 표정과 구별된다. 관심과는 눈썹 방향과 입의 방향이 모두 반대라 게임 크기에서도 구별된다. 원작의 압박하는 시선·굳은 입을 따르되 원작의 넓은 얼굴 음영은 넣지 않았다. 턱 당김은 외곽 변화가 아니라 작은 내부 긴장만이며, 이것만으로 머리가 숙여졌다고 주장하지 않는다.

어이없음은 열린 눈과 벌어진 입, 냉소는 낮은 눈꺼풀과 비뚤어진 입으로 구별된다. 세 비교판과 원작 모음을 직접 확인했다.

## 검증 범위

두 원격 생성, 합성, 캡처 배율 측정, 비교판 제작과 픽셀 검증은 종료 코드 0이다. 검증기는 두 후보를 다시 열어 불변량·선명도·이미지 규격·호출 제한·로그의 프롬프트 전달을 확인하며 보조 Python 파일은 구문 컴파일한다. 기본 편집기 환경의 PIL/numpy 및 동적 경로의 이전 도구 import 진단은 남아 있다. 실행은 지정 uv 환경에서 정상이며 별도 정적 타입 검사는 하지 않았다.

후보 제작 범위이므로 앱 시험·설치·로컬 서버·커밋·crq는 실행하지 않았다.
