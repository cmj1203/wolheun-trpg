# 19-H 돌아보기(리플레이) — 2026-11-04

원안: apply_plan ⑬ "판이 끝나면 선택·주사위 눈·대가 리플레이".

## 바뀐 것
- 엔진: 대가를 플레이 기록(`log`)에 `kind: 'price'` 로 남긴다. 판정 대가(`finishResolve`)와 세계 무브로 쓴 대가(`sayPrice`, 압박·시간) 두 곳이다.
- 요약: `summarize()` 가 `replay` 를 만든다. 선택·자유 입력 → 판정 → 대가가 일어난 순서대로 들어간다. 여우에게 물은 말(질문 모드)은 빠진다. `decisions`·`checks` 는 e2e가 쓰므로 그대로 둔다.
- 결과 화면: '판정 기록' 표와 '선택과 입력' 목록을 '돌아보기' 목록 하나로 합쳤다. 장면이 바뀔 때마다 장면 이름 한 줄이 들어간다. 판정 줄은 주사위 두 눈을 따로 보여 준다(`주사위 4·4 + 수치 0 = 8 / 목표 10`).
- 손대지 않은 것: 새 사건 글 8건, 긴장 칩, 장면 검사 줄(사용자 답 전). 장면 검사(twist)는 돌아보기에 넣지 않았다.
