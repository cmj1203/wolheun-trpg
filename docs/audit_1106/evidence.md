# 문제별 실제 엔진 출력

`E`는 b00에서 시작한 실제 시드 경로, `B`는 그 경로에서 얻은 상태를 복제한 뒤 다음 RNG만 바꾼 경계 검증, `D`는 실제 도달한 fixture에 직접 입력한 사례다. B는 게임 시작 시드 재현이라고 주장하지 않는다. `resume-ending`은 실제 결말의 플래그·소지품·수치를 결말 상태에 넣어 `resume()`의 조건 처리만 검사한 API 검증이다. 원작 컷 비교는 flow_audit.md를 본다.
