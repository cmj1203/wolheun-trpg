# 50차: 베히다트 눈 간격 후보 — 반려 수정 2차

후보: `work/demo-slice/lane50/behidat_{neutral,smile,surprised,wary}.png`.
설치·커밋·게임 화면 촬영은 하지 않았다. assets 및 서버·저장·로그·피드백은 변경하지 않았다.

## 방법

이번 수정에서 `generate_image`를 한 번 호출했으나 provider native 안내만 반환했다.
이미지가 없어 재시도 없이 허용된 픽셀 이동 방식으로 만들었다. 로컬 생성 모델은 쓰지 않았다.
neutral은 7px, smile은 4px, surprised·wary는 2px 화면 왼쪽 눈을 콧대 쪽으로 옮겼다.
세로 이동·크기 조절·오른쪽 눈 편집은 없다.
현재 입식의 눈·눈꺼풀 픽셀을 복사하고, 가려졌던 부분만 같은 행의 인접 눈 픽셀을 보간해 늘렸다.
첫 후보는 y=249 공여 행의 머리카락 끝까지 늘렸고, 색 마스크가 눈의 흰 부분까지 앞머리로 잡았다.
이번에는 (495,253)-(501,258)의 피부 전용 6×5 패치만 늘린다.
공여 픽셀 전체가 R-G>55, G-B>10인지 실행 때 검사해 머리카락이 들어가지 않게 했다.
앞머리는 표정마다 실제 가닥 경로를 따로 추적한 원본 레이어를 제자리에 다시 얹는다.
wary는 눈꺼풀 경계를 좁혀 위의 넓은 앞머리·눈썹이 이동 영역에 들어가지 않게 했다.
새 선이나 색을 그리지 않았다. 눈 경계 페더 0.65px, 앞머리 경계 페더 0.45px.
완전한 앞머리 코어는 원본과 동일하며 반투명 경계는 원본 색을 섞는다.

`correct_eyes.py`, `measure_eyes.py`, `render_review.py`로 재현한다.
`source_eye_*.png`는 이동 전 눈 범위, `hair_*.png`는 제자리 앞머리 가중치,
`foreground_original_*.png`는 원본 픽셀 앞머리 레이어, `mask_*.png`는 변경 허용 마스크다.

## 측정

원본 해상도에서 눈꺼풀 날개를 제외한 **보이는 눈 틈의 양 끝**을 수동으로 찍고 x축 투영 길이를 쟀다.
가닥에 가린 끝은 인접 눈꺼풀의 연장으로 추정했다. 세로 차이와 원근을 보정하지 않았다.
`work/style/style_rules.md`를 읽었다. D=안쪽 끝 사이 간격, E=두 눈 너비의 평균.
정면 기준 D/E=0.9~1.1이며 콧대 좌우 거리 차/E는 10% 이하여야 한다.
콧대에는 단일 세로 선이 없어 이마 중앙과 코 중심을 잇는 추정 축을 사용했다.
축은 1차 측정값을 그대로 유지했다. 스프라이트 좌표 오차 약 ±2px·원작 약 ±10px다.
표의 같은 너비는 수평 평행이동의 결과이며 독립적인 자동 검출 결과가 아니다.
정확한 자동 해부학 측정이나 완전 대칭을 입증하는 수치로 쓰면 안 된다.
`landmarks.json`에 선택한 좌표, `landmarks.jpg`에 초록 눈 끝·파랑 콧대 축을 남겼다.

## 검증과 육안 판단

`verification.json`: 네 파일 모두 1024×1536 RGBA 유지.
마스크 밖 최대 채널 차이 0, 알파 차이 0, 오른쪽 눈 영역 차이 0,
앞머리 코어 차이 0. 가닥에 가리지 않은 눈의 복사 대응 픽셀 차이도 0.

`faces_compare.jpg`: 네 행 × ‘41차 전 | 지금 | 고친 뒤 | 원작’.
입식은 모두 (352,90)-(672,370)으로 같은 크기·위치에서 잘랐다.
원작은 위 두 행 c046, 아래 두 행 c036이며 원근·표정이 달라 비율 참고로만 쓴다.

`zoom_compare_r2.jpg`는 네 표정의 원본 160×90 얼굴 영역을 정확히 3배 확대했다.
41차 전 | 지금 | 고친 뒤 순서다. 직접 확인한 범위에서 첫 반려의 새 뺨 사선 잔상,
가닥의 끊김·번짐, 눈 둘레의 새 흰 잔줄은 보이지 않았다.
원래 가려졌던 눈은 인접 픽셀 보간이므로 그 부분의 원래 모양은 여전히 알 수 없다.

`game_scale_compare.jpg`는 1440×810 비교판이며 라이브 게임 캡처가 아니다.
기존 `docs/lead_check41/game/game_behidat_neutral_1440.png`의 변하지 않은 터번 장식을
템플릿 매칭해 얻은 0.67배로 얼굴을 줄였고, 다시 확대하지 않았다.
원본 화면 크기·매칭 위치·오차는 `game_scale.json`에 있다.
이 배율에서 눈 이동은 neutral 4.69px, smile 2.68px, surprised·wary 1.34px다.
직접 보면 neutral은 코 쪽으로 모인 차이가 보이고 smile은 미세하다.
surprised·wary는 나란히 놓아도 차이가 작다. 숫자 통과만으로 사용자 체감이 해결됐다고 단정하지 않는다.

스크립트 실행과 구문 검사는 성공했다. 편집기 LSP는 Pillow·NumPy를 못 찾지만
지정한 uv 환경에서 두 패키지를 실제로 불러오고 전체 처리를 완료했다.
