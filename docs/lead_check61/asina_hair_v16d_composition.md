# 아시나 v16c 합성 선택 재검토

2026-11-09. **원본 알파 보존은 제품 요구가 아니라 보호 구현 선택이었다. 이 선택과 갈색 교집합 제한이 제거 대상 잔머리를 남겼다. v16c를 머리 정리 완료본이나 최종 QA 후보로 확정하면 안 된다.**

기존 결과와 명세는 수정하지 않았다. 이 문서는 앞선 복구 보고의 디자인 판단을 보완한다. 독립 Claude 미술 QA는 계속 계정 차단으로 대기하며, 아래 결과는 GPT 담당자의 자체 조사·부분 대안이다.

얼굴 옆 확대판에서 원본의 분리된 분홍·초록 가장자리 가닥은 네이티브에서 정리됐지만 v16c에는 남았다. 바깥 긴 머리도 네이티브는 연속된 묶음인데 v16c는 원래 가는 S자 윤곽을 유지하고 부분적으로 다른 음영만 섞였다. 후드의 옷 위 머리도 교집합으로 걸러진 구간에서 원래 모양이 남았다.

수치 기준은 원본 alpha≥32, 네이티브 alpha≤8이다. 일반 8종에서 네이티브가 없앤 1,169~1,738화소를 v16c가 모두 원래 알파로 유지했다. 따라서 RGB만 바꾸거나 양쪽 모두 갈색인 화소만 고르면 이 제거를 구현할 수 없다. 이 수치 전체를 불필요한 잔머리라고 단정하지는 않는다. 실제 분리 가닥은 확대판으로 확인했고, 수치는 합성 선택이 원래 실루엣을 되살리는 작동을 증명한다.

후드의 같은 알파 차이는 4~46화소뿐이며 대부분 후드·옷 경계에 있다. 후드의 주된 문제는 불투명한 옷 위 머리의 RGB·모양 변화다. 그 소수의 알파 차이만으로 제거해야 할 외곽 잔머리라고 판단하지 않았다.

## v16d 대안 범위

**일반 8종만 외곽 머리 합성 대안을 만들었다. 전체 머리 정리 완료본이 아니다. 후드 8종은 만들지 않았다.**

원본에서 시작해 기존 선택 네이티브의 RGBA를 명시적 기하 ROI 안에 적용했다. 원본/생성본 갈색 교집합을 적용하지 않는다. 가까운 색으로 덮거나 눈·얼굴을 이식하지 않았다. 원본과 네이티브가 모두 alpha≥250인 곳은 원본 불투명 알파를 유지하고, 외곽에서만 네이티브 알파를 받아들인다. ROI 경계의 8px 페더는 안쪽으로만 적용했다.

ROI는 머리 상자 `[280,235,725,935]`에서 아래 영역을 뺀 것이다.

- 얼굴 보호 상자 `[451,350,558,465]`
- 귀찌 중심 `(462.5,413)`, `(544.5,412.5)` 각각 반경 10px
- 목·옷·가방·손·몸을 보수적으로 덮는 다각형:
  `[(425,465),(590,465),(620,500),(642,570),(660,700),(675,840),(685,950),(310,950),(325,840),(337,700),(350,600),(365,530),(395,485)]`

이 다각형은 옷 위의 머리 일부까지 보호한다. 옷을 보존하려고 남긴 부분을 새 머리로 채우거나 원본 옷 화소를 생성본 옷으로 교체하지 않았다. 상자 밖의 몸 전체도 원본 그대로다. 이 ROI는 **외곽으로 확장한 별도 마스크이며 v16c 마스크 전체의 상위집합이 아니다.**

각 파일에 정확한 이진 ROI, 페더 가중치, 실제 RGBA 차이, 실제 알파 차이 마스크를 따로 저장했다. 같은 기하 ROI를 쓰더라도 후보별 파일 경로와 SHA-256을 명세에 적었다.

## 보존 검사와 남은 결함

- ROI 밖 RGBA 변경 0
- 얼굴·귀찌 보호 영역 RGBA 변경 0
- 목·몸·옷·손·가방 보호 다각형 안 RGBA 변경 0
- 저장된 PNG와 실제 변경/알파 변경 마스크 불일치 0
- 후보 및 마스크의 SHA-256 일치

두 새 스크립트는 기존 Bun/Node 타입 정의를 지정한 `tsc --strict --noEmit`에서 통과했고, 합성 및 저장 PNG 검증도 exit 0이다. 원본 18장, 네이티브 결과 19장, v16c 후보·마스크 48개, 기존 명세 7개, 대표 r3 2장으로 총 94개 파일의 전후 해시가 같다. 원본/네이티브 해시는 이전 inventory/생성 기록과도 같다. 한글 경로는 NFC/NFD 정규화 후 대응시켰다.

`v16d/comparison_original_native_v16c_v16d.png`를 직접 보았다. 2×4칸이며 각 칸은 원본 / 네이티브 / v16c / v16d 순서다. v16d의 허용 외곽에서는 네이티브가 지운 가닥이 사라지지만, 옷과 얼굴을 보호한 경계에는 원래 가는 물결·색 가장자리가 남는다. 예를 들어 neutral `(595,467)`의 알파는 원본 47, 네이티브 4, v16d 36이다. 몸 보호 경계 쪽 페더 때문에 완전히 지워지지 않았다.

따라서 **v16d 역시 전체 정리 완료본으로 채택하지 않는다.** 기존 생성본은 외곽 수리의 유효한 부분 대안을 제공하지만, 얼굴·옷 주변을 포함한 전체 머리의 충실한 수리는 이번 결과로 입증하지 못했다. 독립 Claude 승인이나 실제 앱 표시 검증을 새로 주장하지 않는다.
