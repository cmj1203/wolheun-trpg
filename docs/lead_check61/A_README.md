## 원인과 방식

R1에서 모든 표정에 가는 아몬드 눈을 지시하고 공통 눈 폭으로 맞춘 것이 잘못이었다.
어이없음·놀람의 열린 눈 의미를 잃었고, 눈별 변형과 좁은 마스크가 주변 음영을 끊었다.

이번에는 각 생성에 다음 실제 이미지 4개를 `codex exec -i`로 첨부했다.

1. 원작 전체 컷 c046 또는 c057.
2. 같은 원작의 얼굴 확대.
3. **해당 표정 자체의 원본 전체 입식 또는 CG**.
4. 같은 표정 원본에서 자른 정사각 얼굴 확대.

각 얼굴을 GPT가 한 장으로 편집했다. 다른 표정의 눈을 복사하지 않았고, 눈별 가로 변형도 하지 않았다.
생성된 자기 얼굴 한 장을 동일 배율로 축소하고, 눈·콧등·인접 볼을 이어 주는 하나의 부드러운
얼굴 마스크로 합성했다. 두 눈과 코를 각각 붙이는 R1 방식은 사용하지 않았다.
입·얼굴 바깥·장신구·몸을 생성물 전체로 교체하지 않았다.

로컬 처리는 원본 크롭 준비, 균일 축소, 보존 마스크 합성, 검증·비교판 제작이다.
이를 그림 생성이라고 부르지 않는다. 실제 생성 PNG의 원본 경로는
`A_revision2_verification.json`의 `generation_runs[].native_sources`에 있다.

Codex 이미지 생성은 이번 7회 모두 저장 성공·종료 코드 0이다.
6종을 각각 생성한 뒤 CG만 동일 얼굴에서 오른눈 위치를 조금 더 조정했다.
원래 눈 높이·홍채·얇은 윗선을 유지한 채 GPT가 간격을 바꿨으며 로컬 눈 이동은 하지 않았다.
정확한 실행 배열·로그·PID·PGID는 `work/demo-slice/lane61/art/revision2/generated/`에 있다.
성공 실행법은 `work/demo-slice/lane61/art/CODEX_SUCCESS61.md`에 별도로 기록했다.

## 눈 간격과 열린 눈 검증

50차와 같은 눈 개구부 끝의 x축 투영이다. 아이라인 날개는 제외한다.
앞머리에 가린 끝은 눈꺼풀 연장으로 추정했으며 좌표 오차는 약 ±1~2px다.
이번 수치는 출력에서 읽은 값이다. 서로 다른 표정을 공통 눈 폭으로 강제하거나
측정값을 모두 1.067로 덮어쓰지 않았다.

| surprised | c046: 1.021 | 0.906 | 1.040 | 475·500 / 526·551 |
| intrigued | c046: 1.021 | 0.979 | 1.021 | 480·502 / 526·551 |

모두 50차의 0.9~1.1 범위 안에 있다. 정확히 1.067이라고 주장하지 않는다.
PASS 3종은 R1의 간격·모양 그대로이며 이번에 다시 측정하거나 바꾸지 않았다.
