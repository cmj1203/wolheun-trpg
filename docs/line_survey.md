# 원작 대사 전수 조사 (입력과 맞는지)

자유 입력 장면 9곳에서 판정 뒤에 나오는 대사와, 그 뒤 장면의 고정 대사를 셋으로 나눴다.
- a: 어떤 입력에도 맞는다. 그대로 둔다.
- b: 플레이어의 특정 말·주장·몸짓을 전제로 한다. 그 입력일 때만 나오게 조건을 걸거나, 직접 입력한 판에서는 빼고 중립 줄로 바꾼다.
- c: 플레이어 대신 하는 말이다. 직접 입력한 판에서는 GM 에 '뜻과 말투의 기준'으로만 넘기고, GM 이 실제 입력에 맞게 다시 쓴다(검사 그대로). GM 이 실패하면 쓰지 않는다.

버튼으로 행동을 고른 판은 그 버튼 문장이 곧 행동이라 판정 대사를 그대로 쓴다. 판정 대사 전체(210줄)는 직접 입력한 판에서 GM 에 원작 기준으로 넘어간다.

집계: a 146줄, b 18줄, c 46줄.
