# 34차 메모

## 5번: 앞서 고치려던 분기가 다른 입력을 망친 원인

되돌린 분기는 같은 장면 프롬프트(접근법 목록 포함)를 그대로 둔 채 `action` 을 고를 수 있게 남겨 다시 물었다.
- '불러오기 하면 지금까지 한 거 사라져?' 는 다시 물어도 '그대로 살핀다' 접근법으로 읽혔다.
- `person` 을 허용해 '저 사람들한테 가 볼까?' 가 판정 없는 물음으로 바뀌었다(docs/lead_check30/idle_model.md 79행).

이번 분기는 물음표 문장을 장면 없이 먼저 묻는다(`ASK_SYSTEM`). 스스로 할 일을 정하는 말이면 행동으로 두고, 아니면 `action`·`idle` 을 뺀 종류로 다시 읽는다.
