## 입력 종류를 나눈 방법

- 동작마다 '하고 나면 무엇이 달라지는가'를 묻는다. 달라지는 동작이 없으면 시도가 아니다.
- '닥친 일을 받아들임'을 종류로 새로 나눴다. 체념·항복이 기타 칸이나 물건 칸으로 새지 않는다.
- 하지 않는다고 적은 동작('반항하지 않고')은 세지 않는다.
- 물음표 문장은 장면 없이 먼저 묻는다. 스스로 할 일을 정하는 말만 행동이다.

## 단어로 처리한 것 하나

'칼을 받아들인다'는 규칙 문구를 세 가지로 바꾸고 문장 전체를 함께 줘도 모델이 칼을 쥐는 동작으로 읽었다(`change_v8.jsonl`). 그래서 `isRefusedClause` 에 '받아들' 꼴 하나를 넣었다. 이 꼴 말고 단어 목록은 늘리지 않았다.

코드레빗 지적으로 '모델과 대본 낱말이 같은 접근법을 고른 입력은 변화 분류를 건너뛴다'를 더했다. 단, 하지 않는다고 적은 문장은 건너뛰지 않는다.
