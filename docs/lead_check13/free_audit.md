# 18차 자유 입력 감사표 (11-04, 열셋째 세션)

규칙(docs/spec.md 판정 절에 추가): 자유 입력은 상대 인물이나 사건이 플레이어에게 답을 요구하는 자리에만 둔다. 혼자 있는 서술 장면은 입력 없이 흐른다. prompt 는 그 장면이 실제로 묻는 것을 적는다.

## 2. b01_sand 에 걸려 있던 것이 어디로 갔나
