## 손상

`harm: 몸/마음`은 손상 태그다. 기존 `tag: 시간/상대행동/자리/수치/소지품`은 그대로 유지한다. 이를 바꾸면 기존 세계 무브가 시간·압박 대가를 찾지 못하므로 별도 속성으로 표시했다. 7~9는 soft 하나, 실패는 기존 선택 규칙에 따라 hard 우선 또는 실패 결과를 쓴다.

## 낮은 상태와 0

| 상태 | 판정·경로 |
|---|---|
| 체력 ≤1 | 근력 판정에 `지친 몸 -1`. 다른 능력에는 적용하지 않는다. |
| 정신력 ≤1 | 매력·재치 판정에 `흔들리는 마음 -1`. |
| 정신력이 처음 0에 닿음 | 다음 판정 한 번에 `흔들리는 마음 -2`. 해당 판정의 정신력 -1을 대체하며 중첩하지 않는다. 근력의 지친 몸과는 합산한다. |
| 정신력 0 유지 | 다음 충격이 소비된 뒤에도 매력·재치 -1과 행운 사용 금지는 유지된다. |
| 정신력 회복 | 0을 벗어나면 행운을 다시 사용할 수 있다. 이미 받은 다음 판정 충격은 한 번 소비될 때까지 남는다. |
| 체력 0 도달 | 즉시 종료하지 않는다. |
| 체력 0에서 다시 손상 | `체력_쓰러짐` → `sheet.collapse_to: e_spy` → 기존 결말 `spy`. 가방 상실·밧줄·정신을 잃는 기존 줄을 그대로 쓴다. 새 결말·새 징조는 없다. |

## 300시드 균형

변경 전에 현재 작업 트리로 측정했다. `git show HEAD`나 stash를 사용하지 않았다. `work/demo-slice/lane45/balance.ts`는 기존 `search_fates19g.ts`의 시드 1~300, 같은 Mulberry 난수, 기본 접근/무작위 접근·선택지, 최대 60턴, 행운 거절 정책을 사용한다. 상태 로그의 중간 0도 집계하므로 뒤에서 회복한 판을 놓치지 않는다.

|---|---|---|
| 보통 | 상태 없음 → 1/300 (0.33%) | 상태 없음 → 1/300 (0.33%) |
| 무작위 | 상태 없음 → 2/300 (0.67%) | 상태 없음 → 0/300 (0%) |
